# Player 07 — 동쪽 능선 탐험

seed 191907, repair 짐. 공개 라벨로 동쪽 능선길을 선택했고 선택 시점의 기존 coverage가 가장 낮은 활성 선택을 우선했다. 동률만 기존 탐험가 정책으로 정했다. 결과/효과를 미리 읽거나 자원·동료·플래그를 주입하지 않았다.

실제 소스 엔진을 독립 Node VM 저장소에서 실행했다. 실제 화면에서 누른 브라우저 플레이나 사람 플레이가 아니다. 현재 사용자 타이틀/저장과 생산 코드는 건드리지 않았다.

## 오독·중복에서 제외

대구 하 여사의 경비 회상은 이미 첫 물결 검토 대상이라 신규 계수하지 않았다. 아웃도어 매장의 고철 지불은 실제 -2로 맞는다. 수원 직전 연료 위기는 정착지가 아닌 도로에서 발생했고 선택의 600분 비용도 실제 지불됐다. 마지막 새벽/귀환은 구분된 에필로그이므로 현재 시계 불변만 보고 순간 이동으로 세지 않았다. 격리 수면 선택률은 봇 정책의 결과이며 밸런스 판단 자료가 아니다.

전체 진입·선택·결과와 일반 행동 전후를 읽었다. 새 고확신 치명 진행 버그는 없었고 재시도는 하지 않았다. 숨은 RNG 경로, 화면 배치, 음성, 실제 입력·애니메이션은 검증 범위 밖이다.
