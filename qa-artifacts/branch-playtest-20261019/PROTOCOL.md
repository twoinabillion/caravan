# 선택 분기 확장 플레이 — 2026-10-19

이전 감사에서 덜 누른 선택을 우선하는 테스트다. 실제 소스 엔진을 새 seed와
독립 메모리 저장소에서 실행한다. 브라우저 클릭·사람 플레이·화면/음성 검수가 아니다.
기존 기록은 덮어쓰지 않고 baseline으로만 읽는다. 현재 사용자 타이틀/저장은 건드리지 않는다.

- 각 담당자는 playerNN/만 작성하고 생산 코드·공용 실행기 수정은 하지 않는다.
- 실행 전에 선택 성향/새로 누를 분기를 정한다. 선택은 공개 본문·라벨·조건만 이용한다.
- 과거 coverage 수는 시험 선택 우선순위에만 사용한다. 미래 효과/결과를 보고 고르지 않는다.
- 자원/동료/플래그/확률을 주입하지 않는다. 실패와 정책 막힘도 원본을 남긴다.
- 새 선택 뒤 다음 사건·자원·시각·장소·동료·목표를 읽고 가능하면 엔딩까지 간다.
- 재접속은 유료 결과 중복 차감/현재 상태와 이후 RNG 경로를 구분한다.
- 문제는 eventId, trace n, 진입/선택/결과 원문, 실제 전후 상태, 기대/실제, 영향,
  확신도, 도구 한계를 findings.json과 report.md에 남긴다. 후보를 즉시 고치지 않는다.
- 문구가 이상하다는 이유만으로 버그로 세지 않는다. 기존 paid 기록과 현재 소스도 구분한다.
- 본편 완주, 실패 결말, 정책 제한 종료, 도구 오류를 구별해 보고한다.

주 디렉터가 중복·실행기 오독·의견을 걸러 확인된 문제만 회귀 검사와 함께 묶어 고친다.
