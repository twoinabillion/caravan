## 보류한 제보와 남은 검수

- `story_family_key`의 ‘복원한 영상’은 진입에서 이미 살아난 영상 조각을 뜻할 수 있다. 선택하지 않은 말끝 복원 완료라고 단정하지 않았다.
- `relay` 목표의 raw act5→4는 낮은 우선순위의 메타데이터 후보로 보존했다. 현재 공책의 활동 중 표제는 날짜로 바뀐다. 실제 사용자가 잘못된 장 번호를 봤다는 검수는 없다.
- 캠프 손님/새벽 탐조등이 기상 뒤 열리는 것은 야영 비용 선처리/밤 회고의 기존 계약과 분리해야 한다. 별도 표시·실제 밤/아침 전환을 못 본 상태에서 추가 시간 비용이나 새 게이트를 넣지 않았다.
- 이음망을 만나기 전 다른 거점이 차 소문을 들었다는 문구는 NPC의 화면 밖 연락일 수 있다. 없는 물건/만남을 발명한 확정 버그로 세지 않았다.
- 기존 저장→로드는 이후 RNG 경로를 다시 시드한다. 이번 검사는 현재 관측 상태와 중복 지급을 확인하며 숨은 난수/타이머의 완전 동일성을 주장하지 않는다.
