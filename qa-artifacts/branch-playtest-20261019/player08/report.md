## 새 확인 문제 1개

`comp_kw_stop`, n207: 수원 마을에서 자고 일어난 즉시 주행 장면이 나온다. n204 실제 도착 → n205 연료 거래 → n206 마을 숙박 → n207 “세워/그냥 가죠” → n209 같은 시장 거래다. 이 사이 출발 행동은 없다. `driving:null`, km485, DAY8 06:30이 유지된다.

그런데 무장 트럭과 언덕에서 마주쳐 논길로 도피했다고 하고, 연료36.4836→32.4836 / 차체93.9700→85.9700이 실제로 차감된다. 기상 행동에 운전 위험이 붙는 맥락 버그다. `G.camp` 종료가 동행 풀 전체에서 `G.fireDriveEvent2`를 호출하는 코드와 일치한다. P1 / 높은 확신. 전체 동행 장면을 삭제하지 말고 주행 전용/정차 가능 맥락을 나누어야 한다는 검토 의견만 남겼고 수정하지 않았다.

## 중복 및 판정 제외

논산 강우 장면 n147의 무료5분, 남산 장치 확인 n249의 비전원 간섭은 첫 파동에서 이미 확인한 문제와 중복이다. 새 수로 세지 않았다. 엔딩 이동은 에필로그이며, 정책 이름 길이 검증은 정상 동작이다. 호송 정찰 뒤 천막 행동도 다음 장면에 실제로 서술되어 있으므로 누락 선택 모순으로 세지 않았다.

75개 선택의 진입·선택·결과와 실제 바로 전후 상태를 전부 읽었다. 미선택 결과, 다른 seed, 시각·음성·입력·애니메이션 동작은 확인하지 않았다.
