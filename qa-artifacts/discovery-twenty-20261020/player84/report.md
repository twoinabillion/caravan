# 게이머84 — 갈등 중재자

첫 자연 시도에서 본편을 끝냈다. `storyDone=true`, `ending=story_done`, 방법은 `core_sleep`이다. n270 결과에 `〔 서울까지 400km · SESSION 1 END 〕`가 있고, 결과 재개 뒤 실제 엔딩으로 종료됐다. 6일차 14:14, 누적 571km, 선택 61번이다. 실패 시도와 추가 자연 재실행은 없다.

부산 → 김해 → 진주 → 남원 → 전주 → 논산 → 대전 → 청주 → 천안 → 평택 → 천안 → 청주 → 천안 → 평택 → 수원 → 서울로 갔다. 배정 지역 논산(n86, 3일차 10:51), 대전(n99, 3일차 16:56), 평택(n134, 4일차 16:52)을 모두 방문했다. 지역 방문을 끝낸 뒤에는 공개 메인 목표를 따라 빠진 기록을 찾았다.

확정한 중대 버그는 없다. 낮은 우선순위의 명료성 문제 하나를 남겼다.

- **P84-C01 · 폐병원 약국 결과의 식량 설명 누락** — n92, 3일차 12:51–13:36 논산. `위칸을 뒤진다`를 고르자 “진통제, 항생제, 소독약을 챙겼다”는 결과와 함께 의약품1·식량1이 늘었다. 식량은 9→10이고 칩도 `식량 +1`이므로 재고 처리와 칩은 맞는다. 추가 식량을 찾았다는 문장이 없는 작은 설명 누락이다. 당시 정식 동료는 없고 박 선생의 구미행 임시 부탁만 진행 중이었다. 물10·고철36·연료 약34.965L는 그대로였고 n93 재개 후 n94 대전 출발이 가능했다. 모든 자연 시도 종료 뒤 선택된 결과의 `src/03-data.js:9197`을 확인했다. 브라우저 표시 버그나 “약품이 음식으로 계산된다”는 주장은 아니다.

중재 성향으로 좋았던 대목은 n173의 증언 사본이었다. “이 사본을 남산에 가져가도 될까요?”라고 묻고, 세 사람이 자기 표현과 날짜를 고친 뒤 서명한다. 5일차 11:58 청주에서 식량7·물8을 가진 상태였고, 다음으로 천안에 갈 수 있었다. n222의 거점 회의도 “오늘 받은 것은 그 일을 맡겠다는 수락”이라고 선을 그어, 미래 합의까지 끝낸 것처럼 말하지 않았다. 마지막에는 남산행 편지가 미배달 상태라는 점도 분명히 남았다.

정책의 한계는 따로 기록했다. n74에서 박 선생의 약품 운송을 받았지만 공개된 구미행 모집 목표를 경로 우선순위에 넣지 않아 완수하지 않았다. 게임의 모집 결함이 아니라 정책의 누락이다. 문구 가중도 완전한 의미 판단은 아니다. `함께`가 들어간 복사 선택을 허락을 구하는 선택보다 높게 매겼고, 낮은 양수 가중의 몸싸움 선택도 한 번 뽑혔다. 이 결과를 보고 다시 고르지 않았다.

정책은 게임과 별개인 xorshift32를 썼다. 다중 선택43회 중 균등 분기15회, 성향 가중28회이며, 분기 확률 자체는 매번 25%/75%다. 모든 대안 가중치는 양수다. 원 실행의 카운터와 종료 후 정책만 재생해 61개 선택이 모두 일치한 증거를 `policy-evidence.json`에 보존했다. 실현 비율을 맞추는 재시도는 하지 않았다.

전편은 n1–271의 모든 행과 61개 선택을 시간순으로 읽었다. `compact-review.cjs`가 도입·노출 선택지·요구량·결과·전후 시각/위치/동료/재고·메시지·다음 행동을 함께 보여 준다. 잘린 출력은 해당 범위를 다시 읽었다. 범위별 검토 메모는 `review-notes.md`에 있다. 61번의 선택 전 reload와 61번의 결과 reload는 모두 성공했고, 이미 지불한 효과를 다시 적용한 경우는 없었다.

모든 15번 출발은 실제 UI 예보의 허가 조건을 만족했다. 수원에 연료0.744L로 도착했을 때는 밤에 야영한 뒤 아침 시장에서 정상 구매했다. `연료 구하기`는 공개 관측에 있었지만 쓰지 않았다. 강제 자원 지급이나 실제 사용자 저장·탭·Studio·서버 조작은 없었다.

이 결과는 실제 현재 소스를 격리 VM에서 실행한 엔진 감사다. 화면·입력·그림·음성 검증은 포함하지 않는다. 후일담의 밤/새벽이나 수원 재방문을 현재 시계와 바로 대조해 오류로 세지 않았고, raw 목표 데이터를 실제 공책 UI로 단정하지 않았다. 사후 소스 확인은 약국에서 실제 본 후보에 한정했으며, 그 출력에 노출된 인접 미관측 대안은 다음 자연 플레이에 쓰지 않았다.
