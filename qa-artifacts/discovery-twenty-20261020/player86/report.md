# player86 · 역사 순례자

첫 시도에서 경주·남원·공주를 거쳐 `SESSION 1 END`까지 마쳤다. 6일, 611km, 선택 64회다. 최종 방식은 집행권 인계(`core_transfer`). 진행을 막는 확정 버그는 없었다. 설명 문제 1건과 서사 표현 후보 1건을 아래에 남긴다.

부산 → 양산 → 울산 → 경주 → 대구 → 밀양 → 합천 → 거창 → 남원 → 전주 → 논산 → 공주 → 세종 → 청주 → 천안 → 평택 → 수원 → 서울. 경주는 DAY2 09:24(n59), 남원은 DAY4 09:54(n122), 공주는 DAY5 12:11(n159)에 도착했다. 원본 실행은 `attempt01/`에 보존했고 추가 시도는 하지 않았다.

## 확인한 설명 문제

**P86-C01 · 우체국에서 편지를 찾으려면 편지가 먼저 필요하다.** DAY5 08:30 논산의 우체국(n152)에서 “남산 방향 편지가 있나 찾는다”가 보였지만, “남산행 편지 1개 필요” 조건으로 비활성화됐다. 혼자 여행 중이었고 편지는 없었다. 당시 연료44.37L·물15·식량9·고철63·부품9였다. 다른 선택인 소포 열기는 가능했다. 이를 골라40분 뒤 식량14·부품10이 됐고, 다음에는 공주로 출발했다(n154).

완주 후 소스를 확인하니 이 분기는 이미 맡은 편지와 같은 동네의 우편을 더 챙기는 내용이었다(`src/03-data.js:10653`). 조건을 잘못 붙였다고 단정할 근거는 없다. 다만 선택 이름만으로는 그 전제를 알기 어렵다. “맡은 편지와 같은 행선지의 우편을 더 찾는다” 정도로 읽히면 조건을 이해할 수 있다. 기능 차단이나 편지 획득 불가 버그로 세지 않았다. 우체국의 미선택 결과는 이 사후 확인에서 처음 읽었다.

## 서사 표현 후보

**P86-N01 · 혼자인데 산지기가 여러 여행자의 얼굴을 살핀다.** DAY3 20:05 거창에서 만난 산지기(n111)가 “달구지와 우리 얼굴을 번갈아 봤다”, “우리를 능선 위 은거지로 안내했다”고 서술됐다. `party=[]`였으며 결과를 새로 불러온 n112에서도 같았다. 연료40.02L·물17·식량9·고철51·부품8 상태에서 식량3을 받았고, 다음에는 야영했다(n113).

현장의 산지기들은 바라보고 안내하는 쪽이라 “우리 얼굴”에 포함시키기는 어색하다. 완주 뒤 동일한 고정 결과를 확인했다(`src/03-data.js:8813`). 다만 한국어의 포괄적인 “우리”로 읽을 여지가 있어 후보로 남긴다. 이름 있는 부재 동료나 실제 화면의 화자 오류를 확인한 것은 아니다.

## 역사 순례자로서 남은 장면

세 장의 이송표에서 노인이 이름을 다시 읽어 달라고 하는 장면(n120), 세 당사자가 자기 문장을 고친 뒤 서명하는 장면(n196), 담당자와 원본의 마지막 숫자까지 대조하는 장면(n206)이 좋았다. 아빠의 마지막17분도 시간순 기록으로 옮겼다(n219). 기억, 증언 사본, 명령 원본의 출처가 각각 드러났다.

경주에서는 왕릉 소풍(n61)이 장소를 남겼다. 이번 남원의 선택은 일반 방송국 테이프(n125), 공주는 폐주유소의 매점 물자(n162)였다. 두 곳에서 유적이나 전승을 더 듣고 싶었다. 이번 추첨에 대한 취향이며 해당 지역의 콘텐츠 부재를 주장하지 않는다.

## 실행과 검토 범위

현재 v8 harness로 실제 엔진을 격리 저장·유한자원 상태에서 실행했다. 다른 정책은 복사하지 않았고, 별도 xorshift32로 다중 선택42회 중 균등 추첨9회·성향 가중33회가 나왔다. 분기 확률은25%/75%이며 실현 비율을 맞추는 quota는 쓰지 않았다. 관측된 최저 가중치는0.7로 모든 대안이 양수였다. 단일 선택은22회다. runtime 카운터와 선택별 가중치는 `attempt01/policy-runtime-evidence.json`에 있다.

전체283행과 선택64회 본문을 `compact-review.cjs`로 시간순으로 읽었다. entry·선택·조건·결과·자원·시간·위치·동료·메시지·다음 행동을 확인했고, 검토 구간은 `review-log.json`에 남겼다. 선택 전64회와 결과 후64회의 reload가 모두 성공했다. 전후 snapshot 차이와 결과 중복 적용은0회였다. 출발17회 모두 실제 UI 출발 조건과 연료 조건을 통과했다. 자원 최저치는 연료19.24L·물9·식량7·고철13·차체77.36%였다. 연료 구하기 컨트롤은 노출되지 않아 실행하지 않았다.

이것은 브라우저·사람·시각·음성 플레이가 아니다. 화면 배치, 클리핑, 실제 화자 표시, 음성, 전환 타이밍은 검증하지 않았다. 야영 사건은 지난밤의 기록으로, 에필로그·후일담은 결말 서술로 읽었다. raw 공책 객체나 내부 숫자를 실제 표시 결함으로 세지 않았다. 정책 오류·도구 오류는 관측되지 않았고, 게임 소스와 실제 사용자 저장·탭·Studio·서버는 변경하지 않았다.

산문은 human-voice 스킬로 결과와 근거를 먼저 배치했다. 말투 검사 경고6건은 모두 근거 인용이어서 유지했다. 구조 점검을 마쳤고, 사실은 보존된 trace에 다시 대조했다.
