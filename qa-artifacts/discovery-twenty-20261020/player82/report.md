# player82 생활 개조형 플레이 기록

첫 시도에서 본편을 끝냈다. 담양·광주·전주를 모두 방문했고, 10일차 09:31, 누적 574km에서 코어 격리 수면을 선택했다. n332 결과의 `〔 서울까지 400km · SESSION 1 END 〕`와 최종 `storyDone=true`, `ending=story_done`을 확인했다. 실패나 재시도는 없다.

경로는 부산 → 김해 → 진주 → 남원 → 담양 → 광주 → 전주 → 무주 → 김천 → 상주 → 문경 → 충주 → 청주 → 천안 → 평택 → 수원 → 서울이다. 담양 도착 n72, 광주 n82, 전주 n103이다. 동료 영입 세 번을 모두 거절해 끝까지 혼자 이동했다.

333행과 선택 발생 75회를 처음부터 끝까지 시간순으로 읽었다. `compact-review.cjs`로 매 발생의 본문·선택지·요구량·선택·결과·전후 시각/위치/동료/재고·메시지·다음 행동을 확인했다. 잘린 출력은 겹치는 범위로 다시 읽었고, 반복된 큰 시장/의뢰 본문은 처음 읽은 내용과 이어 확인했다. 마지막에 75개 선택의 origin도 모두 별도로 대조했다. 75회 진입 새로고침과 75회 결과 새로고침은 모두 로드됐고, 결과 재생은 전부 `applied=false`였다. 새로고침 전후 스냅샷 차이는 없었다.

확정 버그와 미해결 버그 후보는 0건이다. n172의 밤길 손님은 6일차 06:30에 보였지만, 기록에 `지난밤 · 야영지`, `kind=memory`가 명시돼 있어 시간 모순 제보에서 제외했다. 당시 상주는 동료 없이 연료 12.425L, 물 22, 식량 13, 고철 31이었다. 자리를 내준 뒤 온천 위치를 얻고 n174에 문경으로 떠났다. n234 밤손님도 지난밤 기억이다.

생활 개조 관점에서는 죽통을 젓가락과 컵까지 쓰는 담양 장면(n75), 광주 발전기 정비와 예비 풀리 품삯(n86), 전주 우물의 물 품삯(n105)이 좋았다. 보조 연료탱크(n87), 지붕 텃밭(n115), 빗물 집수기(n137)를 실제 비용으로 설치했다. 텃밭과 집수기를 갖춘 뒤 n170·204 야영에서는 아침 식사 소모 고지가 나와도 물·식량 순재고가 유지됐다. 씨앗을 직접 얻거나 심는 사건은 이번 경로에 나오지 않았다.

연료 구하기는 6번 사용했다. 같은 세 번째 위기를 네 번 본 것은 반복감이 있었지만, 제품이 회복을 막은 사례는 아니다. 특히 n285 수원에서는 연료 0.047L, 물 16, 식량 5, 고철 0 상태였다. 현재 가능한 ‘북문 망루 교대’와 ‘성문 평형추’를 정책의 좁은 작업 키워드가 놓쳤고, 10시간 도보를 택했다. 이는 정책 한계로 따로 기록했다. 미선택 작업의 결과나 보상은 확인하지 않았다. 모든 출발 16회는 실제 UI 조건을 반영한 `check.ok=true`였고, 연료 부족 예보를 우회하지 않았다.

선택 난수는 게임과 분리한 xorshift32를 썼다. 다중 선택 51회 중 균등 모드 11회, 성향 가중 모드 40회, 단일 선택 24회였다. 실현 비율을 맞추려고 재시도하지 않았다. 실행 직후의 카운터를 보존하고, 완료 뒤 같은 관측 선택지 75개만 정책에 순서대로 다시 넣어 모든 선택 인덱스와 마지막 난수 상태가 같음을 확인했다. 이 검증은 게임을 다시 실행한 시도가 아니다. 자세한 규칙과 수치는 `policy-evidence.json`에 있다.

이 기록은 실제 소스 엔진과 유한 자원을 사용한 격리 VM 플레이다. 화면, 입력, 이미지 크롭, 음성은 검사하지 않았다. 원시 공책 데이터나 칩의 숫자 표기만으로 UI 문제를 주장하지 않는다. 네 시장의 게시판은 열었지만 의뢰를 받지는 않아 배달·조달 완료는 미검증이다. 게임 소스·실제 저장·공유 파일은 수정하지 않았다.
