## 주관적 반응과 제외한 의심

부품을 써서 자리를 만들거나 물건을 구한 행동이 동료의 합류와 마지막 회상으로 돌아오는 점은 정비공 성향과 잘 맞았다. 반면 수원에서 본인 정책이 식량10을 비축하며 거래10회/250분을 썼다. 이 정책의 과한 비축이 만든 흐름이기도 하지만 소량 거래의 시간 단위는 보급을 길게 느끼게 했다. API 실행에서 받은 반응이며 실제 UI 조작감 검수는 아니다.

아침의 모닥불 손님은 origin이 ‘지난밤’인 회상이므로 시각 오류로 잡지 않았다. 강우 사기100에서 chips가0인 경우도 cap과 실제 정산이 맞았다. 보존 엔딩 비활성은 근무 동료2/3라는 공개 gate와 일치했고, 이 정책이 동료를2명으로 제한한 결과다. 최종 수원 복귀 서술은 에필로그/세션 종료로 읽었으며 현재 도로 위치 오류로 분류하지 않았다.
