# 주 디렉터 최종 판정 기준

- 자연 실행에서 재현한 선택·입구·인접 결과·다음 행동을 먼저 읽고 담당 소스와 대조한다. 일부 행의 키워드만 보고 전체 시퀀스를 추정하지 않는다.
- 확정 실행 오류/지급·저장 오류, 서사 상태 모순, 명료성/어색함, 설계 검토, 주관 의견, 참가자 계획 오류, 관측기 한계와 미검증을 분리한다.
- 숫자 비용과 결과는 caps/floors/추가 끼니/부상/할인·perk·가변 수량까지 대조한다. 고정 fx만으로 실제 지급을 단정하지 않는다.
- NPC가 외부 통신으로 아는 것과 플레이어의 실제 기억은 다르다. 임시/현장/무전 인물을 없는 동료로 오인하지 않는다. memory/epilogue/지난밤 표지를 확인한다.
- API 안내 문자열을 실제 화면의 노출·잘림·버튼 접근으로 승격하지 않는다. 이미지·청취·조작 증거 없는 부분은 미검수로 적는다.
- 새 증거 없이 이전에 보류/기각한 우물의 무료 출구나 NPC 선행 지식을 확정 버그로 반복하지 않는다. 반대로 새로 관측한 명백한 반례는 다시 검토한다.
- 엔딩 비율·사망 횟수는 이 정책/seed의 결과다. 사람 선호·전체 난도 통계나 모든 오류 발견 보증으로 해석하지 않는다.
- 이번 요청은 수집/보고다. 모든 제보는 근거/대안 해석/최소 수선 방향까지만 적고 생산 수선은 별도 승인 뒤 진행한다.
