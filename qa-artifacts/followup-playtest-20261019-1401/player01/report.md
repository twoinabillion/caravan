# 박 선생 동행·야영 후속 플레이

이번 담당자는 player01과 player02 두 성향을 맡은 에이전트 한 명이다. 실제 소스 엔진과 독립 저장소로 진행했고, 브라우저에서 누르거나 사람 플레이를 관찰한 결과가 아니다. 생산 코드·사용자 화면·저장은 건드리지 않았다.

## 실행 전 선언과 실제 도달

보호자형 player01은 전주에서 약사를 만나 약품 운반을 돕고, 치료·경청·정비를 우선한다. 실용형 player02는 같은 박 선생 경로에서 다른 공개 선택을 시도하고 첫 야영 답변을 미뤘다가 기록 쪽 답을 고른다. 결과를 미리 보고 선택하거나 동료·자원을 넣지 않았다. 실제 상점·업그레이드의 공개 상태를 보고 구매를 시도하는 정책을 썼으며, 두 최종 실행 모두 좌석 업그레이드 없이 박 선생 한 명만 실제 합류했다.

수정은 공개 라벨 판별과 야영 진입 정책만 했다. 이전 시도는 덮어쓰지 않았다. 최종 두 실행은 합계160선택이며 유료 결과 재접속159회가 모두 `loaded=true`, `replayed=true`, `applied=false`였다. 관측 스냅샷 변화는0회. 이미 여정이 끝난 마지막 thirst 결과는 재결제 재접속이 없다. 전체 숨은 RNG 상태 동일성까지 확인했다는 뜻은 아니다.

동결 소스 해시: `835db1380a435ee7687ac307e37dcd6d01671bd071df140a434d54f88f7fd3af`.

최종 두 경로에서 역사427쌍 대비 새 event/choice ID쌍은12개. 단, `camp_5_parkss` 등의 밤 번호는 서로 다른 콘텐츠가 아니다. 이를 `camp_parkss`로 합치면 새 의미상 선택 조합은9개다. 이 숫자를 새 사건12개나 버그12개로 세면 안 된다.

## 확인한 문제

1. **MED-01, 확정 / 우선 수정:** [attempt02 trace](attempt02/player01-trace.json)의106번 `cleaners_recall` 성공. 한 대로 소개된 승합차를 회수조 넷이 타고 떠난 직후 여자가 그 승합차 안에서 문을 잠근다. 차량을 추가하기보다 퇴장 수단을 원래 현장에 맞추는 작은 수선이 맞다. 같은 소유자의 부분성공 저장 note도 ‘태우고 떠난 뒤’라 현장 하차 본문과 충돌한다. 부분성공은 이번 경로에서 뽑히지 않았고 root의 관련 소유자 원문 대조로 확인했다.
2. **MED-02, 확정:** 262번 `camp_8_parkss`와297번 `camp_9_parkss`가 ‘검문소 앞에 늘어서 있던 수레들’을 회상한다. 즉시 앞254/256/258 및273/275/277은 센서·카메라·차단봉의 일반 검문소 잠입/관찰/철수이며 수레 행렬이 없다. 실제 최종 저장의 report도 threat=`자동 검문소`, objective=`송신 전에 차단봉을 열고 기록 없이 통과한다`다. `G.campReportMemory`가 일반 자동 검문소와 다섯 수레 호송을 합친 데서 생기는 출처 오염이다.
3. **MED-03, 낮은 우선순위:** 333번 `seoul_night` 관계 회수의 ‘박 선생와’. 이름에 맞는 조사 처리 문제다.
4. **MED-05, 확정 / 작은 수선:** 보존한 player01 attempt01의249번 `talk_pss_17`.06:30에 종을 달고 몇 번 여닫은0분 결과 끝에서 ‘그날 하루 조수석 문이 제일 바빴다’고 아직 오지 않은 하루를 완료한다. 짧은 설치 행동에 비용을 붙일 문제가 아니라 마지막 문장을 현재 행동으로 닫을 문제다.

정확한 원문·기대/실제·전후 상태·출처는 [findings.json](findings.json)에 있다. 이 담당자는 고치지 않았다.

## 설계 의견, 버그로 확정하지 않은 것

박 선생의 냉장 약품 운반은 ‘따뜻해지기 전에 / 시간이 모자라다’인데, player02는2일째23:56에 태우고9일째06:45에 구미 진료소에 닿았다. 그 사이 노선 선택은 청주까지 다른 일로 나갈 수 없다고 분명히 경고했다. 따라서 숨은 강제 루프 버그가 아니다. 다만 긴급한 부탁과 플레이어가 정당하게 선택할 수 있는 장기 우회의 서사적 긴장은 있다. **기한이나 실패 비용을 새로 넣으라는 제안은 아니다.** 먼저 약품을 처리하게 알려 줄지, 긴급 표현을 조절할지 디렉터 판단이 필요하다.

## 통과·한계

- 박 선생 야영 첫 share→첫 record→share 후속→record 후속→share 세 번째가 실제 선택 이력에 맞춰 이어졌다. 아직 만들지 않은 인계 종이를 첫 record에서 미리 완성했다고 하지는 않았다.
- player02의218번 ‘대답은 나중에’는 active만false가 되고 시간·물자·차체·피로·동료가 같았다.219번 같은 대화를 다시 열고220번 record를 실제 결제했다.
- player02가 물이 적을 때 세수로 버티고, 우물 자물쇠 파괴에 실패하며, 충분히 보급하지 않은 긴 왕복길에서 탈수로 끝난 것은 정책/선택 결과다. 이 한 경로만 보고 생존 밸런스가 틀렸다거나 진행 불가라고 주장하지 않는다.
- 최종 두 실행의 모든 진입·선택·결과와 전후 상태를 읽었다. 원문이 완전히 같은 행은 비교 후 이미 읽은 player01 원문으로 대조했고, 다른 세 보존 시도의 고유 원문도 읽었다.
- overnight 캠프의 새벽/아침 회고와 엔딩의 별도 시간 구분은 스냅샷 시계 불변만으로 시간 버그로 세지 않았다. 음성·그림·모바일 크롭·키보드·터치·실시간 감속은 검수하지 못했다. 부상자 치료 버튼의 별도 UI 조작도 하지 않았다.
