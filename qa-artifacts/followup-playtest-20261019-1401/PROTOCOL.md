# 후속 집중 플레이 — 동료·야영·게시판

게임 코드는 동결하고, 이전에 덜 밟은 동료 조합과 선택을 실행·기록한다.
서브에이전트3개가 각각2개 성향/경로를 맡는다. 새 독립 에이전트6명이 아니다.
현재 Studio의 타이틀·사용자 저장을 조작하지 않는다. 실제 소스 엔진과 독립 저장소를
사용하며 브라우저·사람·시각·음성·실시간 입력 검수는 아니다.

- main 담당자만 공용 어댑터를 수정한다. 각 담당자는 지정된 playerNN 폴더만 작성한다.
- 생산 src/assets/tools, 생성HTML, 옛 QA 결과는 수정하지 않는다. 새 서버/탭/사용자 저장 금지.
- 실행 전 성향·방문 목표·선택 기준을 선언한다. 공개 라벨/조건/실제 게시판·지도·동료 상태로 고른다.
- 자원·동료·플래그·확률 주입, 특정 결과 강제, 다음 결과를 미리 보고 고르기는 금지다.
- 다른 성향 두 경로와 정책/도구 문제로 필요한 재시도는 원본을 보존해 구분한다.
- 원 실행기의 reqCostText 관찰 누락을 이번 어댑터에서 보완했다. 게시판은 명시적으로 열 때만 실제 rollQuests를 호출한다.
- 추가 행동: board-open / accept-quest(index) / turnin-quest / camp-talk(cid) / camp-meal / camp-repair.
- 야영 대화에서 choose가 camp-later를 반환하면 UI의 '대답은 나중에'처럼 닫고 저장한다. 그 자체는 효과를 적용하지 않는다.
- visitGoals로 알려진 목적지 목록을 주면 routes[].distanceToStops에 공개 지도 거리만 제공한다.
- 편의를 위해 준 관측 필드를 UI 화면을 실제로 보았다는 증거로 쓰지 않는다. 게시판/야영의 DOM·터치·읽기 크롭 검수는 별도다.
- 엔딩까지 또는 실제 실패/막힘까지 진행하고 다음 행동·자원·장소·시각·인물·공책을 기록한다.
- findings.json/report.md에 eventId/trace n/진입·선택·결과/전후 상태/기대·실제/영향·확신·한계를 남긴다.
- 원시 목표 why/act, 야영 선결제의 밤 회상, 표시 생략, 테스트 정책 왕복은 곧바로 게임 버그로 세지 않는다.
- 확정 모순·버그 / 설계 의견 / 정책·도구 한계를 나누고, 고친 이전 제보를 새로운 버그 수로 늘리지 않는다.

root가 원문과 실제 소유자/표시 경로를 대조한다. 이번 요청에서는 발견 기록과 디렉터 판단을 먼저 전달한다.
