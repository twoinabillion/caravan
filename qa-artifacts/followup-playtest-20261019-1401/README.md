## 버그와 분리한 의견

- 우편부 부탁을 거절한 경로의 한강 녹음은 ‘아직 임자를 못 찾았다’로 이미 갈리고 편지 확인도 소지 조건으로 잠긴다. 인계했다고 거짓말하는 버그가 아니라, 남은 부탁을 어디서 이어받는지 모호하다는 **회수/종결감 의견**이다.
- 레오의 노래 앞부분을 못 들은 player03에서 종장의3절 요청이 처음 등장한다. 약속했다고 확정하지는 않는다. 짧은 맥락 연결 후보이며 모든 동료 대화를 필수화할 근거는 아니다. player04는 실제2절 장면을 거쳐 대조군이 됐다.
- 냉장 약품을 싣고 긴 우회를 해도 같은 진료를 이어 가는 긴급성은 설계 긴장. 공개 노선 선택이 귀환을 안내하므로 강제 루프 버그가 아니다. 임의 유통기한·실패 조건을 만들지 않는다.
- 무기한 연속 미션의 가상 due=day+99 때문에 며칠 뒤에도 빠른 처리 보너스가 붙는다. 정산 누락과는 다른 **이름/경제 설계 의견**이며 이번 자동 보상 변경 근거가 아니다.
- `ev_leo_solo`의 보리 가족 설정 대사와 보리 인식표/첫 발견의 충돌 가능성, 시장 일부 식량 단위의 ‘일치’ 잔존은 **소스 후속 후보**다. 이번에 해당 장면·실제 시장 화면을 보지 않았으므로 위6건에 포함하지 않았다.

내 판단은 새 이야기를 늘리기보다 **약속한 규칙·지급 기록 → 장면의 인물·소유물 → 회상 출처** 순서로 좁게 수선하는 것이다. 엔딩 비율이나 봇의 보급 실패를 이유로 난도를 바꾸거나 모든 인물을 설명적인 말투로 만들지 않는다. 다음 테스트는 먼저 무전3/3·조달 성공을 실제 공개 경로로 채우고, 실제 모바일 첫30분 및 수정 장면의 시각·입력 검수를 별도로 해야 한다.
