# player64 — 장터 상인 순회

첫 시도로 본편을 끝냈다. seed `205064`, 연료 꾸러미, 4일차 519km에서 `storyDone=true`, `story_done`, `core_transfer`를 확인했다. n198의 실제 결과에 `〔 서울까지 400km · SESSION 1 END 〕`가 있고, n199에서 저장된 결과를 불러와도 효과는 다시 적용되지 않았다. 실패·재시도는 없다.

밀양·대구·무주·전주·대전·수원 6곳을 모두 방문했다. 실제 경로는 부산→양산→밀양→대구→구미→김천→무주→전주→논산→대전→청주→천안→평택→수원→서울이다. 답사는 32일/1,250km 이내라는 예산을 먼저 정했고, 이미 방문한 거점과 메인 목표 사이를 반복 왕복하지 않았다.

## 실제로 한 일

- 선택 58회, 전체 기록 199행. 모든 선택의 입장 본문·전체 선택지와 비용·요건·실제 결과·전후 자원·시간·장소·다음 행동을 시간순으로 읽었다. 결과 재불러오기 58회 모두 `loaded=true`, `replayed=true`, `applied=false`였다.
- 연료 구매 10회. 밀양 공동 펌프 노동 1회(n28, 13:52→14:17)로 물10→12, 고철9→23이 됐다. 이어 고철14를 내고 연료20L를 샀다(n29–30).
- 게시판4회, 사이드 미션 수락2회·인도2회. 밀양에서 받은 무주 호출 장부는 n74에 고철+20, 무주에서 받은 대전 주파수표는 n102에 +26이었다. 각각 기본16+보너스4, 기본20+보너스6과 맞았다.
- 대전에서 연속 의뢰3/3의 밀양 복귀를 확인했지만 수락하지 않았다(n104–105). 이미 오른 길을 장거리로 되돌아가지 않겠다는 판단이었다. 무기한 의뢰라 게임 오류는 아니다.
- 자원 최저치는 연료14.47L·식량7·물10·고철9·차체74.42%. 정식 동료는0명이며 강우는 임시 동행 상태였다. 자원·동료·결말은 주입하지 않았다.

## 발견 후보 1건

`P64-C01 / P3 / 서사 연결 후보` — 검문소에서 관찰만 한 뒤 철수했는데, 결과가 물리적 개입을 단정한다.

n120에서 「달구지를 폐기 차량처럼 갓길에 세운다」를 골랐고, n122에서는 「점등 순서를 한 바퀴 더 지켜본다」를 골랐다. 이어 n124의 유일하게 가능한 「작업을 버리고 논길로 물러난다」를 택하자 “제어함은 손댄 채로 남았고, 손댄 흔적은 열린 것보다 오래 남는다.”가 나오고 「손댄 채로 둔 제어함」 기록을 받았다. 이 선택 경로에는 제어함을 열거나 케이블을 꽂는 행동이 없다. 종료 뒤 확인한 `src/03-data.js:6253`도 공통 철수 결과를 사용한다.

당시 4일차 천안→평택 주행 중442.2km, 정식 동료0명, 쇠파이프·화염병 없음이었다. 철수는07:58→08:38, 연료37.235→33.235L로 처리됐고 n125 재불러오기 뒤 n126 평택 도착, n127 수원 출발까지 가능했다. 중단이나 자원 오류는 아니다. 생략된 접근 자체를 접촉으로 보는 작가 의도는 확인하지 못했으므로 확정 버그로 올리지 않았다.

## 정책이 놓친 부분

무주의 「물 2통 ⇄ 식량 1」 등 물물교환을 보았지만 `barter_*` 키를 실제 구매 대안으로 평가하지 않았다(n74–77). 물13·식량8·의약품1·부품2가 있었는데도 실제 교환은0회다. 상인 정책의 결함이며 물물교환이 안 된다는 게임 문제는 아니다. 현장 노동도 이름 정규식이 좁아 밀양 펌프1회에 그쳤다. 성공한 시도를 교환·노동 횟수 맞추기 용도로 다시 실행하지 않았다.

다중선택에는 게임과 분리한 PRNG로 균등25% + 양수 가중 선택75%를 선언했다. 실제 다중선택38회 중 균등 모드는3회, 가중 모드는35회였다. 단일선택은20회다. 완료 후 저장된 공개 관찰만으로 `choose`를 다시 평가해58개 인덱스가 모두 같음을 확인했다. 엔진을 다시 플레이한 것은 아니다.

## 범위와 증거

이 실행은 실제 소스를 쓰는 Node VM/격리 저장 어댑터이며 브라우저·모바일·시각·음향 검증이 아니다. raw 목표 메타데이터를 수첩 UI로, raw 소수를 표시 오류로, 회상·영상 장면을 현재 시각 오류로 보지 않았다. 수용 상한은 이번 자원 상태에서 실제로 시험되지 않았다.

소스 확인은 플레이가 모두 끝난 뒤에만 했다. 검문소·수레 호송 후보의 같은 이벤트 미선택 분기 일부가 검색 결과에 노출됐다. 또한 `src/03-data.js:6237–6268` 범위를 읽다가 인접 미플레이 `lib_meet`(6258–6266)의 본문·선택과 `lib_request` 식별자(6267–6268)가 우발적으로 노출됐다. 그 뒤 추가 플레이·정책 변경은 없었고, 해당 내용을 발견사항에 사용하지 않았다.
