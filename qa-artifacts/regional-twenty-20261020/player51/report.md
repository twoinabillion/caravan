# 플레이어 51 — 동해안의 조심스러운 수리공

첫 시도에서 울산·경주·포항을 모두 방문하고 메인 엔딩까지 도달했다. 수리 준비로 출발했고, 동료 없이 6일차 611km에 집행권을 저항 연대망으로 넘겼다. 마지막 장면 n199의 `〔 서울까지 400km · SESSION 1 END 〕`와 최종 저장의 `story_done=true`, `ended=true`를 확인했다. 사망·중단·재시도는 없다.

부산 → 양산 → 울산 → 경주 → 포항 → 경주 → 대구 → 구미 → 김천 → 무주 → 전주 → 논산 → 대전 → 청주 → 천안 → 평택 → 수원 → 서울로 이동했다. 울산에서는 첫 주변 탐색(n28), 경주에서는 왕릉 소풍(n36)과 주변 탐색(n41)을 했다. 포항은 도착(n46) 후 경주로 돌아왔으며 지역 탐색은 하지 못했다. 이후 서쪽 장터길을 골라 수레 통과를 돕고, 전주와 수원에서는 우물·기와·망루·평형추 일을 했다.

확인한 문제는 한 건이다. 울산의 첫 연락망 만남인 n29 `해도의 김 선장`은 “노인이 달구지의 흰 X를 확인하고” “이음망에서 말한 차가 맞구먼”이라고 시작한다. 하지만 앞선 n1–28에는 이음망 소개나 흰 X를 받거나 그리는 장면이 없다. 당시에는 1일차 16:06, 울산, 동료 없음, 연료 21.99L·물 9·식량 11·고철 30·차체 82%였다. n28의 두 시간 탐색 직후 처음 만난 노인이 이미 소개받은 차와 표식을 알아본 셈이다. 선택 0번 뒤 보급을 받고 n31 경주 출발까지 진행은 가능했다. 이 분기의 서사 선후 관계 문제(P2)이며, 실제 차 그림에 표식이 있는지는 검증하지 않았다.

자연 플레이가 끝난 뒤 해당 이벤트의 진입문만 소스와 대조했다. 해안 지역 조건은 있지만 앞선 소개를 요구하는 조건은 없다. 짧은 소스 구간에서 미선택 두 번째 답변과 다음 이벤트의 ID·제목, 미선택 인용 경로 일부도 함께 보였다. 그 내용은 정책이나 추가 발견의 근거로 쓰지 않았다.

연료 위기는 정책의 실수로 구분했다. n52 경주 출발 때 공개 예보가 “연료 3L 부족”이라고 알렸는데도 대구까지 갔다. n57에서 연료가 떨어졌고, 기다리기 선택으로 물·식량 각 3과 10시간을 써 연료 8L를 구했다. 생존은 이어졌지만 조심스러운 수리공이라는 성향에 비해 예보를 충분히 반영하지 못했다. 세 번째 답사지에 닿자 답사를 종료하는 정책 때문에 포항 탐색을 건너뛴 점도 함께 남긴다.

왕릉에서 아이와 옥수수를 먹는 장면은 유적 답사의 이유를 만들어 줬다. 쉬어가기 라벨에 5시간이 적혔고 실제로 18:45에서 23:45로 넘어간 뒤 야영했으므로 숨은 시간 비용으로 보지 않았다. 후반에는 동료가 없어도 여행 일지를 내미는 선택(n189)이 남아 있었고, 마지막 결정과 후일담까지 막히지 않았다.

전체 기록 200행과 선택 56회의 본문·모든 선택 라벨과 비용·선택 결과·전후 자원과 시각·메시지·다음 행동을 순서대로 읽었다. 같은 관찰 필드는 이전 행 참조로 줄였고 잘린 n60·n104는 별도로 다시 읽었다. 선택 후 저장/불러오기 56회는 모두 성공했으며 효과가 다시 적용되지 않았다. 다중 선택 38회에서 균등 추첨 확률은 매번 25%였고, 실제 균등 분기는 7회(18.42%)였다. 종료 뒤 저장된 공개 관찰값으로 선택 함수만 다시 계산해 56개 선택이 모두 일치함을 확인했다. 성공한 게임을 다시 실행해 비율을 맞추지 않았다.
