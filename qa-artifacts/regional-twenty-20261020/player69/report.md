# player69 플레이 결과

첫 시도에서 본편을 완료했다. 10일째, 누적 914km에서 집행권을 저항 연대망에 넘겼고 `storyDone=true`, `ending=story_done`, `method=core_transfer`를 확인했다. n307 결과의 `〔 서울까지 400km · SESSION 1 END 〕`까지 읽고 n308에서 결제 결과를 재불러왔다. 실패·추가 시도는 없다. 확정 게임 버그와 미해결 후보는 0건이다.

농사와 품앗이, 달구지의 생활 개조와 가족 같은 동행을 좋아하는 이주자로 플레이했다. 물자를 강제로 늘리지 않고 `provisions` 꾸러미로 시작했다. seed는 205069다. 게임 난수와 분리한 xorshift PRNG를 사용했고, 다중 활성 선택에서는 25% 확률로 균등 추출하고 나머지는 성향 가중치를 적용했다. 모든 대안의 가중치는 양수였다. 다중 선택 49회 가운데 균등 14회·가중 35회, 단일 선택 28회로 총 77회다. 정책 난수만 공개 관측에 다시 적용한 77개 인덱스도 실제 선택과 모두 일치했다. 이 확인은 게임 재실행이 아니다.

답사는 26일/650km 예산 안에 마쳤다. 최단 경로상 담양을 먼저 지났으므로 목표 기억에 방문을 남겨 재방문하지 않았다.

광주에서는 국밥 꾸러미, 발전기 벨트, 영수증철 일을 거들었다(n59·61·64). 국밥 꾸러미를 만들며 식량1을 보태고 물1을 받았고, 발전기와 기록 정리는 각각 고철14로 이어졌다. 발전기 일 뒤 공개 가격이 내려간 상태에서 연료를 샀다. 전주행 씨앗 상자를 실제로 받아(n70) 도착 후 넘겼으며(n79), 고철19가 실제 증가했다. 기본15에 빠른 처리 보너스4가 붙었다. 우물 순서를 정리한 뒤 고철14·물3을 받고(n80), 후미 레일 좌석칸을 고철12·부품1·5시간으로 설치했다(n84). 다음 날 우물 품앗이는 고철5·물3으로 달랐고(n87), 무주 촛불 순찰에는 고철1이 들었다(n97). 이 흐름은 물자와 손길이 생활 변화로 이어진다는 점에서 성향에 잘 맞았다. 텃밭·온실은 실제 설치하지 못했으므로 수확이나 사용성을 평가하지 않았다.

레오에게는 자리가 없다고 답했지만(n67), 박 선생의 약품 이동을 맡았다(n82). 구미에서 의약품 대신 물3과 3.5시간을 써 아이들의 냉각·해열을 도왔고(n190), 이후 하룻밤 조건을 마친 뒤 정식 동료가 되었다(n212). 마지막 기록에 “박 선생: 물과 시간으로 버텼다”가 남았다(n307). 한 사람의 합류 방식이 마지막까지 기억되는 점이 좋았다. 도중 행정소 천막을 걷거나(n76), 모닥불 손님을 거절하고(n129), 회수조를 지나친(n161) 선택도 나와 성향이 다른 대안을 배제하지 않았음을 확인했다.

연료 위기와 허기는 정책의 문제로 남겼다. 남원 출발 때 “연료 4L 부족”, 문경에서는 “연료 1L 부족”, 청주에서는 “연료 3L 부족”이 공개 예보에 있었지만 `check.ok`만으로 이동 후보를 만들었다(n38·131·156). 세 차례 위기에서 시간·고철·물·식량을 실제로 지불했다(n40·136·158). 마지막에는 연료를 우선 구매하고 식량이 적으면 일을 피하는 조건 때문에 수입을 스스로 막았다. 수원에서 고철4로 식량1을 살 수 있었는데 물을 먼저 사 고철3이 된 것도 같은 오류다(n259). 게임이 경고를 숨긴 사례로 취급하지 않는다.

모집 안내를 행동으로 옮기는 기억도 부족했다. 7일 16:40 김천에서 “박 선생과 하룻밤을 보낸 뒤 다시 이야기해 보자”는 안내가 나왔는데(n197), 곧바로 야영하지 않고 김천–영동을 왕복해 66km를 더 달렸다(n198–207). 김천에서 밤을 보낸 뒤에는 바로 진행되었다(n208–212). 대전의 “부품2 조달”도 당시 부품4로 가능했지만(n171), 공개 `need={name,qty}` 형식을 자원별 수량 맵으로 잘못 해석해 놓쳤다. 둘 다 게임 막힘이 아니라 정책 오류다.

전체 trace n1–308을 순서대로 읽었다. 모든 선택의 제시 문구·비용·요구 조건, 실제 고른 결과와 자원 chips, 전후 상태, 메시지, 이어지는 행동을 검토했다. 반복 내용은 정확히 같은 객체만 참조로 접고, 매 발생의 시간·장소·자원과 다음 행동은 유지했다. 출력이 잘린 n72–74는 따로 다시 읽었다. 77회 결제 결과 재불러오기는 전부 `loaded=true`, `replayed=true`, `applied=false`였고 전후 상태도 동일했다. 이는 VM의 결제 영수증 재생 검사이며 실제 브라우저 입력·새로고침 검증은 아니다.

시간 표현 후보 하나는 철회했다. n303은 엔진 상태로 10일 10:14, 서울, 박 선생1명, 연료10.353L·물17·식량0·고철3인데 결과에 “새벽, 남쪽에서 첫 차량들이 한강을 건넜다”가 있었다. 모든 자연 시도가 끝난 뒤 해당 장면만 소스로 확인했다. 실제 읽기 turn에는 `timeKind:'epilogue'`와 “후일담 · 그날 밤”, “후일담 · 다음 날 새벽” 표지가 있었다. VM 평문이 이 표지를 생략하므로 현재 오전의 확정 시각 오류로 분류하지 않았다. 확인 범위에서 다른 선택/결말의 인접 코드와 UI의 ‘남산의 밤’ 문구 한 줄도 노출됐으며, 이후 게임 재실행이나 정책 수정은 하지 않았다.

이 결과는 현재 엔진을 격리 저장·유한 물자로 실행한 Node VM 플레이 기록이다. 사람·브라우저·모바일·시각·청취 QA를 뜻하지 않는다. 화면, 오디오, 타이머, 도착·모집·퍼크·터미널 일부 제어는 harness가 대신한다. 실제 목표 수첩 UI, 취소/Escape, 렌더링, 보지 않은 분기나 동료는 평가하지 않았다. 소스·에셋·빌드·Studio·사용자 저장에는 변경을 가하지 않았다.
