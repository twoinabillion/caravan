# player65 — 혼자 기록을 확인하는 역사 애호가

첫 시도에서 경주·안동·문경을 답사하고 본편 `SESSION 1 END`까지 도달했다. seed 205065, 이름 상혁, 준비 물자는 provisions. 8일차, 누적 612km, 선택 62회, 종료 방식은 `core_transfer`다. 동료는 끝까지 없었다. 실패 시도와 재시도는 없다.

이것은 현재 소스 엔진을 유한 자원으로 실행한 격리 VM 검증이다. 사람·브라우저·모바일·시각·음향 플레이 테스트로 해석하면 안 된다. 게임 소스와 실제 사용자 저장은 수정하지 않았다.

## 실제 답사와 종료

경주는 n43 도착 후 n45에서 인사만 하고 지났고, n47에서 주변을 탐색했다. 마을회관의 녹음은 n49에서 재생했다. 안동은 n77 도착, n79 하회탈, n81 탐색, n83 간고등어 구입으로 이어졌다. 문경은 n110 도착, n112 새재 나무판에 한 줄을 남기고 n114에서 탐색했다. 세 답사지는 모두 3일차까지 방문했다.

전체 경로는 부산 → 양산 → 울산 → 경주 → 대구 → 구미 → 안동 → 단양 → 충주 → 문경 → 상주 → 문경 → 충주 → 청주 → 천안 → 평택 → 수원 → 서울이었다. 문경에서 상주로 가던 중 본편 목표가 바뀌어 청주 방향으로 되돌아간 구간이 한 번 있다. 답사 예산은 24일 또는 650km였고, 세 곳을 마친 뒤에는 공개 본편 목표를 따랐다.

n259에서 집행권 인계를 선택했다. n268 결과에 `〔 서울까지 400km · SESSION 1 END 〕`가 포함됐고 summary의 `storyDone=true`, `ending=story_done`으로 실제 종료를 확인했다. 마지막 유료 결과 재불러오기 n269까지 보존돼 있다. 종료 자원은 연료 약 9.93L, 물 8, 식량 1, 고철 0, 차체 약 89.52%, 피로 약 12.33이었다.

## 발견 사항

확정 생산 버그는 0건이다. 후보 1건은 기록의 취득 과정이 생략된 듯한 연결이다.

F65-01 — n121, 3일차 19:33, 문경→상주 도로 367.2km에서 「오지 않은 다음 차」가 열렸다. 본문은 “남쪽 환승소에서 찾은 운행표와 분류 기록을 나란히 펼쳤다”고 한다. 이때까지 김천 방문이나 그 묶음을 취득·전달받는 발생은 없다. n131의 부모님 기록 대조도 비슷하게 이어진다. 김천/청주에서 탐색하라는 공개 목표와 자동으로 열린 기록 사이에서, 내가 자료를 언제 확보했는지 한 문장이 부족하게 느껴졌다.

다만 이 장면은 `storyOrigin.kind=record`다. 현재 장소가 환승소로 바뀌었다거나 기록의 내용이 틀렸다고 판단하지 않았다. 이미 가진 기록을 다시 펼치는 압축일 수 있어 낮은 확신(0.62)의 후보로 남겼다. 종료 후 관련 원문과 진입 조건을 확인했지만, 의도된 압축 여부까지 소스로 단정할 수는 없다. 재현 경로와 자원은 findings.json에 있다.

## 정책의 실패와 검증 범위

연료 위기 네 번은 정책 문제다. n128·144·169·196은 각각 공개 forecast에 1·4·2·4L 부족이 적혀 있었는데도 출발했다. 경로를 `check.ok`와 거리로 고르면서 `forecast.shortage`를 반영하지 못한 오류였다. n135·147·176·199의 위기 결과는 이 선택의 뒤를 정상적으로 이었다. 이를 게임의 허위 경고나 보급 불가능 문제로 바꾸어 보고하지 않는다. 성공을 다시 실행해 이 기록을 지우지도 않았다.

지역 일거리도 이름의 일반 단어만 찾다가 전부 놓쳤다. 노동은 0회이며, 공개된 망루·평형추·전광판·교대선 같은 행동의 보상을 실제로 확인하지 않았다. 따라서 이 실행은 안전한 자원 운영이나 노동 밸런스를 평가하는 근거로 약하다. 실제 행동 종류는 이동 17, 주행 진행 40, 탐색 10, 야영 5, 거래 5였다.

독립 xorshift PRNG로 다중 가용 선택마다 25% 확률의 균등 추첨, 나머지는 모든 대안에 양수 가중치를 둔 페르소나 추첨을 사용했다. 다중 선택 41회 중 균등 모드 10회, 페르소나 모드 31회였고 단일 선택은 21회였다. 종료 후 저장된 공개 관측만 재입력해 모드를 복원했으며 62개 선택 모두 실제 기록과 일치했다. 게임 RNG를 정책에 쓰지 않았고, 엔진 재실행은 없었다.

전체 269행을 순서대로 읽었다. 각 선택의 진입 본문·출처·제안 비용과 가용성·결과·전후 자원/장소/시간/동료·다음 행동을 확인했고, 반복 저장 행도 각각 확인했다. 입장 전 재불러오기 62회와 결과 재불러오기 62회는 모두 성공했다. 결과 재적용은 전부 `applied=false`였다. 이것은 데이터의 지급 1회성 검증이며 실제 화면의 페이지·커서·취소·포커스 검증은 아니다.

이 페르소나로서는 n108의 “아직 모름. 빈칸 지우지 말 것.”, n181의 확인 불가 항목, n253의 책임과 미해결 목적 구분이 설득력 있었다. n256은 혼자 온 상태를 인정해 감시 근무 0/3을 설명했고, n259에는 인계·격리와 수원 준비 경로가 남아 있었다. n268도 우편부의 편지를 배달 완료로 꾸미지 않고 별도 약속으로 남겼다. 이 평가는 실제 본 분기의 취향과 문맥에 한정된다.

소스는 모든 자연 플레이와 전체 기록 검토가 끝난 뒤에 읽었다. 좁은 후보 확인 중 인접한 `memory_empty_workshop` 및 부모님 관련 미선택 결과 일부, 북부 복구 사본 원문이 노출됐다. 미경험 내용은 정책과 결론에 사용하지 않았다. 화자 오류는 주장하지 않아 별도 파서 검증은 하지 않았다.
