# player52 — 남해를 둘러본 요리사

두 번째 시도에서 진주·여수·순천을 모두 방문한 뒤 서울의 메인 엔딩까지 마쳤다. DAY7, 누적 675km, 집행권 인계(`core_transfer`)를 선택했고, n218에서 `SESSION 1 END`를 읽었다. 마지막 저장도 `story_done=true`, `ended=true`다. 첫 번째 시도의 DAY10 탈수 사망 기록은 그대로 보존했다.

실제 소스 엔진을 격리된 Node VM에서 실행한 테스트다. 사람의 직접 플레이나 브라우저·모바일·화면·음향 QA로 보아서는 안 된다. 생산 코드와 실제 사용자 저장은 건드리지 않았다.

첫 시도는 보급 판단이 부족했다. 순천에서 연료 2.387L로 남원행을 골랐고(n51), 공개 예고에는 이미 연료 9L 부족이 적혀 있었다. 마지막 평택 출발(n195)도 DAY9 23:56, 물0·식량0·고철1인 상태에서 **“자정 전 물 1 보급 필요 · 탈수 위험”**을 무시했다. n196에서 자정을 넘기며 탈수로 끝났다. 이 실패를 안내 누락이나 게임 소프트록으로 신고하지 않는다.

재시도는 같은 신원과 seed를 유지했다. 연료 준비로 바꾸고, 자원이 줄면 공개 경로 예고의 보급 점수를 보고 장터를 찾도록 했다. 광주의 발전기 줄, 전주의 우물 순서, 무주의 환기팬, 대전의 배급판, 수원의 망루와 성문 일을 실제로 수행했다. 두 번째 시도에도 무주→전주에서 한 차례 연료가 떨어졌지만, 공개 선택으로 회수한 뒤 계속 진행했다. 성공 후에는 다시 플레이하지 않았다.

## 발견한 문제

P52-01 · P3 · 회상 결과가 남쪽 우회 중에도 북행으로 고정된다.

두 시도 모두 n33 `memory_busan_terminal`에서 “엄마는 약속을 지킨다고 말한다”를 골랐다. 결과 끝에 **“기억에서 돌아오자 달구지는 여전히 북쪽을 향하고 있었다.”**가 나온다.

당시 실제 이동은 진주→여수 48km 중 26.455km 지점이다. 두 번째 시도는 DAY1 19:58, 동료0명, 연료22.261L·물9·식량9·고철25였다. 직전 출발 n31의 여수 예고는 **“서울에서 2km 멀어짐”**이고, 게임 지도 좌표도 진주(360,600)에서 여수(330,644)로 남서쪽을 향한다. 다음에는 n34에서 유료 결과를 재로드하고 n35에서 여수까지 달렸다.

회상의 부산이나 여덟 살을 현재 장면으로 잘못 읽은 지적이 아니다. 회상에서 돌아온 **현재의 달구지 방향**을 경로와 무관하게 단정하는 문장이다. 선택한 결과는 [src/03-data.js:12940](/Users/sang/caravan/src/03-data.js:12940)에 정적 문자열로 들어 있다. 방향을 특정하지 않는 문장이나 실제 경로에 따른 문장이 맞겠다. 지도와 서사의 연속성 문제이며, 실제 도로의 순간 곡률이나 렌더러 방향을 시각 검증한 것은 아니다.

## 검토 범위와 남긴 증거

두 시도의 전체 415행, 선택 발생 120건을 시간순으로 읽었다. 각 발생의 선택지·요구 조건·가격·본문·결과·자원 변화·메시지와 다음 행동을 확인했다. 같은 텍스트만 최초 발생을 참조했고, 다시 나왔을 때의 시간·위치·자원은 매번 따로 확인했다. 120건 모두 노출되고 활성화된 선택이었다. 결과 재로드 120건도 모두 `loaded=true`, `replayed=true`, `applied=false`여서 중복 지불은 관찰되지 않았다.

선택 정책은 게임과 분리한 PRNG로 다중 활성 선택의 25% 확률에 균등 추첨을 선언했다. 실현값은 첫 시도 40건 중12건, 두 번째 43건 중13건이다. 나머지는 음식·시장·사람·도움·기록에 가중치를 두되 다른 선택의 가중치도 남겼다. 저장한 정책에서 실제 관찰 순서로 선택을 재산출해 120건 전부 일치함을 확인했다.

밤과 새벽이 이어지는 에필로그는 별도 문제로 세지 않았다. 평문 trace에서는 게임 시각이 DAY7 09:09로 남지만, 실제 presentation owner는 해당 턴을 ‘후일담 · 그날 밤’과 ‘다음 날 새벽’으로 명시한다. 이 adapter의 평문 합치기에는 턴별 시간 표지가 빠진다. 화자 오류는 주장하지 않는다.

자연 실행이 전부 끝난 뒤 정확히 본 후보를 소스와 대조했다. 그 과정에서 인접한 미선택 분기도 일부 노출됐다. `memory_busan_terminal` 선택0, `cell_sea_meet` 선택0, `seoul_night` 선택0/원본 결과와 다른 처분·동료 조건, 검색에 잡힌 `core_sleep` 결과, finale의 `leave_key` 회상이 해당한다. 이후 추가 플레이나 정책 수정은 하지 않았다.
