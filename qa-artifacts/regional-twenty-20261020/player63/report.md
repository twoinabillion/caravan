# player63 — 항구의 저녁과 밤

첫 시도로 메인 스토리를 끝냈다. 여수·군산·평택을 모두 실제로 방문한 뒤 8일차, 누적 651km에서 코어 격리 수면을 골랐다. n274의 유료 결과에 `〔 서울까지 400km · SESSION 1 END 〕`가 있고 최종 요약은 `storyDone:true`, `ending:story_done`, `method:core_sleep`이다. 죽음·중단·재시도는 없었다.

실제 현재 소스를 격리 저장소의 Node VM 엔진으로 실행한 QA다. 화면·입력·타이머·소리 표현은 harness가 대체했다. 사람이나 브라우저, 모바일, 화면, 오디오 플레이테스트라는 뜻은 아니다. 소스·빌드·Studio·실제 사용자 저장은 수정하지 않았다.

## 발견과 경계

확정한 진행 차단·이중 결제·리로드 효과 중복 오류는 없었다. 58개의 미결 선택 진입 로드와 58개의 유료 결과 로드가 모두 성공했고, 유료 결과는 모두 `replayed:true / applied:false`였다. 275행 전체를 n1부터 n275까지 읽으며 상황·제안된 선택/비용·선택·결과·전후 재고·다음 행동을 확인했다. 반복 항목은 최초 본문을 읽은 뒤 같은 내용만 참조했으며, 각 발생의 시각·위치·자원은 따로 확인했다. 출력이 잘린 도입 일부와 n71~74는 다시 읽었다.

후보 P63-C01은 연료 구조 선택의 사전 비용 정보다. n61의 ‘걸어서 연료를 구해온다’와 n181의 ‘지나가는 차를 기다린다’는 공개 hint가 비었지만, 각각 7시간+물2+식량2와 11시간+물3+식량3+피로15의 결과가 나왔다. n206의 고철20 유료 구조도 사전에 5시간은 보이지 않았다. n181은 6일15:06, 물26/식량14/피로29.68에서 시작해 7일02:06, 물23/식량11/피로67.25가 됐다. 결과 후 리로드와 이어지는 주행은 정상이다. 엔진 메타데이터와 현 UI의 비용 생성 경로에 해당 시간·소모가 자동 노출되지 않는 점은 확인했지만, 실제 화면의 다른 안내나 의도적인 불확실성까지 확인한 것은 아니다. 확정 UI 버그로 올리지 않았다.

여수 첫마디 ‘이음망에서 말한 차가 맞구먼’은 이 실행에서 이음망 인물과 먼저 만난 장면이 없어서 소개가 조금 갑작스럽게 느껴졌다(n46). 차량의 기존 흰 X와 화면 밖 연락으로 성립할 수도 있어 취향 의견으로 남겼다. 사람 없는 차에 동료가 등장했다거나 화자가 틀렸다고 주장하지 않는다.

연료 고갈 세 번은 정책 오류와 분리했다. n58은 2.34L로 예보8L인 광주 길, n178은 1.22L로 예보4L인 평택 길, n199는 4.07L로 예보5L인 수원 길을 출발했다. 정책이 `check.ok`와 물·식량 생존 경고만 우선하고 fuel margin을 필수 출발 조건으로 다루지 않은 탓이다. 이전 보급소나 경유지를 더 신중히 계획했어야 한다. 구조는 공개 선택으로 해결했고, 강제 자원·시각·날씨 설정이나 실패 삭제는 하지 않았다.
