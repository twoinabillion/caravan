## 검증과 미검수 범위

각 담당자는 자신의 실패 포함 전편을 시간순으로 검토했다. 완전히 같은 본문만 최초 발생 참조로 줄이되 매 발생의 위치·시각·인원·자원·모든 제시 선택·결과·다음 행동을 다시 확인하도록 했다. 검토 진술은 담당자 attestations다. root가8,185행 전부를 독립 재독하거나 사람이 검수했다는 뜻은 아니며, root는 제보와 해당 인접 로그·소유자·필요한 격리 진단을 대조했다.

다중 선택의 균등 추첨은 별도 PRNG의 **선언 확률25%**이고 나머지는 모든 대안이 양수인 성향 가중이다. 유한 실현 비율을 할당량으로 강제하거나 성공을 비율 때문에 재실행하지 않았다. 모든 자연 시도가 끝난 뒤에만 실제로 본 후보 소스를 확인했다. 일부 인접 미관찰 대안이 함께 노출된 범위는 개별 보고서에 공개했고 이후 자연 플레이에 쓰지 않았다. 프로젝트 지침 자체가 과거 수선 부류를 알려 주므로 ‘인간 신규 유저와 완전히 같은 블라인드’는 아니다.

지급 결과 재개1,863회·미지급 진입1,139회·일반1회에서 **기록된 관측 차이0·재지급0·불러오기 실패0**, 엔진 예외0이다. 총3,003회다. 치명 경계로 끝난3선택에는 지급 결과 재개가 없었다. 미래 난수/후속 경로 동일성을 증명하지 않으며 실제 브라우저 Continue·네이티브 저장·터치/취소·Escape·음성·성능 QA가 아니다. 66의 야영 미루기→일반reload→재열기→지급은 어댑터 경로의 증거일 뿐 실제 입력 증거가 아니다.

최초 공개 지도42곳의 방문, 엔딩20회로도 모든 사건/선택/희귀 결과/숨은 지역/인물/보존 결말을 보장하지 않는다. 프레젠테이션·음성·시간 대기·입력은 대체한 Node VM이다. 오프닝·모집 수락/영입 단계·획득 퍼크·서울/터미널 제어도 문서화된 보조를 사용했다. raw main metadata는 실제 목표 공책 UI가 아니고 raw choice hint만 비어 있다고 비용 UI 결함으로 판정하지 않았다.
