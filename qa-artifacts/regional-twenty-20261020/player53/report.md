# player53 — 서해 항구 상인 관점 플레이 기록

첫 시도에서 광주·목포·군산을 모두 둘러본 뒤 메인 결말에 도달했다. DAY 6, 629km에서 집행권 인계(`core_transfer`)를 선택했고, 마지막 「SESSION 1 END」까지 읽었다. `storyDone=true`, `ending=story_done`이다. 실패·사망·재시도는 없었다.

확정한 진행 불가 결함은 없다. 검토가 필요한 선택 구조 후보 1건을 남겼다. 연락망 인물의 사전 지식과 늦게 들린 부산 방송은 명료화·연출 의견으로 분리했다. 수정은 하지 않았다.

## 실제 경로와 활동

부산 → 김해 → 진주 → 남원 → 담양 → 광주 → 목포 → 광주 → 전주 → 군산 → 전주 → 논산 → 공주 → 세종 → 청주 → 천안 → 평택 → 수원 → 서울.

광주는 DAY 2 10:43, 목포는 DAY 2 21:16, 군산은 DAY 3 20:19에 처음 도착했다. 58개 사건에서 58번 선택했고, 이동 18회·탐색 12회·거래 17회·현지 작업 6회·게시판 5회·야영 5회를 실행했다. 씨앗 상자 배달도 1건 완료했다. 동료는 끝까지 없었으며 유한한 물자와 품삯·거래·탐색 수확으로 진행했다.

선택 정책은 게임 RNG와 별개인 고정 PRNG를 사용했다. 복수 선택에서 균등 샘플링 확률을 25%로 선언하고, 나머지는 교환·작업·기록·대화를 선호하되 모든 대안에 양의 가중치를 남겼다. 실제 복수 선택 37회 중 균등 모드 6회, 가중 모드 31회였고 단일 선택은 21회였다. 성공을 재생해 비율을 맞추지 않았다. 기록된 공개 관측만 정책에 다시 입력했을 때 58/58 선택이 원본과 일치했다. [선택 증거](policy-evidence.json)에 모드를 보존했다.

## 선택 구조 후보

**P53-01 · 낮음 · 군산 빵집의 구매 단일 선택 — n98–101**

DAY 4 06:30 군산에서 주변 탐색을 시작했고(n98), 08:30에 「가장 오래된 빵집」이 열렸다(n99). 제시된 선택은 「단팥빵을 산다 (고철 3)」 한 개였다. 당시 고철 33, 식량 7, 동료 0명이라 구매는 가능했고, 선택 뒤 고철 30·식량 9가 됐다. n100에서 유료 결과를 재열람한 뒤 n101에 전주로 출발했다.

탐색 중 발견한 상점에서 구매를 보류하고 떠날 선택도 있으면 좋겠다. 실제 사건 정의에도 구매 한 개만 들어 있다(`src/03-data.js:5781`). 다만 이번에는 돈이 있었고 구매 후 정상 진행했다. 브라우저 공통 닫기·Escape·뒤로는 시험하지 않았으며 무자원 상태도 만들지 않았다. 따라서 강제 결제 UI나 무자원 소프트락으로 확정하지 않는다.

재현은 보존된 `policy-attempt01.cjs`, seed 205053으로 군산까지 이동한 다음 DAY 4 아침 첫 탐색의 선택 목록을 확인하면 된다. 기존 `attempt01` 경로는 덮어쓰지 않아야 한다.

## 명료화·연출 의견

- **연락망 소개 순서 — n61·72.** 광주의 금자는 「자네들, 이음망이 말한 그 달구지제?」라고 했고, 목포의 김 선장은 「달구지의 흰 X」를 확인한 뒤 「이음망에서 말한 차가 맞구먼」이라고 했다. 이 경로에서는 이음망과 직접 만나는 사건이나 표식 설명을 읽지 않아 누가 차를 소개했는지 궁금했다. 장외 연락이나 기본 차량 표식일 수 있으므로 설정 모순으로 판정하지 않는다. 김 선장과 만난 시점은 DAY 3 08:30, 목포 217km, 고철 21·연료 38.53L·물 13·식량 10이었다. 다음 행동은 광주 귀환이었다.
- **출발 방송의 시점 — n46.** 「부산 항만 방송이 잡음 속으로 멀어질 즈음」이라는 도입이 DAY 2 10:05, 담양→광주 168.6km에서 나와 출발 직후 같은 말이 늦게 들리는 느낌이었다. 장거리 방송을 의도했을 수 있고 전파 범위를 확인하지 않아 지리 결함으로 보지 않는다.
- **상인 역할의 지역 밀도 — n50·54·56·68·72·99.** 광주는 발전기 작업, 국밥 꾸러미, 영수증 장부, 할인 거래와 배달로 이어졌다. 이번 관측의 목포·군산에는 정착지 거래/품삯 목록이 없었고 수색·항로 이야기·빵 구매 중심이라 항구 상인 역할은 광주에서 가장 풍부했다. 지역 전체 콘텐츠를 조사한 평가는 아니다.

## 정상 확인과 검토 범위

n82의 씨앗 상자는 전주에서 n88에 직접 인계했다. 「빠른 처리 보너스 — 고철 +4」와 「씨앗 상자 완료 — 고철 +15」가 실제 고철 1→16과 일치했고 활성 배달이 해제됐다. 완료 뒤 우물 작업과 다음 이동이 가능했다.

유료 결과 저장·불러오기 58회가 모두 `loaded=true`, `replayed=true`, `applied=false`였다. n215 최종 채널에는 실제로 연결한 해도·솥·유령 3곳만 나왔다. n223은 남산행 편지를 아직 수신인에게 전하지 못했다고 명시해 미완료 배달을 완료로 꾸미지 않았다.

원본 추적의 n1–224를 순서대로 전부 읽었다. 제시된 선택·비용·비활성 이유, 선택 결과, 매 행의 실제 장소·시각·명단·물자 변화와 다음 행동을 대조했다. 반복된 상태·시설·업그레이드는 동일 원문 참조로 축약해도 각 발생의 문맥을 확인했고, 출력이 잘렸던 n56은 따로 다시 읽었다. 결말 행 n223의 「SESSION 1 END」와 최종 요약을 모두 확인했다. raw 메인 메타데이터를 실제 목표 수첩 UI로 간주하지 않았고, raw 소수점을 화면 표시 오류로 분류하지 않았다. 발화자 오귀속 주장은 없다.

실제 현재 소스 엔진의 격리 Node VM 플레이이며 화면·음향·표시 타이밍은 하네스 대체다. 사람·브라우저·모바일·시각·음향 QA가 아니다. 에필로그의 새벽/수원 귀환은 압축된 종료 서사일 수 있으므로 저장 시계·좌표 오류로 단정하지 않았다.

자연 플레이가 끝난 뒤 정확히 본 후보만 소스 확인했다. 인접 범위를 읽는 과정에서 미선택 해도 첫 번째 결과, 미방문 `cell_dome_meet` 본문/결과, 유령의 조건 분기, 미발생 다리 사건 ID/게이트, `lc_icheon_rice` 헤더 한 줄이 노출됐다. 정책과 시도는 이미 끝난 상태였고 추가 플레이에는 사용하지 않았다. 소스·자산·생성 HTML·Studio·실제 사용자 저장·공유 체크포인트는 수정하지 않았다.
