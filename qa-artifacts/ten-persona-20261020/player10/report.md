# player10 — 신중한 복귀 플레이어 독립 감사

새 seed `201010`의 첫 실행에서 본편을 완료했다. 엔딩은 `story_done`, 최종 방식은 `core_transfer`(집행권 인계)다. DAY7 20:40, 562km, 민지·강우와 함께 84개 사건에서 84회 선택했고 전체 trace는 425행이다. 신규 제품 문제 후보는 0건이다. 기존 후보 3건의 추가 자연 관측과 정책 한계 1건을 분리했다. 실패·막힘은 없었고 재시도도 하지 않았다.

## 선언과 실제 경로

실행 전에 `policy.cjs`에 성향·방문 목표·공개 관측 기준을 선언했다. 현재 목표와 상태를 재확인하고, 대사·조건·비용·예보를 읽으며 기록·청취·중재를 선호했다. 공개된 `status.ok` 현장 행동은 시설 이름 정규식에 맞지 않아도 후보에 남겼다. 보급과 좌석 조건, 메인 목표의 현재 탐색 지시를 반영했다. 결과·효과·숨은 플래그를 미리 읽어 선택하거나 자원·동료를 주입하지 않았다.

부산→양산→밀양에서 민지의 부탁을 받고 양산→울산으로 갔다. 도르래로 진단기를 회수한 뒤 돌아오는 구간과 하룻밤을 거쳐 민지가 합류했다. 대구에서는 강우의 감시 표식을 뜯고 후임 인계를 도왔으며, 구미에서 정식 합류했다. 이후 김천→상주→문경→충주→청주→천안→평택→수원→서울로 갔다. 대전은 실제 방문하지 않았다. 민지와 강우가 좌석 2개를 채웠고 더 모집하지 않았으므로 좌석 부족 후 업그레이드 복구는 자연 관측하지 않았다.

동쪽 능선길에서는 역할 분담→발판 마련→사람 줄과 수레 줄 분리로 네 사람과 약을 구했다. 이 사건이 뒤의 두 캠프 대화에서 실제 회상으로 이어졌다. 아버지의 마지막 기록을 읽은 뒤 수원에서 어머니를 만났고, 어머니는 송신소에 남도록 했다. 최종 집행권은 연결된 연대망에 넘겼다. 이 선택 비율로 엔딩의 선호도나 균형을 판단하지 않는다.

## 플레이의 느낌과 정책 한계

기록을 남기는 선택들이 빈 사유란→당사자 정정→명령 원본 대조→최종 인간 확인 규칙으로 이어져, 앞에서 챙긴 기록의 쓰임을 따라가기 쉬웠다. 미룬 대화는 다시 열었을 때 같은 질문이었고, 다음 밤에는 지난 선택의 다음 대화로 이어졌다. 서두르지 않는 성향에서 특히 이 연속성이 잘 읽혔다. 이 평가는 실제 문장과 엔진 흐름에 한정한다.

반면 신중한 성향을 구현한 정책은 장거리 보급 계획이 부족했다. 시장에서는 예보로 보급을 샀지만 상점이 없는 구간에서 #299의 연료 1L 부족, #310의 연료 4L 부족 예보를 보고도 전진했다. #313에서 도로 연료 0으로 구조를 받았고 10시간이 지났으며 #329에 식량 한 끼가 부족했다. 수원에서 실제 거래 15회를 거쳐 보급하고 현장 교대로 돈을 벌어 엔딩까지 진행했다. 이것은 공개 위험을 감수한 정책 결과다. 정착지 시장이 사라지는 버그나 게임 경제가 불가능하다는 증거로 쓰지 않는다. 본편 완료 후 정책을 개선해 재실행하지 않았다.

## 증거와 한계

`attempt01/player10-trace.json`, `player10-summary.json`, `player10-save.json`을 보존했다. 최종 선택 `#424 seoul_session_reset`은 귀환과 `SESSION 1 END` 결과를 보여 줬고 `#425`에서 지급 후 재접속이 재지급 없이 통과했다. 최종 저장은 `ended=true`, `endKind=story_done`, `flags.story_done=true`다. 실행 source hash는 `6f9b628b020bcc8b22034294185f9b8dcf0ec4bdaa3f6efa4f5689b1196161b4`다.

이번 감사는 실제 소스 엔진의 Node VM 자동 플레이와 격리 Map 저장소 검사다. 브라우저·사람 플레이·시각·청취 검수가 아니다. 현재 Studio·새 서버·새 탭·실제 사용자 저장에 접근하거나 생산·공용 파일을 수정하지 않았다. 작성 범위는 이 player10 폴더뿐이다.

저장/로드는 같은 격리 엔진 안에서 수행한다. 선택 전 로드 뒤 기존 event 객체를 쓰기 때문에 UI Continue의 장면 재구성, 페이지·읽기 커서·공책 패널의 복구까지 증명하지 않는다. 지급 후 재접속 로그는 상태와 재지급 여부를 확인하며 결과 문장의 실제 재표시 동일성을 기록하지 않는다. 캠프 미루기도 지원 어댑터의 `active=false` 저장과 `prepareCamp(talk)` 재열기이며 실제 UI 취소·뒤로·포커스 검수가 아니다. 공개 목표·상태를 다시 읽었지만 실제 기록 패널을 클릭했다고 주장하지 않는다.

다른 엔딩·모든 선택 분기·3인 이상 좌석 문제·보관한도 실패·숨은 RNG와 타이머의 후속 동등성은 미검증이다. `coverage.json`의 기준 대비 7개 새 pair에는 캠프 night ID가 들어가므로 새 이야기 7개를 발견했다는 뜻이 아니다. 원문 대조는 실제 밟은 후보에 한정했고 정적 전 코퍼스 감사로 확장하지 않았다.
