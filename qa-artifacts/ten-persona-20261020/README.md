명료화 후보는 이미 지불한 지난밤 야영 사건의 아침 시계/출처(T10), 연구실의 종이 기록과 삭제된 전자 기록 범위(T13), 45분 교대를 ‘한 시간’이라 쓴 문장(T14), 독행 방송국의 ‘누가’(T15), 현장 쇠파이프 출처(T18), 임시 동행 강우를 아직 못 만난 듯 소개하는 문맥(T20)이다. 뒤의 세 항목을 특정 동료 오등장·아이템 무단 지급·모집 진행 버그로 과장하지 않는다.

별도 판단 T16은 물을 재확보해도 다음 자동 식사 전에 누적 갈증으로 자정에 사망하는 구제 시점이다. **종료 후 상태 변경 T01은 확정 결함이지만, T16은 의도한 생존 규칙을 먼저 정해야 한다.** 모든 탈수 실패를 이 원인으로 돌리거나 난이도를 무조건 낮추지 않는다. T21은 실제 맡은 남산행 편지가 세션 말까지 열린 약속으로 남는 마무리 의견이며, 거짓 전달 완료나 소모 오류는 아니다.

한 번에 고친다는 것은 독립 제보를 모두 즉시 반영한다는 뜻이 아니다. 위 우선순위로 같은 소유자·상태 계약을 묶고, 진입→선택→결과→재접속→다음 행동 회귀 검사를 붙인다. 생존 규칙·엔딩 조건·무료 대화 비용·옛 지급 결과는 별도 판단 없이 변경하지 않는다. 시각 구조가 필요하면 Studio 디자인 초안에서 먼저 논의하고, 구현된 구조는 새 코드 준비됨 배지로 의도적으로 적용한 뒤 실제 장면을 검수해야 한다.
