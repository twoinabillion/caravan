# 숨은 시설 6곳 집중 QA · agent03

자연 출발 seed221003에서 숨은 시설 5곳을 방문했다. 잠든 휴게소, 달빛 자동차극장, 책의 터널, 폐 군 비행장, 태양광 농장의 현장 선택, 미지급/기지급 reload, 다음 도로 출발까지 확인했다. 시대극 세트장은 자연 조우가 나오지 않아 방문하지 못했다. 별도 fixture에서는 6곳의 두 선택씩, 총 12개 분기를 실제 이동·도착 경로로 실행하고 저장 후 인접 도시로 돌아왔다.

생산 소스, 생성 HTML, 기존 QA 결과, 사용자 Studio/저장/서버는 수정하지 않았다. Node VM 실엔진과 표현 stub 검사이며 브라우저 클릭·시각·음성·모바일 검수는 하지 않았다.

## 확인한 후보

- P2 `G03-01`: 식량0에서도 책의 터널 ‘실용서를 고른다’를 실행해 의약품1과 차체 회복을 받고, 통조림을 책값으로 냈다고 서술한다. 식량은0→0이다. 세트장 숙박도 식량0으로 실행되면서 우리 식량을 저녁상에 합쳤다고 한다. 선택 조건에 자발적 식량 비용 게이트가 없다. 실제 실행과 미지급/기지급 reload까지 재현했다. 앞선30명 A03의 강제 안개 대기와 달리 자발적 물품 교환/식사 분기다.
- P2 `G03-02`: 기존 A01 수면 정산 문제의 새 장소 사례다. 자동차극장8시간 야영은 피로16.024→37.624로21.6이 늘었다. 세트장10시간 숙박은 깨어 있는 피로27을 더한 뒤30을 빼므로, 밤20시 피로40으로 시작해 다음날06시37이 된다. 별도 버그 수로 중복 집계하지 않는다. `sleep:true`는 피로0 초기화도 하므로 일괄 추가보다 숙박 회복 의도부터 확인해야 한다.
- P3 `G03-03`: 자동차극장의 영화 결과는 차량 라디오로 소리를 듣지만, 수리하지 않은 상태에서도 동일하다. 자연 n210에서 해당 결과를 읽었고, 수리 행동·수리 조우 없이 끝난 최종 저장의 radio_fixed도false다. 직접 fixture false→false에서도 확인했다. 기존 무전/장거리 수신과 차내 FM이 별도 장치일 가능성이 있어 명료성 후보로 남기며, 확정 기계 고장 버그로 세지 않는다.

## 보존 자료와 한계

`attempt02/agent03-trace.json`은 전체 자연 로그, `agent03-save.json`은 최종 저장, `policy-evidence.json`은 정책 결정이다. `fixtures01.json`은12개 도착/분기/귀환, `boundaries01.json`과 `boundaries02.json`은 미지급 reload·부족 자원·라디오·야간 수면 검증이다. `report.json`에 구조화한 근거를 모았다.

fixture는 기존 setup의 opening.completed 설정을 사용하고, 인접 도시 위치·대상 발견·유한 자원·북부 첫 경계 통과 상태를 명시적으로 구성했다. 경계 검사 일부는 현장 미지급 사건을 직접 구성했다. 따라서 자연 플레이 수에 합산하지 않는다. 실제 닫기/Escape/취소 버튼은 검사하지 않았고, 분기 완료 뒤 귀환 API와 다음 이동만 검증했다. 선택 전에 즉시 떠나는 비파괴 선택지가 없는 곳의 설계는 이번 확정 결함에 넣지 않았다.
