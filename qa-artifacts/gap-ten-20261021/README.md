# 미검증 영역 10인 집중 감사 — 2026-10-21

Sang의 요청에 따라 **새 서브에이전트10개**를 만들어, 이전에 못 간 장소와 실행하지 못한 기능을 나눠 검사했다. 동시 실행 제한에 맞춰 최대3명씩 진행했다. 이번에는 **수집만 했으며 게임 코드는 수정하지 않았다.**

무작위 엔딩30회 반복이 아니라 소스와 과거 기록을 읽은 목표형 감사다. 격리된 실제 게임 엔진, 실제 UI 함수와 DOM 대역을 사용했다. 정상 출발·정상 저장 재개·인위 조건 검사를 구분한다. 사람10명이나 브라우저 완주10회가 아니며, 실제 화면·터치·음성 검수도 아니다.

## 결과 요약

- 이전 미방문 숨은 장소13곳 중 **11곳을 공개 행동으로 발견·방문**했다. 재이 창고와 영화 세트장은 현장 조건·선택·재개를 fixture로 검사했지만 정상 발견부터 도착하는 경로는 미검증이다.
- 정상 영입한 민지·강우·재이와 **보존·공동 감시 결말을 SESSION 1 END까지 완료**했다. 사기 부족 차단→준비 복귀→회복→재진입·서명·강우 반대 비용도 확인했다.
- 진공관을 실제 획득했던 저장의 라디오 수리, 무기 해금 저장의5종 제작, 조달 정산, 야영 취소·재읽기·재개를 실행했다.
- 우선 수선은 아래9묶음이다. **7묶음은 이번에 새로 확인**, 수면 정산과 레오 선택 불가는 이전 문제의 확대·재확인이다. 설명 검토4묶음과 비정상 저장 방어 후보1건은 확정 기능 오류와 분리했다.

## 정상 확인과 남은 검사

보존 조건을 완화해야 한다는 근거는 나오지 않았다. 라디오 중복 수리·진공관 중복 차감, 정상 조달의 보상 오차·중복 지급, 정상 자정 만료, 야영 취소 과금·재읽기 중복 정산도 검사 범위에서 재현되지 않았다. 연료5L 이상이어도 허용 경로가 모두 부족하면 기존 구제가 열리고, 선택한 노선 내부 역방향은 허용되며 합류점에서 잠금이 풀렸다.

이번 원시 제보와 별개로 **이전 A03 식량0 안개 식사 문구와 우물 D01 설계 질문은 여전히 미수정**이다. 추가로 확인하지 않은 기존 의견을 모두 해결했다고 처리하지 않는다.

실제 모바일/Studio 입력·레이아웃·음성, 브라우저 새로고침/Back/초점, 두 숨은 장소의 정상 발견, 긴 거리 조달 수집·귀환은 남아 있다. 이번10명이 모든 경로·모든 버그를 다 찾았다는 보장은 없다.
