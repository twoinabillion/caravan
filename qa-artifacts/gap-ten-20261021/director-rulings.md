# 미검증 영역 감사 — 디렉터 판정

이번 작업은 오류 수집이다. 아래 수정 방향은 제안이며 게임에 적용하지 않았다. 실제 엔진·UI 함수 실행과 원시 기록을 대조했고, 브라우저에서 화면을 본 증거와는 구분한다. 이전에 지급된 결과를 다시 계산하거나 사람들의 반대·위험·비용을 없애는 방향은 피한다.

## 우선 수정 후보

### GAP01 · P1 · 게임 종료 뒤 제작 UI와 자원 변경이 계속됨

- 근거: [agent06 G06-01](agent06/report.json), [실제 handler 호출 기록](agent06/terminal-followup-log.json). 정상 획득 저장을 바탕으로 자정·갈증 경계만 명시적으로 설정한 검사다.
- 제작 중 종료 뒤 호출 순서는 `ending → audio:craft → driving:false → open`. 작업대 접기는 종료 상태에서 빠져나와 모달을 닫지 못하고, 다음 제작은 시간 변화 없이 고철을 더 쓰고 물건을 추가한다. 종료 기록과 삭제된 저장은 바뀌지 않는다.
- 최소 방향: 엔진의 종료 후 제작을 거부하고 UI도 종료 결과를 확인해 재열기·결과음을 중단한다. 종료 handoff가 마지막 화면 동작이어야 한다.
- 수용 검사: 정상 제작, 자정 비치명 제작, 치명 제작, 종료 뒤 접기/재클릭, 종료 기록·저장 상태를 실제 handler까지 검사한다. 스텁의 호출 순서 재현은 실제 화면 겹침을 보았다는 뜻이 아니다.

### GAP02 · P2 · 제작 할인 견적과 실제 결제가 서로 다름

- 근거: [agent06 G06-02](agent06/report.json), `raw-log.json` index14–28와 실제 생성 HTML.
- 무기 선반 보유 시 파이프/석궁/탄약의 실제 고철 비용은5/10/7인데 허용 조건과 표시는6/12/8이다. 할인 비용만 있으면 만들 수 없다.
- 최소 방향: 표시·허용·지급에 같은 견적을 사용한다. 반올림 때문에 볼트3/화염병2가 그대로인 것은 오류가 아니다.
- 수용 검사: 원가 및 할인액 직전/정확한 금액, 부품 부족, 정상 결제·시간·재개. 이번 armory 보유 조건은 fixture이며 차고 구매 흐름 검증이 아니다.

### GAP03 · P2 · 주인공 진료가 다른 동료를 치료함

- 근거: [agent07-F01](agent07/report.json), `raw-attempt02.json` 첫 사례. 실제 등장 조건·선택·새 VM 재개까지 실행했다.
- 운전자2일/강우3일 부상에서 주인공 진료를 선택하면 약품1개·35분을 쓰고 강우만 낫는다. `healInjury:'latest'`가 잔여 기간 최대 대상을 고르기 때문이다.
- 최소 방향: 이 사건의 대상을 명시적인 운전자로 맞춘다. 범용 치료 규칙이나 이미 지급된 결과를 전역으로 바꾸지 않는다.
- 수용 검사: 운전자 단독/동료와 동시 부상, 약품0의 기존 휴식 대안, 절약 퍼크, 자정 회복, 미정산/기지급 재개와 다음 출발.

### GAP04 · P2 · 자발적 교환·식사에서 없는 자원을 사용했다고 처리함

- 근거: [agent02 A02-01](agent02/report.json), [agent03 G03-01](agent03/report.json). 부족 자원 경계는 fixture다.
- 매화마을 교환은 고철0으로도 보상을 받는다. 터널 서점은 식량0으로 통조림 책값을 냈다고 하며 수리/의약품 보상을 준다. 영화 세트장은 식량0인데 우리 식량으로 저녁상을 차렸다고 한다.
- 최소 방향: 자발적 물물교환은 비용 요구와 실제 지급을 일치시킨다. 영화 세트장은 숙박 허용과 자기 식량 사용 문구를 분리해 판단한다. 고철3/식량1 등의 기존 비용을 임의로 바꾸지 않는다.
- 수용 검사:0/비용 직전/정확한 비용/상한, 기존 대체 선택, 실제 차감·보상·기지급 재개. 강제 손해나 저자원 생존용 대기까지 일괄 금지하면 안 된다.

### GAP05 · P2 · 숨은 장소의 밤·아침 묘사와 실제 시각 불일치

- 근거: [agent02 A02-02](agent02/report.json). 온천07:54→11:54와 등대11:09→19:09는 정상 플레이, 호수09:00→17:00은 낮 시간 fixture다.
- 온천은 밤하늘, 등대는 다음 아침 미역국, 호수는 달빛/밤새/떠나는 아침을 단정한다.
- 최소 방향: 실제 시작·종료 시각에 맞는 서술 또는 명시적인 시간 처리 중 하나를 선택한다. 조용한 밤 장면의 분위기를 전부 평문으로 삭제하거나 숨은 장소 전체를 밤 전용으로 잠그지는 않는다.
- 수용 검사: 낮/저녁/자정 통과, 실제 비용 시간, 결과 기록과 재개 본문의 일치.

### GAP06 · P2 · 수면을 각성 시간으로 계산하는 기존 문제의 추가 장소

- 근거: [agent03 G03-02](agent03/report.json). 자동차극장480분은 잠을 잤는데 피로가21.6 증가한다. 식량이 충분한 영화 세트장600분은 각성 피로27을 더한 뒤30을 빼서 순회복이3뿐이다.
- 이전30명 감사 A01의 범위 확대다. 별개 신규 근본 원인 두 개로 부풀리지 않는다.
- 최소 방향: 수면과 깨어 있는 활동의 시간 정산을 구분하되, 모든 짧은 휴식에 완전 회복을 주지 않는다. 끼니·급수·자정 종결은 유지한다.
- 온천의 기분 회복과 피로 증가는 수면을 명시하지 않아 이 확정 목록에 별도로 추가하지 않았다. 호수 낚시/등대 보초도 잠과 같다고 가정하지 않는다.

### GAP07 · P2 · 저녁에도 ‘새벽 두 시’ 방송

- 근거: [agent05 G05-01](agent05/report.json), `audit03.json` rows14–15.19:30의 실제 방송 선택/출력 함수에서 재현했다. 정상 수리·주행 타이머 수신은 별도 정상 저장으로 확인했지만, 잘못된 대사를 자연 주행에서 들은 검사는 아니다.
- 현재 필터는 밤 전체를 허용한다. 본문에는 이 방송이 녹음이라는 표시도 없다.
- 최소 방향: 실제 시각 창과 대사를 맞추거나 재방송 여부를 명료하게 한다. 기존 같은 대사의 음성 자산도 함께 확인해야 하며 텍스트만 바꾸고 청음까지 완료했다고 해서는 안 된다.

### GAP08 · P2 · 정차 중 전체 지도 복원이 다른 지도를 토글함

- 근거: [agent09 GAP09-MAP-RESTORE-TARGET](agent09/report.json), `audit05.json` n13. 실제 정차 경로의 `지도 보기 → 전체 여정` 진입과 Live shell의 capture/restore 함수를 실행했다. 원본 DOM 순서와 실제 버튼 handler를 사용한 격리 검사다.
- 복원은 `ovl-map`을 열어야 하는데 ‘지도’라는 글자가 들어간 첫 버튼을 눌러 지역 지도만 닫는다. 주행 대조군은 전체 지도를 정상 복원한다. 여정 데이터·시간·자원은 보존된다.
- 최소 방향: 텍스트 검색 대신 저장한 도구 식별자와 명시적인 복원 동작을 연결한다. 전체 지도와 지역 지도는 서로 다른 상태다.
- 수용 검사: 정차의 지역 지도 열림/닫힘과 전체 지도, 주행 전체 지도, 저장 재개·의도적 코드 적용·초점·다음 행동. 실제 Studio 새로고침/시각 결과는 후속 확인이 필요하다.

## 이전 우선 문제와 이번 수선의 경계

- 이전30명 A02 레오의 식사 제안은 새 원인으로 세지 않는다. 정상 실패 저장을 다시 읽어 활성 선택0과 미정산 재개를 검사한다. 내부 닫기 함수가 존재해도 플레이어에게 실행 가능한 버튼이 있는지는 별도다.
- 이전 A01은 위 GAP06으로 범위를 넓혔다. 이전 A03 식량0 안개 대기의 식사 본문은 이번 새 숨은 장소 교환과 같은 사건이 아니다. 이전 보고의 미수정 상태를 유지한다.
- 기존 우물 D01의 압박·철수 설계 선택도 그대로 남긴다. 이번 감사가 무료 출구·급수 보장·난도 변경의 승인으로 해석되어서는 안 된다.

## 낮은 우선순위와 판단 보류

- **수리 전 라디오 수신의 장비 관계**: agent03 G03-03와 agent05 G05-02는 같은 후보다. 자동차극장의 차내 수신과 ‘죽은 라디오’ 수리 설명을 정리할 필요가 있다. 별도 FM/단파 장치라는 설정을 임의로 만들거나 모든 사건에 수리 gate를 걸어 진공관 획득 경로를 막지 않는다.
- **온천의 수다 상대**: agent02 A02-03. 혼자 방문했지만 다른 손님일 수 있으므로 없는 동료 등장으로 확정하지 않는다. 한 줄 소개가 필요한지 검토한다.
- **화염병 제작의 연료 여유**: agent06 G06-03. 소모2L 외에3L를 남겨야 하는 조건이 안내에 없다. 실제 소모 오류는 아니다.
- **진행 중 게시판의 약속 금액**: agent08 A08-C01. 공책은 보상을 숨기지만 활성 게시판에는 기본 사례가 남는다. 이미 수락한 계약 금액 재표시를 허용할지 승인된 활성 카드 규칙과 대조한다. 실제 지급은 정확하다.
- **기한 지난 활성 저장**: agent08 A08-D01. 정상 자정 경로는 실패 처리되지만 dawn을 건너뛰어 만든 저장은 공책/게시판이 다르다. 정상 발생 경로를 입증하지 못했으므로 legacy/malformed 저장 방어 후보이지 자연 플레이 확정 버그가 아니다.
- **재이 창고 정상 도달**: agent04 A04-C01. 현장 조건 검사는 통과했으나 자연 저장에서 마지막 개인 대화를 만나지 못했다. 유대 수치만 충분하다고 해금 오류로 판단하지 않는다.

## 정상 확인과 과잉 수선 방지

- 보존 근무 결말은 실제 민지·강우·재이 영입과 회복, 준비 복귀를 통해 완료했다. 강우의 반대와 유대-6도 일치한다. 보존이 불가능하다는 이유로 조건을 완화할 근거는 없다.
- 소문을 통한 숨은 장소 진입 누락은 이전 QA 관측기가 NPC 대화를 실행하지 않았던 범위 문제였다. 게임 전체를 잠긴 지역으로 판정하지 않는다.
- 라디오 수리·진공관 차감·기록·재개·실제 주행 방송, 조달 비용·보너스·정상 자정 만료·지역 후속 유지, 야영 대화 취소·재읽기의 검사 범위는 정상이다.
- 처음 실행의 계측 오류, 정책 정체, 실제 게임 상태 오류는 개별 보고에서 분리했다. 검사 스크립트 성공에는 ‘버그가 그대로 재현됨’을 확인하는 assertion도 포함하므로 게임 무결함 인증이 아니다.
