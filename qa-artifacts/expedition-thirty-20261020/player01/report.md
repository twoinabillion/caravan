# player01 — 공동체형 리더

시드 207001의 첫 실행에서 본편 `story_done` 엔딩에 도달했다. 방법은 `core_sleep`, 여정은 8일·598km였다. **민지와 강우를 실제 부탁·임시 동행·합류 제안 순서로 영입**했고, 배정된 밀양·대구·대전·수원을 모두 방문했다. 생산 코드와 사용자 Studio·저장은 건드리지 않았다.

이것은 실제 소스를 격리 저장소에서 실행한 Node VM 감사다. 사람 플레이, 브라우저 클릭, 화면·음성 QA로 주장하지 않는다.

## 실행과 전편 검토

- 실행: `attempt01` 한 번, trace 416행, 선택 94회. 전 행과 전 선택의 원문·선택지·결과·전후 자원/동료·직전/직후 상태를 읽었다. 선택 26–40 구간에서 잘린 두 항목도 다시 읽었다.
- 독립 xorshift32 가중 랜덤. 매 선택에 25% 균등 분기를 두고 나머지는 동행·돌봄·수리·기록 표현을 선호했다. 모든 활성 선택지의 가중치는 양수다. 실제 균등 분기 28회, 성향 분기 66회. index 분포는 0=54, 1=37, 2=2, 3=1이다.
- 선택 전 94회 reload와 선택 후 94회 reload를 통과했다. 지급 후 재해결은 모두 `applied:false`였다. 중복 비용·영입은 관측하지 못했다.
- 근거는 [전체 trace](attempt01/player01-trace.json), [요약](attempt01/player01-summary.json), [정책](policy.cjs), [상세 발견](findings.json), [실행 카운터](policy-evidence.json)에 남겼다. 정책의 긴 stdout은 도구에서 중간이 잘렸으므로 호출별 균등/성향 로그가 전부 파일로 남았다고 주장하지 않는다.

## 발견

확정한 게임 진행·논리 오류는 0건이다. 낮은 심각도의 시간 표현 불일치 후보 1건을 남겼다.

**P01-01 — 대세탁의 ‘두 시간’과 실제 150분.** `wx_bigwash`의 유일한 선택 ‘대세탁을 집행한다’ 결과가 ‘두 시간의 대세탁’으로 시작하지만, 실제 시각은 상주 5일 06:30→09:00이고 저장 영수증은 ‘2.5시간 경과’다(n195–199). 물 17→15, 민지/강우 동행, 피로 0→0이며 다음 행동은 정상 reload 뒤 민지 대화였다. 준비·널기·건조에 30분을 썼다는 해석은 가능하다. 현재 문장에는 그 회계가 드러나지 않으므로 총시간을 맞추거나 부가 시간을 한마디 설명하면 된다. 원래 시간 효과는 바꾸지 않았다. 실행 이후 소스 확인에서 `time:150`과 같은 문구를 확인했다.

## 동료와 보존 감시

민지는 경주에서 3일 00:31, 강우는 구미에서 4일 13:28에 정식 합류했다. 엔딩 상태는 민지 사기87·유대29, 강우 사기85·유대17이며 두 사람 모두 부상은 없다. 민지의 임시 도르래와 퓨즈 접시, 강우와 나눈 경계·휴식 순번이 후속 야영 및 엔딩에 남은 점이 좋았다.

좌석·침상 구매는 실행하지 못했다. 좌석칸은 실제로 구매 가능했으나 정책이 비용 외 고철30을 남기려 해 미뤘다. 대전에 6일19:42에 도착해 야간 서비스와 은수의 영입 기회를 지나쳤고, 식량 부족으로 이후의 개조도 미뤘다. 이 실행으로 구매·설치 실패를 발견했다고 말할 수 없다.

마지막 결정의 보존은 ‘감시 근무를 설 사람 2/3 — 근무 가능한 동료 1명 더 필요’로 비활성 상태였다(n406). 건강·사기는 좋았지만 정식 동료가 둘뿐이므로 조건과 일치했다. 실제 ‘수원으로 내려가 준비한다 · 60분’ control도 있었으나 이 정책은 일반 활성 선택지에서 격리 수면을 골랐다. 따라서 준비 귀환·세 번째 동료·보존 실행 결과는 **미검증**이다.

## 의견과 한계

후반 연료 지원이 5시간→11시간→5시간으로 길어지고 공복·탈진까지 겹쳐, 더 많은 사람을 모으러 돌아갈 여유가 빠르게 줄었다. 내 정책은 밤에 도착한 대전에서 출발을 서둘렀고, 식량 부족 시 야영을 피하는 규칙 때문에 피로100에서도 이동했다. 이는 정책의 보급 계획 실패이며 게임 softlock으로 보고하지 않았다. 감시 세 명 조건과 좌석 확장의 연결을 일찍 알면 공동체 지향 준비에 도움이 되겠다는 의견은 있지만, 실제 UI에 그 안내가 없는지까지는 이 어댑터로 알 수 없다.

`피로 +10.26541` 같은 raw trace 숫자는 UI 오류로 채택하지 않았다. 실행 후 확인한 reader가 한 자리 소수로 표시한다. 시간 경과로 생긴 피로를 뒤의 회복 효과가 줄이므로, 결과 영수증의 피로 회복량이 행동 전체 전후 차이와 다르다는 이유만으로 비용 오류를 만들지도 않았다. 임시 승객이 정식 party에 없거나, 에필로그가 현재 엔진 시각보다 뒤의 일을 서술하는 경우도 오류 후보에서 제외했다.

추가 실행, 시드 교체, 자원·동료·개조·엔딩 강제 지급은 없었다. 수정은 하지 않았다.
