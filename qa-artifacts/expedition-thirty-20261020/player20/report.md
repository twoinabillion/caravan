## 정책 실패와 독립성 한계

첫 시도는 미확보 의약품 조달 목적지를 계속 왕복하고, 좌석2/정식 동료2인데 ready 레오 영입 지점을 다시 쫓았다. 결국 물·식량·고철이 고갈됐다. 이 왕복과 갈증 사망은 정책의 계획 오류이며 게임 softlock으로 보고하지 않는다. 현장일 선택도 때로 국수·촛불처럼 비용을 내는 일을 고철 벌이로 잘못 골랐다.

원정책은 [policy-attempt01.cjs](policy-attempt01.cjs)에 보존했다. [policy.cjs](policy.cjs)는 현재 공개 need 품목 구매, 미확보 조달품/자리 부족 ready 영입 추적 해제, 선택적 우회 거리·날짜·동일 방향 반복 한도를 더했다. 시드는 그대로이며 결과별 정답표, 자원 지급, 강제 엔딩 선택은 없다. 선택은 독립 xorshift32로25% 균등 탐색과 양수 성격 가중치를 섞었다. 같은 프로세스의 실행 후 증거에서 균등65회/성격 가중219회가 남았다.

첫 실행 전 공개 observation/action 스키마를 찾는 과정에서 공용 runner의 내장 `defaultDecision` 일부가 함께 노출됐다. 이전 플레이어 정책·보고·발견·미래 결과 소스는 읽지 않았고 내장 정책을 호출하거나 복사하지 않았지만, 완전히 블라인드인 정책 개발이라고 주장하지 않는다.

새로 알려진 hidden 장소는 attempt01에서 호수·통신탑·책의 터널을 실제 방문했다. 주로 실패 왕복 중 진입한 기록이므로 계획적인 탐험 성과로 포장하지 않는다. attempt02는 배정 경유지를 모두 거쳐 엔딩에 도달했고 hidden 새 방문은 없다.

## 전수 검토와 검증 범위

[review.cjs](review.cjs)로 모든 행을 순서대로 출력했다. 선택마다 본문·옵션·선택·결과·출처와 장소·시각·자원·일행의 전후 상태, 즉시 인접행을 읽었다. 같은 텍스트는 첫 출현 전문을 검토하고 후속 발생은 `SAME` 사전 참조 및 해당 상태/선택/효과로 검토했다. 출력이 잘린 구간은 다시 읽었고 샘플링하지 않았다. 중복 열람은 검토 합계에서 중복 계산하지 않았다.

모든 n이1부터 연속했고 모든 실제 선택이 enabled/visible이었다. unpaid 재개284회는 성공했고 paid-result 재개284회는 `replayed:true`, `applied:false`, 전후 snapshot 완전 동일이었다. 완료장부28건도 실제 delta와 맞았다. [build-findings.cjs](build-findings.cjs)는 이 검증과 근거 묶음을 읽기 전용으로 다시 산출한다.

`origin:memory`/지난밤 사건은 현재시각 모순에서 제외했다. 정식 party 밖의 임시 승객은 인물 부재로 단정하지 않았다. 원시 chip의 긴 소수점은 렌더링을 검사하지 않은 상태에서 UI 결함으로 세지 않았다. 반복 ready 영입 진입은 어댑터의 자동 진행과 수락 정책 영향을 받으므로 실제 UI 반복 결함으로 세지 않았다.

이것은 격리 저장소의 Node VM 실엔진 실행이다. 실제 사람, Studio 화면, 시각·음성·클릭·키·터치 검증을 수행하지 않았다. 사용자 Studio/서버/저장 파일에는 접근하지 않았다. 엔진 재개 성공은 브라우저 읽기 커서·스크롤·현재 도구 복원을 검증한 뜻이 아니다. 보고 파일 외 생산 소스나 다른 플레이어 폴더는 수정하지 않았다.
