# player30 원정 결과

seed 207030, ‘계획을 자주 바꾸는 호기심형 실험가’ 정책의 첫 실행으로 메인 결말 `story_done / core_transfer`에 도달했다. 13일째, 누적 975km였다. 안동·영동·이천·속초를 모두 방문했다. 추가 실행은 하지 않았다.

508행과 106회 선택을 전부 순서대로 읽었다. [review-ledger.json](review-ledger.json)에 연속 구간별 검토 수를 남겼다. [review.cjs](review.cjs)는 모든 선택 본문·선택지·결과, 전후 상태와 직전·직후 행동을 출력한다. 미지급 진입과 지급 결과의 저장 재개는 각각 106회였다. 지급 결과 재개에 상태 변화나 효과 재적용은 없었다. 27번의 출발 모두 공개 forecast가 허용한 경로였다.

확정 결함은 0건이다. 긴 소수가 결과 칩에 남은 두 사례는 실제 UI 소비자를 따라가 기각했다. `n326` 현장활동의 `피로 +1.4039`는 `storyFeedbackChip`을 거쳐 `+1.4`로, `n443` 전투 후퇴의 `연료 -3.693782L`는 `−3.7L`로 표시되는 코드 경로다. 연료는 보유 3.6937821666661135L를 소진한 것이므로 청구량도 맞았다. 이 확인은 실행 뒤 좁은 소스 추적으로 했으며, 화면을 보았다는 뜻은 아니다. 자세한 인용·인접 행·전후 물자는 [findings.json](findings.json)의 `rejected`에 있다.

숨은 장소의 실제 방문은 0이다. `n139`에서 멈춘 케이블카가 발견됐고, 다음 공개 관측 `n141`에는 문경에서 16km·84분·연료4L의 직접 경로가 있었다. 연료22.429L, 물23, 식량12였고 `check.ok=true`, `forecast.ok=true`, `shortage=false`, 준비도 ‘여유’였다. 경로 게이트나 보급 부족이 방문을 막은 상황은 아니었다. 정책이 영동에서 정한 속초 목표를 유지해 충주로 출발했다.

이후에는 목표를 정할 때마다 배정 목적지에도 `optional` 횟수를 올린 설계 때문에 9회가 누적됐다. 안동까지 마친 뒤 비배정 목적지 후보를 여는 `<8` 조건이 닫혀 있었다. 이 실행은 1–2일 우회 자체는 감수했지만, 배정 목표를 새로 발견한 숨은 장소보다 우선한 정책이었다. 숨은 곳 접근성을 검증했다고 말할 수 없다. 이 한계를 채우기 위한 재실행은 하지 않았다.

다른 정책 한계도 있었다. 밀양에서 탱크 여유가 10L 미만인데 10L 묶음을 8회 재구매하려다 거절됐다. 시간·물자 전체를 차단 키로 삼아 다른 행동 후 같은 실패를 다시 시도한 탓이다. 비용이나 연료는 줄거나 늘지 않았다. 오래된 게시판의 `boardAt/boardDay`를 확인하지 않아 원주·이천에서 수락 시도 3회가 거절된 것도 정책 실수다. 북부 왕복 때 시장이 있는 보급 경유지를 충분히 계획하지 못해 연료 위기 9회와 허기·졸음을 겪었고, 수원 시장에서 실제로 회복했다.

무작위 선택의 25% 균등 분기는 실제 23/106회, 나머지 성향 가중 분기는 83회였다. 모든 enabled 선택의 기록된 가중치는 양수였고 선택 index는 0·1·2·3·5로 갈렸다. 카운터와 결정 때 받은 공개 관측은 같은 실행 프로세스에서 저장한 [adapter-policy-evidence.json](attempt01/adapter-policy-evidence.json)에 있다. 동료 제안을 받은 적은 없었고, 영입·개조·제작을 실행하지 않아 그 영역은 평가 범위 밖이다.

좋았던 부분은 속초 노인의 부탁이 종장의 실제 선택과 답변으로 돌아온 점이다(`n211→492`). 큰 우회의 의미가 마지막 대화에 남았다. 반복 검문소 5회는 피로하게 느껴졌지만, 도구 미제작과 같은 길 왕복을 택한 정책의 영향이 커서 페이싱 의견으로만 남겼다.

이 원정은 격리된 Node VM 엔진 실행이다. 사용자 Studio·브라우저·저장·서버와 production 파일을 건드리지 않았다. 텍스트·상태·결과·저장 재개를 검토했으며 실제 화면, 클릭, 크롭, 오디오, 애니메이션, 네이티브 폰 품질은 검수하지 않았다.
