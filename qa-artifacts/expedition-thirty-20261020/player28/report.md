# player28 — 저장 후 자주 돌아오는 신중파

seed 207028의 첫 실행에서 메인 엔딩 `story_done / core_transfer`에 도달했다. 6일차 09:31, 443km이며 무주·청주·수원을 모두 방문했다. 추가 시도는 하지 않았다. 확정 결함은 0건이다.

`attempt01/player28-trace.json`의 287행과 60개 선택을 전수 순차 검토했다. `review.cjs`가 모든 선택 전문·라벨·결과·origin, 전후 장소·시간·자원·동료, 인접 행과 일반 행동을 출력한다. 최초 출력에서 잘린 15~25행도 별도 재출력해 보충했다. 고유 검토 범위별 행/선택 수는 1~40: 40/10, 41~70: 30/4, 71~100: 30/5, 101~130: 30/6, 131~160: 30/4, 161~190: 30/6, 191~210: 20/5, 211~230: 20/6, 231~250: 20/5, 251~270: 20/4, 271~287: 17/5다.

재개는 미지급 진입 61회, 지급 결과 60회, 정책이 공개 `reload`로 요청한 일반 재개 24회, 총 145회다. 모두 load에 성공했고 각 재개 행의 전체 공개 before/after snapshot은 정확히 같았다. 지급 결과는 60회 모두 `replayed:true / applied:false`였다. 일반 재개는 장소와 행동 유형을 키로 한 번씩, 전체 24회로 제한했다.

행 47~53에서는 밀양 도착→재개→연료 거래→재개→다음 거래, 공동 펌프 작업→재개→민지 만남이 연결됐다. 행 65~68에서는 야영 전후 재개를 거쳐 다음 출발로 이어졌다. 무주에서도 행 98~106의 재개→야영→재개→재이 만남→재개→탐색이 연결됐다. 자원·동료·업그레이드를 주입하지 않았고 출발은 공개 forecast의 부족 게이트를 따랐다.

마지막 결정에서 실제로 제시된 `수원으로 내려가 준비한다 · 60분`을 행 267에서 사용했다. 서울 5일차 18:20, 연료 44.596/물 17/식량 9/고철 83/동료 0에서 수원 19:20으로 이동했다. 다음 목표는 준비 후 서울 복귀였다. 행 268 연료 구매, 269 야영, 270 서울 출발, 275 도착, 276 미지급 재개를 거쳐 277의 마지막 결정으로 돌아왔다. 이미 지급한 서울 단계 다섯 장면을 다시 진행하지 않았다. 행 278의 지급 재개 뒤 후일담과 최종 결과까지 이어졌다.

민지·재이·은수의 동행 제안을 실제 선택에서 사양해 동료는 끝까지 없었다. 이 때문에 야영 대화가 열리지 않았고 `camp-later`의 실제 취소·재개는 확인하지 못했다. 일반 재개 24회 상한도 대전 행 146에서 소진돼 준비 귀환 후 수원 road의 일반 재개는 미검증이다. 단, 그 뒤 사건의 미지급·지급 재개는 계속 실행했다.

독립 xorshift32로 각 enabled visible 선택에 양수 가중치를 줬다. 호출별 25% 확률로 균등 탐색했으며 실제로는 균등 11회, 성향 가중 49회였다. 선택 index는 0~4에 분산됐다. 61번째 선택 호출 중 한 번은 실제 준비 복귀 control이다. 런타임 카운터는 같은 실행 프로세스가 쓴 `attempt01/adapter-policy-evidence.json`에 있다.

취향 의견으로는 행 190~233의 수원 본편 12개 선택이 같은 탐색 행동에 집중돼 호흡이 촘촘했다. 반면 결정을 미룬 후 정착지 행동을 하고 마지막 결정부터 이어가는 경로는 신중파 성향에 잘 맞았다. 이 의견을 결함으로 세지 않았다.

의심한 세 항목은 기각했다. 별도 이음망 만남 없이 결말에 등장하는 것은 행 232의 공개 회의에서 실제 수락을 받았기 때문이다. 첫 실행 후 해당 회의의 정의와 reading turns만 국소 확인했다. 오전 시계에서 밤을 말하는 행 280은 명시된 에필로그다. 최종 trace 행의 `ended:false`는 결과를 닫기 전 deferred-ending snapshot이며, 결과 닫기 후 최종 summary는 `ended:true / storyDone:true`다.

이 감사는 실제 유한 자원 엔진 API 실행이며 실제 Studio/브라우저 조작이 아니다. 사용자 저장·서버·production 파일을 건드리지 않았다. `G.save/G.load`와 receipt 재해결은 실제 `browserContinue`, 읽기 커서, 결과 Continue 클릭, 열어 둔 도구, 화면·이미지·음성 QA를 인증하지 않는다. 어댑터가 자동 처리한 서울 진입의 실제 버튼 발견 가능성도 평가하지 않았다.

상세 관측·인접 증거·정책 한계·기각 사유는 `findings.json`에 있다. 최종 자원은 연료 49.677, 물 18, 식량 9, 고철 73, 차체 82.3, 피로 12.523이며 동료는 없다.
