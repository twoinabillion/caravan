# 반복 어두 경고 검토

6차 고정본의 대사 검사에는 박 선생 `자네` 10회, 재이 `그럼` 10회라는 자동 수동검토 후보가 남는다. [검출된 20개 표본](manual-opening-candidates.json)을 직접 읽었다.

박 선생의 표본은 발밑의 물건, 손 진료, 배분한 몫, 글씨, 얼굴과 타인의 눈을 가리키는 서로 다른 말이다. `자네`는 해당 인물의 기존 호칭이다. 재이는 상대의 말에 답해 짐을 옮기거나 분류하고, 의미를 되묻는 서로 다른 반응이다. 같은 문장 복제나 이 표본만으로 확정할 인과 모순은 발견하지 못했다. 경고 수를 없애려고 호칭·접속사를 일괄 교체하지 않았다.

이는 20개 문장 표본의 텍스트 판정이다. 모든 인접 대화의 새 전편 검토나 실제 청음·연기 리듬의 승인으로 확대하지 않는다. 자동 경고와 임계값은 그대로 유지한다.
