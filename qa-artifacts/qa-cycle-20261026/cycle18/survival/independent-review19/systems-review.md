# 19 수선 독립 검토 · systems

18 동결본과 현재 `src/04e-engine-world.js`, `src/04f-engine-quests.js`를 직접 대조했다. 생산 변경은 각각 한 줄이며 이 검토에서는 편집하지 않았다.

- 편지 완료 문구는 이름에 붙인 `이(가)`를 이미 쓰이는 `D.withParticle(name, '이', '가')` 호출로 대체했다. 헬퍼는 한글 끝 글자의 받침을 검사하며 비한글은 기존 정책대로 열린 조사를 쓴다. 지급액·조기 완료 보너스·NPC 태도·완료 상태·노트 제목과 저장 순서는 그대로다.
- 동료 다음 행동 안내는 실제 `S.driving`이 있을 때만 `정차한 뒤`를 붙인다. 유대·스토리 단계·영입·특기 선택 조건은 그대로이며, 정차 중에는 이미 정차해 있는데 다시 정차하라고 하지 않는다. 안내를 고친 것이며 대화를 즉시 실행하거나 조건을 바꾸지 않는다.

`tests/test_qa_cycle18_systems_copy.cjs`를 독립 실행해 **10/10 통과**했다(`systems-copy-tests.txt`). 테스트를 읽어 한글 받침/무받침/영문, 정상 완료 1회 지급, repeated handoff 거절, 여섯 동료의 주행/정차 안내, 다른 임무 단계 불변을 확인했다.

저장 경계도 확인했다. 자연18의 `entry-331-exp_glasshouse-export.json`에 이미 저장된 옛 편지 노트는 수정하지 않는다. 구름·고향 대화의 새 지급 결과는 18 동결본과 자원·효과·칩이 같고, 기존 paid receipt의 본문·안내 업데이트·reader view 또는 text-only 상태를 재지급 없이 보존한다. 구름/고향의 옛 paid 증거는 동결18 정상 unpaid에서 분기한 **cohortExcluded fixture**이며 추가 자연 원정으로 세지 않는다.

검토 결과: 추가 결함 없음. 현재 두 줄의 수선은 보고된 원인에 맞고 효과·저장 경계를 좁게 지킨다.
