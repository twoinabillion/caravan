# Cycle 19 준비 · 실행 전

새 동결을 받은 뒤 seed279001 정상 새 게임 1회를 실행한다. 아직 새 게임이나 부분 재생은 시작하지 않았다. 민지·재이·은수 정상 영입과 `core_quarantine`을 목표로 하되 실제 공개 조건과 엔딩 도달을 우선한다.

18차 정책에서 확인된 두 원인을 먼저 고친다. 현재 정착지의 이용 가능한 거래를 다른 보급 경로보다 먼저 사용한다. 목표 보급처로 가까워지는 길이 자원 부족으로 막혔을 때 허용되는 반대 길을 타고 왕복하지 않고, 현재 공개 연료 확보·휴식·작업 중 가능한 행동으로 조건을 회복한다. 경로가 실제로 목표에 가까워지는지 기록한다. 출발 전 식량·물·연료와 다음 정착지까지의 공개 예측을 함께 확인한다.

좌석은 세 명이 합류하기 전에 정상 구매한다. 동료는 해당 정착지에서 제안을 듣고 개인 부탁·임시 동행·야영 조건을 거쳐 수락한다. 능력·제작·의뢰는 정상 물자 여유가 있는 기회에만 사용하며 희귀 사건을 강제로 뽑거나 이미 지나온 지도를 무한 탐색하지 않는다. 목표 인물이나 결말이 불가능하면 실제 범위로 보고한다.

모든 실제 entry/result reader·선택 힌트·노트·짧은 말·NPC 첫 인사/후속·그림 키를 수집하고, 매 선택의 entry/paid reload와 40src 시작/종료 비교를 유지한다. 화자·기록 출처·주행/정차·현재/회상/계획을 실제 시간순으로 판정한다. 단편 문구만 보고 첫 주행이라고 단정했던 18차 실수를 반복하지 않는다.
