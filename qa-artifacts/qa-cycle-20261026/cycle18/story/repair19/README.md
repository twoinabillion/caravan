# 19차 준비 — 주행 대사 시점 수선

18차 전편 검토와 종료 40개 source 확인 뒤 승인된 15개 문자열만 바꿨다. 민지의 레일 대사는 이미 운전석에 앉아 있는 사람에게 현재 자세를 묻는다. 검증키·손씻기는 다음 정차를 약속하며, 마지막 서술도 그 일을 미리 끝내지 않는다. 오프닝 콜백은 실제 오프닝 선택의 회상과 다음 정차의 점검 계획으로 정리했다. 열쇠 위탁은 새 무전이나 단골의 완료 확인을 만들지 않고 원래 부탁을 떠올린다. 약 운반 기억은 수첩을 펴는 대신 부탁을 되뇐다.

자연 확정은 본인 원정의 민지 2건을 유지한다. 손씻기, 기록 이름 쓰기, 나머지 정비 콜백은 명료성으로 분리했다. `answer_call`의 ‘다음 정차에서야’는 최초 보고와 달리 김해 도착·사건·탐색 이후 주행에서 나왔으므로 이전 정차의 회상일 수 있다. 미래 완료 확정을 철회했으며, 초기 원시 관측과 실패 로그는 보존했다. `record_names`도 survival 최종 판정의 회상 가능성을 유지하여 추가 확정 수로 올리지 않았다. 변경하지 않은 오프닝 4개와 약 운반 거절 분기도 보존했다.

`copy-delta.json`은 정확한 이전/새 문자열 15개, `before.json`은 전체 대상 정의다. 두 source 파일을 이 15개 문자열만 이전 값으로 되돌리면 frozen18 원문과 바이트가 같다. 화자·조건·선택 순서·거리·사건 수·once·arc·관계·효과는 바뀌지 않았다. event corpus에 변화가 없어 기존 역사 해시나 projection 파일을 수정할 필요가 없었다.

회귀는 `tests/test_qa_cycle18_driving_copy.cjs`: 수선 전 4 통과·6 실패, 후 10/10 통과. 실제 picker, 11개 오프닝 callback의 주행/거리/사건 게이트, 일회성 reload, 새 약 운반 기억 snapshot, 이전 echoLines, 이미 완료된 opening 결정, 기존 paid reader와 text-only reader를 검사했다. 관련 기존 대사·오프닝·chat·기억 검사는 50/50 통과했고 lint 오류는 0이다. 전체 테스트와 빌드는 root 담당이다.

기존 주행 chat에 유료 receipt가 있다고 주장하지 않는다. 오프닝 콜백 문구는 별도 snapshot 없이 현재 정의를 참조하지만, 이미 재생한 결정의 callbackEchoed는 그대로여서 다시 재생되지 않는다. 실제 원정18의 speech·trace·source snapshot을 고치지 않았다. 약 운반 기억은 저장된 echoLines가 있어 옛 문구를 그대로 재생한다. old-meet-paid.json은 정상 원정18 unpaid를 frozen18 엔진에서 선택해 만든 별도 회귀 fixture이며 새 자연 원정으로 세지 않는다.
