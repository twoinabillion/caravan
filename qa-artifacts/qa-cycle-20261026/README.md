## 방법과 증거

- 각 담당이 다른 seed/정책으로 실제 게임 엔진의 공개 행동을 사용했다. 유한 자원·정상 영입·개조·보급·엔딩을 유지하며, 완주한 경로의 진입/결과 대사를 끝까지 검토했다. 이전에 읽은 것과 정확히 같은 본문은 동일성 대조로 구분했다.
- 기지급 결과/미지급 선택 저장을 다시 불러 재지급과 상태 변경을 확인했다. 자연 여정, 정상 저장 재개, 자원0/시각/부상/종료 경계 fixture를 분리한다.
- 영입 거절·좌석 정책 실수·음식0에서의 과도한 이동 거부 등 QA 정책 실패는 원본을 보존하고 수정해 재시도했다. 재시도는 독립 참가자나 새 seed로 부풀리지 않는다.
- 주 담당은 실제 Chrome 모바일 화면에서 오프닝, 지도 복원, 백업 파일, 진료대/등대 이미지, 제작, 정상 저장에서의 엔딩 이후까지 직접 조작했다. [브라우저 검수 및 화면](browser/README.md).
- 작업 전부터 변경돼 있던 저장소를 `/Users/sang/_workspace/caravan-qa-cycle-20261026-before`에 보관했다. 이번 변경은 git HEAD가 아니라 그 시점과 비교한다. [작업 전 상태](baseline.json), [이번 파일 변경](changes-current.json), [생산 코드 차이](production-current.patch).

## 고친 문제

### 진행·정산·저장

- 식량0/민지 부재에서 레오의 식사 제안에 실행 가능한 선택이 없던 문제. 기존 선택 인덱스 뒤에 비용·보상 없는 응답을 추가했다.
- 명시적으로 잠을 자도 각성 피로가 누적되던 시간 정산. 부분 수면은 기존 회복량을 유지하고, 완전 수면과 구분했다. 식사·급수·자정 종료는 그대로다.
- 무기 선반 할인 견적/허용/실제 결제가 달랐던 제작. `craftQuote`가 세 경로의 비용·시간을 공유한다. 화염병의 소모2L/필요5L/남길3L도 표시한다.
- 제작·수리·개조·라디오·탐색·시장 거래 중 여정이 끝나도 효과음/패널/추가 거래가 이어지던 경계. 엔진과 실제 UI 콜백 양쪽을 보호했다.
- 운전자를 진료했는데 더 오래 다친 동료가 낫던 사건의 치료 대상.
- 저녁에도 ‘새벽 두 시’라고 하던 방송의 실제 수신 시각 창.
- 정차 전체지도 복원에서 지역지도를 대신 토글하던 live shell의 버튼 선택.
- 자발적 교환·기부·식사·목욕·치료에서 자원0으로 정상 보상을 받던 조건. 숨은 장소3개, 만화방/보리, 추가29선택, 아이들2선택/박 선생 물 치료를 각각 검증했다. 원래 강제 손실·비상 탈출은 무조건 비용 gate로 막지 않았다. [29선택 원인과 경계](cycle3/survival/payment-report.json).
- 비용 조건 추가로 모든 응답이 잠길 수 있는 이발소·터널 창고·서커스·아이들에게 무료 응답을 추가했다. 기존 확률/효과/인덱스와 옛 지급 결과는 유지한다.
- 순증가 효과만 있어 놓쳤던 죽통밥·사냥꾼 소금·뻥튀기 옥수수 교환도 최초 식량1을 요구하도록 고쳤다. 필요할 때만 기존 선택 뒤에 무료 응답을 붙였다. 교환 표현이 있는 순증가 후보42개를 검토했고, 식량0/0.5/1·재개·과거 지급 경계를 확인했다. 죽통밥은 자연 여정에서 발견 후 경계 재현, 나머지2곳은 같은 원인의 정적 파생 검토다.
- 일반 정착지에 들어가기만 해도 활성 조달 의뢰가 자동 완료되던 오류. 허브/장터/취소는 상태를 유지하고, 명시 전달만 한 번 지급한다. 실제 Chrome에서 동일 정상 저장의 수정 전/후와 지급 후 새로고침을 확인했다.

### 이야기·대화·이미지

- 안개/눈길/병중 휴식의 없는 음식을 먹었다는 표현, 오전/밤/정오와 어긋나는 수면·호수·온천·등대 결과.
- 미영입 민지의 송곳을 빌렸다는 레오 대사, 미만남 DJ의 말·박 선생의 미발생 약속·은수의 미발생 이전 수업/대화.
- 즉시 결과에 미래의 반복 행동을 확정하던 레오 공연·은수 방송·민지와 정비·명명식·강우 훈련 문장.
- 맑은 날 박 선생 대사의 빗소리/미발생 계곡 취수와 마지막 대사의 잘못된 화자.
- 오프닝 민원 사본 중복 전달, 혼자 꽃 아래 ‘둘러앉는’ 장면, 서울 진입의 미소지 편지·봉투 표현, 편의점의 흡연 설정 충돌.
- 소문으로 발견한 쇼핑몰에서 미획득 아이의 크레용 지도를 소유했다고 하던 진입/결과/노트.
- 인계 엔딩에서 실제로 연결하지 않은 이음망이 응답하던 고정 문구. 실제 연결 거점의 채널을 따른다.
- 소방복과 부품 보상 출처, 공구함/셔터 열쇠 관계, 지역 접촉으로 완료한 연락망 설명, 못판70분/작전지도 출처, 도보 구제의 보유분 최대소모, 빌린 연장 반납을 명료화했다.
- 수리하지 않은 라디오로 영화 소리를 듣던 결과를 실제 수리 상태에 맞췄다. 새 장비 설정/수리 필수 gate를 만들지 않았다.
- 실제 진료대와 맞지 않던 버스/발전기 그림을 진료 물품 장면으로, 등대 점검을 내부 비상등/일지 장면으로 교체했다. canonical 스타일/크기/자산 등록과 실제 모바일 크롭을 확인했다.
- 문서·방송 뒤 다시 말하는 동일 인물의 이름이 생략되던 페이지 렌더러. 실제 엔딩에서 재현 → 같은 저장의 같은 페이지로 수선 확인했다.
- 수락한 활성 게시판 카드에서 보상을 미리 노출하던 문구. 수락 전 제안과 실제 인계 보상은 유지한다.
- 실제 새벽 입실·낮 수면에도 고정된 영화 세트장의 저녁/하룻밤 표현을 시각에 의존하지 않는 휴식과 식사로 정리했다. 600분·식량·기존 회복과 과거 지급 문구는 유지한다.
- 비용 토론에서 조회 예약자를 만난 할아버지로 단정하던 은수의 남은 인용을 중립화했다. 확인한 것은 면사무소 예약이며 신원은 확인되지 않는다.
- 선택지의 `위험 · 위험` 중복과 시장 소문의 `밀양 장터은` 조사를 고쳤다. 구체적인 위험 설명·비용·동료 반대는 유지하며 실제 선택 화면도 확인했다.

## 검수 범위의 한계

6명 동료와 보리를 실제 영입한 경로, 세 본편 결말을 정상 조건으로 완료한 경로를 확보했다. 모든 무작위 사건·모든 이미지·모든 동료 조합이 자연 발생한 것은 아니다. 누적 원본 재감사에서 인식표는 6차 시스템 두 번째 정상 여정 trace278에 실제 발생·지급됐음을 확인했다. 앞선 인식표 미발생 표기는 누적 범위에 대해 잘못된 제한 설명이어서 바로잡았다. 보리 냄새 추적 등 미발생 세부 피처와 실제 라디오/부상 경계의 자연 발생 여부는 담당 보고에 분리했다. 보리 가족 찾기는13차 별도 정상 저장 분기에서 확인했다. 이번 추가 이미지의360px 검수는 viewport 제어 timeout과 file: URL 보안차단으로 완료하지 못했으며480px 실제 영역 검수와 구분한다. 차단 경로를 우회하지 않았다. 실물 휴대폰·청음·패키지 설치·성능 전수 측정은 하지 않았다. 21차 HTML은109,231,962바이트로 기존 권장32MB를 넘는 경고가 남는다. 대사 반복 수동 후보2개는 [20개 표본을 직접 검토](manual-opening-review.md)했고 확정 오류로 판정하지 않았으며 자동 경고를 숨기지 않았다. 배포·commit·push는 하지 않았다.

## 15차 발견 → 16차 수선

- 합류 직후의 사흘 전제, 좌표를 태운 뒤 좌표가 남았다는 은수 합류, 정품 확인 대화의 미발생 어제 전제를 정리했다.

- 40분/0분 말다툼 결과의 며칠 침묵, 주간 영화의 밤 표현, 주행 중 차 밖 바퀴 점검을 현재 반응/시간 중립/다음 정차 약속으로 맞췄다.

- 전파사의 일반부품 지급을 특정 라디오 진공관 획득으로 오해시키는 명칭을 정리했다. 실제 과거 진공관 저장의 별도23선택·124기록·공동감시 결말은 본 집계에서 제외했다. [라디오 정상 분기](cycle15/systems/old-radio/report.md), [실제 브라우저 수리·방송 확인](cycle15/radio-ui-review.json).
- 고래 앞바다/와인 철도터널/얼음골/무인 빗물 저수조의 새 전용그림4장을 생성했다. 원본·프롬프트·갤러리 선검수는 [이미지 근거](cycle15/visual/provenance.json)에 보존했고16차 새 진입에서 네 그림 모두 실제480px 선택·결과·길 복귀를 확인했고, 고래 확대·복원과 저수조 복원도 통과했다. 기존 범용 자산은 다른 사건을 위해 유지했다.
