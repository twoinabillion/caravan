# Cycle 8 준비 — 실행 대기

- 새 seed268003, fresh 한 번만 실행한다. 현재는 정책 문법 검사만 했고 `attempt01`이나 새 여정은 만들지 않았다. root의 source freeze와 LF hash 일치 확인 전 실행하지 않는다.
- 재이·박 선생·레오를 공개 영입 조건 안에서 우선하며 무주·전주·광주·등대 방향을 탐색한다. 임시 동행이나 좌석 제한으로 성사되지 않은 목표는 미검사로 기록한다.
- 자체 cycles1–7의 모든 보존 attempt coverage를 읽어 미선택 쌍을 우선한다. 신규 선택이 없으면 event ID로 결정되는 다른 공개 선택을 사용한다. 재이05가 자연 발생하면 수선된 고철 선물 답을 고른다. 재이09와 보리 후속은 실제 발생·표시된 선택만 사용한다.
- 공개 야영 대화는 실제 참가자 중 한 명과, 잠들기 직전 완료된 대화가 없을 때만 진행한다. 수면 전 대화는 공개 `G.prepareCamp`를 기존 adapter로 호출한다. 기존 결과나 날을 주입하지 않는다.
- 보급·지역 작업·연료 구제와 합법 출발을 사용한다. 경고가 있는 출발까지 필요해지면 그대로 기록한다. 최대1800행동·35일, 선택 피처를 강제로 만들기 위한 재시도나 무한 반복은 하지 않는다.
- 실행 뒤 모든 선택의 실제 entry·result를 다시 읽는다. 이전 본문과 동일한 범위와 새 문구·새 인물/시간 맥락을 구분한다. 이미지·crop·실제 UI 증거는 root의 별도 검수이며 이 Node VM의 주장에 포함하지 않는다.
