# 23차 정적 미관측 경로의 실제 reader 확인

완료된22차까지 관측하지 않은7개 사건의 본문과 모든 선택 결과를 읽고 실제 production parser의 화자를 대조했다. 정상 원정에 더하지 않는 명시 fixture이며 대금 지급·저장 복원·자연 도달·브라우저 검사 증거가 아니다. [전체 원문/reader](reader-before.json), [실행 코드](inspect-unvisited.cjs). 소스40개는 동결23과 시작·종료 모두 같다.

- `comp_pss_night`, `pss_daejeon`, `pss_forgive`, `kw_base`: 박 선생/주인공/수진/환자의 아들/강우의 연속 발화와 응답이 본문에 맞았다.
- `comp_water_fight`, `comp_sick`, `comp_polaroid`: 실제 화자가 본문에 맞았다. 물 배급의 선택1은 물을 차감하지 않는데 이미 반 통을 쓴 것처럼 읽히는 문구를 독립 검토 후보로 보존했다. 물통 용량을 추정해 숫자 버그로 확정하지 않았다. 생존 담당의23전편 검토 후 판정을 기다린다.
- 이전 파생 회귀로 수선된 폴라로이드는 이번 감사에서도 자연 도달로 부풀리지 않는다.

신규 화자 오류를 확인하지 못했다는 범위만 유효하다. 이7건의 모든 상태 조합이나 게임 전체가 무결함이라는 뜻이 아니다.
