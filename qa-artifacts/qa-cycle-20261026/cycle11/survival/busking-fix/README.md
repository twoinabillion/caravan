11차 자연 원정 trace475에서 확정한 시간·장소 인과 오류를 root 승인 후 수정했다. 담당 변경은 src/03-data.js의 pair_leo_jy_1 블록 두 문자열뿐이다.

- 진입: “우리 정착지에서 공연해요!” → “여기서 잠깐 공연해요!”
- 결과 첫 문장: “다음 정착지 장터에서 세 곡짜리 공연이 열렸다.” → “달구지 옆에 모인 행인들 앞에서 세 곡짜리 공연을 했다.”

현재 잠깐 멈춘 자리에서 사람들과 공연을 시작하므로 다음 정착지 이동이나 미래 완료를 선지급하지 않는다. 별도 정착지 gate는 추가하지 않았다. 동료 카드 대화와 도로 추첨을 모두 유지하고, 시간·보상·필요 동료·once·선택 순서·노트·장면 ID·인용 수는 그대로다.

기존 plan-v2와 performance-v1 이미지를 직접 열어 확인했다. 전자는 달구지 옆 두 사람, 후자는 천막 장터의 작은 공연이다. 인물과 기타·모자·행인 공연은 문구와 일치한다. 도로에서의 천막 장터 배경/페이지별 실제 크롭은 root 이미지 검수로 남겼으며, 이미지 파일이나 연결은 바꾸지 않았다.

자연 원본과 별도로 격리 엔진 fixture를 만들어 정착지 D16 07:45에서 구문 오류를 재현했다. before.json과 red-check.log를 수선 전에 저장했다. 새 원정으로 세지 않는다. 수선 뒤 event object를 두 문자열만 되돌려 원본과 정확 비교했고, 나머지 전 필드가 같았다. 위치/시각/이동거리, fx/chips, 기지급 replay, 수정 전 fixture의 저장결과 보존과 재지급0을 검사해 통과했다. 실제 옛 버전 파일을 재개한 증거는 아니다.

기존 main-story-flow / narrative_context / dialogue-register 검사158/158 통과, lint:dialogue exit0·몰입 파괴0건(기존 수동 후보2)이다. 이 작은 문구 변경을 위해 새 전용 정식 테스트는 추가하지 않았다. before/after 재현 근거와 기존 계약 검사를 사용했다.

## 이미지 확인 후 추가한 정착지 위치 계약

root가 performance-v1의 큰 천막 장터를 직접 검수한 뒤 정착지에서만 새로 발견되도록 추가 수선을 승인했다. 위 첫 단계의 “gate 미추가” 판단은 이 추가 결정으로 대체된다. 기존 D.eventLocations에 pair_leo_jy_1을 kind:node, type:settlement인8개 노드로 등록했다. 새 엔진 필드는 만들지 않았다. 진입·결과의 현재 공연 문구는 유지한다.

의도한 동작 변화는 일반 도로/외곽 및 동료 카드의 일반 잡담 풀에서 빠지고, 레오와 재이가 함께 있는 정착지 주변 탐색에서 새로 발견되는 것이다. 장소 목록은 부산·밀양·대구·무주·전주·대전·수원·광주이다. 장면의 실제 장소 계약만 추가했으며 event object의 조건/보상/시간/once/선택/notes는 변하지 않았다.

새 tests/test_qa_cycle11_busking_location.cjs에서 먼저 정착지 탐색 후보 누락과 외곽 잡담 노출을 재현했다(2실패/3통과). 수정 뒤5/5 통과. 실제 G.explore를 통한 정착지 진입·1회보상, 일반 주행풀 제외, 외곽 제외, 두 동료 필수, 기존 미지급 화면의 Continue·1회보상, 기지급 옛 문구 보존을 검증했다. 자연 원정으로 세지 않는다.

pre-gate-unpaid.json은 gate 추가 전에 실제 격리 엔진에서 저장한 외곽 미지급 fixture다. 새 소스의 G.load에서 그대로 복원해600분/김해를 유지하고 식량12→13·고철20→24가 한 번만 지급됐다. 다시 저장/재생하면 재지급0·상태변이0이다. 이는 직접 보존한 수정 전 fixture이지 실제 옛 버전 자연 원정 파일은 아니다. location-after-verification.json에 결과를 남겼다.
