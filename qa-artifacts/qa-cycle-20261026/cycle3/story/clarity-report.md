# 이전 미결 명료성 항목 종결

이전30인 README C01~C07과 gap-ten director-rulings를 대조했다. 아래는 이전 자연 기록의 소스 진단과 명시 fixture 검사이며 새 원정 발견 수에 더하지 않는다. 낮은 우선순위 명료성 항목을 모두 정산 결함으로 바꿔 세지 않는다.

| 항목 | 판정과 최소 수선 |
|---|---|
| C01 방화복→부품 | 명료성. `ev_fire_station` 선택0의 두 번째 결과에 선반 밑 예비 연결 부품을 챙긴 경위를 넣었다. 방화복도 유지하고 기존 부품1·35분은 그대로다. 방어구 체계는 추가하지 않았다. |
| C02 공구함→셔터 열쇠 | 명료성. `opening_departure` 진입에서 공구함 열쇠와 셔터 열쇠가 한 고리에 있음을 소개하고 선택의 물건명을 작업장 열쇠로 맞췄다. 맡김/소지 선택, 기존 노트와 finale 회수 문구는 그대로다. |
| C03 지역 접촉 완료 설명 | 완료 조건은 정상, 설명의 출처 불일치. `G.departureSteps`의 relay 완료 설명은 실제 지역 접촉이면 그 거점 이름, `main_relay_confirmed`이면 수원에서 받은 응답을 말한다. 미완료 안내와 완료 조건은 바꾸지 않았다. |
| C04 못판 한나절/70분 | 시간 표현 명료성. `ev_nail_trap` 선택2의 한나절을 한 시간 남짓으로 바꿨다. 70분·피해·부품 보상은 유지했다. |
| C05 작전 지도 출처 | 명료성. `story_parent_route_guarded` 첫 문장에서 배차실에 남은 지도를 펼쳐 앞서 베낀 묶음 번호를 대조했다고 연결했다. 새 아이템·분기·보상·기록을 추가하지 않았다. |
| C06 서울 편지/봉투 | cycle3의 수첩만 언급하는 수선과 중복. 추가 변경 없음. 기존 보고가 이를 명료성으로 분류한 사실을 보존한다. 특정 아이템 무단 지급/소실 오류로 세지 않는다. |
| C07 도보 급유 고정 소모 | 비상 구제는 정상, 안내 명료성. nofuel 1/2/3의 걷기 선택 안내만 보유분에서 각각 최대2/3 소모, 끼니 소모 별도로 명시했다. 식량0 구제 출구, 원래 시간·연료·끼니·손해·영수증 유지. |
| gap 수리 전 극장 소리 | 장비 관계가 불명확해 새 FM/단파 장비 설정을 만들지 않고 `loc_drivein` 결과를 실제 `radio_fixed`로 구분했다. 미수리이면 표정과 몸짓으로 무성 관람하고, 수리했으면 기존 차내 수신을 한다. 끝부분도 들을 수 없는 엔딩곡 대신 마지막 자막으로 맞췄다. 영화·수리 gate·연료4·150분·사기·노트는 유지했다. |

D02 홍수/겨울정전 권한 이력, D03 승인 추론/아빠 사망 설정, T01 경로 등급과 보급 경고는 기존 반증과 비결함 판정을 유지하고 canon을 바꾸지 않았다. gap의 비정상 기한 저장과 재이 창고 미도달도 새 확정 버그로 세지 않았다.

검사 `tests/test_qa_cycle_story_clarity.cjs`: 13/13 통과. 기존 두 선택의 비용, local/remote 완료 출처, 70분, 검증키 지급, 3단계 식량0 구제, 수리 전후 영화·paid reload, 활성 게시판/수락 전 견적/실제 인계20고철/중복 지급 없음, 옛 결과와 노트 보존을 확인했다. 변경 사건8개의 선택 조건·확률·fx·노트를 수정 전 직렬화와 비교해 완전히 같음을 확인했다(`clarity-mechanics-after.json`).

실패 원본을 보존했다. 첫 검사 파일의 괄호 오류는 `clarity-test-syntax-failure.txt`, 그 뒤 수정 전 실행은2통과·10기대실패·열쇠 검사1개의 VM 문자열 오류다(`clarity-before.txt`). 열쇠 검사를 바로잡고 보존한 수정 전 본문으로도 기대실패를 확인했다(`clarity-key-before-corrected.txt`). 생산 변경 뒤 VM 오류가 남은12/13 결과도 `clarity-after-harness-error.txt`에 남겼고, 최종은13/13이다(`clarity-after.txt`). 이 검사 코드 오류들을 게임 오류로 세지 않는다.

계약 projection은 survival 담당에게 정확한 새 foreseeable 문자열을 전달했고 직접 수정하지 않았다. 실제 화면·음성·터치 검증을 완료했다고 주장하지 않는다. 4차 자연 원정은 부모의 동결 신호 전까지 실행하지 않았다.
