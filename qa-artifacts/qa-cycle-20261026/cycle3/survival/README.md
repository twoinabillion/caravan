## 검토했지만 결함으로 확정하지 않은 부분

- 성숙한 민지 캠프 대화는 여러 날 같은 ‘거기 두 번 덜컹했지’ 결과로 돌아왔다. 기능 실패는 아니지만 반복 감각이 강한 문장 후보로 남긴다. 추가 고유 대사는 이번에 만들지 않았다.
- 레오14의 ‘부산에서 지금까지’는 레오의 합류 전 구간까지 주제곡을 설명한다. 직접 동행 기억을 주장하는 문장은 아니므로 미발생 과거 사건으로 확정하지 않았다.
- `seoul_night`는 시각을 소비하지 않고 새벽과 이후 행동을 묶어 서술한다. 최종 결정 뒤의 마무리 장면이라 일반 대화 S3-01과 구분해 그대로 두었다. 표시 시각과 엔딩 문장 정합성은 UI 설계 검토 여지가 있다.

실제 게임 엔진을 격리 VM에서 실행했다. 표현·타이머·오디오 대역을 쓰므로 화면/모바일 crop/음성/입력 품질의 검증은 아니다. 무한 자원, 숨은 이동, 스토리 flag 지급은 사용하지 않았다. 전체 source 검사·build 및 실제 브라우저 확인은 root 담당이다.
