- **S-A01 / P2 / 기존 수면 각성 피로**: 인공 유한 fixture에서 2시간 낮잠90→50.4, 소파60분40→36.7, 자동차극장8시간40→61.6, 세트장10시간40→37을 재현했다. `fx.sleeping:true`로 수면 시간과 full-reset `fx.sleep:true`를 구분했다. 낮잠/소파/세트장은 기존 -45/-6/-30 유지, 자동차극장은 8시간 숙면에 맞게 full sleep으로 의도적으로40→0이 된다. 수선 후 각각45/34/0/10. 경과시간, 식사·물 경계, 부상, 치명적 자정 중단, 과거 지급 결과 보존을 검사했다.

## 남은 범위

`exp_jjimjil`의 8시간 불가마 휴식은40→61.6 그대로다. 원문은 ‘쉰다’, 등을 지진다는 표현이며 수면을 확정하지 않는다. 새 자동 수면 처리를 추가하지 않았고 휴식 의도에 대한 설계 검토로 남긴다. 원시 boundaries01/02에 동일 현상을 보존했다.

이 검사는 실제 게임 소스의 Node VM이며 표현·타이머·오디오가 대역이다. 실제 브라우저 클릭, 페이지/모바일 crop, 음성, 사용자 Studio 저장·화면은 검사하거나 변경하지 않았다. 원본 harness/기존 정책·보고·사건 소스를 읽은 목표형 QA이므로 블라인드 실험이 아니다. 의사결정에는 공개 선택·목표·비용·현재 상태만 사용했고 무한 자원·순간이동·스토리 flag 지급을 하지 않았다. 시작부터 마지막 결과까지 엔진 완주이며 현실 시간에 맞춘 수동 플레이를 뜻하지 않는다.
