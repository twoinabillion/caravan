# Cycle 1 — 시스템·엔딩

seed **261002**, 새 여정 attempt01이 **SESSION 1 END**까지 끝났다. 강우를 정상 영입했고 코어 격리 수면(core_sleep)을 골랐다. 6일·430km, 선택68회, 기록307개다. 전편68개 진입·선택·결과 원문을 로스터/시각과 함께 읽었다. 이 경로에서 추가 확정 서사 오류는 없었다.

실제 엔진의 격리 VM이며 브라우저 완주가 아니다. 과거 감사와 정책을 참고한 목표형 검사다. 자원 주입·무한자원 없이 공개 행동으로 진행했고, 선택 전·결과 뒤 저장 재개를68번씩 검사했다. 강우 야영대화4회, 실제5종 제작, 후미 레일 좌석칸(bench) 설치1회, 지역작업6회, 보급 구매10회, 게시판3곳을 이용했다. 신규 라디오 수리·진료·사이드 미션 완료·재이 영입은 이 여정에서 달성하지 않았다.

확정 오류4개를 현소스에서 재현하고 수정했다.

- 종료 뒤 제작창 재열림·접기 불가·재제작: 종료 상태의 엔진/화면 진입을 막고 치명적 시간 경과 뒤 완료 화면/소리를 실행하지 않는다.
- 무기 선반 할인 불일치: 한 견적을 제작 허용, 실제 지불, UI 가격/시간이 함께 쓴다. 파이프5·석궁10·볼트3·화염병2·탄약7 고철 경계를 확인했다.
- 주인공 진료가 강우 치료: 진료 선택의 대상을 driver로 명시했다. 이미 지급한 옛 결과는 재치료·환급하지 않는다.
- ‘새벽 두 시’ 방송: 기존 음성/문구를 유지하고 새 방송 선택은02:00 이상03:00 미만으로 제한했다.

`tests-before.tap`은4개 회귀 실패/2개 정상 통제를 보존한다. `tests-after02.tap`은 시스템6개와 기존 사건 전환11개, 총17개가 통과했다. 중간 `tests-after01.tap`의2개 실패는 테스트가 기본 수량0 키와 주인공 칩 호칭을 잘못 가정한 것으로, 게임 변경 없이 fixture/기대값을 고쳤다. 전체 source 검사와 build는 root 담당이다.

별도 정상 과거 저장 재개에서 라디오 진공관1개/40분 수리, 중복 수리 차단, 재개, 실제 주행 방송을 확인했다(12검사). 대구 조달도 기존 부품2개 인계→고철24 지급→재개→중복 지급 차단→보급 구매를 확인했다(21검사). 각각 `radio-resume-after.json`, `sidequest-resume-after.json`에 정상 재개와 인위 경계 검사를 구분했다. 이번 새 여정의 신규 획득으로 세지 않았다.

상세 원인은 `report.json`, 수선 전 재현은 `preliminary-repros.json`, 전편은 `transcript01.json`, 전체 여정은 `player02/attempt01/`에 있다. 실제 모바일·브라우저·음성·사용자 저장은 다루지 않았다. cycle2는 seed262002로 민지·강우·재이와 보존 공동감시 결말, 라디오와 사이드 미션을 목표로 이어간다.
