# Cycle20 수선 독립 검토

story와 systems의 소유 변경을 원문·전체 diff·회귀 구현과 함께 읽고, 두 회귀 파일을 직접 실행했다. `tests.txt`는 **31/31 통과**이며 추가 결함은 찾지 못했다. 새 원정은 실행하지 않았다.

- **systems:** `signal_bait`에서 녹음 요청 사이의 잡음에만 붙던 AI 표식이 빠졌다. 양쪽 구조 요청의 녹음 매체는 그대로이고, 새 문장 `잡음이 섞였다.`는 천리안이나 플레이어를 발신자로 만들지 않는다. `crisis_nofuel`·`crisis_nofuel2`는 이미 소개된 만물상의 상인 역할만 명시한다. `만수네`라는 가게 이름만으로 별도 NPC 만수 본인이라고 단정하지 않은 점이 맞다. 모든 10결과의 본문·조건·효과 및 지급 1회, 과거 reader/text-only 10+10 보존 검사를 확인했다. 자연 확정·자연 명료성·같은 원인 파생은 보고서에서 분리돼 있다.
- **story:** 인쇄된 제목을 사람 대사 대신 종이 기록으로 표시한다. 천문대는 solo 관측과 여러 사람이 번갈아 보는 관측을 나누고, 보리가 있을 때만 코 자국을 남긴다. 새 노트는 공통 관측만 기록하며, 기존 지급 노트는 유지한다. 민지 벨트 사건은 실제 주행 거리가 변하지 않는 즉시 결과에 맞춰 `20km 뒤`를 제거하고, 이미 정차 중에도 맞는 `손보면`으로 바뀌었다. relay의 완료 flag는 장부 전달을 증명하며 동료의 당시 참여를 증명하지 않으므로, 새 대사는 기록을 읽고 다음 마을을 확인하겠다는 계획으로 읽힌다. 기존 once·need·화자 순서와 효과는 같다. 14개의 기존 reader/text-only receipt 보존을 확인했다.
- **root 이미지 연결:** `03g-scenes.js` diff에서 인쇄소와 들개 야영에 새 키 2개만 연결하고 이전 키를 삭제하지 않았음을 확인했다. `companions:[]`, 기존 인물 없는 그림 설명, provenance 경로와 장면 선택 4조합의 별도 검사 자료도 읽었다. 이 담당자는 원본 이미지를 시각 검수하거나 실제 브라우저 크롭을 확인하지 않았다. root의 갤러리·이미지 증거와 혼동하지 않는다.

`reviewed.diff`는 frozen19와 현재 `03-data.js`, `03i-story-expansion.js`, `03g-scenes.js`의 차이다. 독립 검토에는 survival 자신의 워터파크 수선 판정을 넣지 않았고, 해당 diff에 함께 보이는 한 필드는 별도 소유 회귀 9/9로 기록했다.

최종 현재 소스 캡처는 `../repair20/source-after-team.json`이다. 40개 src 중 frozen19 대비 변경은 위 세 파일뿐이며 engine LF hash는 `a9e246136f3100132bf83625f4b032bd4b315782538f31364b38b0e32df93e0b`다. 전체 테스트·빌드·통합 계약과 최종 20차 동결은 root가 담당한다.
