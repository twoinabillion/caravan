# Cycle 23 그림 독립 대조

계획의 신규 18장과 재사용 1장이 모두 준비됐음을 확인했다. 이 가운데 다른 담당자가 제작한 신규 11장의 보존 원본 PNG와 최종 WebP를 각각 직접 열람했고, 재사용 레오 시장 JPEG도 확인했다. 담당한 사건 12개의 진입문과 결과 28개, 결과 노트, 빵집 동료 유무 및 광장 선행 조건 분기를 읽었다. 이 독립 검수 범위에서 새 그림 모순은 0건이다.

본인이 만든 7장은 별도 자체 검수 기록을 참조했다. 이 일곱 장을 독립 검수 수에 더하지 않았다. 이전 능선 그림의 울타리 오류는 root가 발견한 정정 건이며 이번 신규 발견 0건에 숨기거나 지우지 않았다. 새 울타리 제거본과 이전 초안을 모두 보존했다.

| 구분 | 실제 확인 |
| --- | --- |
| systems 신규 6장 | 건어물 손수레, 만화방, 군 검문소, 회수조, 학교 급식실, 충주호 수몰 마을 |
| root 신규 5장 | 대전 빵집 셔터, 미개관 도서관, 폭포, 부서진 ATM, 빈 서울 광장 |
| 재사용 1장 | 대인시장 레오·보리 첫 만남 |
| 자체 검수 7장 | 지하 문서실, 견인차 차고지, 능선 접시, 들판 탐조등, 남산 케이블카, 오락실, 죽통밥 |

회수조는 흰옷 네 명과 차 안 여자 한 명, 급식실은 솥 세 개와 남아 있는 뚜껑, 도서관은 포장 책과 끊지 않은 테이프, 광장은 수백 벌의 접힌 옷과 빈 공간을 확인했다. 구매·회수·개관·목욕·구조·취사 등 플레이어 선택을 이미 실행한 그림은 발견하지 못했다. 각각의 판단과 SHA-256, 원본 대조는 `visual-cross-review.json`에 있다. 독립 검수한 신규 11개 보존 master는 제작자의 생성 원본과 바이트가 같았다.

검문소 표지판의 뒷면, 만화방 컵 더미, 가뭄에 드러난 젖은 호수 바닥은 본문과 양립한다. 그림에 보이지 않는 사물을 곧바로 존재하지 않는 것으로 단정하지 않았다. 전광판·분필·지도는 장소를 보여주되 생성된 가짜 본문을 읽게 하지 않는 표현으로 보았다. 익명 인물을 얼굴이 조금 닮았다는 이유만으로 미영입 동료라고 확정하지 않았다.

이 검수는 원본과 최종 이미지의 내용·인물·물건·장소 및 선택 전후 관계를 보는 정적 대조다. 실제 브라우저, 모바일 CSS 자르기, 현재 게임 시각과 그림의 배합, 실제 연결 후 장면 전환을 검증한 것은 아니다. root의 갤러리·게임 화면 검수는 별도이며 새 원정도 실행하지 않았다. 소스·생산 assets·갤러리 편집은 0건이다.

그림 밖 후보는 분리했다. 만화방 인접 소스를 읽다 `exp_oilmill[0]`의 시간 효과 없는 “그날 저녁” 식사 완료 문구를 보았다. 추가 스캔이나 runtime fixture 없이 정적 후보로만 기록했으며, 자연 발견이나 이미지 결함으로 합산하지 않았다.

중간 시점에는 광장이 미완성이어서 `visual-cross-review.partial01.json`으로 보존했다. 최종 판단은 `visual-cross-review.json`과 본 문서다. 다음 fresh 원정 seed 283001은 source 동결 신호를 기다린다.
