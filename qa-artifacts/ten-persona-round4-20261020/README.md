## 별도 후보·의견·제외

확정 문제와 합산하지 않은 명료화 후보4건:

- R4-03: 장기 정차일에도 민지 야영 선택이 ‘오늘 지나온 길’이라고 부름. 실제 이전 길의 추억은 살릴 수 있다.
- R4-04: ‘마을로 견인’ 뒤 원래 도로 위치에서 연료6을 받고 운행 재개. 구조 범위/연료 획득 설명을 맞출 후보이며 새 도시 이동을 필수 해법으로 단정하지 않는다.
- R4-06: 첫 산지기 만남의 유일한 대사가 이음망의 파견을 받았다고 함. 이름을 들은 것과 파견받은 것은 다르다. 새 접선 사건이나 암호를 발명할 필요는 없다.
- R4-08: 민지를 만난 적 없는 경로에서 레오의 최근 기타 각인이 민지 송곳을 빌린 일로 연결됨. 물리적 유령 배우 등장이라고 과장하지 않는다.

우편부의 ‘스친 정착지 세 곳’은 이전 생활권 소식을 말한 해석이 가능해 미확정으로 남겼다(02/10 중복). 구제 선택의 예상 부담 안내, ‘그냥 지나간다’ 결과가 정하는 무관심의 의도, 정착지 허기에서 장터로 돌아갈 연결은 의견3건이다. 해도의 흰X/김 선장은 기존 차량 정본과 상대의 선행 인식으로 성립하므로 결함에서 제외했다.

도구 결함1묶음 R4-H1: `stl.actions`가 실제 현장 행동의 req/cost를 관측에 전달하지 않는다. 국수 등 유료 서비스를 고르는 일을 전부 ‘보이는 비용을 무시한 정책’으로 돌릴 수 없다. 실제 UI 소유 경로는 별도 비용을 만들므로 이것을 게임 UI의 비용 누락으로 세지도 않는다. **다음 감사 전 관측자를 보완하되 숨은 결과/보상표를 주지 않는 것**이 필요하다. 일관성을 위해 이번 배치 중 공용 어댑터를 바꾸지 않았다.

명시된 연료 부족 경고 무시, 모집 `ready`/좌석/선택 노선 오독, 식량을 팔지 않는 시장을 식량 공급처로 지정, 포화 재고 메모·무한 야영·일일 대화 제한 오독은 정책 오류다. 관련 원제보4개와 보고서의 실패 원인을 제품 결함에서 분리했다. 재시도는 같은 seed의 공개 계획 보정뿐이며 자원·인물·아이템·확률/숨은 플래그 주입은 없었다.

## 검토·방법의 한계

각 담당자는 실제 자기 trace를 순서대로 진입→전체 관측 선택지→선택→결과→전후 상태로 읽었다. 08/09는 완전히 동일한 텍스트를 앞 발생에 참조하되 매 발생의 시간·자원·명단·조건을 별도로 읽는 방법을 명시했다. root는 원제보24개를 모두 판정하고 후보의 실제 기록·소유 소스를 대조했다. root가2,096개 전체를 별도로 다시 읽은 것은 아니다.

02와05는 공개 지도 위치를 찾는 사전 broad source 검색 출력에 일부 미관측 대사가 섞였음을 보고했다. 선택 기준에 직접 쓰지 않았다는 것은 작성자 진술이지 영향 부재의 증명이 아니다. 이 라운드는 완전 블라인드 연구라고 부르지 않는다. 해당 실제 trace와 사후 소스 대조의 근거는 보존했다.

Node VM/격리 저장의 실제 소스 엔진이다. UI·오디오·타이머·접근 연출을 대체하며 일부 진입·동료 수락·획득 perk 첫 선택을 자동 처리한다. 원시 main/navigation은 실제 공책 표시와 같다는 보장이 없다. 실제 페이지 커서/취소·뒤로/터치·키보드/초점/모바일 크롭/주행 감각·음성·음악/모든 갈래/실기 성능은 미검수다. 사람이 플레이한 결과나 사람의 감정 보고로 표현하지 않는다.
