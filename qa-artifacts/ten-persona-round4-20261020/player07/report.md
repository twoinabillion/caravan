# player07 · 몸부터 움직이는 성급한 구조자

seed 202007, 독립 정책 1회로 본편과 최종 후일담을 마쳤다. `attempt01`의 `status=ended`, `storyDone=true`, `ending=story_done`, `method=core_sleep`, `error=null`이다. 서울 남산에서 집계된 마지막 상태는 7일 16:34, 누적 430km, 강우 1명 동행이다. 67개 실제 선택과 228개 trace record를 남겼다. 사망·실패 시도·한도 종료를 지우거나 재시도하지 않았다.

마지막 실제 선택은 trace 227 `seoul_session_reset`의 ‘화면을 끄고 달구지로 돌아간다’이다. 결과에서 하진에게 이송 취소를 전하고, 수원 중계소에서 엄마와 할아버지 이야기를 나눈 뒤 `〔 서울까지 400km · SESSION 1 END 〕`까지 읽었다. 단순히 `core_sleep` 결정이나 `seoul_night` 도착을 완주로 세지 않았다. 격리 최종 save에는 `ended=true`, `endKind=story_done`, `flags.story_done=true`, `pendingPresentation=null`, `_chain=null`이 남았다. trace 227–228은 마지막 영수증을 읽는 중이라 `ended=false`이고, 이후 어댑터가 결과를 닫고 최종 상태에 도달했다. 실제 UI의 Continue 버튼 검수라는 뜻은 아니다.

## 성향과 공개 정책

첫 파일인 `policy.cjs` 주석에 성격·방문 목표·공개 판단 기준을 선언한 뒤 실행했다. 직접 구조·수리·운반·위험 돌파를 선호하고 협상·기록·대기를 낮게 평가한다. 차체와 피로가 버틸 때 보이는 위험을 가끔 더 높게 평가하되, 공개 문구가 노골적인 무의미한 죽음을 약속하면 피한다. 원하는 엔딩은 정하지 않았다. 동점은 현재 선택 차례와 공개 index로 순환하여 항상 첫 항목만 고르지 않았다. 실제 선택 index 분포는 0번 34회, 1번 26회, 2번 6회, 3번 1회다.

지도 목표는 부산 출발 뒤 공개 북상 축의 밀양·대구·대전·서울이었다. `visitGoals` 거리도 known 필터를 통과한 곳만 관측된다. 실제로는 김천 분기에서 동쪽 능선길을 선택해 대전에는 가지 않았다. 공개 본편 navigation과 실제 모집 목적지를 따라갔고, 현재 목적지에서는 탐색을 반복해 필요한 다음 장면을 찾았다. 생활 탐색은 새 정차지에서 시간이 허락할 때 했으며, 이 조건을 본편 탐색 금지나 경로 영구 금지로 쓰지 않았다. `forecast.shortage`가 있어도 `check.ok`인 실제 도로를 갈 수 있었다. 추가 연료 예비량을 출발 조건으로 만들지 않았다.

시작 pack은 `repair`, 이름은 현오다. 모든 동료 제안은 어댑터의 실제 모집 절차로 수락하도록 했지만, 민지의 최초 부탁에서는 정책이 거절 선택지를 골라 제안까지 가지 않았다. 상태·아이템·동료·확률·플래그를 주입하지 않았다. 기존 정책을 import하거나 복사하지 않았고 이전 실행 결과로 현재 선택을 최적화하지 않았다. 공용 harness와 retained runner는 공개 API와 동작 한계를 파악하는 용도로 읽었다.

## 실제 여정

부산 → 양산 → 밀양 → 대구 → 구미 → 김천 → 상주 → 문경 → 충주 → 청주 → 천안 → 평택 → 수원 → 서울로 갔다. 총 13번 출발, 28번의 운전 구간 기록, 14번 탐색, 6번 야영, 13번 거래, 4번 현장 행동, 1번 업그레이드가 있었다. 사이드 미션 게시판은 대구에서 한 번 열었으나 현재 공개 목표와 일치하는 목적지가 없어 수락하지 않았다. 모든 사이드 미션이나 지역을 순회한 실행은 아니다.

첫 수리 호출에는 바로 부두로 갔고 새 부품으로 버스를 고쳤다. 이후 가족 이름과 검증키 배선을 챙겼다. 양산에서는 스캐너 전원을 끊고 단말을 열었으며, 폐주유소에서는 직접 수동 펌프를 돌렸다. 밀양에서 연료를 사고 국수 좌판을 이용했지만 민지의 울산 부탁은 거절했다. 대구에서는 입구 교대선 일을 하고 강우의 후임 지시를 따르는 6시간을 보냈다. 보조 연료탱크를 실제 비용으로 장착하고 구미에서 하룻밤을 보낸 뒤 강우를 정식 모집했다.

동쪽 능선은 성향이 가장 뚜렷하게 드러난 구간이었다. 가짜 행정소의 천막을 걷으려 하자 사기꾼들이 철수했다. 창고의 다른 입구로 들어가려다 무릎을 다쳤고, 상주 비탈에서는 남자를 직접 업고 오르려다 떨어져 허리도 삐었다. 그래도 마지막에는 수레를 포기하고 사람·약·편지만 릴레이로 올려 네 사람을 구조했다. 무리한 선택이 실제 부담과 다음 회복으로 이어졌으며, 실패를 성공처럼 바꾸지 않았다.

문경 이후 시장 없는 북상 구간에서는 보급 판단이 좋지 않았다. 청주를 떠날 때 연료가 약 4.26L였고 공개 경로는 갈 수 있었으나 부족 예보가 있었다. 길 위에서 연료가 떨어져 7시간 걸어 기름을 얻었고 식량이 0이 됐다. 평택에서 다시 약 3.73L로 수원을 향하다 두 번째 고갈을 맞아 9시간 걸었다. 수원 도착 뒤에는 허기 사건으로 감자를 찾고 야영했다. 이는 자원 주입이나 무한 탐색으로 탈출한 것이 아니라 실제 위기 선택과 마을 보급을 사용한 경로다. 위기 자체를 게임의 진행 불가로 판정하지 않는다.

수원에서는 물·식량·연료를 실제 거래로 채우고 북문 망루 교대와 성문 평형추 작업으로 고철을 벌었다. 이어 엄마와 만나 기록 송신을 부탁하고 세 거점의 응답을 받았다. 남산에서 강우만으로는 보존에 필요한 감시 인원 3명을 채우지 못한다는 공개 안내를 봤다. 활성화된 인계/수면 중 수면을 골라 생활 설비는 살리고 원본 기록 검색창은 잠겼다. 후일담은 잠든 코어와 별도 상위망 단말을 구분했고, 서울에서 이룬 인간 확인층이 보존된다는 설명 뒤에 상위망의 거절과 새 세션이 이어졌다.

최종 자원은 연료 약 32.52L, 물 11, 식량 6, 고철 20, 차체 100%, 피로 약 35.51이다. 강우는 사기 100, 유대 11, 부상 없음이었다. 업그레이드는 `tank1`이고 부모님의 검증키 1개를 보유했다.

## 판정과 의견을 분리한 결과

제품 서사 후보는 `R4-P07-C01` 한 건이다. 산지기의 첫 만남에서 실제로 받지 않은 이음망의 파견을 받은 듯 답하게 했다. 단순히 조직 이름이 낯설다는 취향이 아니라, 현재 실행에 없는 과거 행동을 유일한 선택으로 확정한다는 문제다. 실행 완료 후 해당 관측 사건의 소스만 대조했으며, `src/03-data.js:8783`의 고정 대사와 선행 파견 게이트 부재를 확인했다. 이 라운드·이전 라운드 중복 여부는 주 디렉터가 최종 대조한다.

어댑터 후보 `R4-P07-H01`은 현장 행동의 공개 비용 누락이다. 밀양 ‘순덕의 국수 좌판’은 관측상 시간·설명·status만 있었고 실제로는 고철 2를 지불하는 서비스였다. 이 실행이 비용을 몰랐다는 이유로 게임의 노동 보상을 잘못됐다고 주장할 수 없다. 상세 근거는 `findings.json`에 있다.

다음은 확정 버그로 세지 않은 검토다. `camp_visitor`가 06:30 저장 상태에서 밤을 서술하지만, 소스에 `storyOrigin`이 ‘지난밤 · 야영지’로 명시돼 있었다. 어댑터가 이 출처 표기를 전달하지 않는 한계가 있고, 현재 아침에 노인이 순간적으로 온 것으로 단정하지 않았다. `gp_note1`은 문경에서 야영한 다음 정차 상태에 열리면서 ‘신호 대기 중’이라고 시작한다. 실제 신호가 없는 데 버릇으로 기다린다는 문구까지 있어 전면 모순으로 단정하기보다 정차/출발 맥락의 작은 어색함으로 남긴다. 마지막 동료 제시 결과의 ‘사람들/각자’는 강우 1명 실행에서 다소 큰 무리처럼 들리지만, 플레이어와 강우를 포함한 일행으로도 읽혀 새 인물 등장을 확정하지 않았다. 종장 중 게임 시계는 16:34에 머물러도 밤·새벽·귀환을 서술한다. 종료용 후일담이 경과와 이동을 압축하는 범위를 이 엔진 실행만으로 별도 결함으로 세지 않았다.

성향 관점의 의견으로는 능선 구조가 가장 잘 맞았다. 직접 업고 오르는 위험이 실제 실패와 부상으로 돌아오고, 다음 선택에서 수레보다 사람과 물자를 살리는 방법으로 이어져 장면의 인과가 분명했다. 반면 본편 후반은 번호 대조·보관·증언 확인 선택이 많아 이 성향이 행동으로 개입할 폭이 작았다. 이는 취향 메모이며 텍스트 제거 요청이나 제품 결함 판정이 아니다. 수면 뒤 원본 조회가 잠긴다는 구체적인 사례와 강우 1/3 근무 인원 안내는 선택의 대가를 읽는 데 도움이 됐다.

## 정책 실수와 어댑터 한계

정규식 점수는 사람의 독해를 대체하지 못했다. 민지의 거절 항목에도 ‘함께’가 있어 수락과 같은 점수를 받았고, 회수조의 ‘차에서 내려 여자 옆에 선다’는 직접 구조지만 핵심 동사 패턴에 잡히지 않았다. 결국 ‘지나간다’가 동점 순환으로 선택됐다. 강우 작업에서도 장치를 직접 뜯는 선택 대신 후임의 지시를 따랐다. 성급하지만 때때로 판단을 바꾸는 인물로 읽을 수는 있으나, 정책이 성향을 완벽하게 재현했다고 주장하지 않는다. 첫 실행이 완주했으므로 이를 다듬어 다른 엔딩이나 더 매끄러운 자원 경로를 만들기 위한 재플레이는 하지 않았다.

연료 목표 30L는 시장에서 사는 목표였고 출발 금지 조건은 아니었다. 위험 예보를 감수한 결과 2회의 실제 고갈이 났다. 새 시장이 없는 곳에서 예비분만 기다리며 영구 캠프에 갇히지 않았다. 노동은 모든 `status.ok` 후보를 검토하고 설명에 점수를 매겼으나 공개 비용이 빠져 있어 첫 국수 서비스 지출을 선행 판단할 수 없었다. 추후 어댑터 보완 전에는 ‘어떤 라벨도 가용하면 무료 노동’이라는 결론을 내리면 안 된다.

공용 어댑터가 실제 소스 엔진을 Node VM에 올리고 도로 프레임을 진행하며, 화면·음향·타이머·접근 연출을 대체한다. 동료 수락, 현재 모집 단계 열기, 서울 단계 진입도 실제 게임 함수로 자동 진행한다. 획득 퍼크는 공개 레벨 보상 뒤 기본 첫 항목을 선택해 강우의 경계 태세를 얻었고, 두 번째 퍼크도 어댑터 기본 선택이다. 인간이 직접 퍼크 목록을 읽고 골랐다는 증거는 아니다. `main` 내부 항목도 실제 공책 표시와 같다고 보장되지 않으므로, 정책은 주로 navigation의 현 위치·목표를 사용했다. 관측되지 않는 상점 최대 적재량은 실패 동작을 한 번 관측했을 때 같은 조건에서만 재시도를 막는 장치로 대응하도록 했지만 이 실행에서 반복 no-op 정지는 없었다.
