## 정책과 실제 여정

실행 전에 쓴 `policy.cjs`에 약속·기록·준비 확인·비폭력·책임을 선호하는 성격을 선언했다. 공개 선택 label/hint, visible/enabled, 자원, 실제 지도에 열린 이웃 경로, 현재 메인 안내와 수락한 모집 목표만 썼다. 미관측 지명 목록은 두지 않았고 `visitGoals=[]`였다. 현장 행동은 공개 `status.ok`를 먼저 보고 한 번 시도한 뒤 다음 관측의 자원 차이로만 보상을 배웠다. 관측에 없는 비용을0으로 간주하지 않았다. 게임 데이터·자원·인원·아이템·플래그·확률은 주입하지 않았다.

부산 → 양산 → 밀양 → 대구 → 구미 → 김천 → 상주 → 문경 → 충주 → 청주 → 천안 → 평택 → 수원 → 서울로 갔다. 동쪽 능선길을 골랐으며, 편지와 약을 실은 수레 구조에서 역할을 나누고 발판을 판 뒤 사람과 내용물을 릴레이로 올렸다. 민지의 울산 동행은 거절했고, 강우의 후임 지시를 따르는 과정을 마쳐 구미에서 정식 합류했다. 실제 최종 동료는 강우1명이다.

도윤 가족의 거절 응답과 이송표를 복사했다. 부모님 검증키는 순서를 모르는 동안 건드리지 않았고, 두 장을 찾은 뒤 원본과 사본을 나누어 보관했다. 증언은 각 당사자가 고친 사본으로 받아 원본과 대조했다. 아빠의 의료·급수 유지와 강제 이송선 분리를 확인한 뒤 엄마에게 기록 송신을 맡겼다. 마지막에는 감시 인원1/3으로 보존이 비활성인 조건도 확인하고 집행권 인계를 택했다. 강제 이송 취소 뒤 상위망의 별도 응답, 하진에게 전한 취소 소식, 엄마와의 귀환 대화까지 이어졌다.

가장 설득력 있었던 연결은 빈 사유란 → 부모님의 인간 확인 절차 → 당사자 정정·서명 → 최종 책임의 인계였다. 강우의 후임에게 맡기는 합류 방식이 마지막 영수증에 남았고, 작업장 열쇠와 엄마가 비워 둔 의자가 후일담에서 이어졌다. 이는 이 정책의 텍스트 해석이며 인간 플레이의 감정·재미 통계는 아니다.

## 전편 검토

실제 선택68개를 n순으로 모두 읽었다. 매 건마다 진입 전체, 보이지 않거나 비활성인 것까지 포함한 전체 공개 선택지와 hint/requirement, 선택, 결과 전체, chips, 전후 시간·자원·items·party·crew·up·camp 상태, 다음 메인 안내를 대조했다. 키워드 검색으로 전편 읽기를 대체하지 않았다. `read-choices.cjs`는 원본 trace에서 이 순서를 그대로 출력하는 읽기 전용 도구다. 별도 `review.md`에68개 발생의 판정을 남겼다.

텍스트 중복 제거는 하지 않았다. 실제68개 선택은 서로 다른 eventId68개였으며, 결과·옵션이 일부 비슷해도 매 발생의 전후 상태를 따로 읽었다. 소스는 완주·전편 독해 뒤 우편부와 김 선장이라는 실제 후보의 정의와 화자 라우트만 좁혀 확인했다. 미래 분기를 플레이 정책에 반영하지 않았다.

새 확정 버그는0건이다. `findings.json`의1건은 player02의 우편부 후보 `R4-P02-01` / 주 디렉터 `R4-05`와 중복되는 연결 표현 의견이다. 첫 도로에서 ‘스친 정착지’ 세 곳을 전했다는 문구가 이번 여정의 경험처럼 들렸지만, 이전 생활권 소식을 나눈 해석이 가능하다. 따라서 `category=opinion`, `countAsNew=false`로 기록했다.

김 선장이 초반부터 달구지의 흰X와 이음망 통신을 알아보는 대목은 확정 결함으로 세지 않았다. 차량의 기존 물리 표식이라는 정본 맥락이 있고, 상대가 먼저 알아보는 소개·미스터리로 성립한다. 주인공이 실제로 파견받았다는 거짓 과거를 확정하는 문장은 아니다.

## 정책 실수와 복구

준비를 중시한다는 선언에 비해 보급 정책은 현재 이웃 경로와 당장 보이는 상점만 봤다. 장거리 무보급 구간을 충분히 계획하지 못해 연료 바닥3회와 허기 사건1회를 겪었다. n149·186에서 걸어서 연료를 구했고, n208에서 공개 비용20고철의 견인을 골랐다. n194에서 먹을 것을 찾아 허기를 줄인 뒤 정상 야영으로 해소했다. 수원에서는 시장 거래8회와 실제 현장 행동3회로 보급·노동을 했다. 이 준비 부족은 정책의 한계이며, 강제 이동 금지나 게임의 자원 지급 결함으로 분류하지 않는다.

가짜 행정소와 회수료에서 지불을 고른 것도 비폭력 선호와 짧은 label 점수의 조합이다. 부당한 상대에게 돈을 주는 일이 책임 있는 선택이라는 제품 평가로 해석하지 않는다. 비슷한 점수는 선택 순서를 번갈아 가중하므로, 모든 선택이 사람의 숙고를 재현한 것은 아니다.

실패 반환은3건을 보존했다. n82 모집 단계가 하룻밤 동행을 요구하며 false를 반환했고 다음 야영 후 이어졌다. n107·131은 같은 날 다른 정착지에서 강우에게 다시 말을 걸어 ‘오늘 충분히 이야기했다’며 false였다. 정책의 대화 기억을 장소별로 두어 하루 단위 제한을 온전히 반영하지 못한 결과다. 무한 반복이나 seat-blocked 모집 반복은 없었다. 성공 후 다시 튜닝하지 않았다.
