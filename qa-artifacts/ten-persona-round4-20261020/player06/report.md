# player06 — 빚을 꺼리는 흥정꾼·일하는 상인

attempt01(seed202006) 한 번으로 본편과 마지막 후일담까지 마쳤다. `storyDone=true`, `ended=true`, `endKind=story_done`, 결정 방식은 `core_sleep`이다. N254 `seoul_session_reset` 결과 끝의 `〔 서울까지 400km · SESSION 1 END 〕`를 읽었고, 최종 격리 저장에도 `flags.story_done=true`가 남아 있다. DAY8, 누적791km, 동료0명이다. 결과를 바꾸기 위한 재실행이나 소스 수정은 하지 않았다.

## 선언과 실제 선택

처음 작성한 `policy.cjs`는 빚과 무조건적인 소속 약속을 피하고, 거래·현장 행동·공개 게시판 의뢰로 이동비를 마련하는 성향을 선언했다. 방문지는 관측된 지도와 메인 안내, 수락한 의뢰에서만 정했다. 새 계약은3건까지 맡되 이미 수락한 목표의 탐색 횟수는 제한하지 않았다. 메인 결말은 사전에 정하지 않았다. `policy-attempt01.cjs`는 같은 최초 정책의 보존 사본이다.

실제로 민지의 울산 동행은 거절했고, 재이에게는 가족 상자를 함께 찾는 대신 고물 정보를3고철에 샀다. 은수와 청주로 동행하자는 제안도 아직 믿지 못한다며 거절했다. 따라서 좌석 부족·모집 진행 중단·동료 이탈 문제는 이 실행에서 발생하지 않았다. 업그레이드는 구매하지 않았다.

밀양 게시판에서 ‘세 마을의 무전’ 연속 의뢰를 보고 시작했다. 밀양→대전 장부 전달(N37→N87), 대전→무주 주파수표 전달(N92→N110), 무주→밀양 교대 장부 반환(N113→N135)을 실제 수락·이동·인계했다. 각각 고철20/26/28이 들어왔으며 빠른 처리 보너스를 포함한 실제 전후 차이다. 명목 보상만 세거나, 임의로 퀘스트를 완료시키지 않았다.

현장 행동8회 가운데 실제 유급 노동은 대전 물 배급 화이트보드2회와 수원 북문 망루 교대1회였다. 나머지5회는 국수 구매2회와 촛불 순찰3회로 고철을 지불했다. 어댑터 액션명이 `work`라고 모두 일당 수입으로 세면 안 된다. 거래14회, 야영6회, 야영 정비 준비2회를 수행했다.

## 밟은 길과 결말

부산→양산→밀양→합천→거창→무주→영동→대전으로 올라간 뒤, 연속 의뢰 때문에 영동→무주로 되돌아갔다. 마지막 인계를 위해 거창→합천→밀양까지 내려갔고, 다시 합천→거창→무주→영동→대전→청주→천안→평택→수원→서울로 갔다. 총22개 이동 구간이다.

부모님의 갈라진 이송 경로와 작업 기록, 분리 절차, 아버지의 마지막17분을 순서대로 확인했다. 청주에서는 실제 메인 목표 때문에 탐색을 이어 검증키와 세 사람의 서명 증언을 얻었다. 천안에서 명령 원본을 대조했고 수원에서는 엄마와 재회한 뒤 방송을 부탁했다. 본편 진행에 필요한 반복 탐색을 임의로 차단하지 않았다.

코어에서는 혼자 온 만큼 동료 증언 선택이 막혀 있었고 여행 일지를 내밀었다. 기록 창구가 잠기는 대가를 먼저 확인한 뒤, 인계와 수면 중 수면을 골랐다. 감시 보존은 근무 인원0/3으로 비활성 상태였다. 수면 후의 원본 조회 지연, 상위망의 별도 응답, 부산 하진에게 취소 소식을 전하는 통화, 수원 중계소에서 엄마와 다시 앉는 마지막 대화까지 이어졌다. 격리 수면은 선택 점수와 실제 가용 선택지에서 나온 결과이며 목표 엔딩으로 지정한 적 없다.

## 전편 검토와 제보

실제63선택을 시간순으로 모두 읽었다. 각 장면의 진입 본문, 전체 공개 선택지(표시·활성·조건 포함), 선택, 결과, 전후 시간·자원·아이템·명단을 연결해 확인했다. 키워드 검색만으로 전편 검토를 대신하지 않았다. `chronological-review.md`는 같은 순서의 전체 선택 자료와 검토 메모다. 이후 실제 만난 후보 사건에 한해서 소스 소유자를 확인했다.

`findings.json`의 제품 후보는1건이다. N170의 ‘가까운 마을로 견인’ 선택은 트랙터를 묘사하지만 실제로는 원래 도로의 같은 위치에서 연료6L를 받고 주행을 재개한다. 견인 약속과 구제 결과 사이의 설명 공백으로 좁혀 기록했다. 특정 위치 이동을 강제해야 한다는 구현 결론은 내리지 않았다. 진행은 정상적으로 이어졌으며 심각한 막힘은 없었다.

N248의 단독 수면 결과에 ‘기록을 기다리던 그분한테는 제가 설명할게요’가 나와 발화자를 확인했다. `src/03m-finale-reading.js:74`는 명시적으로 `say('me', ...)`다. 없는 동료의 대사로 세지 않는다. 바로 앞 천리안 상대의 반말에서 존댓말로 바뀌는 상대가 불분명하게 느껴질 수는 있으나, 엄마의 무전과 공개 방송도 맥락에 있어 이를 확정된 말투 오류로 세지 않았다.

길을 오르내린 계약은 이 성향에 맞는 구체적인 생업이 됐다. 다만3건 인계의 약속이 짧은 상태 알림으로 연결된다는 관측만으로 실제 화면의 몰입감이나 재미를 평가할 수는 없다. 본편의 가족 기록과 후일담은 계약 우회 뒤에도 이어졌고, 선택으로 잃는 조회 창구까지 설명했다. 이것은 실행 내용에 대한 해석이며 인간 만족도 조사는 아니다.

## 정책 실수와 검증 한계

공개 경고를 읽는 정책이 불완전했다. `check.ok`만 통과시키고 `forecast.shortage`를 이동 선택에 반영하지 않아 N79/N124/N165에서 부족 경고가 있는 도로를 출발했다. 연료 고갈3회는 게임의 예보 누락이 아니라 정책 실수다. 첫 공개 경고는 이미 ‘연료2L 부족’을 표시했다. 원본을 보존했으며 더 매끈한 실행으로 교체하지 않았다.

또한 현장 행동의 짧은 시간만 우선한 탓에 유급 노동 외에 구매도 실행했다. 같은 점수에서는 높은 index를 고르는 일반 규칙 때문에 가짜 등록비 지불, 졸음 강행, 회수조 지나치기를 택했다. 선언한 신중한 상인이 모든 순간 충실히 구현됐다고 주장할 수 없다. 이러한 정책 한계2건은 `category=harness`, `countAsNew=false`로 구분했다.

모든63개의 유료/완료 선택 뒤 실제 엔진 저장·로드와 같은 결과 재생을 수행했다. 전부 `loaded=true`, `replayed=true`, `applied=false`였고, 동일 비용·보상 재적용은 없었다. 마지막 결과도 격리 저장에 남았다. 이 검증은 브라우저 Continue 버튼, 파일 가져오기, 읽기 커서·화면 복원 검수가 아니다.

실제 소스 엔진을 Node VM에서 실행했고 사용자 저장은 건드리지 않았다. 화면·오디오·타이머는 어댑터가 대신 처리한다. 도로 접근 애니메이션, 레이아웃·잘림·크롭, 실제 버튼 조작, 모바일·오프라인·음성은 검증하지 않았다. 자동 도착/후속 장면 처리, 동료 제안 수락 기본값, 획득 perk 기본 첫 선택 등 어댑터 한계가 있다. 이번에는 동료가 없어 perk 자동 선택의 실사용은 없었다. 전체 분기나 인간 플레이를 대표하지 않으며, 결말 비율을 선호·완주율 통계로 사용하지 않는다.
