# player43 · 추억에 약한 공연 애호가

두 번째 시도에서 실제 엔진의 끝까지 도착했다. `storyDone=true`, `ending=story_done`, 결정 방식은 `core_transfer`다. attempt02 318행 `seoul_session_reset`의 지불된 결과에 `〔 서울까지 400km · SESSION 1 END 〕`가 있으며, 319행 재로드에서도 효과가 다시 적용되지 않았다.

| 시도 | 결과 | 선택 | 전체 기록 |
| --- | --- | ---: | ---: |
| attempt01 | 16일 00:00 갈증 사망, 본편 미완료 | 109 | 434행 |
| attempt02 | 8일 20:23 본편·SESSION 1 END 완료 | 86 | 319행 |

실패 시도와 원래 정책은 그대로 남겼다. 첫 정책은 좌석이 가득 찬 뒤 은수 영입을 시작했고, 미완료 영입 위치를 계속 따라가며 천안과 평택 사이를 왕복했다. 보급을 소진한 원인은 이 정책 오류다. 게임 진행 불가 결함으로 올리지 않았다. 재시도는 공개된 좌석 수·이동 예측·보급 점수를 보고 새 영입과 왕복을 피하도록 바꿨다. 인물·시드 204043·감정적 선택 가중치·초기 보급 꾸러미는 유지했다.

발견 후보는 세 가지다. 독립 확인을 위해 확정 결함과 구분했다.

- P43-C01 · 군번줄의 수가 이어지지 않는다. attempt02 82행에서 강우는 대구 경비탑 난간에 군번줄 하나를 걸어 둔다. 반환 장면 없이 293행에는 두 번째 군번줄을 넣고, 296행 한강 선택 결과에서는 두 개를 꺼낸다. 82행은 3일 대구, 296행은 8일 서울이며, 후자의 동료는 민지·강우다. 선택한 영입 분기의 물건과 한강 회상의 물건을 맞추는 범위가 필요하다.
- P43-C02 · 아침 대화가 아직 오지 않은 저녁을 마친다. attempt01 391행 `comp_food_debate`는 13일 06:30 천안에서 들어온 현재 대화다. `심판을 본다`를 고르면 “그 약속 덕에 그날 저녁이 조금 덜 초라했다”로 끝나지만, 전후 시계는 06:30 그대로다. 식량·물은 모두 0, 동료는 민지·강우다. 비용을 추가하자는 제안이 아니라, 마지막 반응을 지금 대화에 머물게 하는 문장 범위의 후보다. 무료 짧은 대화의 시간 추상화 자체는 결함으로 세지 않았다.
- P43-C03 · 마을 견인 선택이 같은 도로의 연료 지원으로 끝난다. attempt01 385행에서 “가까운 마을로 견인을 부탁한다”를 선택해 고철 20과 5시간을 쓴다. 연료는 0→6L가 되지만 차량은 천안→평택 24.05km 지점 그대로다. 다음 18분 주행으로 정착 서비스가 없는 평택에 도착한다. 실제 효과를 유지한다면 선택·결과가 도로에서 연료를 얻는 행동임을 설명하는 범위가 가장 작다. 마을로 이동시키는 의도였다면 별도 기획 확인이 필요하다.

전체 753행과 선택 195회를 시간순으로 읽었다. 반복되는 원문·선택 목록·결과는 첫 출현 행을 참조했지만, 각 출현의 위치·시각·동료·자원·선택·변화는 모두 확인했다. 1차 출력의 잘린 구간은 더 작은 범위로 다시 읽었다. 모든 자연 시도가 끝나고 전체 검토를 마친 뒤에만 위 세 후보의 실제 출현 정의를 확인했다. 이후 플레이를 다시 돌리지 않았다. 해당 정의를 읽는 과정에서 인접한 대안 원문도 출력됐다는 점을 남긴다.

선택은 별도 시드 난수로 25% 확률의 균등 추첨과 75% 성향 가중 추첨을 섞었다. 가중 추첨에서도 모든 활성 선택의 확률은 양수다. 첫 시도는 복수 선택 69회 중 균등 16회, 가중 53회였다. 재시도는 같은 선택 함수를 유지했으며 복수 선택 59회였다. 재시도 래퍼가 원래 함수의 내부 카운터까지 내보내지 않아 균등 횟수는 보존하지 못했다. 난수 방식·실제 경로·기록한 카운터는 `random-qa.json`에 있다.

엄마를 만났을 때 말을 못 하는 답을 고를 수 있었고, 마지막 중계소 의자로 이어지는 흐름이 이 성향의 플레이에 잘 맞았다. 공연·동물을 선호했어도 실제 사건은 거의 제시되지 않았고, 민지·강우와 가족 기록이 주된 정서 경로였다.

검증 범위는 격리된 Node VM의 실제 소스 엔진이다. 화면·입력·모바일·그림·오디오는 검증하지 않았다. 실제 목표 수첩 대신 관측용 메타데이터를 사용했으며, 영입 수락·획득 퍼크·서울 진입 단계와 지불 결과 재로드는 하네스가 처리했다. 제작 소스·Studio·실제 사용자 저장에는 손대지 않았다. 원본 추적과 저장은 각 attempt 폴더에, 행·인용·재현 경계는 `findings.json`에 보존했다.
