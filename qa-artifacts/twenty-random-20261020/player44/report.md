# player44 — 실리를 따지는 서해안 상인

첫 시도에서 본편을 끝냈다. seed204044, 식량 준비 묶음으로 출발해 레오·민지와 함께53일째 서울에 도착했다. 최종 선택은 집행권 인계(core_transfer), n1261에서 `SESSION 1 END`를 읽었고 summary의 `storyDone=true`, `ending=story_done`을 확인했다. 사망·미완료·재시도는 없다.

자기 trace1,262행과 선택162회를 처음부터 끝까지 읽었다. 활성/비활성 선택, 실제 결과, 재화 변화, 시각·위치·명단과 다음 행동을 매번 대조했다. 출력이 생략된 부분은 범위를 줄여 재독했다.162회 모두 paid-result reload가 성공했고 효과를 다시 적용하지 않았다. 관찰에 사용한 코드는 실제 소스 엔진을 실행하지만 화면·음향·타이머를 대체하므로 실제 화면 QA는 아니다.

후보는 네 건이다. 아직 원 사건 소스나 실제 reader에서 확인하지 않았으므로 수정 확정 목록으로 보지 않는다.

세부 인용, 정확한 행, 이동 구간, 시각·자원·명단과 재현 경계는 [findings.json](findings.json)에 담았다. 원본은 [attempt01/player44-trace.json](attempt01/player44-trace.json), 종료 상태는 [attempt01/player44-summary.json](attempt01/player44-summary.json)이다.

정책은 게임 RNG와 분리한 seeded PRNG를 썼다. 여러 선택이 가능할 때25%는 균등, 나머지는 거래·수리·기록·도움에 무게를 주면서 모든 대안을 양수로 남겼다. 실제 다중 선택은107회였고 인덱스0/1/2/3을 각각104/49/8/1회 골랐다. 이것은 균등 분기의 실현 횟수가 아니다. 프로세스 내부 카운터를 파일로 남기지 못한 한계와 정책·trace·source 해시는 [random-qa.json](random-qa.json)에 기록했다.

긴 여정에는 정책의 영향이 크다. 공개 시장·예측·모집·게시판만 따라갔으며 의뢰40건을 반복 수락하고 모두 완료했다. 거래291회와 노동2회를 했다. 수원에서 서울로 바로 올라갈 수 있을 때도 사이드 배달을 먼저 따라간 탓에 누적6,525km가 됐다. 이 길이 자체를 진행 오류로 올리지 않는다. 또한 연료 예측의 shortage를 차단하지 않은 정책 결함 때문에 세 구간을 무리하게 출발했고 한 아침 식량이 부족했다. 다음 시장에서 회복해 사망 없이 끝났으며, 그 판단 오류는 게임 후보와 분리했다.

새 정책과 원본 시도만 보존했다. harness/runner/observer API 외의 미래 이야기나 다른 플레이어 정책·보고서를 실행 전에 읽지 않았고, 종료 후에도 사건 소스·parser는 열지 않았다. 프로덕션·Studio·실제 사용자 저장본은 건드리지 않았다.
