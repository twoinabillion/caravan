실패 원본과 시도별 정책은 모두 보존했다. 재시도 사이에는 자신의 공개 관찰만 읽고 조달·보급·이동 규칙을 고쳤다. 게임 소스, 미리 보지 않은 결과, 다른 플레이어의 정책과 보고서는 읽지 않았다. 성공 뒤 추가 경로·fixture·플레이는 실행하지 않았다.

이주자 성향은 씨앗·텃밭·생활공간·지역 도움에 높은 확률을 주는 방식으로 적용했다. 여러 선택지가 가능할 때 25% 확률로 균등 추첨하고, 나머지도 모든 대안에 양수 가중치를 남겼다. 균등/가중 추첨 횟수는 각각 16/50, 15/31, 18/47이었다. 이는 선택과 개조·의뢰 추첨을 합한 수치이며 실현 비율을 맞추기 위한 재실행은 없었다.

완주 시도에서는 씨앗을 챙겼고(27행), 지붕 텃밭·빗물 집수기·좌석칸을 설치했다(79·81·118행). 밀양 펌프와 부품 분류, 돔 경계·배선 일을 도왔고 의약품 조달도 끝냈다(115–117행). 민지·강우·은수와 남산에 갔다. 확률 선택 때문에 온실 수확과 몇몇 동료 부탁은 거절했다.

세 기록 1,013행, 선택 발생 245회를 시간순으로 전부 읽었다. 진입 본문, 비활성 선택지까지 포함한 제안, 실제 선택, 결과·칩, 위치·시각·동료·자원 전후를 확인했다. 완전히 같은 문장은 최초 발생 위치로 대조했지만 매 발생의 문맥은 따로 확인했다. 유료 결과 재불러오기 244회는 모두 `loaded=true`, `replayed=true`, `applied=false`이고 관측 전후 상태도 같았다. 실제 브라우저의 뒤로가기나 입력 검증을 뜻하지는 않는다.

확정 결함은 주장하지 않는다. 후보 두 개를 findings.json에 남겼다.

- P49-C01: attempt01 400행의 결과 칩이 `연료 -1.61909L`이다. 421행의 `연료 -3.450293L`, 403행의 `피로 +15.45802`도 같은 표시 정밀도 후보다. 실제 차감량과 바닥값은 일치했다. 수정 검토 범위는 표시 문자열이며 저장 자원 값은 아니다. 실제 리더가 재포맷하는지는 확인하지 않았다.
- P49-C02: attempt01 436행에서 10시간 연료 회수 선택이 갈증 사망 경계인 다음 날 00:00에 끊긴 뒤, 반환 자료에 연료 +8과 귀환 문장이 남았다. 연료가 시간 진행 전에 적용됐을 가능성, 실제 UI가 종료 뒤 결과를 표시하지 않을 가능성이 있어 결함으로 확정하지 않았다. 확인 범위는 해당 거래의 적용 순서와 결과 소비자다.

첫 두 시도의 물·식량 부족은 정책이 공개 경고에 충분히 대응하지 못한 결과다. 의도한 기아 시험이 아니었고, 이를 게임의 진행 불가 결함으로 세지 않았다. 실제 소스 엔진을 격리 저장소에서 실행했으며 화면·오디오·타이머는 대체돼 있다. 사람·모바일·브라우저·시각·오디오 QA는 하지 않았다. 게임과 실제 저장은 변경하지 않았다.
