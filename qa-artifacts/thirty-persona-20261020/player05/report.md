# player05 — 의심 많은 증거 조사자

첫 시도에서 실제 `SESSION 1 END`(trace **237행**)와 `storyDone=true`까지 완료했다. `provisions`, seed `203005`, 상혁. 민지 한 명과 8일·530km를 이동했고, 73번의 선택 끝에 코어 격리 수면(`core_sleep`)을 택했다. 실행 오류·사망·정지·재시도는 없다.

원본 [trace](attempt01/player05-trace.json)의 **1–238행 전체**를 [review.cjs](review.cjs)로 연속 구간별 읽었다. 모든 사건의 진입문, 제시된 선택과 게이트, 실제 선택·결과·칩을 시간·장소·일행·자원과 대조했다. 반복 위기도 매번 확인했다. 73번의 결과 재불러오기는 모두 상태 전체가 같고 `applied=false`였다. 마지막 장면에는 하진과의 통화, 수원 외곽의 엄마에게 돌아간 뒤 대화, 실제 종료 표식이 포함된다.

플레이와 전체 검토가 끝난 뒤 위의 실제 본 사건 정의와 사기 처리만 확인했다. 사기 처리 소스는 100으로 제한한 뒤 명목 `fx.mood` 값을 칩에 넣는다. 수정 경계는 해당 영수증 생성부가 적절하다. 번호판 문제는 회수조의 결과·일지에서 식별 대상을 외관으로 바꾸는 정도, 날씨 문제는 해당 진입문의 날씨 분기 또는 중립 표현 정도가 가장 작다. **수정은 하지 않았다.** 세부 근거·확신·재현 경로는 [findings.json](findings.json)에 있다.

## 실패와 정책 한계

자원난은 숨기지 않았다. 부족 경고를 무시한 출발이 83·113·132·166·180·201행에 있었고, 연료 구난은 **89·118·134·168·203행의 5회**였다. 졸음 두 번과 굶주림 한 번도 정상 선택으로 회복했다. 이는 정책의 보급 판단 실패이며 게임이 강제한 진행 불가로 보지 않는다. 선택 점수 동점 때 첫 항목을 고른 탓에 53행의 확인되지 않은 회수료 지불과 보급보다 빠른 동쪽 노선 선택도 있었다. 다른 장소에서 같은 날 소진된 대화를 5번 재시도했으나 매번 다음 행동으로 진행했다.

기록·증언·명령 원본을 순서대로 확인하고, 어머니의 설명을 즉시 용서로 처리하지 않으며, 수면으로 잠길 조회 예약을 먼저 살펴볼 수 있는 흐름은 조사자 플레이에 맞았다. 다만 이 정책은 게시판 의뢰와 현장 일거리를 실행하지 않았으므로 경제 균형이나 모든 회복 경로에 대한 평가가 아니다.

이번 검증은 격리 Node VM의 실제 엔진 플레이다. 화면·그림·터치·음성·화자 파서 검증은 하지 않았다. 엔진의 main/navigation 관찰값을 실제 목표 수첩의 표시로 단정하지 않았다. 한 경로의 검토이며 모든 분기나 실제 인간 반응을 대표하지 않는다. 소스·사용자 저장·Studio·브라우저·서버·빌드는 건드리지 않았다.
