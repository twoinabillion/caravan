# player21 — 서쪽 마을 문화 탐방

두 시도 모두 실제 `SESSION 1 END`와 `storyDone=true`, `ended=true`까지 완료했다. 결말은 집행권 인계(`core_transfer`)다. 확정된 진행 버그는 없고 서술·자원 계약의 연속성 후보 2건을 남긴다.

| 시도 | 결과 | 경로와 검토 |
| --- | --- | --- |
| attempt01 | DAY6, 430km, 선택 59회 | 중앙 능선 경로. 원본 정책을 `policy-attempt01.cjs`로 보존. 1–187행 전부 검토. 마지막 결과 186행. |
| attempt02 | DAY7, 505km, 선택 61회 | 밀양→합천→거창→남원→전주→논산→공주→세종→대전→청주, 이후 본편. 1–200행 전부 검토. 마지막 결과 199행. |

첫 정책은 우회 상한 100km가 너무 짧았고, 김천 공개 fork에서 동률인 첫 선택 ‘동쪽 능선길’을 골랐다. Root가 허용한 재시도에서는 양산 방문 뒤 공개 거리 180km 이내·14일 미만의 서쪽 우회만 허용했다. ‘서쪽 장터길’ 우선순위도 추가했으나 실제 두 번째 경로는 김천을 지나지 않았다. 같은 seed 203021, 이름 상혁, 실제 준비 묶음 `provisions`를 유지했다. 보이지 않는 결과나 상태를 정책에 사용하지 않았다.

## 연속성 후보

1. **번호판 없음과 번호 식별의 충돌** — attempt02 52행 `salvage_claim` 0번에서 “번호판 없어요.”라고 말하고 상대도 ‘오늘 세 번째 차’로 대체 기록한다. 번호판 획득 없이 80행 `cleaners_recall` 0번 결과는 “물러나면서도 남자는 우리 차 번호를 오래 봤다.”라고 한다. 119행 `patrol_toll`도 “아직 우리 번호를 읽지는 못했다.”라고 전제한다. 앞 대사가 거짓말이거나 다른 번호를 뜻한다는 설명은 없다. 낮은 심각도의 연속성 후보이며, 차량 추적 수치가 아니라 해당 식별 문구만 검토하면 된다.

2. **고기날의 고철 2 지출과 답례 서술** — attempt02 166행(동일 현상 attempt01 153행), `lc_suwon_galbi` 유일한 0번 선택은 ‘고기날에 합류한다’다. 관측된 hint/requirement는 비어 있고, 결과는 “답례로 차에 있던 조미료를 조금 덜어 주방 선반에 놓고 왔다.”라고 하지만 고철은 12→10, 식량은 2→3이 된다. 사후 정확한 정의도 `req/hint/cost` 없이 `fx.scrap=-2`다. 식사비인지 조미료의 물물교환 추상화인지 확인하고 문구·비용 계약을 맞출 후보로 남긴다. 실제 UI의 별도 비용 예고 유무는 확인하지 않았으므로 UI 결함으로 확정하지 않았다.

## 정책 책임과 관측 범위

연료 위기는 첫 시도 3회, 두 번째 4회였다. 부족 예보를 보고도 출발했고, 회수료를 내거나 오전에 식량 0인 채 피로만 보고 camp를 실행한 것은 내 정책 실수다. 무상점 구간 전체의 연료를 미리 확보하지 않은 문제를 강제 소프트락으로 집계하지 않았다. 두 번째 시도에서 실제 가격으로 보급 5회를 샀고, 무한 노동이나 시장 왕복은 없었다. 일손 라벨을 좁게 찾은 탓에 work는 실행하지 못했으므로 노동 회복을 평가할 근거가 없다.

총 387행·선택 120회를 시간순으로 읽었다. 진입·모든 선택지/게이트·실제 선택·결과·전후 자원과 위치/시각을 확인했다. 반복 문단은 첫 시도의 정확한 행을 참조하면서 발생별 상태를 다시 읽었다. 결과 재불러오기 120회는 모두 loaded/replayed=true, applied=false였고 전후 스냅샷 차이도 없었다. 모든 게임이 끝난 뒤에만 만난 사건의 정의를 확인했다.

Node VM 엔진 감사이며 실제 화면·모바일·오디오·화자 파서·입력 QA는 아니다. 영입/동료 이야기/게시판 임무/업그레이드와 미선택 분기는 미검증이다. 엔진 목표 데이터가 실제 수첩에서 같은 문구로 보인다는 주장도 하지 않는다. 프로덕션·Studio·브라우저·실제 저장·빌드·서버는 건드리지 않았다.

원본 trace/summary/save는 각 attempt 폴더, 재현 정책은 위 두 파일, 구조화된 근거와 제한은 `findings.json`에 보존했다.
