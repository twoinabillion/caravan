## 연속성 후보 P16-C01

81행 `story_family_principle`에서 1번 「천리안의 분류 화면까지 함께 저장한다」를 골랐다. 다른 표시 선택지는 「끊긴 다음 문장을 찾아 복원한다」였다. 실제 결과는 “사람 옆의 점수와 화살표까지 저장했다.”이며 저장·확대·기록만 설명한다.

103행 `story_family_key`는 “복원한 발표 연습 영상의 첨부 목록에 ‘검증키 분리 절차 4–5쪽’이 남아 있었다.”로 시작한다. 둘 사이에 복원 선택은 없었다. 198행 결말의 회고도 “부모님의 영상과 천리안의 분류 화면을 함께 남겼다.”로 저장 선택을 유지한다.

예상은 저장하거나 확인한 영상이라고 부르거나, 실제 복원 이력에 따라 표현을 나누는 것이다. 실제로는 공통 진입문이 복원을 완료한 것으로 부른다. 플레이 종료 후 해당 두 사건 정의만 확인했다. `story_family_key.text`의 첫 문장은 정적 문자열이고, 앞서 고른 결과는 분류 화면 저장만 설명한다. 최소 검토 범위는 `src/03-data.js:11322`의 첫 문구다. 비용·검증키 획득 절차·기존 유료 결과를 바꿀 사안은 아니다.

신뢰도 0.83. 진입에서 영상 조각이 재생된 일 자체를 넓게 ‘복원’이라 부른 것일 수도 있어, 확정 버그로 올리지는 않았다.

## 전체 기록 검토와 한계

1–18 / 19–40 / 41–64 / 65–88 / 89–112 / 113–136 / 137–159 / 160–179 / 180–199행을 순서대로 읽었다. 모든 진입문·선택지·표시/활성 조건·고른 답·결과·비용 칩·알림·전후 자원을 대조했다. 경로·시설·게시판 관측도 각 출현 시점마다 확인했다. `review.cjs`는 구간 첫 상태와 이후 모든 변경을 출력하며, 빈 delta는 앞 행과 같다는 뜻이다. 59회 모두 결과 저장/재불러오기에 성공했고 재적용은 false, 공개 상태 전후가 같았다.

18행 커피와 53행 회수료는 동점에서 첫 선택을 택한 정책의 지출이다. 연료 위기 5회(49/100/111/131/153행)는 공개 부족 경고를 보고도 출발한 정책 실수다. 모두 회복해 끝까지 갔다. 제목만 보는 일손 정규식은 시설 설명에 담긴 기회를 놓쳤다. 이를 게임의 일손 부재나 강제 진행 막힘으로 보고하지 않는다. 재시도는 없었다.

194행의 밤·새벽과 198행 수원 귀환은 종료 후일담이며 실시간 자원 시계는 진행되지 않았다. 해당 결말 정의가 ‘그날 밤/다음 날 새벽’ 출처를 명시하므로, 오전 시계와 다르다는 이유만으로 시간 결함을 만들지 않았다.

이 실행은 UI·오디오·타이머를 대체한 격리 Node VM의 실제 엔진 플레이다. 실제 모바일 화면, 인물 화자 파서, 레이아웃, 입력·취소 동작, 미선택 분기와 다른 결말은 검증하지 않았다. 198행에서 `〔 서울까지 400km · SESSION 1 END 〕`를 직접 읽었고, 최종 요약은 `storyDone=true`, `ending=story_done`이다. 정책·원본 trace·summary·save는 `attempt01/`에 남겼다. 소스, 사용자 저장, Studio, 브라우저, 빌드·서버에는 변경하지 않았다.
