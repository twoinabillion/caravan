# Player 07 · 위험 감수·행동파

성향: 빠른 해결·강행·직접 개입을 선호하고, 야간 운전과 충돌 위험도 감수한다. 현재 표시된 선택지·공개 조건·위험 힌트만으로 결정했다. 잠긴 선택·없는 자원은 강제로 사용하지 않았다. seed 181007, 연료 짐.

## 실행 범위와 결과

- 실제 엔진을 독립 Node VM에서 실행했다. 브라우저·음성·그림·입력 타이밍은 검수하지 않았고 사용자의 저장/화면/서버/생산 소스는 변경하지 않았다.
- 대표 경로는 아래의 유료 좌석 구매 실험(`player07-attempt2-*`)으로 삼는다. 실제 유저가 공개된 좌석 부족 안내에 반응할 수 있는데, 기본 하네스 정책은 그 행동을 구현하지 않았기 때문이다. 원래 정책의 실패와 합쳐 단일 완주율을 계산하지 않는다.
- 현재 `player07-trace.json`은 원래 정책을 수정된 공통 runner로 재실행한 별첨 결과다. Day 13 00:24, 1,146km, 258개 기록/92개 선택 뒤 `thirst` 사망. 본편 10/13 진행, 민지·강우 동행, 은수 정식 합류는 좌석 부족으로 실패했다.
- 최초 하네스 반복 실패는 `player07-initial-*`와 `player07-attempt1-*`에 보존했다. 하네스 수정 후에도 남은 경로 선택 한계를 아래에 별도 분리했다.
- 별도 `player07-attempt2-*`는 공개 좌석/업그레이드를 보고 실제 좌석을 구매하는 정책 민감도 실험이다. Day 9, 908km, 228개 기록/87개 선택 뒤 `core_transfer` → `story_done` 도달. 같은 인간이 시행착오 후 새로 플레이한 것에 해당하므로 원래 정책의 성공으로 바꾸어 세지 않는다.

## 확인한 점 5개

1. **[하네스/봇 한계 · 게임 버그로 집계 금지] 좌석이 꽉 찬 영입을 경로 추적이 반복했다.** 최초 시도는 천안에서 `rq_eunsu_join` → `doRecruit=false` → 자동 재오픈을 반복했다. 수정 runner의 본 시도에서는 n183·186·229·248의 「조수석 아래에 수신기 자리를 만든다」 이후에도 파티는 민지·강우 2명 그대로이고 합류가 실패했다. 이후 n190부터 평택 도착 직후 `recruitQuest={stage:ready,target:cheonan}`를 우선 추적해 천안↔평택을 반복했다. 메인 목표는 평택 주변 탐색인데 n254에서 다시 천안으로 출발, n258에서 물0/식량0으로 사망했다. 고철28·부품8을 갖고도 봇이 좌석 구매나 사이드 미션 추적 해제를 못한 결과이며, 실제 유저가 갇힌다는 증거는 아니다. 다음 다중 페르소나 실행은 미완 영입의 ready 상태를 주행 목적지보다 우선하지 않거나, 공개 좌석 안내를 해석해야 한다.

2. **[기획적 결과 · 정상 작동] 위험 경고와 실제 사고가 연결된다.** n62·103·114·122에서 「노래를 크게 틀고 강행한다」의 공개 힌트는 「위험 · 사고 위험」이다. n62는 피로-12/사기+2로 버텼지만 n103·114·122는 가드레일을 긁고 각각 차체-9%, 피로-28, 사기-4를 받았다. 성공만 되풀이되는 가짜 위험은 아니었다. 다만 여러 번 똑같은 사고 문구가 이어져, 위험을 즐기는 유저에게는 반복 체감이 클 수 있다. 성공률/평균 피해의 밸런스 결론은 이 seed 하나로 내릴 수 없다.

3. **[서사·선택 연결 개선 후보] 손을 이미 넣은 레버를 왜 도구 없이는 못 당기는지 빠졌다.** n239 「배수로를 따라 제어함까지 붙는다」 → n240 「센서가 더 켜지기 전에 손부터 댄다」 결과는 「손을 레버 안쪽까지 넣었다. 이제 여섯 초 안에 당기기만 하면 된다」다. 그런데 n241의 당기기 선택은 쇠파이프1개 필요로 비활성, 은수 선택은 미합류로 숨김, 화염병도 없어 「작업을 버리고 논길로 물러난다」만 가능했다. 결과는 연료-4L/40분/관측+1. 자원 게이트를 없앨 문제가 아니라, 지금 가진 손잡이만으로는 안 되는 고착/지렛대 필요를 앞 결과에서 알려주거나 초기 돌입 전에 공개 도구 조건을 연결할 문제다. 실제 n241 결과도 자원 없는 돌파로 바꾸지 않았다.

4. **[정보 설계 개선 후보] 자원 고갈의 대가가 선택 전에는 잘 안 보인다.** n112 「걸어서 연료를 구해온다」는 표시 힌트가 비어 있지만 실제 결과가 연료+9L, 물-2, 식량-2, 7시간, 사기-4다. n158 「다시 걷는다」도 힌트 없이 연료+8L/물-3/식량-3/9시간/피로+18을 받았다. 직행을 고르는 성격에게는 이미 늦은 뒤 긴 우회 비용을 배우게 된다. 정확한 보상을 미리 누설하지 않으면서 「장시간 도보 · 물과 식량 소모」 정도는 선택 전 공지할 가치가 있다. n215 「자물쇠를 부순다」는 반대로 「위험 · 마을과 척진다」가 실제로 보이고 물+5/30분/불편한 관계 묘사로 연결되어 비교적 납득된다. 다만 이 한 번으로 후속 관계 페널티 유무는 판단하지 않는다.

5. **[정상 도달 확인 · 별도 정책 실험] 자리 마련을 실제 비용으로 해결하면 본편과 작별이 연결됐다.** attempt2 n159에서 공개된 「후미 레일 좌석칸」을 실제 구매해 고철29→17, 부품8→7, 시간225분을 지불했다. n184 합류 장면 뒤 은수가 실제 파티에 들어왔고, n225 「집행권을 저항 연대망에 넘긴다」를 선택해 포탑·차단기 중단/전력·수도 보존 결과를 읽었다. n226은 민지·강우·은수의 서로 다른 정리 행동과 맡긴 감천 열쇠를 회수했고, n228은 하진의 귀향 선택과 엄마에게 돌아가는 대화로 `SESSION 1 END`에 도달했다. 감정적 마무리가 없는 것은 아니다. 이 실험에서는 밤/새벽/수원 이동 후일담에도 게임 시각·장소가 서울 Day9 22:34로 고정되므로, 이후 UI가 이 부분을 시간 압축된 에필로그로 충분히 구분하는지는 별도 실제 화면 검수가 필요하다.

## 우선순위

이 결과만 보면 먼저 하네스의 ready 영입 경로 루프를 제거해야 실제 완주율을 논할 수 있다. 게임 쪽 우선 확인 후보는 전투 진입 전 도구 조건의 공개/서사 연결, 고갈 복구 선택의 장시간·소모 안내다. 더 많은 사건이나 분량을 더해야 한다는 근거는 이번 실행에서 나오지 않았다.
