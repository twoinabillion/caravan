# attempt02 최소 적응

attempt01은 19일차 탈수 엔딩으로 끝났고 본편은 미완료였다. 청주에서 공개 목표가 새 기록을 `주변 탐색`으로 열도록 안내하고 `explore.ok=true`였지만, 탐험 정책의 장소별 3회 상한이 모든 열람을 막았다. 정책은 이후 청주와 세종을 왕복하며 식량·물을 소진했다.

이는 게임의 진행 불능으로 확정하지 않는다. 공개된 새 메인 기록은 일반 탐색 상한에서 제외하는 한 가지만 적응한다. seed 181305, repair 준비물, 사건 선택 성향, 거래·노동·수리·야영·동료 정책은 유지한다. attempt01의 파일과 결과는 보존한다.
