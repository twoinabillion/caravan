# player10 — 꼼꼼한 재접속·기록형

첫 시도 `attempt01`에서 본편을 끝냈다. 종결은 `story_done`, 마지막 집행 방식은 `core_transfer`(저항 연대망 인계)다. 재시도는 없었다. 7일차 10:09, 서울 — 남산, 누적 530km에 민지·강우 두 명이 함께했다. 실제 상태에는 연료 약 49.63, 물 16, 식량 4, 고철 0, 차체 100, 부품 11, 의약품 2, 부모님의 검증키 1개가 남았다.

## 진행과 검수 범위

정책은 실행 전에 독립 작성했다. seed는 181310, 출발 꾸러미는 repair다. 공개 본문·선택 label/hint·조건·자원·현재 목표·지도 예보만 보고 기록 확인과 수리·복원·전달을 우선했다. 동점은 공개 선택 순서로 골랐다. 원본 outcome/fx/확률을 참조하거나 보급·명단·플래그를 주입하지 않았다.

경로는 부산 → 양산 → 밀양 → 양산 → 울산 → 경주 → 대구 → 구미 → 김천 → 상주 → 문경 → 충주 → 청주 → 천안 → 평택 → 수원 → 서울이다. 민지 의뢰로 울산에 들렀고, 김천에서는 동쪽 능선길을 골랐다. 보급 거래 13회, 실제 현지 노동 1회, 탐색 15회, 야영 6회, 동료 영입 2회와 이동 16회를 수행했다. 버스 수리에 부품 1개를 썼다. 차체가 필드 수리 기준 아래로 내려가지 않아 필드 수리는 하지 않았고 야영으로 회복했다.

281개 trace 중 선택 73건 전부의 진입 원문, 모든 공개 선택, 고른 이유, 결과, 시간·장소·명단·보유 자원·목표 전후를 읽었다. 최종 저장의 공책 84개 항목과 목표 갱신·완료 이력, 영입 방식, 엔딩 회수를 추가 대조했다. 전체 선택 전사본은 `full-journey-review.txt`에 있다. 결과 선택 전 미래 결과를 읽은 것은 아니며, 전편 대조는 종결 후 진행했다.

선택 결과마다 실제 G.save/G.load 후 같은 유료 결과를 다시 해석한 73회에서 모두 loaded/replay가 성공했고 `applied:false`였다. 새 장소/날짜에서 한 일반 저장·불러오기 21회도 성공했다. 이 94회 모두 실행기에서 관측한 스냅샷의 변화는 0건이다. 이는 동일 VM의 관측 필드 검증이며 브라우저 새로고침·전체 숨은 상태 동등성 검증은 아니다.

민지는 울산에서 임시 도르래로 진단기를 회수한 뒤 경주에서 정식 합류했고, 강우는 대구의 경계선을 다시 짠 뒤 구미에서 정식 합류했다. 두 영입 방식은 최종 저장의 approach와 마지막 결과 칩에도 그대로 남았다. 검증키는 두 장을 확보한 뒤 실제 보유품에 생겼고, 명령 원본 확인 → 아빠 기록 → 엄마 재회 → 중계 응답 → 서울 진입 → 집행권 인계 → 상위망 후일담 → 본편 완료로 이어졌다. 마지막 방식·story_done·ended와 최종 메인 목표 완료는 서로 일치했다.

## 주관적인 불편과 검수 한계

P10-S01은 공책의 출처 표현이다. `story_family_principle`은 발표 전날의 연습 영상을 복원했는데 공책 n39는 “엄마의 발표 원고를 복원했다”고 쓴다. 발언 내용을 원고라고 부른 것으로도 읽혀 확정 모순에 포함하지 않았다.

실행기는 실제 UI가 붙이는 G.reqCostText(req)를 전부 전달하지 않는다. 빈 hint만 보고 비용이 보이지 않는다고 판정하지 않았다. 원시 `main.why`의 운영 문체도 공책 변환을 확인한 결과가 아니므로 플레이어 말투 문제로 세지 않았다. `seoul_night`와 상위망·마지막 가족 대화는 에필로그/후일담이므로 저장 시계·노드와의 차이를 현재 행동 오류로 세지 않았다. 임시 승객이 party 배열에 없는 것도 정식 명단 누락으로 세지 않았다.

이번 검수는 Node VM에서 실제 엔진을 실행하고 문맥을 읽은 것이다. 프레젠테이션·음성·실시간 대기는 생략됐다. 브라우저·사람 플레이·시각·음성 검수가 아니며 실제 공책 화면의 노출, 취소/뒤로, 페이지 커서, 새로고침 후 패널 복원, 최종 결과 Continue 입력은 확인하지 않았다. 실제 Studio 4319, 탭, 서버, 사용자 저장에는 접근하지 않았다. 게임 소스·자산·기존 감사 자료는 수정하지 않았다.
