## 관측한 문제

### P01-01 · 중간 · 경고사격과 차체 피해의 원인이 맞지 않는다

`perimeter_first`, trace 85, 충주호 DAY 2 18:54.

> 탕. 경고사격이 차 옆 아스팔트를 때렸다.
>
> 보행기는 유유히 갓길로 물러나 도로를 열어줬다.

선택은 ‘…지나간다’ 하나이며 힌트가 없다. 결과는 북부의 위험을 깨닫고 뒤 칸에 대장간을 폈다는 이야기다. 그런데 같은 거래에서 차체가 **84.44 → 78.44**로 줄고 `차체 -6%` 칩이 생긴다. 피격·파편·충돌 같은 원인은 앞뒤 원문 어디에도 없다. 피해 수치는 공개됐지만, 설명을 읽어도 왜 차가 상했는지 알기 어렵다.

플레이 종료 후 현재 소스도 해당 경고사격 본문과 `van:-6`을 함께 가진 것을 확인했다. 결과 칩의 실제 화면 배치는 보지 않았다.

### P01-02 · 중간 · 최종 인계 뒤 목표가 코어 진입 이전으로 돌아간다

`seoul_decision`, trace 180. 앞 trace 178에서는 목표가 ‘남산 코어에서 마지막 결정을 내린다’였다.

> 집행권은 저항 연대망으로 넘어갔다. 포탑과 차단기는 멈추고 전력과 수도는 남았다.

실제로 인계가 완료된 뒤 공개 목표는 다시 ‘코어 앞을 지나 남산 코어로 오른다’, 다음 행동은 ‘코어 앞에서 막힌 길을 열고 다음 진입 지점으로 간다’, 진행은 4/5가 된다. trace 182의 에필로그와 184의 후일담에도 남는다. 최종 trace 186에서야 완료 목표로 바뀐다.

현재 해야 할 일은 인계 결과와 후일담 확인이다. 성공한 사건과 다음 행동이 어긋나는 목표 데이터 문제다. 연속 장면은 정상 진행됐으므로 소프트락은 아니다. 모달 중 이 목표가 실제 어디에 보이는지는 브라우저 미검수라 따로 제한한다.

### P01-03 · 낮음 · 다음 조사에서 알 답이 목표 설명에 먼저 나온다

이 항목은 초보 성향의 **주관적 정보 배치 관측이며, 원시 목표 데이터에 한정된다**. 실제 공책 표시나 논리 오류로 확정하지 않는다.

`parents_diversion_manifest`, trace 60은 부모님이 기술 경력 때문에 서로 다른 이송선에 배정됐다는 사실을 확인한다. 직후 갱신된 목표의 why는 다음과 같다.

> 부모님은 갈라진 뒤에도 강제 이송선만 떼는 순서와 지워질 증언을 서로에게 보냈다.

두 사람이 그 자료를 주고받았다는 실제 발견은 다음 기록 `parents_separated_work`(trace 82)에 나온다. 이 원시 why를 그대로 읽으면 조사 전에 답을 알게 된다. trace 144 원시 next의 ‘엄마가 살아 있었다’ 제목도 직접 재회 전에 같은 느낌을 준다. 다만 실제 공책의 표시 단계는 why·next·title을 변환할 수 있으므로 이 관측만으로 플레이어 화면의 스포일러라고 결론내리지 않는다. 표시 단계 대조가 필요하다.

## 재접속과 검사 범위

각 선택 직후 58번 `G.save → G.load → 동일 지급 결과 재열람`을 실행했다. 모두 `loaded=true`, `replayed=true`, `applied=false`였고 저장 전후 공개 상태도 같았다. 대구 DAY 1 19:27에서 일반 저장/로드도 1회 성공했다. 실제 사용자 저장, Studio 4319, 브라우저 탭, 서버는 건드리지 않았다. 이는 VM 내부 저장 검증이며 실제 브라우저 새로고침·UI 복원 검증은 아니다.

정책 결정 로그는 `attempt01/policy-decisions.json`에 58개 남겼다. 정책은 공개 label/hint의 어휘 점수를 쓰고 동률이면 앞 선택을 고른다. 사람처럼 본문의 의미를 해석하는 것은 아니어서, ‘보급·안전’이라고 본문에 쓰인 서쪽 대신 동률의 첫 항목인 동쪽으로 갔다. 정착지 일도 시설명만으로 노동을 잘 알아보지 못해 실행하지 않았고 연료 부족 예보에도 계속 출발했다. 이 때문에 생긴 보급 실패를 전부 게임의 난이도 문제로 돌리지 않는다.

마지막 결정에는 수원으로 내려가 준비하는 공개 control도 있었다. 현재 가능한 인계를 바로 골랐으므로 수면·보존 결말의 전 과정은 미검수다. 에필로그는 다음 날 새벽과 그 뒤 수원이라는 별도 이야기 시간·장소 표식을 가진다. 마지막 저장 시계와 위치가 그대로라는 이유만으로 에필로그를 시간·순간이동 버그라고 판단하지 않았다.

공유 실행기는 실제 소스 엔진을 독립 Map 저장소로 실행하지만 프레젠테이션·오디오·실시간 기다림을 대체한다. 화면, 그림/크롭, 글자 잘림, 포커스/키보드/터치, 읽기 페이지, 음성·음악은 보거나 듣지 않았다. 브라우저·인간의 1회 완주로 주장하지 않는다.
