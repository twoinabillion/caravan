## 실행 방식과 한계

실제 src/03*·04* 엔진을 공유 runner의 독립 Node VM/Map 저장소에서 실행했다.
각 에이전트의 정책은 공개 문구/조건/목표/자원을 쓰지만, 사람이나 LLM이 매번
실시간 숙고한 것이 아닌 규칙 기반이다. 동률 첫 선택·어휘 오독·탐색 제한 등
편향을 실제 사용자 집단의 재미/완주율/윤리적 선호로 일반화할 수 없다.

실제 UI reqCostText 일부가 관찰 API에 빠져 있다. 프레젠테이션·음성·실시간
대기·입력도 대체되고 후일담 표식은 합본 글에서 빠질 수 있다. **인간 참가0·
브라우저 완주0**. 글자 크기/잘림·그림/크롭·포커스·터치·음성·실제 브라우저
저장 복원은 미검수다. [검사 규약](PROTOCOL.md).
