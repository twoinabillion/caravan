# 성향 플레이 감사 후속 · 연결과 안내 수정

Sang의 “ㄱㄱ” 승인으로 10개 성향 감사에서 확인된 연결부터 수정했다.
전면 대사 윤문이나 새 사건 추가는 하지 않았다. 기존 시간·출처 표시줄을
활용하며 CSS·레이아웃·시각 자산은 변경하지 않았다.

## 바뀐 것

- 문경 나무판: 소개되지 않은 질문자와 대답을 빼고, 한 단어를 적는 독백과
  판자의 글씨로 마친다. 혼자일 때도 없는 동료가 말하지 않는다.
- 합류 제안: 박 선생·레오/보리·재이·은수·강우는 공간을 재거나 짐을 접고
  대답을 기다린다. 정식 합류·보리 동행은 기존 수락 거래 뒤에만 성립한다.
  이미 준비 단계로 끝나는 민지 결과는 유지했다. 좌석 부족·거절·재방문 API는
  바꾸지 않았다.
- 능선 구조: 세 번째 구조 대상은 아래의 남자다. 계단·보조줄·업기 각각의
  성공/실패 결과가 그를 도로로 올리는 과정까지 설명한다. 실패의 붕괴·추가
  시간·압박·부상은 남는다. 마지막에 남은 발목 다친 여자를 두 번 구하지 않는다.
  운전자의 실제 허리 부상도 본문과 맞췄다.
- 강우: 보존 반대는 유지한다. 그 방식으로 정해지면 혼자 세우지 않겠다는
  조건부 답을 먼저 한다. 근무 가능한 명단과 실제 세 사람의 서명을 구분하고,
  서명은 기존 최종 결정 거래가 맡는다. 밤의 “반대했으니까 내가 먼저 선다”는
  그대로다.
- 민지/강우 중재: 현재의 클러치 조정과 앞으로의 일주일 시험 약속까지만 쓴다.
  즉시 사흘·일주일이 지나 배움을 마친 것처럼 쓰지 않는다. 기록도 약속으로 남긴다.
- 종장: 밤·다음 날 새벽·수원 귀환은 기존 출처줄에 `후일담`으로 표시한다.
  출처가 바뀌면 페이지를 나누고, 이전/다시 읽기/저장 복원에도 보존한다.
  엔진 시각·위치를 임의로 밀거나 귀환 요금을 추가하지 않았다.
- 준비: 감시 가능한 인원 부족, 추가 합류, 부상, 사기 부족을 각각 안내한다.
  수원 재준비 중에도 6장과 기존 진입 진척을 유지한다. 공책과 목표 바로가기
  모두 첫 서울 진입이 아닌 멈춘 결정을 이어 가도록 안내한다.

게임 디렉터·대화 시스템 지침으로 입장과 분기를 함께 확인했다. human-voice
지침은 잘 쓰인 대사를 전부 바꾸지 않고 필요한 연결만 쓰는 데 적용했다.
Claude의 중재/조건부 협력 초안을 검토해 채택했으며, 기간을 실제 경과로 쓰거나
밤의 회수 대사를 미리 쓰지 않았다.

## 검증과 범위

`tests/test_persona_continuity.cjs`의 10검사는 15사건의 수정 전 기계적 계약 hash,
독행/각 동료, 합류 6명×좌석 부족·거절·재접속·수락, 구조 중간 6결과,
중재 실제 화자/0분, 64명단의 조건부 답, 인원/부상/사기 안내, 재준비 60분과
4/5진척, 세 엔딩 시점 표지와 페이지/이전/기록, 과거 지급 결과/커서를 확인한다.
이 검사의 강제 상태 구성은 단위 테스트이며 자연 완주라고 주장하지 않는다.
기존 대사 corpus 기준 hash는 교체하지 않고 정확한 세 예외만 검증·투영했다.

`node rerun.cjs`는 이전 감사의 **정책** 10개를 현재 실제 엔진에서 재실행한다.
사람이나 새로운 에이전트 10명이 추가로 검토한 것이 아니다. 독립 VM과 메모리
저장을 쓰고 자원 지급·무한 자원·사용자 저장 변경 없이 새 게임부터 종결한다.
현재 10개는 모두 story_done, 인계·격리 수면·보존 감시가 포함된다. 별도 유료
좌석 정책도 엔딩에 도달했다. 선택 수·기준 대비 차이는 [comparison.json](comparison.json).

9개의 최종 게임 상태는 앞선 기록과 같다. 02는 공개 업기 문구가 달라지자
공감 정책이 계단을 골랐고 최종 상태는 같았다. 07은 이전 실행기와 hash가 다르다.
이전 실행 뒤 추가된 현재 단서 위치 탐색 보정 때문에 평택에서 탐색했고,
예전의 왕복 갈증 대신 엔딩에 도달했다. 이를 이번 게임 코드의 개선 효과나
인간 완주율로 계산하지 않는다. 원래 갈증/재시도 기록은 기준 폴더에 남겼다.

첫 실행 도구의 정책 import가 player01을 원 감사 폴더에서 한 번 재실행했다.
이를 `first-import-replay/`에 보존하고, 해당 기준 3파일은 당시 HEAD 엔진/hash와
원 정책으로 재구성했다(`player01-baseline-reconstruction/`). 원 실행 타임스탬프까지
같은 원본이라고 주장하지 않는다. 이후 도구는 정책을 실행하지 않고 설정만
포착하며, 새 결과는 이 폴더에만 쓴다.

전체 source 검사·대사 검사·콘텐츠 참조·HTML 빌드를 실행했다. 기존 32MB
권장 용량 초과와 반복 어두 후보 2건은 남아 있다. 새 이미지/음성은 없다.
전체 **797/797**, 마지막 안내 조건 수정 뒤 집중 **22/22**, 최종 HTML
106,297,952bytes 빌드 및 diff 검사가 통과했다. 최종 10개 재실행의 공통
엔진/데이터 source hash는 `4d167324a7b64c0beef29ef0b8b562e7192eef010fa02b10012cd8f4503af661`.
말투 검사 후보1건은 보존한 강우의 실제 회수 대사를 인용한 부분이라 유지했다.
