# Claude 변경 통합 정합성 감사

- 날짜: 2026-08-17
- 대상: 현재 `/Users/sang/caravan` 작업 트리와 새로 빌드한 `서울까지400km.html`
- 브라우저: Google Chrome
- 모바일 규격: 320×578, 390×844, 475×948

## 결론

Claude의 최신 UI 변경은 현재 게임 구조와 시각적으로 맞는다. 지도 문구는 프레임 안의
두 줄 계약을 지키고, 정착지 주민·합류 인물 행은 얼굴 / 이름·설명 / 상태 라벨의 세 칸
정렬을 유지한다. 전체 화면 캡처에서는 넘침·잘림·44px 미만 조작 요소가 없었다.

다만 통합 검사에서 런타임이 아니라 **두 개의 옛 테스트 계약**이 새 정본과 충돌했다.
정착지 전용 테스트는 주민 초상을 96px로 강제했고, 자산 감사기는 17명의 256px 초상과
대구 세로 고해상도 도착 컷, WebP 밀양 허브를 오류로 판정했다. 승인된 현재 규격으로
테스트 계약을 갱신했으며 모든 검증이 통과한다.

## 단계별 건강 상태

1. **길·머물기·목표·지도·가방·메뉴 — 양호**
   - 핵심 화면 29상태를 3개 모바일 규격에서 새로 캡처했다.
   - 문서 넘침 0, 화면 밖 조작 요소 0, 잘린 텍스트 0, 44px 미만 조작 요소 0.
   - 지도 상단 `여정 지도`, `발견 42/58 · 서울까지 약 356km`, 하단 `선택한 길`,
     `이 길 선택 / 거리·연료`가 프레임 안에서 역할별 두 줄로 유지된다.

2. **7개 큰 정착지 주민 목록 — 양호**
   - 광주·밀양·대구·무주·전주·대전·수원 전부 다시 캡처했다.
   - 긴 합류 소개문이 있어도 상태 라벨이 설명 중간에 끼지 않고 이름 줄에 붙는다.
   - 주민과 합류 후보 모두 실제 초상을 사용한다.

3. **주민 대화 17개 — 양호**
   - 각 인물을 선택한 대화 상태 17개를 3개 모바일 규격에서 확인했다.
   - 대화 카드, 주민 목록, 선택 상태, 역할 라벨이 같은 위계로 유지된다.
   - 17/17 초상이 256×256 이상이며 legacy 삽화는 0명이다.

4. **도착 화면 58개 — 양호**
   - 58개 도착 화면을 전수 캡처했다.
   - 57개 가로 장면은 16:9 선명 프레임, 대구는 세로 전용 고해상도 장면을 사용한다.
   - 브라우저 오류·가로 이탈·작은 조작 요소 0.

5. **사건 화면·결과 화면 — 양호**
   - 사건 시작, 기록, 선택지, 결과, 전투 선택 상태를 다시 캡처했다.
   - 장면과 종이 패널의 글자가 프레임 안에 남고, 계속/선택 버튼 위치가 안정적이다.

6. **자동 검증 계약 — 수정 후 양호**
   - `tests/test_settlement_story_overhaul.py`: 96px 고정 기대를 256px 이상 + auto 렌더링으로 변경.
   - `tools/check-scene-assets.mjs`: 상주 주민 17명의 256px 정본과 승인된 대구·밀양 장면 예외를 명시.
   - 화면을 낮은 해상도로 되돌리지 않고 감사기가 현재 디자인 정본을 보호하도록 수정했다.
