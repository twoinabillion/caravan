# Field Board visual finish — Phase 1

`docs/history/handoffs/CODEX-FIELD-BOARD-VISUAL.md`의 착수 순서에 따라 처음 대구 장터 한 화면에만 새 표면 언어를
격리 적용했던 확인용 산출물이다. 이 비교로 방향을 승인한 뒤 27개 시설 화면에도 확장했다.
최종 전체 비교는 `../field-board-visual-rollout-2026-08-18/`에 있다.

- `after-daegu-market-320.png`, `390.png`, `475.png`: 세 모바일 폭 결과
- `before-after-daegu-market.png`: 기존 화면과 390px 결과 비교
- `capture.py`: 화면 재현과 오버플로·색 토큰·도트 격자 자동 검사

이 단계에서는 신규 이미지 자산을 만들지 않았고, 구조·정보·행 높이·게임 동작도 바꾸지 않았다.
`capture.py`는 현재 최종 클래스 이름으로 같은 대구 체크포인트를 재현한다.
