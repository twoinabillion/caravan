# 목표·가방 UI 정렬 점검

점검일: 2026-08-15

브라우저: Google Chrome

화면: 390×844, 360×700

## 결과

기존 가죽 가방과 종이 목표판의 시각 디자인은 유지하고, 라이브 텍스트와 조작 요소의 정렬 기준만 통일했다.

1. 목표 상단 헤더의 좌우 선이 본문보다 넓었던 문제를 수정했다.
   - 수정 전 390px: `x 55.8 / width 285.5`
   - 본문 기준: `x 61.5 / width 274.1`
   - 수정 후: 헤더, 제목, 진행 단계, 단서, 다음 행동, 복귀 버튼 모두 `x 61.5 / width 274.1`

2. 가방 제목과 핵심 자원 칸의 좌우 레일을 일치시켰다.
   - 수정 후 390px: 둘 다 `x 35.9 / width 318.3`

3. 선택 물건 상세 영역의 행동 버튼을 제목·설명과 같은 레일에 맞췄다.
   - 수정 전 390px 버튼: `x 152.7 / width 189.8`
   - 상세 텍스트: `x 131.6 / width 210.8`
   - 수정 후: 제목, 설명, 버튼 모두 `x 131.6 / width 210.8`

4. 다섯 수납칸의 이름, 아이콘, 보유량 중심축을 동일하게 유지했다.

5. 물·식량·연료, 차체, 보급일, 보유량 숫자에 고정 숫자 폭을 적용해 값이 바뀌어도 기준선이 흔들리지 않게 했다.
