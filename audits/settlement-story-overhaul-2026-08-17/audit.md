# 정착지 공간·동료 등장 전수 감사 — 2026-08-17

## 결론

기존 큰 도시 화면은 장소 사진 아래에 2×2 메뉴 카드를 붙인 구조라, 장터 안에 들어왔다는 감각보다 기능 목록을 고르는 감각이 강했다. 또 핵심 동료의 첫 만남이 도로 랜덤 풀에 섞여 있어, 인물이 어느 공동체에서 무엇을 하던 사람인지 이해하기 전에 합류 이야기가 시작됐다.

이번 수정은 다음 두 계약으로 정리했다.

1. 큰 도시는 사진 위 마커가 아니라 매 프레임 코드로 그리는 실제 공간이며, 시설·주민·합류 인물·주인공이 같은 좌표계 안에 존재한다.
2. 동료 첫 만남과 장소가 필요한 개인 서사는 도로 주사위로 열지 않는다.

## 구현

- 광주, 밀양, 대구, 무주, 전주, 대전, 수원 내부를 매 프레임 코드로 그리는 고전 탑다운 타일 Canvas 월드로 교체했다.
- 정착지 내부에서는 도착 시네마틱 JPG를 배경으로 쓰지 않는다. 사진은 장소 도착 연출에만 남는다.
- 12px 타일 격자, 넓은 직교 거리, 단색 건물 외벽, 지붕·창·문, 제한된 도시별 팔레트로 고전 RPG 마을처럼 한눈에 읽힌다.
- 대구의 큰 돔 출입구, 무주의 터널 벽과 작업실, 대전의 연구동 격자, 수원의 성문과 성벽처럼 도시 랜드마크를 일반 점포보다 크게 그린다.
- 사람은 6–9px 폭의 동일 규격 타일 스프라이트다. 일반 행인은 이름표 없이 소수만 움직이고, 합류 인물은 이름 대신 `!` 표시로 구분한다.
- 벡터형 사람·광원 번짐·원형 선택 링·과도한 군중을 제거했다. 선택 시설과 인물은 고전 게임처럼 픽셀 코너 표시만 사용한다.
- 참고 이미지처럼 플레이 필드를 깨끗하게 유지하기 위해 도시 위에 겹치던 중복 제목과 설명도 제거했다.
- 중복 목적지 설명을 도시 위 고정 포커스 패널 하나로 합치고, `들어간다`와 `달구지로 돌아간다`를 같은 행에 배치했다.
- Image Gen으로 만든 픽셀 UI 원본을 48색 이하 팔레트로 정리해 지도 프레임, 일반·선택·닫힘 버튼, 아이콘 베젤로 분리했다. 도시 그림은 계속 코드 Canvas가 담당하고 생성 이미지는 UI 크롬에만 쓴다.
- 두 번째 Image Gen 패스에서 장터·정비소·모닥불·보관소와 사람 8종을 만들고, 크로마 제거 후 256×90·32색 투명 WebP 아틀라스로 묶었다. Canvas가 이 아틀라스를 실제 시설 좌표와 이동 인물 좌표에 그리므로 사진을 붙인 화면이 아니라 계속 움직이는 코드 월드다.
- 시설에는 지붕·창·문·상자·타이어·공구·모닥불 같은 기능 소품이 보이고, 사람은 모자·머리·가방·도구·걷는 다리가 구분된다. 기존 인물 크기와 시설 터치 좌표는 유지했다.
- 2×2 장소 버튼은 번호·실제 장소 아이콘·한 줄 설명·선택 LED를 갖는다. 선택은 따뜻한 황동 프레임, 야간 닫힘은 탈색된 프레임, 일반 상태는 짙은 캔버스 프레임으로 즉시 구분된다.
- `들어간다`와 `달구지로 돌아간다`도 같은 프레임 체계로 통일해 아래쪽에 생짜 사각형 버튼이 남지 않는다.
- 시장·정비소·사람·현장 시설의 이름과 위치가 도시마다 다르다.
- 바닥을 누르면 주인공 코드 스프라이트가 그 좌표까지 걷고, 시설을 누르면 실제 건물 앞으로 이동한다.
- 주민 코드 스프라이트를 누르면 다가간 뒤 대화가 열리고, 합류 인물도 같은 방식으로 첫 만남이 시작된다.
- 도시마다 행인 이동, 용접 불꽃, 모닥불, 램프와 전광판 같은 반복 ambience가 프레임마다 변한다.
- 모든 도시 입구에 현재 증축 단계가 반영된 코드형 달구지가 주차된다.
- 민지=밀양, 박 선생=전주, 레오=광주, 재이=무주, 은수=대전, 강우=대구로 첫 만남을 고정했다.
- 첫 만남 사건 여섯 개를 일반 도로 풀에서 제거했다.
- 민지·박 선생·레오·재이·은수는 첫 만남 뒤 다른 목적지까지 임시 승객으로 탄다. 주행 중 탑승 카드에도 실제로 표시된다.
- 강우는 대구 시장에서 후임에게 자리를 넘기는 일을 먼저 끝내고, 다음 구간부터 임시 동행한다.
- 박 선생의 수진 재회와 마지막 해열제, 강우의 제3방어선도 각각 대전·수원 탐색 사건으로 고정했다.
- 차 안 잡담·동료 간 대화만 주행 사건으로 남겼다.

## 남은 의도적 구분

- 모든 동료 대화를 정착지에만 가두지는 않는다. 이미 함께 탄 동료의 차 안 잡담과 야영 대화는 이동 생활의 생동감이므로 남긴다.
- 특정 사람·건물·과거 현장을 물리적으로 만나야 하는 사건만 도착지 탐색으로 제한한다.
- 지역 전용 사진은 도착 시네마틱과 시설 상세 장면에만 유지한다. 실제 도시 내부 이동 화면은 사진·핫스팟·초상 핀을 쓰지 않는다.

## 추가 패스 3 — ImageGen 시설 아틀라스 v3 선별 채택

내장 ImageGen으로 네 시설, 여덟 주연형 사람, 여덟 군중 후보를 생성했다. 프롬프트는
Caravan의 젖은 한국형 포스트붕괴 세계, 3/4 탑다운 16-bit 픽셀 클러스터, 무채색 금속·
낡은 캔버스·녹슨 갈색·절제된 호박빛, 텍스트/로고 없음, 단색 초록 크로마 배경을
공통으로 고정했다. 시설은 장터/정비소/모닥불 쉼터/기록 작업장, 인물은 기존 캐릭터
시트의 다온·민지·박 선생·레오·재이·은수·강우와 익명 합류자를 참조했다.

`tools/settlement-atlas-v3.py`가 세 원본을 재현 가능하게 크로마 키잉하고, 건물은
50×43의 12배, 사람은 11×17의 27배, 군중은 7×12의 32배 캔버스에서 정확한 정수
블록으로 축소한다. 전체 ImageGen 후보를 따로 남긴 뒤 실제 1× 비교로 채택을 나눴다.

- 시설은 지붕·차양·개구부·상자·조명·안테나의 기능 구분이 v2보다 명백히 좋아 채택.
- 생성 인물·군중은 큰 원본과 달리 1×에서 더 가늘고 어두워 v2보다 덜 읽혀 미채택.
  최종 v3에는 검증된 v2 인물·군중 셀을 픽셀 그대로 합성했다.
- 런타임: `assets/ui/settlement/town-world-sprite-atlas-v3.webp`, 224×70,
  47 opaque colors, lossless 2,594B. 크롭 계약·시설 좌표·히트 영역·이동 로직 불변.
