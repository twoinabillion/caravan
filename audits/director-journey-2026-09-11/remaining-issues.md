# 우선순위가 남은 문제

승인된 Task 1–8과 Task 9A 검증에서 확인된 Critical 또는 Important 제품 결함은 없다. 전달 중 드러난 좁은 정차 화면 문제도 원인을 수정하고 독립 검토·실행 검증을 마쳤다. 아래 항목은 후속 경험 질문과 기술 개선 후보이며 전달 차단 결함은 아니다.

1. **처음 하는 참가자의 초반 이해와 주도권.** 설명 없이 부산의 첫 목표를 이해하는지, 다섯 행동의 비용 차이를 자기 선택으로 받아들이는지, 메인 증거가 부족할 때 지도·목표 안내를 따라가는지 관찰한다. 화면 도달성과 자동 진행 통과는 발견 가능성이나 이해도를 증명하지 않는다.
2. **동료 애착과 결말의 읽기 양·회수.** 야영 선택과 달구지 변화가 기억에 남는지, 서울에서 자기 선택을 알아보는지, 코어 37턴·에필로그 도입 10턴·방식별 밤 후속 최대 29턴의 양이 보상과 집중에 어떤 영향을 주는지 확인한다. 이 숫자는 UI 턴 수이며 읽기 시간이나 품질 점수가 아니다. 결과를 보기 전에 새로운 페이싱 개편을 정하지 않는다.
3. **실제 휴대폰 성능과 조작성.** 대표 iOS/Android 기기에서 첫 실행 시간, 메모리, 발열, 터치 반응, 긴 화면 스크롤과 마지막 행동 도달을 측정한다. 320~476px 데스크톱 브라우저 검사는 물리 기기 측정이 아니다.
4. **HTML 용량과 기존 자산 경고.** 현재 HTML 77,667,306 bytes는 80MB 상한에 가깝고 32MB 권고선을 넘는다. 기존 시각 경고 58건도 남아 있다. Phase B에서 두 기준과 정확한 경고 문자열 집합을 다시 확인했으며 추가·삭제는 0개다. 이후 최적화는 품질 저하와 로딩 개선량을 함께 측정해 별도 범위로 판단한다.

원본 전달 증명은 [Phase B](phase-b/README.md)에서 완료했다. 기존 캠페인 해시와 UI 보완 뒤 최종 전달 해시는 따로 기록했다.
