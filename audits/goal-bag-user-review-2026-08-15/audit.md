# 목표·가방 사용자 화면 재검토

- 날짜: 2026-08-15
- 근거: 사용자가 현재 실행 화면에서 첨부한 목표·가방 스크린샷 2장
- 범위: 시각적 정보 위계, 여백, 정렬, 읽기 편의성

## 1. 목표 화면 — 추가 조정 필요

### 좋아진 점

- 외곽 소품에 좌우 숨 쉴 공간이 생겼다.
- 제목, 현재 위치, 진행 단계, 확인된 단서의 읽는 순서가 명확해졌다.
- 이전의 별도 테두리 박스는 사라져 중복 프레임이 줄었다.

### 남은 문제

- 하단 종이 영역이 여전히 실제 정보량보다 너무 크다. `다음 행동` 아래부터 버튼까지 넓은 빈 면이 남는다.
- `분리 절차 복원·검증키 안전 회수`가 진행 단계와 다음 행동에서 그대로 반복돼, 공간을 쓰면서도 새 정보를 주지 않는다.
- 지도 쪽지가 어느 정보와 연결되는지 불분명해 장식처럼 보인다.
- 우측에 글자 없는 세 번째 종이 탭이 남아 있어 누를 수 있는 빈 탭처럼 보인다.
- 오래된 종이 위의 회색 보조 설명은 작은 화면에서 대비가 약해질 가능성이 있다.

### 권장 수정

- 하단을 `다음 행동 / 장소 / 필요한 조건`의 한 묶음으로 재구성한다.
- 지도 쪽지는 다음 행동 묶음 안에 명확히 귀속시키고, 빈 아래 프레임을 줄이거나 실제 목표 정보로 채운다.
- 빈 우측 탭은 소품 이미지에서 제거하거나 비활성 장식임이 분명하도록 처리한다.

## 2. 가방 화면 — 대체로 안정적, 미세 조정 필요

### 좋아진 점

- 물·식량·연료, 차체·남은 보급, 다섯 수납칸의 세로 축이 안정됐다.
- 수량이 `보유 2개`처럼 한 덩어리로 읽히고 수납칸 간 기준선도 맞는다.
- 선택 항목과 하단 상세 설명의 연결이 명확하다.

### 남은 문제

- 선택한 수납칸의 금색 세로 테두리가 다른 요소보다 강해 화면을 둘로 자르는 느낌이 조금 남는다.
- `보유`, 단위, 상세 설명처럼 작은 회색 글자는 어두운 질감 위에서 읽기 부담이 있다.
- 하단 상세 카드의 아이콘이 큰 반면 설명 영역은 좁아, 긴 항목명이나 긴 설명에서 다시 답답해질 여지가 있다.

### 권장 수정

- 선택 상태를 긴 세로선보다 상단 라벨·수량 배경의 금색 강조 중심으로 약화한다.
- 작은 회색 글자의 밝기와 최소 크기를 한 단계 높인다.
- 상세 카드의 아이콘 폭을 소폭 줄여 설명과 버튼에 공간을 돌려준다.

## 종합 판정

가방은 현재 구조를 유지한 채 미세 조정하면 되는 수준이다. 목표는 전보다 좋아졌지만, 하단 빈 공간과 반복 정보 때문에 아직 완성된 화면으로 보이지 않는다. 다음 작업 우선순위는 목표 하단 재구성, 빈 우측 탭 제거, 가방의 대비와 선택선 완화 순서가 적절하다.

## 확인 한계

스크린샷에서는 초점 표시, 키보드 이동, 스크린리더 순서, 실제 탭 반응은 판단할 수 없다. 이번 판정은 첨부된 두 화면의 시각 상태에 한정한다.
