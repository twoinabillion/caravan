# QA 증거 보관 정책

`audits/`는 다시 확인할 가치가 있는 최종 판단과 최소한의 재현 증거만 장기 보관한다.
화면을 탐색하며 생긴 중간 캡처와 대량 비교본은 Git에서 제외되는 `artifacts/`에 둔다.

## Git에 남기는 것

- 감사 결론을 담은 `audit.md` 또는 `README.md`
- 문제와 수정 결과를 직접 보여 주는 대표 전후 비교 이미지 1~3장
- 동일 상태를 재현하는 캡처 스크립트
- 판정에 필요한 작은 JSON 또는 측정 결과

## artifacts에 두는 것

- 전체 화면 순회 캡처
- 여러 해상도의 반복 이미지
- contact sheet 생성 중간본
- 브라우저 런타임 로그와 임시 인벤토리
- 채택하지 않은 ImageGen 초안

## 폴더 규칙

- 감사 폴더는 `주제-YYYY-MM-DD` 형식을 사용한다.
- 보고서에는 대상 빌드, 화면 크기, 재현 단계, 발견 사항, 수정 여부를 기록한다.
- 새 감사가 이전 감사를 대체하면 이전 자료를 수정하지 말고 새 보고서에서 연결한다.
- 릴리스에 필요한 구조화된 수치는 `reports/`, 사람이 판단하는 시각 증거는 `audits/`에 둔다.
