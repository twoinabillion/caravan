# Option 3 목적지 콘솔 Deep-dive — 2026-08-13

## 최종 판정

사진 규격과 설명 가독성을 망가뜨리던 레이아웃 원인을 수정했다. 최종 화면은 원본의
지도/설명/사진 세로 비율과 중앙 카드 규격을 수치로 고정했으며, 양산과 김해 모두 설명이
두 줄로 유지된다.

## 단계와 상태

1. 양산 고가차도 선택 — 정상
   - 증거: `after-final/01-route-primary.png`
   - 중앙 사진 193×114px, 설명 2줄, 연료·시간·거리 아이콘 정상.
2. 김해 들판 선택 — 정상
   - 증거: `after-final/02-route-secondary.png`
   - 사진과 설명이 같은 규격을 유지하고 지도 배지와 수치가 함께 갱신된다.
3. 머물기 전환 — 정상
   - 증거: `after-final/03-stay-mode.png`
   - 최상단 프레임 마스크와 세로 로커가 행동 목록을 가리거나 자르지 않는다.
4. 360×700 — 정상
   - 증거: `after-final/04-route-360x700.png`
   - 가로 넘침 없이 중앙 카드 최소 130px, 두 줄 설명, 도크 조작을 유지한다.

## 원인

- 원본의 상단은 좁고 하단은 넓은 내부 윤곽을 직사각형으로 단순화했다.
- 지도/설명/캐러셀 높이를 48.5/18.5/33으로 배분해 설명과 사진을 압박했다.
- 두 목적지를 일반 스크롤 캐러셀에 억지로 넣어 중앙 카드가 밀렸다.
- 장소 설명 데이터가 짧아 할당된 영역에서도 한 줄만 보였다.
- 시간/거리 표시에 의미가 다른 임시 아이콘을 사용했다.

## 수정

- 상단 콘텐츠 좌우 20px 인셋과 넓은 하단 캐러셀 윤곽을 분리했다.
- 세로 비율을 45/21/34로 고정했다.
- 두 목적지는 대칭 3장 그리드로 렌더한다.
- 양산·김해 설명을 관측된 지형 사실만으로 두 줄 보강했다.
- 원본 연료·시계·도로 아이콘을 개별 PNG로 적용했다.
- 프레임 래스터를 최상단 마스크로 올렸다.
