# 대구 도착·주민 대화 UI 감사 — 2026-08-17

## 판정

대구 돔 시장 도착 화면은 16:9 원본을 세로 화면 전체에 확대하던 구조에서 전용 9:16 고해상도 장면으로 교체했다. 다른 도시의 기존 가로 원본은 화면 전체로 늘리지 않고 원본 비율의 선명한 전경 패널과 분위기용 배경으로 분리했다. 정착지 주민 화면의 정보 순서는 `장소 → 선택한 대화 → 주민 목록 → 체류/나가기`로 고정했고, 대구 주민 세 명의 초상을 같은 반실사 캐스트 시트 문법으로 통일했다.

## 검수 흐름

1. **도착 시네마틱 — 양호**
   - 대구: 941×1672 전용 세로 원본을 320×578, 390×844, 475×948에서 직접 표시한다.
   - 다른 도시: 가로 원본을 16:9로 보호하고, 세로 전체 확대에 따른 흐림을 막는다.
2. **대구 돔 시장 허브 — 양호**
   - 기존 코드형 도시 월드와 이동 동선은 유지했다.
3. **주민 목록 — 양호**
   - 중복 도착 알림 카드와 중복 장소 부제를 제거했다.
   - 태호·세라·만수 초상을 256×256 반실사로 교체했다.
4. **태호 대화 — 양호**
   - 장소 이미지 아래에 대화가 나타나고, 선택된 주민이 목록에서 강조된다.
5. **세라 대화 — 양호**
   - 같은 크기와 선택지 그리드를 유지해 화면 높이가 갑자기 바뀌지 않는다.
6. **만수 대화 — 양호**
   - 세 번째 선택지는 한 줄 전체 폭을 사용하고, 대화 뒤에 주민 목록이 이어진다.
