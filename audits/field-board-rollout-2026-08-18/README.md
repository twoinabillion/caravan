# Field Board full rollout QA — 2026-08-18

대구 장터에서 검증한 현장 판을 게임 전체 정착지 시설로 확장한 증거다.

## 범위

- 도시 7곳: 광주, 밀양, 대구, 무주, 전주, 대전, 수원
- 시설 4종: 장터, 정비소, 사람들, 현장 통로
- 총 28개 화면을 `390×844`에서 캡처했다.
- `capture.py`를 실행하면 같은 상태로 28장을 다시 생성한다.
- `contact-sheet.png`는 28장을 도시별 4열로 묶은 최종 육안 검수판이다.
- 구조 적용 전후와 최종 표면 마감 비교는
  `../field-board-visual-rollout-2026-08-18/`에 별도로 보존한다.

## 공통 계약

1. 시설 내부에서 도착 사진을 다시 쓰지 않는다.
2. 한 장의 `field-board` 셸 안에서 구획과 행을 정리한다.
3. 행은 선택만 하며 실행은 하단 고정 버튼 하나에서 한다.
4. 도시마다 기존 정착지 팔레트를 사용하고, 의뢰 쪽지와 시설 목록의 재질을 구분한다.
5. 장터·정비소·사람들·현장 행동의 실제 상태 변화를 보존한다.

## 자동 검사

`tests/test_field_board_rollout.py`는 실제 Chrome에서 7도시 × 4시설 × 3폭
(`320×578`, `390×844`, `475×844`)을 확인한다. 화면당 판 1개, 실행 버튼 1개,
44px 이상 행·쪽지, 가로 오버플로 없음, 실행 바의 화면 내 고정, 7개 팔레트 구분을 검사하며
대표 수리·대화·현장 행동까지 실행한다.

`tests/test_field_board_visual.py`는 7개 도시 파생 색(±2), 제목 대비 4.5:1 이상,
도트 격자, 압정 쪽지 재질, 28개 화면의 320px 텍스트·비용 라벨 비겹침을 추가 검사한다.

빌드 결과는 39MB 하드 한도 이내이며 신규 프레임 자산은 672 bytes다.
