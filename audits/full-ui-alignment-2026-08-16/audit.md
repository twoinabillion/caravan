# Caravan 전체 UI 정렬·이미지 적합성 감사

- 기준 빌드: `서울까지400km.html` / `caravan.ait`
- 브라우저: Google Chrome
- 뷰포트: 320 × 578, 390 × 844, 475 × 948, deviceScaleFactor 1
- 검사 범위: 길, 머물기, 목표, 지도, 가방, 메뉴, 야영, 정착지, 이벤트 전 턴, 선택지, 결과, 전투, 주행

## 결론

실제 조작 상태 29개를 전수 캡처했고, 최종 검사에서 문서 가로 오버플로 0건, 화면 밖 조작부 0건, 44px 미만 핵심 터치 영역 0건, 텍스트 잘림 0건, 브라우저 오류 0건을 확인했다. 남은 P0·P1·P2 UI 정렬 문제는 없다.

## 수정한 핵심 문제

1. [P1, 해결] 목적지 ↔ 머물기 전환 시 달구지·도로·콘솔이 움직이던 문제

   - 원인: 탭을 누를 때마다 정차 화면을 전체 재렌더해 높이를 다시 계산함.
   - 수정: 두 패널을 한 장치 안에 한 번만 마운트하고 `hidden` 상태만 바꾸도록 변경.
   - 검증: 3개 뷰포트의 동기 프레임, 12개 animation frame, settled 상태 모두에서 stage/panel/console/dock 지오메트리 변화 0.

2. [P1, 해결] 이벤트 이미지가 세로로 느어나 장면을 볼 수 없고 대사가 잘리던 문제

   - 원인: 768 × 432 장면을 고정 세로 영역에 `cover`/확대로 배치하고, 대사·기록·결과가 서로 다른 카드 규칙으로 떨어짐.
   - 수정: 원본 비율을 읽어 `contain`으로 전체 장면을 노출하고, 장면·대사·기록·선택·결과를 모두 동일한 종이 필드 리포트 컴포넌트로 통일.
   - 검증: `story_family_key` 14개 턴 + 결과를 3개 뷰포트에서 전부 캡처. report/reader/latest 오버플로 0.

3. [P2, 해결] 가방의 보이지 않는 보조 탭이 화면 밖에서 키보드 포커스를 받던 문제

   - 수정: 실제로 보이지 않는 상태에서 `display:none`, `aria-hidden=true`, `tabIndex=-1`로 정리함.
   - 검증: 화면 밖 조작부 0, 44px 미만 조작부 0, 가방 선택·의약품 선택·현장 정비 회귀 통과.

4. [P2, 해결] 짧은 화면에서 이동 시간·머물기 설명·지도 제목이 잘리던 문제

   - 수정: 이동 시간을 `93분` 형식으로 간결화하고, 머물기 설명에 두 줄 영역을 할당하고, 지도 제목의 한글 행간을 보정함.
   - 검증: 최종 29개 상태에서 잘림 0.

5. [P2, 해결] 야영 행동에만 임시 이모지 아이콘을 사용하던 시각 언어 불일치

   - 수정: 기존 식량·부품·달구지 래스터 아이콘으로 교체해 독립된 한 개의 화면에서도 게임의 자산 언어를 유지함.

## 화면별 검토

- 길 / 머물기: 외곽, 실효 화면, 스위치, 하단 키덱, 달구지 스테이지가 동일 좌표에 유지된다.
- 목표: 제목, 위치, 3단계, 단서, 다음 행동, 완료 기준, 단일 복귀 버튼이 종이 레일 안에 정렬된다.
- 지도: 전국 여정 지도는 목적지 선택용으로만 사용되고, 24km 구간의 현재 주행은 길 콘솔의 구간 확대도로 표현된다.
- 가방: 5개 수납칸의 제목·아이콘·수량은 각 포켓의 시각 중심에 맞고, 선택 상세는 단일 행동 또는 수량만 남긴다.
- 이벤트: 장면 아트는 원본 비율로 모두 보이고, 대사·기록·선택·결과는 동일한 리포트 문법을 유지한다. 전투는 의도적으로 어두운 전술 콘솔을 유지하지만 동일한 외곽 프레임과 44px 조작 규칙을 따른다.
- 정착지 / 야영 / 메뉴 / 주행: 가로 오버플로 없음, 조작 순서 유지, 핵심 CTA 하단 고정 또는 스크롤 종료점에서 확실히 노출.

## 이미지·타이포그래피 적합성

- 게임 신에서 실제 의미를 갖는 이미지는 장면 제목·초상 alt를 제공한다. 아이콘과 질감 셸은 의도적으로 장식 자산으로 처리한다.
- 이벤트 768 × 432 아트는 스토리 모드에서 `contain`, 전투 모드에서만 전술적 집중을 위해 `cover`를 사용한다. 두 모드 모두 전체 화면 확대를 제공한다.
- 목표·지도·가방의 셸은 스트레치되지 않고 정해진 아스펙트 비율을 유지하며, 텍스트·수치·버튼은 모두 실시간 DOM으로 분리되어 있다.
- 제목·본문·수치·버튼은 각 자산의 인쇄 레일과 포켓을 범위로 삼아 정렬했고, 320–475px에서 줄바꿈·잘림·포커스 이탈이 없다.
