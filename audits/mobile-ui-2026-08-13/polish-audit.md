# Caravan 가방·지도 UI 품질 감사 — 2026-08-13

## 범위와 증거

- 현재 빌드 `서울까지400km.html`의 목표·지도·가방 화면을 다시 캡처했다.
- 뷰포트: 360×700, 390×844, 430×932.
- 수정 전 증거: `polish-before/`; 수정 후 증거: `polish-after/`.
- 기존 가죽 가방과 CRT 지도 shell은 유지하고, 그 위의 실제 DOM 정보와 상호작용만 개선했다.

## 발견한 문제

1. 가방의 수납칸 이름·아이콘·수량이 세로로 멀리 떨어져 한 아이템으로 묶여 보이지 않았다.
2. 선택 상태가 글자색만 바뀌어 현재 수납칸이 약했고, 상세 패널과의 연결도 분명하지 않았다.
3. 부품 버튼이 `정비에 사용`만 표시해 실제 소비량과 차체 회복량을 누르기 전에 알 수 없었다.
4. 차체와 보급 패널에 그룹 제목이 없어 상단 자원과 중간 상태의 정보 층위가 평평했다.
5. 지도 하단의 선택 길 이름과 CTA가 좁은 금속 슬롯 안에서 서로 밀려 보였다.

## 적용한 개선

- 수납칸마다 아이콘을 키우고 `보유 · 수량 · 단위`를 한 묶음으로 올렸다.
- 선택 칸에 얇은 주황 인셋과 수량 배경 강조를 추가했다.
- 상세 패널을 `선택한 수납칸 → 이름/수량 → 설명 → 행동` 순서로 재정렬했다.
- 부품 행동을 `부품 1개로 정비 · 차체 +35/+45`로 구체화했다. 실제 업그레이드 상태에 따라 회복량이 바뀐다.
- 정보 확인 버튼은 청록색 보조 행동, 실제 정비는 주황색 주요 행동으로 구분했다.
- 중간 패널에 `여정 상태`, `남은 보급` 라벨을 추가하고 글자·아이콘 대비를 높였다.
- 지도 하단 선택 패널은 텍스트와 CTA의 점유 영역을 고정해 shell 슬롯 안에서 정렬했다.

## 검증 결과

- 360×700, 390×844, 480×860 및 200% 확대 접근성 회귀 검증 통과.
- 가방 수납칸 선택 시 상세 제목·수량이 바뀌는 상호작용 통과.
- 부품 정비 시 부품 1개가 소모되고 차체가 회복되는 상태 변경 통과.
- 세 캡처 뷰포트 모두 콘솔 오류와 문서 가로 오버플로 0건.

## 남은 한계

- 실기기 Safari/Chrome의 주소창 축소와 OS 동적 글자 크기는 별도 실기기 확인이 필요하다.
- 현재 단일 HTML은 권장 32MB보다 크다. UI 품질과 별개로 배포 성능 최적화 항목으로 남는다.
