## 디렉터 판단과 범위

서울로 가는 이유는 본편이, 길을 계속 가고 싶은 이유는 사람과 달구지가 맡는다.
이번에는 도시나 성장 체계를 늘리지 않고, 첫 동료를 발견하는 입구와 두 노선의
사건 이후를 잇는다. 본편 정사·영입 조건·전투 결과·운영 방식은 유지한다.

- 동료가 없는 플레이어에게 현재 정착지의 첫 만남을 기존 안내 칸에서 소개한다.
  말을 거는 것은 선택이며, 거절 후에도 기존 사람들 경로로 다시 만날 수 있다.
- 문경 보급 선반과 전주 수레 수선터가 실제 구조·호송 결과에 반응한다.
  물자를 보태거나, 시간을 들여 돕거나, 북행을 이어 간다. 손실을 소급해 지우지 않는다.
- 실제로 선택한 행동 하나를 기본 엔딩에서 기억한다. 하지 않은 도움이나 약속을
  만들어 내지 않으며, 기존 엔딩 턴 수 상한과 선택적으로 펼치는 기록은 유지한다.

기획과 비용표는 [설계](../../docs/superpowers/specs/2026-09-14-director-payoff.md)와
[완료 계획](../../docs/history/director-payoff-2026-09-14.md)에 있다.

## 검증 증거

### 고정된 작업본 빌드

`npm run build`가 로컬 HTML과 AIT 생성을 마쳤다. 패키지 내부의 배포 식별자는
빌드 메타데이터이며 외부 배포를 실행한 것은 아니다.

| 산출물 | 바이트 | SHA-256 |
| --- | ---: | --- |
| `서울까지400km.html` | 77,458,306 | `0cd1a30af4e7de8598f0dc5eb67422e47e6450ea64e53f23c025958190a01a5e` |
| `caravan.ait` | 61,958,308 | `01405f43f9dca0c1b9cb95c8d10d136ddb7fa0dcffc62d9eb9eafad38660dc96` |

`verify-ait-web`는13개 내부 항목과5개 웹 파일의 해시, 참조 자산을 검증했다.
패키지 웹 HTML은77,457,433 bytes / SHA-256
`5521197aa99a45ba2d2b12e95e1556416057abe9eadf8dd59d829790c3e2dc53`이다.
7개 주연 초상도 정본과 바이트가 같다. 기존9개 운영 방식/동료 조합의 결말 검사와
독립 콘텐츠 레지스트리 검사도 통과했다. `GAME_BUILD` 표기는 이전과 같아 이 작업본은
파일 해시로 구분한다.

### 실제 입력으로 획득한 출발점

`artifacts/director-payoff/earned-prefix-v2/`는 민지 합류와 두 번의 야영을 거쳐
302km의 노선 선택 직전까지 진행한 648개 입력 기록이다. 자원이나 진행 플래그를
지급하지 않았다. 대사·운행 입력은 가속했으므로 사람의 플레이 시간 측정이 아니다.

- 출발점 HTML: 77,445,832 bytes / SHA-256 `469e851bf278ee6bb8cf092c6bd2c8aac06ccc0f3b525354247c0b951db7686b`
- 획득 저장본: 43,702 bytes / SHA-256 `0bf4efd3df4481eccf62c4b9edaa48cc34bd9913165de2e85bd15e8d70b01637`
- 이 출발점은 첫 만남 기능만 반영된 중간 빌드에서 획득했다. 최종 빌드의 처음부터 완주 증거로 취급하지 않는다.
- 첫 시도는 QA 입력기가 같은 밤의 완료된 야영을 반복해 중단했다. 입력기만 고쳐 다시 진행했으며 게임 결함으로 기록하지 않는다.

### 검수 중 발견한 실제 수정과 관찰기 수정

- 실제 수정: 거절한 첫 만남이 첫 새로고침 뒤 다시 강조됐다. 새 게임에 기존
  `recruit_migration_v2` 표시를 초기화해 구형 저장 보정을 다시 타지 않게 했다.
  실제 거절→새로고침→이어하기 RED 이후13개 첫 만남 검사가 통과했다.
- 실제 수정: 후속 선택의 시간·피로 비용이 선택 전 화면에 없었다. 기존
  `foreseeable.expense`에 명시하고 여섯 선택의 실제 표시를 검증했다.
- 관찰기 수정: 초기 분기 실행은 후속 선택 후 새로고침까지 도달했지만 전체
  저장 바이트 비교에서 중단됐다. 기존 저장·세션 종료 처리는 `_quality`의
  `lastSeenAt`, `activeSession`, `lastStop`, `playMs`, `sessions`와
  `timeline`의 `session_start`/`session_end`를 갱신한다. 진단에서 게임 상태
  차이는 없었다. 게임의 세션 처리는 그대로 두고 이 부가 기록만 비교에서
  제외했다. 나머지 모든 저장 필드와 자원·선택·메모·동료·시각·거리의 동일성을
  검사한다. 실패 기록은 `artifacts/director-payoff/final-{ridge,market}/` 및
  `final-{ridge,market}-v2/`에, 실제 새로고침의 비교는 v3 폴더에 보존한다.
- 라이브 서버의 기존 `/assets/app-icon.png` 404는 JS 오류와 구분한다.
  AIT 내부의 실제 아이콘 참조는 패키지 검사에서 확인됐다.

### 최종 회귀 검사와 독립 리뷰

- 고정 HTML의 pytest 150개 통과, 400.81초. 첫 만남·노선 후속·엔딩 회상과
  기존 연결성·도시 노선·저장된 사건·대화 연속성·주행 대화를 함께 검사했다.
  전체 저장소의 모든 검사 실행이라는 뜻은 아니다. JUnit 원본은
  `artifacts/director-payoff/final-regressions.xml`이다.
- 별도 실행: 저장된 사건 연결 12개, 동료 재방문 6명, Node 엔딩 9조합,
  콘텐츠 레지스트리, 빌드·AIT·정본 초상 검사 통과. 중복 검사 수를 합산하지 않는다.
- 첫 만남·후속 선택·엔딩의 세 개별 리뷰와 새 게임의 거절 복원 수정 리뷰 승인.
  최종 통합 리뷰는 `60a47b8..ab6de2b` 전체 변경과 관련 기존 처리기를 확인했고
  Critical/Important/Minor 지적 없이 Ready 판정했다. 리뷰어는 검사를 재실행하지 않았다.
- Task 3 초기 리뷰의 전투 플래그 중복 거부 제안은 철회됐다. 구형 기록의
  실패→부분 성공→성공 우선순위는 명시한 호환 정책이다. 엔딩은 그 뒤 실제로
  선택한 행동 하나만 회상하며, 전투 성공을 새로 주장하지 않는다.
- 320px 일반 글씨·390px 큰 글씨·데스크톱 첫 만남 조작, 두 후속 장면의
  도입/비용/결과, 접힌 기록 밖의 엔딩과 이어하기를 확인했다.

### 같은 획득 저장본에서 이어 간 최종 두 노선

두 임시 브라우저 모두 위의 43,702바이트 저장본을 그대로 가져와 실제 노선 선택,
전투, 이동, 후속 선택, 결과 새로고침, 서울 결말을 진행했다. 자원·플래그를
지급하지 않았다. 첫 응답과 새로고침은 모두 위 최종 HTML 해시와 같다.

| 노선 | 실제 후속 행동 | 최종 거리 / 날짜 | 입력 수 | 끝 상태 |
| --- | --- | --- | ---: | --- |
| 능선길 | 문경에서 다음 약 꾸러미 포장 | 562km / 9일 | 1,240 | `story_done`, 기록 1개 |
| 장터길 | 전주에서 수선을 맡지 않고 북행 | 651km / 9일 | 1,234 | `story_done`, 기록 1개 |

둘 다 민지와 함께 `core_transfer` 결말에 도달했다. 후속 결과 새로고침에서
모든 비세션 저장 필드와 실제 게임 상태가 같았으며, 기본 엔딩에 각 행동의 정확한
문장이 표시됐다. 최종 두 화면도 직접 확인했다. JS 예외는 0개였고 앞서 적은
아이콘 404는 남아 있다. 두 캠페인이 모든 여섯 후속 행동을 실제 완주한 것은 아니다.
나머지 선택·전투 결과·운영 방식 조합은 별도 회귀 행렬의 증거다.

[작은 증거 색인](earned-evidence.json)에 입력 저장/런타임/추적/결과 저장의
해시와 엔딩 문장을 보존했다. 전체 추적·캡처·저장은
`artifacts/director-payoff/final-ridge-v3/`, `final-market-v3/`에 있다.
[재현용 획득 저장](earned-fork-save.json)은 원본과 바이트가 같으며 개인 저장이 아니다.

재현은 이 작업 공간에서 라이브 서버를 켠 뒤 실행한다. Playwright 임시 프로필을
쓰고, `--route market`으로 다른 갈래를 확인한다. 기존 출력 폴더는 덮어쓰지 않는다.

```sh
node tools/dev-live.mjs --port=4181
python3 audits/director-payoff-2026-09-14/run-earned.py --scenario route --route ridge --checkpoint audits/director-payoff-2026-09-14/earned-fork-save.json --url 'http://127.0.0.1:4181/game?caravan-live=1' --output artifacts/director-payoff/recheck-ridge --seed 400911 --limit 2400
```

개발 커밋: `5724e03` 첫 만남, `493bad4` 노선 후속,
`41f00c5` 거절 복원, `ab6de2b` 엔딩 회상. 기준 `60a47b8`은 이번 기능 이전의
미커밋 변경까지 보존한 스냅샷이다. 뒤의 문서·증거 커밋은 게임 실행 파일을 바꾸지 않는다.

## 평가 한계

자동 검사는 분기 도달 가능성, 실제 선택과 회상의 일치, 저장 복원, 화면 잘림을
확인한다. 처음 하는 사람이 동료에게 애착을 느끼는지, 중간 선택이 기억에 남는지는
참가자 테스트가 필요하다. 실제 휴대폰의 첫 실행 시간과 메모리 사용량도 아직
측정하지 않았다. 기존 시각 경고 58건과 단일 HTML의 32MB 권고 초과는 별도 과제다.
