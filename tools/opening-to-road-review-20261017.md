## 별도 실제 번들 플레이

`tools/qa-opening-runtime.html`이 현재 생성 HTML을 그대로 읽어 opaque sandbox의 Blob 문서로 실행한다. 바뀐 것은 상대 경로의 base와 임시 메모리 Storage 어댑터뿐이다. 게임 엔진/그림/UI 함수/자원/읽기 커서는 패치하거나 직접 호출하지 않는다. 조작은 실제 화면의 버튼/키보드로 했다. 부모 문서에 저장된 임시 기록을 재접속 때 주입하며 사용자의 localStorage/sessionStorage에는 접근하지 않는다. 첫 srcdoc 방식은 브라우저 도구의64MiB 메시지 상한에 걸려 Blob 문서로 바꿨다.

1. **준비 복원** —360×728에서 부품 상자·이름 다온·합계 펼침·스크롤25 선택 후 번들 재접속. 같은 이름/선택/펼침/스크롤을 확인했다. 타이틀 복귀 후 재진입도 보존됐다.
2. **작은 화면/큰 글씨** —320×568에서 큰 글씨, End 키로 물·식량 선택. 설명이 두 줄로 흐르고 선택과 준비 버튼이 보인다. 이는 모바일 가상 키보드 검사가 아니다.
3. **오프닝** — 실제 이름/물·식량이 새 게임에 전달되고 감천 작업장부터 시작한다. 첫 선택 결과07:35에서 재접속→이어가기 후 같은 결과와 시각·물자 유지. 첫 장면을 다시 시작하거나 비용을 다시 내지 않았다.
4. **수리/연결** — 새 부품 수리로 부품1→0과 소모 결과 페이지를 확인했다. 이의 제기→검증키→작업장 셔터의 실제 장면을 읽고 선택했다.320폭 큰 글씨에서는 선택/결과가 페이지로 나뉘며 다음 행동이 도달 가능했다.
5. **첫 주행** — 부산 DAY1 08:45, 연료30L·부품0에서 양산20km/93분/연료4L 예측. 목적지 선택창 Escape 취소는 시각/연료/위치를 바꾸지 않았다. 실제 출발 버튼으로 주행에 진입했다.
6. **주행 중 복귀** — 트럭 카페 DAY1 09:53, 주행14.9243076667km에서 재접속→이어가기로 같은 사건/구간/거리/시각/연료를 확인했다. `냄새만 맡고 지난다`로 결과→길 복귀 후 메뉴에서 큰 글씨 켜짐·지금 저장을 확인했다. 저장 거리15.4301593333km, 물·식량 선택과 부품0 유지. 양산 도착이나 이후 전 구간 완주 검수는 아니다.

Chrome 확장 프로그램 오류와 opaque sandbox의 serviceWorker 접근 오류는 검수판 제한으로 기록하며, 오류0/서비스워커/PWA 검수로 주장하지 않는다.
