# quiet v2 본게임 통합

Sang은 v1 흐름에 ‘ㄱㄱ’, 제목·밀도 v2에 ‘그게 낫네’로 승인했다.
이번 작업은 별도 시안 추가가 아니라 실제 src 통합이다. 기존 dirty 변경은 보존했다.

## 구현

- 기존 `passenger-story-reader` 소유자에서 `data-reader-density="quiet"`로 구조 적용을
  기다린다. 일반 제목은 접근성 heading/사건 이름에 남기되 화면에서 숨긴다.
  기본 본문·선택17px, 큰 글씨21px, 화자36/44px. 사진은 기존 고정16:9 contain과
  viewport별 높이를 유지한다. 초안의36px 표지줄과 달리 실제 읽기 버튼은44px을 보장한다.
- 출처/시간은 턴의 명시적 표지로 바뀐다. 여덟 살 기억의 첫 컷과 현재 복귀에서 페이지가
  갈라지고, 이전/기록/저장 복원에도 원문·사진·출처가 유지된다. 기록 전체 보기에도 출처를
  반복 표기해 현재 시각 아래 과거 대사가 섞이는 문제를 막았다.
- 새 여정의 이송표 뒤에 정본의 짧은 부모님 기억3턴을 넣었다. 필수 가족·명령·장치 동기는
  본선에 유지하고 천리안의 역사3턴은 출처를 밝힌 선택 기록으로 둔다.
- 두 열쇠 선택의 비용·효과·노트는 동일하다. 새 여정의 keep_key 결과 시동 문장만 작별 뒤로
  옮겼다. 도윤·하진의 기존 대사→시동→‘할아버지, 다녀올게’→명시적 출발→장 경계를
  별도 presentation-only 오프닝 단계로 연결했다. 이 단계는 시간·물자·게임 RNG를 소비하지 않는다.
- 오프닝 이름 버전2와 별도로 `narrativeVersion=1`을 새 interactive 저장에만 넣는다.
  기존5단계 정의는 그대로 두어 레거시 결과·완료 저장에 작별을 소급하지 않는다.
- 준비 화면 미리 읽기는 과거10장면과 출처만 보여주고 같은 짐 선택으로 돌아온다.
  기존27장면 full/summary/restart 진입은 호환용으로 보존한다.
- 새로운 래스터/음성/API 생성은 없다. 작별은 기존 부두 환경음 프로필만 공유하고
  없던 목소리나 과거 인트로의 턴 번호를 임의로 연결하지 않았다. 실제 엔진 출발 효과음은
  기존 실제 주행 시작 소유자가 유지한다.

## 확인 범위

자동 검사는 격리된 엔진·스토리지/DOM 대역이며 실제 사용자 저장을 교체하지 않는다.
새 회상 페이지 경계, 현재/이전/기록 출처, 부분 커서·펼침 복원, 두 열쇠/모든 짐·수리
분기의 once-only 결과와 이름 인사, 구버전 저장, 무비용 작별, 첫 실제 주행을 검증한다.
구조 적용 전 CSS가 기존 화면을 바꾸지 않도록 새 속성으로 격리했다.

작업 전02:25:48Z와 중간02:37:40Z 실제 GET은 부산 DAY1 08:45(525)·정차·game/사건
없음·연료30/물10/식량10/고철24/차체82·동행 없음·360×728/DPR2 동일했다.
후자는 loaded1792287583332, style1792290764390, pending1792290996021, applyingfalse다.
CSS live 갱신과 새 JS/구조 대기는 서로 다른 상태다. 최신 검증 수치/리비전은 아래에 기록한다.

최종 확인:

- `npm run test:source` **771/771**. 변경 reader/오프닝/오디오 집중 검사 **94/94**,
  신규 presence 검사9개 포함. `git diff --check`, JS 문법 검사 통과.
- `npm run build:html` 통과, HTML **106,291,207bytes**. 콘텐츠 참조·시각 계약의
  파일/형상 검사 통과. 기존 권장32MB 초과 경고는 남으며 이를 성능 검증으로 보지 않는다.
- 최종02:39:42Z 실제 GET의 위치/화면/시각/자원/동행/viewport는 위와 같다.
  loaded **1792287583332**, style **1792290764390**, pending **1792291114865**,
  applyingfalse. style 리비전의 변화만으로 새 quiet 구조까지 적용됐다고 볼 수 없다.

## 남은 검수

실제4319 플레이 화면의 접근 제한을 우회하지 않았다. 현재 GET은 이미지 없는 게임 상태이며
시각 증거가 아니다. 현재 부산 완료 저장을 되감거나 새 저장을 현재 화면으로 대체하지 않았다.
따라서 **실제 구조 적용·실게임320/360 큰 글씨/사진 크롭·새 기억과 작별의 실청취/모바일
키보드 검수는 대기**다. 앞선 독립 초안의 관찰로 이를 대신 완료했다고 주장하지 않는다.
배포/Toss AIT 재빌드/커밋/서버 재시작은 하지 않는다.

게임 디렉터·프런트엔드/UI 지침은 제목/밀도를 먼저 정리하고44px 조작을 남기는 데,
대사/저장 지침은 정본 재사용과 새 여정만의 버전 분리·구버전 결과 보존에 사용했다.
