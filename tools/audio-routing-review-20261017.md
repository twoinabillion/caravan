## 변경

- `src/03h-audio.js`의 `D.eventAudio`: 새 오프닝6장면의 story 음악과
  실내/차 안/처마 아래 환경, 명시적인 선택별 성공음을 정의한다. 역사
  프롤로그의 장면/턴 번호를 새 사건에 그대로 적용하지 않는다.
- `src/07e-ui-audio.js`의 기존 AMBI: 작업장 환경음을 연결하고 장면 인계 때
  앞 동작음의 잔여 재생을 중단한다. `result`는 실제 선택 객체와
  `applied:true`인 성공 결과만 재생한다. 실패·기지급 결과 복원은 무음이며
  음소거·백그라운드 동안 생략한 동작을 나중에 재생하지 않는다.
- `src/07-ui.js`: 사건별 음악 프로필과 성공 결과 소유자를 사용한다.
  새 오프닝이 `본편` 타입이라는 이유로 drive_day 음악에 빠지던 경로를
  바로잡았다. 수리, 공구/짐 챙기기, 이송표 복사, 이름 기록, 배선 도면/번호표,
  출발 쪽지는 해당 선택이 성공한 뒤에만 기존 소리로 연결한다.
- 자동 주유는 카드 선택 성공 뒤에만 펌프음을 낸다. 주유소 진입은 무음이고,
  대응 녹음이 없는 수동 펌프에는 자동 펌프음을 붙이지 않는다.
- 존재하지 않는 천리안 이벤트 음성 키6개 호출은 제거했다. 이 대사들은
  여전히 자막이며 **새 녹음을 만들거나 음성 제공을 완료한 것이 아니다.**
  코어 음성15개/명시적 턴 재생은 유지하고 다른 대사로 돌려 쓰지 않는다.
- UI/CSS/그림·대사·비용/보상·저장 스키마·게임 RNG 변경 없음. 생성 청음
  음원의 로컬 전용 제한과 배포 앱의 원본 절차 합성 대체음도 유지한다.
