# 풍경은 그대로, 할 일만 바뀌게 · v1

2026-10-03 Sang 요청에 따른 Studio 디자인 초안. **게임 적용 전 검토용**이다.

## 방향

- 풍경이 화면의 중심이고, 아래 패널은 운전석에서 다음 행동을 고르는 자리다. 기존 올리브 금속/황동 강조를 유지하고 새 카드·장식을 추가하지 않는다.
- 색: 바탕 `#131b17`, 패널 `#202820`, 본문 `#f0eee2`, 보조 글씨 `#c1c4b5`, 강조 `#edc986`, 경계 `#626a52`. 기존 Apple SD Gothic Neo/Malgun Gothic 시스템 UI체, 왼쪽 정렬 선택명19px, 실행15px, 보조11~13px.
- 제안의 바깥 패널은272px(안쪽258px)로 고정한다. 목적지와 머물기의 선택명·예상치·48px 실행·44px 보조 행동이 같은 높이에 놓인다. 기존 목적지292px보다20px, 다섯 행동 머물기340px보다68px 작다. 이는 CSS 설계값이지 브라우저 실측값이 아니다.
- 머물기 행동은 전부 남기되 기본 화면에 동시에 펼치지 않는다. ‘행동 변경 · 5가지’ → 목록에서 선택 → 원래 패널 → 명시적 실행. 목록 선택으로 게임 행동을 실행하지 않는다.
- 목록에서 취소하거나 바깥을 누르면 이전 선택으로 돌아온다. 목적지 왕복에도 선택 해시는 유지된다. 링크 이동은 iframe 내부 해시만 바꾼다.
- 탭 내용은150ms 밝기 페이드만 사용한다. 풍경·차량 크기/좌표와 패널 높이를 애니메이션하지 않는다. `prefers-reduced-motion`에서는 전환을 끈다.
- ‘현재 높이 비교’는 제안 내용을 그대로 둔 채 기존292/340px 높이 차이만 재현한다. 원래 UI의 스크린샷이나 충실한 복제 화면이 아니다.
- ‘대구 풍경 예시’는 원경 두 장만650ms 교차 페이드한다. 달구지와 지면은 같은 요소로 남는다. 가상 도착임을 헤더에 표시하며 시간이나 실제 위치를 바꾸지 않는다. 실제 구현에서는 탭/목적지 선택이 아닌 이동 진행에 따라 기존 캔버스 원경을 이어야 한다.

- HTML/CSS, native radio/details, 해시 링크만 사용한다. 실행 스크립트·API·저장·live apply 연결 없음. 해시 선택 목록에는 취소/바깥 닫기를 제공하지만 Escape 닫기·자동 포커스 복귀는 재현하지 않는다. 실제 구현은 기존 목적지 dialog와 같은 키보드/포커스 계약을 따라야 한다.
