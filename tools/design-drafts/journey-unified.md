# 같은 여정 · UI 초안 v1

2026-09-27 Sang 요청: DAY/시간을 정차 기준으로 주행과 통일하고, 머물기를 목적지 패널과 같은 높이에 담는 프로토타입. 아래 초안은 별도로 보존한다. Sang의 “완전 좋은데?” 및 후속 적용 제안에 대한 “응응 좋아” 승인 후 게임 소스에 구현했다. **현재 사용자 게임창은 새 구조 적용 대기**다.

## 제안

- 장소는 왼쪽, `DAY 3 · 08:52`는 오른쪽. 정차와 주행이 같은 헤더 구조를 사용한다. 주행 때 장소만 `세종 → 공주`로 바꾼다. 숫자를 일부러 고정해 위치 변화만 비교한다.
- 자원·날씨는 풍경 아래 동일한 38px 상태줄. 기존 추적 위험은 오른쪽 아래. 풍경에 민트 덮개 없음.
- 머물기는 2×2 선택기 + 선택한 행동의 예측 3칸 + 명시적인 실행 버튼. 선택은 미리 보기만 바꾼다. 야영은 준비 화면으로 이어지고 바로 쉬지 않는다.
- 현재 상태 기준 탐색/야영/정비/라디오 4개. 기본 패널은 현재 목적지와 같은 278px(바깥 여백 포함292px), 글씨 축소나 내부 스크롤 없이 담는다.
- 조건부 동료 행동이 있으면 전체 너비 한 줄 추가. 패널48px 증가, 풍경48px 감소. `행동 5개`는 합류를 뜻하지 않는 명시적 가상 상태이다. 현 저장은 동료/보리 없음.
- 비용 부족/야간 제한 구현에서는 선택은 가능하게 두되 예측 영역에 실제 사유를 표시하고 실행만 비활성화해야 한다. 이 초안의 기본 비용은 사용자 테스트 모드(∞)를 참조한 예시다.
- 승인 후 구현에서는 기존 localActions의 조건/상한을 그대로 복사하지 말고 검토할 것. 현재 `slice(0, hasRecruitAction ? 5 : 4)` 때문에 생성된 후순위 활동이 잘릴 수 있다. 초안은 이 정책을 변경하지 않는다.

## 범위와 출처

- `src/07-ui.js` `renderHud`가 정차/주행 시간 표시를 별도로 채우고, `src/01-style.html` `Journey scene/deck owner`가 정차 때만 `.journey-location`을 표시한다. 정차와 이동의 디자인 불일치 원인이다.
- 머물기의 최종 `non-narrative-mobile-qa-fixes` 규칙은 최소94px 카드를 한 열로 스크롤시킨다. 새 디자인은 그 카드마다 반복되는 상세를 선택 패널 하나로 모으는 제안이다.
- 기존 `assets/ui/road-environment/sejong-v1.webp`, `journey-dalguji-base-v1.webp`, `journey-surface-v1.webp`, `stay-icon-*-v1.webp` 및 Tabler MIT `assets/icons/journey/*.svg` 사용. 새 래스터 생성/편집 없음. 이미지 계약 읽고 기존 자산 확인 후 배치.
- 원경·차량은 **정적인 레이아웃 예시**다. 실제 세종 캔버스·날씨·개조·주행을 재현했다고 주장하지 않는다. 주행 하단은 개략도이며 실제 목적지 사진/사건/동료 UI를 없애는 제안이 아니다.
- HTML/CSS 및 네이티브 radio/details만 사용. 게임 소스/실행/저장/API/스크립트/자동 적용에 연결하지 않는다. 실행 모양 컨트롤은 다음 화면의 동작 설명을 열고 다시 눌러 닫는다.
- 비교 도구54px와 초안 안내24px는 게임 밖. 따라서728px 초안 뷰포트에서 게임 예시는650px이고, 기본 패널과 메뉴 높이는 보존한 채 풍경만 더 짧게 확인한다.

## 승인 후 구현 — 2026-09-27

- `src/07-ui.js`의 실제 행동 조건과 예측값을 데이터 모델로 유지하고 2열 선택기·예측 3칸·실행 하나로 연결했다. 선택과 방향키 이동은 실행하지 않는다. 실행만 기존 `wireStopActionButtons` 경로를 사용한다. 야영은 기존 준비 화면으로 이어진다.
- 전체 설명은 실행 옆 `?`에서 열고 Escape로 닫는다. 비용 부족 행동도 선택해서 실제 사유를 읽을 수 있으며 실행만 비활성화한다. 임시 동행 상태는 해당 상태가 있을 때만 표시한다.
- 기존 후순위 행동을 잘라내던 `slice`를 제거했다. 자격 조건은 유지하고 생성된 행동을 모두 표시한다. 기본 4개는 동일한 패널 높이, 추가 행마다 풍경에서48px 배분한다. 320×568의 최대8개 예외에서는 **선택기만 내부 스크롤**, 예상치·실행·하단 메뉴는 고정된다. 이를 모든 화면에서 무조건 스크롤 없음으로 주장하지 않는다.
- 장소/DAY·시간 헤더와 얇은 자원·날씨줄을 주행에도 사용한다. 주행의 장소만 실제 구간명으로 바뀐다. 기존 주행 목적지 미리보기·캔버스·날씨·개조·동료·게임 규칙은 유지했다. `data-journey-ui="unified"`로 새 JS가 준비되기 전 주행 헤더가 숨겨지는 부분 적용을 막는다.
- 선택은 같은 장소에서 UI 재렌더·새로고침 복원 대상이다. 장소가 바뀌거나 선택한 행동이 사라지면 유효한 첫 행동으로 되돌린다. 목표의 지역 행동 바로가기도 해당 행동을 **미리 선택**하고 자동 실행하지 않는다.
- CSS는 `Journey scene/deck owner`에서 소유한다. 새 컴포넌트는 폐기한 `stop-action-*`/`route-console` 카드 클래스를 쓰지 않는다. 이전 머물기 카드의 중첩 final/lock CSS 약424줄을 정리했고 레거시 버튼 정규화에서도 `.journey-deck`를 제외했다. 80MB 빌드 상한은 변경하지 않았다.
