## 범위와 사실

- 정차/주행 선택은 **배치 비교**만 한다. 차량은 정적 합성이다. 실제 주행 속도·물리·시간·날씨/보유 개조·플레이 상태를 재현한 것으로 보지 않는다.
- 기존 `journey-road-backdrop-v1.webp`와 `journey-dalguji-base-v1.webp`를 그대로 참조했다. 새 래스터 생성/편집/게임 연결 없음.
- 설명은 실제 `S.pursuit` 0~5, 추적 사건 가중치, 3부터 검문, 5부터 숙박 거절 규칙을 기준으로 작성했다. 추적 위험이라는 이름은 기존 관측 수치의 **표시명 제안**이다. 현재 카메라의 직접 시선이나 즉각적인 전투 개시를 뜻하지 않는다.
- 초안의 김천/무주·시각·자원은 배치 샘플이며, 현재 전주 DAY2 13:46 플레이와 다르다. 현재 상태에 없는 인물·개는 넣지 않았다.
- 단계 변경 강조 애니메이션/소리/카메라 회전은 이 초안에 넣지 않았다. 상시 가독성과 위치를 먼저 검토한다.
- JS, 저장, 게임 iframe, 자동 적용, 네트워크 전송 없이 CSS radio와 details만 사용한다.

## 게임 구현 · 2026-09-27

- 원본 `src/01-style.html`, `src/02-dom.html`, `src/07-ui.js`에 승인한 132×46px 이상 표시와 설명을 구현했다. 기존 CSS owner 자리에서 민트 덮개를 교체했다. 게임에서는 native button/region과 `aria-expanded`를 사용한다. 표시·설명만 읽으며 추적 수치, 시간, 자원, 저장을 변경하지 않는다.
- `src/05-scene.js`의 감시 효과만 제거했다. 스캔선, 카메라 점멸, 추적 모서리, 글리치와 서울 붉은 덮개를 더 이상 그리지 않는다. 날씨·도로·달구지·접근 연출은 그대로다. 서울이라는 이유로 표시를 5로 만들지 않고 실제 `S.pursuit`를 따른다.
- 표시를 누르면 설명을 열고 다시 누르기/닫기/바깥 클릭/Escape로 닫는다. Escape/닫기는 표시로 초점을 돌린다. 사건·다른 화면·지역 지도 진입 시 닫으며, 지도 위에는 표시를 올리지 않는다. HUD 수치가 같을 때 DOM을 다시 쓰지 않고, 새 주기 타이머나 저장 키를 추가하지 않았다. 새로고침 후 설명은 닫힌 채 기존 저장의 추적 수치를 읽는다.
- 빌드 79,999,720bytes(80,000,000 상한 유지, 여유280bytes). 용량 상한을 올리거나 그림을 재압축하지 않고 수정한 소스의 설명 주석만 축약했다. 생성 HTML은 빌드로만 갱신했다.
