# 달구지의 손때 · 대화와 선택 v1

2026-10-05 Sang의 요청에 따라 만든 독립 디자인 초안. 게임 적용/승인은 별도다.

## 방향

부산 부두 인트로의 청회색 차체와 생활 조명을 이어, 얇은 낡은 금속 프레임 안에 차분한 읽기 면을 둔다. 본문까지 철판 재질로 덮지 않는다. 생성한 빈 크림색 도색 철판 버튼은 선택 가능한 행동의 표면을 분명히 한다. 프레임은 9-slice, 버튼은 중앙 포함 9-slice로 긴 선택지에 대응한다. 네 모서리의 손때만 강조하고, 얼굴·단말·본문에 반복되는 장식을 줄인다.

- 팔레트: 바깥 `#142027`, 읽기 면 `#293239`, 본문 `#f0eadb`, 보조 `#c2c8c6`, 이름/단서 `#d6b47b`, 단말 잉크 `#a9c7be`.
- 글: 기존 게임 계열 고딕, 기본18px/1.6, 큰 글씨21px. 이야기·선택지 원문을 이미지에 그리지 않는다.
- 배치: 사건 제목 → 기존16:9 그림 → 가변 읽기 면 → 도달 가능한 진행 버튼. 사람 초상48px와 이름, 단말 응답의 작은 삽입 면으로 발화 출처를 구분한다.
- 절제: 무기 장식·금색 문양·네온·스캔 애니메이션·무작위 스크래치를 추가하지 않는다. ‘질감 빼기’로 재질의 실제 기여를 비교한다.

## 내용과 동작

`src/03-data.js`의 `opening_failed_appeal` turns5개, choices2개, 각 결과·시간·기록 제목을 보존한다. 읽기 묶음과 ‘어떻게 할까?’는 배치 제안이며 현재 저장의 cursor나 실제 게임의 페이지 수를 재현하지 않는다. 새로운 사건/대사/보상/인물을 만들지 않았다.

대화 → 주인공/단말 → 마지막 서술/두 선택 → 선택별 결과 → 초안 종료로 해시 이동한다. 그림 확대는 native details로 열고 닫아 읽기 위치를 유지한다. 앞 대사는 선택 화면에서만 details로 확인한다. 결과는 선택 후에만 표시한다. 큰 글씨·질감 제거는 native checkbox로 비교한다. 스크립트, 게임 API, storage, iframe 및 form 전송은 없다.

## 생성 자산과 경계

기본 image_gen으로 정본4장을 참조해 투명 금속 프레임1장, 빈 버튼1장을 각각 생성했다. 프레임/버튼은 서사 그림과 분리된 **UI 소재 초안**이다. 장면 이미지에 금지된 프레임을 구워 넣는 것이 아니다. 기존 cinematicScene 규격을 이 UI 컴포넌트의 규격으로 주장하지 않는다. 초안 전용 기하/알파/용량 계약은 [provenance.json](event-materials/provenance.json), 실제 프롬프트는 [prompts.json](event-materials/prompts.json)에 보존한다.

- 프레임: 원본1122×1402, 배포800×1000 알파 WebP.
- 버튼: 원본2206×713, 배포960×180 알파 WebP.
- 원본 PNG는 `event-materials/masters/`, 배포본은 `event-materials/`에 분리 보존. exporter는 투명 여백 trim·크기 조절·압축만 한다.
- 기존 `assets/intro/15-appeal-denied.jpg`, `passer_woman.png`, `me.png`를 사용한다. 생성 원본/배포본/기존 그림을 관찰했으며, 실제 초안 크롭/텍스트 겹침/터치 검수와는 구분한다.

## 검수 범위

Studio4317의 디자인 초안 목록 첫 항목에 등록. 정적 HTML/CSS/링크·원문·자산 알파/기하 검사를 사용하며, 이는 브라우저 시각 검수가 아니다. Chrome 연결에서 AppleEvent timeout(-1712)이 발생해 실제 Studio 초안 창을 열거나 모바일320/360/480 화면을 직접 확인하지 못했다. 게임 UI·빌드·저장·적용 배지는 변경하지 않는다. 현재 사건/시간/viewport/revision은 작업 전후 읽기 전용 endpoint로 비교한다.

## 승인 후 게임 연결 · 2026-10-05

Sang의 적용 요청과 ‘흰 사각형/타원 틈, 버튼만 바뀐 느낌’ 의견을 반영했다. 기존 `passenger-story-reader` 소유 블록에 구조 적용 게이트를 두고 제목·읽기 면·인물 이름·단말 응답·선택·결과를 같은 청회색/금속 소재로 연결했다. 대사와 선택 효과, 기록 및 읽기 cursor는 유지한다. 전투와 출발 브리프는 제외한다.

버튼은 중앙 포함 9-slice 대신 전체 알파 실루엣을 투명 바탕에 그린다. 별도 크림색 사각형/타원 바탕을 제거해 외곽의 흰 틈을 없앴다. 프레임 안쪽만 불투명 읽기 면으로 채우고, 장면 그림·초상은 기존 자산과 비율을 유지한다.

승인 원본을 보존하고 [게임 exporter](../export-event-materials-game.cjs)로 배포본을 줄였다. 프레임320×400(7,862bytes), 버튼480×90(5,924bytes), 알파 유지. [전달 계약](../../assets/ui/event-materials-v1.json)에 출처·규격·예산을 기록했다. 실제4319 `/__live/assets`에 노출되는 것을 확인한 후 연결했다. HTML은 기존80MB 상한 안에서 빌드한다.

이번에는 Chrome 연결이 복구되어 실제 Studio의360×728 게임 화면을 직접 관찰했다. 적용 전 `opening_failed_appeal`의 beat/decision → 적용 후 같은 decision 유지와 금속 프레임·제목·버튼을 확인했다. 이후 사용자 플레이가 `opening_parents_module`, `opening_departure`로 진행되어 전체 작업의 사건/시간이 같다고 주장하지 않는다. QA에서는 사건 선택을 대신 누르지 않았다. `opening_departure` 결과에서 기록 열기/이야기로 복귀/앞 대사/결과 확인/Studio 새로고침을 검증했고 결과·시간09:00·연료42·물10·식량10·고철16·차체82%가 유지됐다. 다음 행동 ‘길로 나가기’가 도달 가능하다.

관련 회귀 검사는 소유 selector·알파/기하/예산·출처·대사 페이지·출발 흐름·동료 존재를 다룬다. 320/480 viewport, 큰 글씨21px 및 모든 사건의 직접 재생은 이번 시각 검수 범위가 아니다.
