## 피드백과 추천

Sang은 2026-10-18 v1 흐름에 ‘ㄱㄱ’라고 했으며, 글자가 전반적으로 크고 사진이 더 잘
보였으면 한다고 했다. 특히 매 장면의 제목 면적을 지적했다. 이는 모든 HUD/버튼을 일괄
축소하라는 승인이나 필수 이야기 삭제 요청으로 확대하지 않는다.

이번 안은 매 장면 제목을 목차로 옮기고 시간·장소·기억/출처 표시만36px 줄에 남긴다.
기본 본문18→17px, 화자 초상48→36px/큰 글씨44px, 문단/화자 간 여백을 줄였다.
큰 글씨는 본문·이야기 선택지21px이며 터치 영역은 그대로 크다. 선택2개도 같은 강조다.
제목은 접근성 heading/region 이름에 남기며 ‘서장을 마치고’ 장 경계의 큰 제목은 유지한다.

모든 `data-source`/`data-result`의 원문, 그림 목록, 선택지와 왕복 링크는 v1과 정확히 같다.
기본안에서 숨기는 설명은 초안 자체의 편집 주석뿐이며 흐름 메뉴에 발췌·무음·시동 위치
조정이라는 한계를 모아 썼다. 단말 이름, 질문/대답, 메모, 출발 이유는 줄이지 않았다.
현재·기억·전해 들은 이야기의 재질/출처 구분도 보존했다.

상단 네이티브 ‘이전 안’ 체크는 같은 대사/사진에서 제목64px 줄·본문18px·초상48px으로
되돌려 비교한다. 큰 글씨를 선택하면 비교안도21px이다. 이 체크는 게임 설정이 아니다.
두 안 모두 원본16:9 그림의 높이/contain을 그대로 쓴다. 사진을 키우거나 자른 실험이 아니다.

## 이번 시각 검수

1. **Studio360 현재·기억·현재 복귀: 정상.** 실제 sandbox에 시안 표시, 제목 토글과
   큰 글씨 체크가 네이티브로 동작한다. 동일 기억의 제목 줄63.99→35.998px,
   사진202.50px 그대로, 본문 높이324.25→376.74px로 **52.48px 증가**했다.
   기본17px/이전18px을 실제 computed style로 확인했으며 가로 overflow가 없다.
2. **독립 시안320×568 큰 글씨 기억·역사: 정상, 본문 스크롤 필요.** 최종 DOM의 실제
   CSS viewport가320×568임을 확인했다. Chrome 배율 때문에 override320×568의 첫
   관찰은355×631이었으므로 이를320 검수로 사용하지 않고 다시 맞췄다. 마지막 엄마
   대사까지 직접 내리고 복귀 버튼을 눌렀다. 역사 출처2개도36px 줄 안에 들어간다.
3. **같은 짧은 화면의 두 선택: 정상, 본문 스크롤 필요.** 본문21px과 선택지21px,
   첫 버튼62px/둘째88.09px 높이로 줄바꿈한다. 끝까지 내려 둘째 바닥487.64px가
   본문 바닥505.23px 안에 들어옴을 확인했다. 가로 넘침이 없고 하단 돌아가기는 별도다.

캡처는 [이번 검수 폴더](../../qa-artifacts/opening-presence-quiet-v2/)에 보존했다.
`01` 현재, `02` 기억 축소안, `03` 같은 기억 이전 안, `04` 짧은 큰 글씨 기억 끝,
`05` 역사 출처, `06` 짧은 큰 글씨 선택 끝이다. 첫 자르기는 배율로 잘못된 범위가
나와 거절하고 `02`/`03`을 전체 Studio 화면으로 교체했다. `07`은 배율을 맞춰 다시
캡처한 검토용 상세 화면이며 저장 파일을 직접 열어 내용과 ‘게임 미적용’ 표시를 확인했다.

임시320×568 검수 탭은 이 독립 HTML만 열었고 게임을 실행하지 않는다. viewport override를
해제하고 그 탭은 닫았다. 실제 Studio 초안 창을360 기본·이전 안 꺼짐으로 남긴다.
전체762/762, 새 quiet검사5/5와 기존 초안6/6, diff 통과. 단일 CSS 소유자·원문·이미지·
