# 사람 원형 제작

범위: 주연·동료 / 기존 정본이 있는 인물 / 공용 초상을 쓰던 인물의 얼굴과 전신 비교 초안. 게임 도로에 PNG를 삽입하거나 기존 초상을 덮어쓰지 않는다.

## 비교판 디자인

- 색: 작업대 배경 #273139, 인물판 #35414a, 본문 #eee9df, 보조 글 #b7c1c4, 비교 표시 #c2b78f.
- 글꼴: 게임을 보는 기기의 한국어 고딕체. 이름 22px, 역할 13px, 설명 13px. 이미지가 중심이며 장식용 문구는 넣지 않는다.
- 배치: 얼굴 정본과 새 전신을 한 묶음으로, 모바일에서는 한 인물씩. 큰 화면에서는 두 인물을 병렬로 비교. 모든 글은 왼쪽 정렬.
- 한 장을 고급스럽게 포장하기보다 서로 다른 인물의 얼굴·체형·옷·자세를 비교하는 데 집중한다. 수치 대시보드, 반복 장식, 카드 그림자, 자동 애니메이션은 사용하지 않는다.

## 원본과 적용 단계

- 생성 도구: built-in imagegen. 프롬프트는 prompts/에, 원본은 masters/에 보관.
- 필수 참조: assets/reference/visual-canon-2026-08-11.png, world-canon-2026-08-11.png, people-canon-2026-08-11.png, dalguji-technical-canon-2026-08-11.webp.
- 기존 인물은 assets/portraits/의 해당 정본을 다섯 번째 참조로 첨부한다. 다섯 장 제한 때문에 정본 4장과 개별 초상 외 참조는 추가하지 않는다.
- 전신은 1024×1536 검토용 마스터이며 계약의 256×256 사건 초상 납품물이 아니다. 얼굴 확대는 같은 마스터에서 보여 준다.
- 비교판은 512×768 WebP 미리보기를 사용하고 원본을 누를 때만 PNG를 연다. `node tools/export-people-catalog.cjs`로 크기·포맷만 변환한다. 얼굴이나 의상 픽셀을 코드로 수정하지 않는다.
- 원형 목록은 97항목(기존 정본 39 + 새 얼굴 제안 58)이다. 어린 상혁은 성인 상혁의 과거 모습이므로 두 명의 별개 사람으로 세지 않는다. 원형 수와 고유 등장인물 수는 다르다.
- `catalog.json`의 `version`이 비교판에서 선택한 원본이다. v1을 삭제하거나 덮지 않고 레오·수완·산지기의 불필요한 표식, 면사무소 노인·무장한 남자·폐차장 형의 얼굴 유사성을 v2로 수정했다.
- 새 얼굴의 구체적인 연령·체격·머리 모양은 캐스팅 제안이지 새 스토리 설정이 아니다. 기존 인물의 설정이나 사건 대사는 변경하지 않았다.
- 게임용 얼굴 크롭, 이벤트별 personId 연결, 움직이는 캔버스 인물은 별도 적용 단계다. 익명 화자 이름만 같다고 같은 사람으로 합치지 않는다.
- 이미지 검수와 Studio 배치 검수를 구분한다. Studio UI 접근은 이전 도구 호출에서 거부되어 이 작업에서도 우회하지 않는다. 실제 창 안 배치는 미검수다.

## 감사 범위

`node tools/audit-people-catalog.cjs`는 저장을 읽지 않고 정적 콘텐츠에서 정본 목록과 명시적인 공용 초상 화자를 추출한다. 일반 서술에서 실행 시 추론되는 모든 행인을 포함한다고 주장하지 않는다. 57개 화자 표기는 57명의 확정된 인원 수가 아니다.

검토 상태와 제작 완료 수는 catalog.json 및 비교판에 실제 파일이 있는 항목만 표시한다. 생성만 된 원본을 게임 적용 완료로 표시하지 않는다.

현재 제작 목록의 97항목 모두에 전신 원형이 있다(기존 정본 39, 새 얼굴 제안 58). ‘수레를 돕는 아이’와 ‘장터 아이’의 최초 출력은 중단됐으나, 사용자의 추가 제작 요청에 따라 새로 생성한 v2 원형을 확인하고 등록했다. 이전 오류는 `previousGenerationError`에 보존하며 완료 이미지와 혼동하지 않는다. 두 인물의 마스터는 `masters/cart_child-v2.png`, `masters/market_child-v2.png`이고, 각각의 생성 지시문은 `prompts/`에 같은 이름으로 보관한다. 제작은 built-in imagegen을 사용했다.

## 검증

- `node tools/build-people-catalog.cjs`: 정적 비교판과 콘텐츠 감사 파일만 갱신.
- `node tools/audit-people-masters.cjs`: 치수·알파·불투명 영역의 가장자리 접촉 검사. 얼굴 동일성이나 투명 경계의 시각 품질을 판정하는 검사는 아니다.
- `node --test tools/test-people-catalog.cjs`: 인물 ID, 정본 포함 여부, 파일·프롬프트·참조, 링크, 미완료 표기, 저장/게임 비연결 검사.
- 생성된 이미지 자체의 인체·인상·소품은 화면으로 검토하되, 실제 Studio 배치 검수와 최종 게임용 작은 크기 검수를 대체하지 않는다.
