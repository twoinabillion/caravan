# 상혁의 공책 — 문구 검토

2026-09-26 Sang 요청에 따라 Codex는 형태, Claude는 문구를 담당했다. 이번 결과는 **디자인 초안만**이다. `src/07d-ui-quests.js`나 저장된 목표를 수정하지 않았다.

## v3 — 지우고 고쳐 쓴 한마디

Sang이 혼잣말·낙서를 모든 목표에 일괄 삽입하지 말고 필요한 순간에만 사용하라고 요청했다. 현재 메인 페이지의 망설임 한 곳에만 Claude의 문구를 넣었다.

- 지운 말: 혼자서는 무리일 것 같다
- 덧쓴 말: 해 보기 전엔 모르지.
- 본문 뒤에 작은 손글씨로 비껴 쓰고, 세 번 그은 펜 선과 짧은 화살표로 수정 흔적을 남겼다. 스크린리더에는 지운 말/덧쓴 말을 구분한다.
- 달구지 낙서는 확인한 기록 뒤 공책 구석에만 둔다. 코드로 그린 작은 펜 선이며 게임의 차량 외형·개조나 도로 렌더러를 바꾸는 자산이 아니다.
- 장소·조작·단서는 지우지 않는다. 부모님에 관한 새 사실/추측을 추가하지 않는다. 같은 걱정을 반복하지 않도록 앞서 제안한 별도 속말은 중복 삽입하지 않는다.
- 사이드/완료 빈 예시는 조용히 유지한다. 초안 전용 SVG/CSS이며 애니메이션·랜덤 장식·저장 상태 변경은 없다.

## v2 — 발표문에서 참고한 생각의 흐름

Sang의 요청으로 Obsidian의 본인 AX 발표 v10 대본 일부와 말투 최종 정리, 다른 발표자 비교 노트의 발췌를 읽었다. 발표 영상·음성을 검수한 것은 아니다. 원본 발표의 업무 내용이나 다른 사람의 경험은 가져오지 않았다.

- 어미 비율이나 문장 길이를 기계적으로 맞추지 않는다. 무엇을 알고 무엇이 궁금해서 다음에 무엇을 해보려는지 이어 쓴다.
- 청중을 향한 해요체와 설명식 접속사는 개인 공책에 그대로 옮기지 않는다. 소감·교훈으로 매번 마무리하지 않는다.
- Claude 재초안의 중심 흐름을 채택하고, Codex가 설명형 도입과 반복 연결어를 덜었다. `parents_work`의 미확인 결과는 그대로 숨긴다.
- 이번에도 **공책 초안만 변경**하며 기존 게임 문구·퀘스트·저장과 Obsidian 원문은 수정하지 않는다.

## 초안에 채택한 문구

- 제목: 아빠와 엄마가 남긴 기록
- 본문: 아빠랑 엄마가 뭘 하려던 건지는 아직 모르겠다. 둘이 남긴 기록을 같이 봐야 좀 알 것 같다.
- 작은 메모: 청주 방송국에 가면 주변부터 둘러보자.
- 확인한 것: 도윤이네를 돕다가 이송표를 봤다. 지금도 가족을 갈라놓는 표가 나오고 있었다.
- 기능 안내: 청주 방송국 · 주변 탐색 · 열람 준비 30분 / 경로 보기
- 빈 사이드: 아직 맡은 부탁은 없다 / 정착지에 들르면 사람들 얘기부터 들어 보자.
- 빈 완료: 끝낸 일 / 부탁을 끝내면 까먹기 전에 여기 적어 두자.

빈 페이지는 배치 예시이며 실제 완료 이력이 없다는 뜻이 아니다. `parents_work` 완료 사실(같은 번호, 주고받은 기록 등)은 넣지 않았다. ‘지금 알아볼 것’ 라벨은 반복 소제목을 줄이기 위해 생략했다.

## 게임 적용 전 남은 문구 후보

Claude가 실제 `QuestJournal`을 읽고 제안한 후보. 승인이 나면 실제 상태와 대조해 채택하며 기계적으로 일괄 치환하지 않는다.

| 위치 | 제안 / 검토 사항 |
| --- | --- |
| `main.module[1]` | 후반을 ‘이 장치가 무슨 일을 하는지는 아직 모른다.’로. 현재 다른 문장과 ‘아직 모른다’가 겹치는지 재검토. |
| `main.parents_split[1]` | 후반을 ‘환승소 운행표에 이름이 남아 있는지 찾아볼 것.’으로. |
| `main.father[1]` | ‘남산에 남은 아빠의 정비 기록을 읽어 볼 것. 아빠의 번호가 어디서 끊겼는지 아직 모른다.’ |
| 동료 `follow` | ‘오늘은 같이 야영하기로 했다. 계속 같이 갈지는 내일 다시 이야기해 볼 것.’ 단, 야영 결정 전이면 확정형 금지. |
| 동료 기본 | ‘{이름}에 대해선 아직 모르는 게 많다. 쉬는 동안 이야기를 더 나눠 볼 것.’ |
| 조달 | ‘{have}개는 챙겼다. {left}개만 더 구해서 돌아가자.’ 물품명은 제목에 남겨 고정 조사 ‘은’ 문제 방지. |
| 배달 | 목적지와 물품을 자연스러운 한 문장으로. 물품명의 을/를 처리 후 ‘{to}까지 {item}을/를 전해 주기로 했다.’ 검토. |
| 완료 결과 | 실제 영수증인 `row.expected`는 버리지 않는다. 회고 문장과 보상 표기를 분리하더라도 원본 사실·보상 보존. |

Claude의 제안은 입력 상태를 변경하거나 새 사실을 확정하는 권한이 아니다. 특히 동료 야영 확정형 및 완료 영수증 분리는 그대로 적용하지 않았다.
