## 결정과 범위

Sang은 이벤트도 인트로처럼 스크롤 없이 읽고 싶다고 요청하고 변경 방향을 승인했다.
저장소의 선행 디자인 초안 검토 규칙에 따라 먼저 조작 가능한 별도 초안을 등록했다.
실제 이벤트 렌더러·CSS·대사·분기·게임 저장은 변경하지 않았다. 아직 게임 구현 완료가 아니다.

방향은 큰 그림 + 의미 단위 대화 → 답변 선택 → 인물 반응이다.
짧은 대사는 합쳐 읽고, 큰 글씨·좁거나 짧은 화면일 때만 자연스러운 두 덩어리로 나눈다.
제목, 자동 읽기, 반복 진행 숫자는 이 수동 읽기 초안에서 제외했다.
실제 적용 시 자동 읽기 설정은 별도 검토가 필요하며 기능 삭제가 승인된 것은 아니다.

- 초상: 48×48px 정사각 초상과 이름을 왼쪽에 한 줄로 놓고 대사는 그 아래 전체 폭을 쓴다. 같은 화자가 이어 말하면 얼굴을 반복하지 않는다. 화자가 바뀌거나 새 페이지에서 다시 식별해야 할 때만 표시하며 서술에는 붙이지 않는다. 원본을 확대 크롭하지 않는다.
- v2 사전 재검토: 프로필을 대사 옆의 고정 열로 두면 좁은 화면에서 줄 수가 늘어난다. 이름 행으로 분리하고 기존 장터 팔레트·18/21px 본문은 유지했다. 말풍선, 추가 카드, 장식 테두리는 넣지 않았다. 짧은 문답은 같은 화면을 지키고 뒤 행동 묘사만 필요할 때 나눈다.
- 검토 후 덜어낸 것: 한 줄짜리 동행 결과 때문에 별도의 빈 요약 화면을 만들지 않는다. 짧은 반응 바로 아래 다음 장소 한 줄을 붙이고 길 복귀로 끝낸다.
- 실제 적용에서 많은 선택지가 있는 사건은 이2선택 예시만으로 검증된 것이 아니다. 선택지 수/길이에 맞는 별도 페이지 규칙이 필요하다. 전투·타이머 사건은 이번 초안 범위가 아니다.

- 기본 읽기: `text`4문단 전체. 큰 글씨/349px 이하 폭/650px 이하 높이는 앞2문단 → 뒤2문단.
