초안 안내

현재 부산 ‘사유가 없는 이송표’의 원문·선택·결과를 사용한 독립 초안입니다. 현재 읽기 위치를 복제한 화면은 아닙니다.

‘계속 읽기’로 사람 대화 → 단말 응답 → 선택 → 반응을 비교하세요. 두 선택의 비용과 원문은 유지했습니다.

새로 생성한 것은 투명 금속 프레임과 빈 버튼 재질 두 장뿐입니다. 장면·초상은 게임 자산이며, 글자는 이미지에 그리지 않았습니다.

초안은 자동 읽기를 재생하지 않습니다. 게임·저장·자원·현재 읽기 진행에는 연결하지 않았습니다.

작은 높이와 큰 글씨에서는 본문만 스크롤합니다. 실제 게임 적용 시 기존 페이지 측정·읽기 저장을 유지해야 합니다.

Studio 직접 화면·터치 검수는 연결 시간 초과로 미완료입니다.
