새 연결 지형과 기존 기본 달구지로 만든 독립 CSS 초안입니다. 게임과 저장에는 미적용이며, 현재 차량의 개조·탑승자·날씨나 실제 이동 시간을 복제하지 않습니다. 그림 속 지형은 구간의 연결감을 살펴보는 예시이지 실제 도로 위치를 재현한 지도가 아닙니다.

하늘·도로·차량은 지형 그림에 포함하지 않았습니다. 시장과 돔 사이의 농가·들판·산줄기는 한 지형 안에서 이어지고, 그림 경계는 화면을 쓸고 지나가지 않습니다. 앞 초안의 둔덕 가림 도형도 없습니다.

실제 게임에서는 이 지형의 이동을 이동 거리와 묶어야 합니다. 정지·감속·사건 중단·재개·도착·새로고침에서 같은 위치를 이어 받고, 준비되지 않은 그림으로 갑자기 바꾸지 않는지 별도로 확인해야 합니다. 이 초안을 모든 구간에 같은 산으로 붙이지 않습니다.

승인은 이 한 구간의 연결감부터 확인합니다. 초안 선택은 요청 작성만 하며 게임에 자동 적용하지 않습니다.
