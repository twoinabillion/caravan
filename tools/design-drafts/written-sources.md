# 편지·메모·기록 · 제목 한 줄

상태: `written-sources-v1`을 Studio에서 먼저 보여 준 뒤 Sang의 ‘ㄱㄱㄱ’ 승인을
받아 공통 reader 소스에 구현했다. 실제 게임은 새 코드 준비됨 적용·시각 검수 대기다.
선택은 요청 작성만 준비하며 코드·설정·저장을 자동 적용하지 않는다.

## 제안과 코드 근거

- 현재 `storyTurnHtml`은 letter에도 초상과 small(kind)/b(name) 대사 틀을 쓴다.
  `pagedStoryHtml`은 letter/record의 구체적인 name 대신 종류만 표시한다.
- 문서의 명시적인 제목이 있으면 그대로 한 번만 표시하고 종류·초상은 덧붙이지
  않는다. 제목이 없는 문서는 종류를 한 번만 사용하며 인물 이름을 임의로
  문서 제목으로 만들지 않는다. 대사·생각·방송의 의미 구분은 보존한다.
- record 태그에는 글씨뿐 아니라 다른 매체/상황도 섞여 있다. 태그만 보고 모든
  기록을 종이 문서로 바꾸지 않는다. 녹음/영상의 재생 표지·인물·그림은 별도 유지한다.
- 향후 실제 적용은 인트로/현행 paged 사건/기록 다시 읽기의 공통 표제 표시를
  맞추되 저장된 원문·speaker identity·읽기 커서·효과·소리는 바꾸지 않는다.
  letter 본문에 남은58px 초상용 들여쓰기도 문서 전용 구조에서 해제해야 한다.

## 초안의 범위

현재 플레이 재현이 아니라 문서 표제 부분만 발췌한 HTML/CSS 시안이다.
사진·종이 raster·인물 초상을 새로 연결하지 않았다. 기존 색과 산세리프,
본문16px/1.55와 큰 글씨21px을 유지했다. 프런트엔드 지침에 따라 새 장식이나
카드를 추가하지 않고 문서 이름 하나가 출처를 맡도록 정리한다.

원문은 실행된 정본 `D.intro`의 `intro-keepsakes-return-v1:3..5`,
`D.openingDeparture`의 `opening_parents_module:3`에서 가져왔다.
옛 intro-mother-keepsakes 배열은 이후 재구성되어 있어 정본 검사가 이를 잡았고,
실제 사용되는 장면/턴 번호와 서술로 바로잡았다. 게임의 대본은 수정하지 않았다.

‘이전 두 줄’은 헤더의 두 줄만 비교하며 이전 초상까지 재현한 스크린샷이 아니다.
초안에 남은 인트로/사건 표시는 비교 도구이며 게임에 새로운 탭을 추가하는 안이 아니다.
