## 배치와 동작

큰 ‘운전 중 생각’ 카드·그림·제목을 제거하고, 기존 관찰 문장만 풍경 아래에 잠깐 표시한다. 문장은 absolute 배치로 목적지·주행 기록·동행 기록의 공간을 밀지 않는다. 목적지와 상태줄의 합계 높이272px는 유지한다.

‘가끔 / 끄기’, ‘문장 고정’, ‘이벤트 예시’로 비교한다.35초 주기 중 약8초 표시는 빈도 검토용이지 확정된 게임 규칙은 아니다. 이벤트/상세 안내가 열리면 문장을 숨긴다. Studio의 script 없는 sandbox를 유지하며 CSS animation, native radio/checkbox, hash만 쓴다.

실제 구현을 승인하면 위험 안내·접근/감속·이벤트·창 비활성 중 숨김, 이후 재표시 간격, 설정 보존, 현재 읽기 상태/기록 경로를 별도로 검증해야 한다. 초안의 문장 고정 도구는 게임 기능이 아니다.

## 실제 연결 ·2026-10-05

Sang의 적용 요청으로 `src/07f-ui-road-thoughts.js`의 카드 생성기를 작은 원문 caption으로 교체하고 DOM/CSS 단일 소유 블록과 기존 메뉴 설정을 연결했다. UI의 주행 `sys` 관찰만 전달하며 동료·라디오·주인공 말풍선은 기존 흐름을 유지한다. 사건·저장·주행 렌더러·접근 큐는 변경하지 않았다. 새 raster나 정적 초안 차량 그림은 게임에 연결하지 않는다.
