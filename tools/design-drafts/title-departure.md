# 부산 출발 전 · 타이틀 v2

게임에 미적용인 독립 HTML/CSS 초안. Studio **디자인 초안**에서 검토한 뒤 게임 구현 여부를 결정한다.

## 방향

큰 제목 → 항구에 세운 달구지 → 출발 버튼. 제목 전체를 같은 크림색으로 묶고, 메뉴의 큰 테두리·중복 출발 문구·카드 설명을 덜었다. 청회색 원경과 따뜻한 차량 창을 중심에 둔다. 기본 360×728, 320·480폭 비교와 짧은 높이의 명시적 페이지 스크롤을 고려했다.

팔레트: 밤 `#111b22`, 항구 `#344550`, 크림 `#ebe3ce`, 보조 글자 `#acb5b7`, 앰버 `#d1b47f`, 버튼 잉크 `#202b31`. 제목은 굵은 시스템 한국어 산세리프, 본문은 시스템 글꼴. 제목 글꼴의 정본 연결은 승인 후 구현 단계에서 검토한다.

## 출처와 격리

- 기존 `assets/ui/road-environment/busan-v1.webp`, `assets/ui/journey-dalguji-base-v1.webp`를 변경 없이 재사용. CSS 부두 바닥·그림자는 배치 표현이다.
- 기존 렌더러 부품의 **정적 합성**이지 새 시네마틱 삽화나 실제 캔버스/날씨/개조/저장 화면 재현이 아니다. 신규 인물·보리·정체불명 랜드마크는 넣지 않았다.
- 제목·설명·메뉴와 미리보기 발췌는 `src/02-dom.html` 기준. 안내창 문구는 초안 조작 설명이다.
- 상단 ‘저장 기록 있음 예시’는 실제 저장을 조회하지 않는 메뉴 배치 비교다. 허구의 DAY·장소·자원 수치를 표시하지 않는다.
- 시작·이어서·미리보기·소리는 해시 안내창만 연다. 뒤로 링크로 타이틀에 복귀한다. 스크립트·게임 프레임·스토리지·자동 적용·소리 재생 없음.
- 게임 소스·생성 HTML·빌드·실제 저장은 변경하지 않았다. 설치와 저장 위치 안내는 승인 후 기존 기능의 표시 조건을 유지하며 연결할 사항이다.

## 검수

원본 두 이미지 관찰 완료. Studio 독립 디자인 검토 창에서 360폭 기본 화면, 320폭 이어가기 배치와 안내·복귀 동작을 확인했다. 480폭 이어가기에서 차량 지붕이 잘리는 문제를 발견해 차량을 화면 너비뿐 아니라 장면 높이에도 맞추도록 고쳤다. 수정 뒤 480폭에서 지붕·바퀴·짐이 모두 보이며 360폭 기본 화면도 다시 관찰했다. 시작·이어가기·미리보기·소리의 해시 안내와 복귀를 확인했다. 짧은 높이·큰 글씨·실제 게임 연결은 미검수다.

Studio 목록 파서 통과(25개), 모든 초안 내부 링크 대상과 로컬 자산 존재 확인, 스크립트·폼·중첩 게임 iframe 없음, `git diff --check` 통과. 게임 CSS·DOM·장면 렌더러·생성 HTML의 전후 SHA256 동일. 캡처는 `/tmp/caravan-title-departure-review.jpg`에 보관했으며 실제 플레이가 아닌 초안 창이다.

Studio 현재 상태는 타이틀 360×728, 로드·스타일1791125070940, 대기 없음. 실제 게임 화면은 네이티브 Studio 접근 제한으로 직접 관찰하지 못했다. 초안 관찰을 실제 게임 화면 검수로 간주하지 않는다.
