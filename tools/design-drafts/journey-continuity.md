## 디자인 계획과 선택

- 기존 정차 패널의 올리브 금속/황동 강조를 주행에도 이어간다. 색은 바탕 `#131b17`, 패널 `#202820`, 본문 `#f0eee2`, 보조 `#c1c4b5`, 강조 `#edc986`, 경계 `#626a52`.
- 기존 Apple SD Gothic Neo/Malgun Gothic 시스템 글꼴을 유지한다. 왼쪽 정렬, 장소19px, 실행15px, 보조11~13px. 큰 숫자가 주인공인 계기판을 추가하지 않는다.
- 하나의 풍경, 차량, 상태줄, 패널, 하단 메뉴를 공유한다. 상태를 바꿀 때 패널 안 내용만 바뀐다. 이동 중임을 보여 주려고 배경을 줄이거나 카드 높이를 늘리지 않는다.
- v2에서는 출발 전·주행 중 장소 이름 아래에 ‘무너진 고가 아래를 탐색할 수 있다.’를 기본 표시한다. 장소의 특징과 가능한 행동만 예고하며 발견물·보상은 알려 주지 않는다. 목적지 변경 표시는 이름 오른쪽으로 옮긴다.
- 장소 이름24px + 간격3px + 예고18px + 위아래 여백11px + 경계1px = 57px로 기존58px 행 안에 둔다. 예고는13px이며 새 카드나 패널 높이를 추가하지 않는다. 상단 ‘예고’ 스위치는 글의 유무만 비교한다. 꺼도 자리를 유지하며 v1 전체 화면을 재현하는 기능은 아니다.

```text
    장소 / 예시 표시     경로 / 기록 시각     장소 / 도착 시각
    ┌──────────────── 같은 풍경 영역 ────────────────┐
    │              같은 크기·위치의 달구지            │
    └──────────────── 상태줄 44 ───────────────────┘
    │ 목적지 / 머물기   │ 이동 중           │ 목적지 / 머물기 │
    │ 행선 + 짧은 예고  │ 목적지·거리 + 예고 │ 선택한 행동    │
272 │ 예상치           │ 진행선            │ 예상치         │
    │ 명시적 실행      │ 지도 / 목적지 정보 │ 명시적 실행    │
    │ 목표·행동 안내   │ 보급 기록 한 줄    │ 장소 정보      │
    └──────────────── 같은 하단 메뉴 ────────────────┘
```

- 계획 검토에서 주행 전용 큰 사진·정보 카드·보급 카드를 다시 붙이는 안은 제외했다. 세 패널에 가짜 실행 버튼을 맞추는 대신 주행에는 실제로 쓸 지도/정보 두 보조 행동을 둔다. 배치 기준은 같지만 기능까지 같은 척하지 않는다.
- 바깥 패널272px, 외부 여백14px, 테두리2px, 안쪽 아래8px. 머리44px + 내용 위4px + 내용58/38/48/44px + 간격12px = 안쪽248px. 정차 목적지/머물기, 주행, 도착 모두 같은 행 배분이다.
- 내용150ms 페이드와 원경650ms 교차 페이드만 사용하며 높이/차량 좌표 전환은 없다. 모션 감소 설정에서는 생략한다. 원경 변화는 비교 도구의 가상 장면 이동에만 반응한다. 실제 게임에서는 탭/목적지 선택이 아니라 기존 캔버스의 이동 진행을 따라야 한다.

## 정보와 상호작용

- 주행 첫 화면: 목적지, 한 번만 표시한 남은 거리, 짧은 장소 예고, 진행선, 지도/목적지 정보, 보급 기록 한 줄. 이전 STOP 화면의11/10km 혼용 대신 `ceil(34 - 23.727890333333146) = 11`을 사용한다.
- 짧은 예고는 기본 화면에 남기고 기존 양산 사진과 자세한 장소 설명은 ‘목적지 정보’에서 연다. 실시간 도로 원경에 사건 삽화를 합성하지 않는다.
- 지도는 초안 내부 개략도로 표시한다. 두 실제 노드만 사용하고 지형이나 갈 수 있는 새 경로를 만들지 않는다. 게임 연결 시 기존 전체 지도를 그대로 사용한다.
- 식사 기록은 한 줄 요약 → 눌러 원문 확인. 연료 부족/위험 상승/멈춰야 하는 사건까지 조용하게 만들자는 제안이 아니다. 실제 구현 시 위험 상태의 상시 요약/강조와 사건 진입은 보존해야 한다.
- 정차/도착의 목적지·머물기는 라디오로 비교한다. 행동 변경/목적지 선택/실행/목표는 기존 연결을 설명하는 독립 창을 연다. 선택창 자체를 다시 구현하지 않는다.
- 모든 상세창에 명시적 닫기/바깥 닫기 링크가 있다. 닫아도 라디오 선택이 유지된다. 가려진 비교 도구와 패널의 컨트롤은 `visibility:hidden`으로 키보드 순서에서 빠진다. 해시만 바꾸며 스크립트·스토리지·게임 API 호출은 없다.
- Escape 닫기, 자동 포커스 복귀, native dialog containment는 초안에 구현하지 않았다. 실제 연결 시 기존 dialog 계약과 함께 별도 검증해야 한다.
- 도착 후에는 예고를 반복하지 않고 현재 가능한 행동과 비용을 보여 준다. 현재 양산 화면의 ‘주변 탐색’, ‘+2시간 · 피로 약 +5’, ‘발견물 미확인’을 사용한다. 도착 사건을 건너뛰거나 탐색 결과를 예측하는 흐름이 아니다.
