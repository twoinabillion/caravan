# 부산에서 시동을 걸기 전 · 두 화면 초안

Sang 요청: 타이틀과 이름/출발 구성 화면이 모두 2% 부족하다. 같은 장소의 출발 준비로 연결한 디자인을 먼저 본다. **게임 적용 승인은 아직 없다.**

## 디자인 계획과 자가 검토

- 팔레트: 항구 청회색 `#27343c`, 새벽 바탕 `#142027`, 기록 종이 `#e0d6bb`, 종이 잉크 `#30372f`, 생활 조명 `#bb9557`, 흐린 글자 `#b7c0c1`.
- 글꼴: 기존 한국어 UI와 이어지는 Apple SD Gothic Neo/Noto Sans KR. 제목은 굵고 짧게, 이름은 더 큰 입력 글씨, 수치는18px. 폰트나 장식 때문에 내용을 읽기 어렵게 만들지 않는다.
- 배치: 타이틀은 제목→부두에 선 전체 달구지→출발 준비. 다음 화면은 가까운 뒷문→작은 출발 기록(이름/짐 선택/수치)→고정 시작 버튼. 본문은 왼쪽 정렬. 짧은 화면은 기록 부분만 스크롤.
- 고유성: 같은 차/부두/빛을 유지하며 카메라 거리로 두 화면을 잇는다. 생존 장비를 상품 카드로 늘어놓거나 네온/금속 HUD를 더하지 않는다.
- 계획 검토: 앞 초안의 거대한 숫자 격자/설정 카드보다 기록 한 장에 간단한 수치 줄을 쓴다. 전체 화면을 장식용 공책으로 만들지 않고 이름·짐을 적는 부분에만 종이를 쓴다. 새 배경 그림이 주인공이며 주변 UI는 조용하게 유지한다.

## 이미지 출처

`opening-wharf/harbor-v1.webp`와 `cargo-v1.webp`는 built-in imagegen 제작 **컨셉**이며 게임에 연결하지 않았다. 4개 필수 정본을 모두 첨부했고 두 번째에는 첫 장면도 첨부했다. 원본은 같은 폴더 `masters/`에 보존. 공통 스타일/네거티브와 각 최종 프롬프트는 `prompts.json`에 있다.1024×576 WebP 납품 예시. 실제 출발 날씨·개조·보유량의 재현이 아니며 그림 속 물건 개수는 수량이 아니다. 등장 동료·보리·사람·서울 랜드마크 없음.

## 동작과 한계

HTML/CSS·native radio·해시 이동만 사용한다. 타이틀→이름/구성→안내→복귀를 검토할 수 있다. 선택은 그림을 추가로 적재하지 않고 선택 설명과 정확한 수치만 바꾼다. 이후 선택에 따라 그림까지 바꿀지는 승인 후 별도 판단한다. 이름8자/빈 이름 ‘나’, startProfiles의3구성과 수치는 유지한다. 게임 스크립트/폼/저장/빌드/자동 적용 없음. 이어가기·프롤로그·소리·미리보기는 초안 안내이며 실제 기능을 호출하지 않는다.
