# 짐 선택 초안 v2 — 2026-10-05

## 변경

- 첫 부두 타이틀은 `opening-wharf.html`과 동일하게 유지했다.
- 화자가 없는 “기본 짐은 실어뒀어요” 문구와 기본 물자 설명 패널을 제거했다.
- 작은 그림 세 장을 나란히 배치하지 않고, 선택한 짐의 큰 그림 한 장만 보여준다.
- 연료통 / 부품 상자 / 물·식량 라디오 선택이 그림, 추가량, 최종 출발 물자, 출발 버튼의 짐 이름을 함께 전환한다.
- 초기 연료통 선택은 초안에만 적용된다. 실제 게임의 빈 탱크 선택, 이름, 저장 상태를 읽거나 바꾸지 않는다.
- 기존 부두 색감과 종이 기록의 대비를 유지했다. 새 그림이나 설정을 추가하지 않았다.

## 검사

`node --test tests/test_opening_extra_pack_draft.cjs tests/test_opening_wharf_draft.cjs`: 8개 통과.

등록과 게임 빌드 분리, 타이틀 보존, 하나의 초기 선택, 세 전환 규칙, 제안 물자 합계, CSS 파싱·스크롤/고정 푸터 구조, 키보드 포커스 규칙, 정본 참조 및 이미지 크기를 검사했다. `git diff --check`도 통과했다.

## 미확인

이번 v2의 브라우저 시각·조작 검수는 완료하지 못했다. 브라우저 연결 목록이 비어 있었고, 제공된 현재 장면 GET은 HTTP400 “Studio 창에서 현재 장면을 받지 못했습니다”를 반환했다. 따라서 모바일 잘림·크롭·전환 클릭을 확인했다고 간주하지 않는다. 기존 evidence 폴더의 이미지는 v1 검수 자료이며 v2 증거가 아니다.

Studio 디자인 초안의 “출발 전, 짐 하나 더 · 두 화면”, revision 2에서 검토한다. 실제 게임 코드나 생성 HTML은 수정하지 않았으며, 새 시작 규칙의 수치는 여전히 밸런스 검증 전 제안이다.
