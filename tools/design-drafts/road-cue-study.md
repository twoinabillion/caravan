# 길 위의 사람들 — 도로 조우 초안

2026-09-27. 사용자 요청은 도로 접근 중 보이는 작은 사람·사건 표현을 달구지 수준으로 다듬은 **예시 초안**이다. 게임 적용 승인은 아직 없다.

## 제안

현재 `src/05-scene.js`는 일반 조우의 픽셀 이미지와 일부 상세 차량 부품을 혼용한다. 상세 차량 옆 사람은 `detailedCuePerson`의 짧은 선·몸통·타원 머리로 그린다. 따라서 모든 차량을 다시 만드는 대신 인물·짐의 표현을 먼저 맞춘다.

- 색: 외부 청회색 `#849598`, 아스팔트 `#303e43`, 작업복 올리브 `#717765`, 바랜 천 `#a29a78`, 피부 중간색 `#b1977b`, 부드러운 밝은 면 `#bac9bf`.
- 형태: 굵은 외곽선 대신 면 명도, 겹침, 작은 재질 차이. 긴 소매·무릎 주름·낡은 신발은 자세를 읽는 데만 쓴다. 얼굴을 크게 만들지 않는다.
- 배치: 같은 원경과 달구지 안에서 비교 → 아래에서 대상만 확대. 제목/설명은 Apple SD Gothic Neo 계열로 조용히 왼쪽 정렬한다. 게임 전체 HUD를 흉내 내는 장식·가짜 기능 버튼은 넣지 않는다.
- 절제: 화면 전체를 새 일러스트로 덮거나 사물에 발광 테두리를 두지 않는다. 새 래스터 생성 없이 코드 도형으로 인물과 짐을 분리한다.

첫 계획의 '새로운 고장차 전체 제작'을 제외했다. 이미 승인된 상세 차량이 있어, 이번 문제는 차량 재생성보다 사람·일반 사건과의 표현 간격을 좁히는 쪽이 맞는다.

## 초안에서 볼 것

1. `사람과 짐` / `고장 난 차`로 예시 전환.
2. `제안` / `현재 자산`으로 형태 비교. 비교를 위한 정적 배치이지 실제 런타임 캡처가 아니다. 고장차의 현재 사람은 기존 절차형 실루엣의 개략 재현이다.
3. `대상 확대`는 검토용 확대이며 실제 접근 중 크기 변화 제안이 아니다.
4. 펼침 설명은 기존 발견 → 점진 감속 → 정차 → 사건 화면의 연결을 유지한다는 제안이다. 움직이는 데모는 아니다.

이름 없는 두 성인은 배치 예시다. 현재 `story_family_principle`의 등장인물이 아니고 기존 가족 트럭 사건의 아버지·아이 수를 바꾸지 않는다. 실제 연결 단계에서는 `roadApproach.scene`의 인원·나이·자세를 그대로 따른다.

## 출처 / 기술 범위

- `assets/ui/journey-dalguji-base-v1.webp`: 기존 달구지, 폭155 단위.
- `assets/ui/road-environment/sejong-v1.webp`: 기존 세종 원경. 요청 시점 세종→공주 구간에서 가져온 배치 배경이며 해당 주행의 실시간 재현은 아님.
- `assets/road-cues/cue-people.png`: 현재 일반 사람 조우 이미지.
- `assets/road-cues/cue-broken-vehicle-v3.webp`: 기존 상세 차량, 폭80 단위. 달구지 대비51.6%. 그림과 가로세로비 유지.
- 새 사람·가방·그림자: Codex 직접 작성 SVG path/ellipse/linearGradient. Canvas2D의 path/ellipse/gradient로 옮길 수 있는 형태 초안. Studio는 script 없는 sandbox이므로 SVG로 제시하며 **게임 캔버스 구현은 하지 않음**.
- 고장차 사람 높이 약20단위, 차량 높이37.2단위. 그림자와 손짓을 제외한 성인 몸높이는 차량 차체 높이의 약 절반 수준으로 유지한다. 달구지 확대나 cue의 접근 확대 애니메이션 없음.
- CSS 소유자는 `road-cue-study.css` 하나. 기존 게임 CSS·엔진·빌드·save·라이브 적용 명령에 접근하지 않는다.
