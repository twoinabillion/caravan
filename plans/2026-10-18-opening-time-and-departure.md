# 현재에서 기억으로, 다시 내 출발로

상태: v1 흐름 ‘ㄱㄱ’, quiet v2 ‘그게 낫네’ 승인 뒤 본게임 소스에 통합했다.
본게임 구조는 ‘새 코드 준비됨’으로 대기 중이며 현재 부산08:45 저장을 되감지 않았다.
이하 초안 제작 기록은 과거 시점이다. [구현·검증·남은 범위](../tools/opening-presence-implementation-20261018.md).

## 이번 범위

- Studio4327 디자인 초안에 `opening-presence-v1`을 등록한다.
- 같은 읽기 위치에서 현재 / 직접 겪은 기억 / 전해 들은 이야기를 구분한다.
- 현재 사건이 본선이다. 기억은 이송표로 열고 다시 이송표로 돌아온다.
- 긴 역사는 선택 읽기로 분리하되 부모님의 표, 장치의 목적, 떠나는 이유는 본선에 둔다.
- 기존 열쇠 선택 뒤 도윤·하진의 부탁과 작별을 읽고, 명시적 출발 뒤 장 경계를 만난다.
- 새 대사/그림/음성보다 기존 정본의 발췌·재배치로 먼저 비교한다.

## 추가 피드백: 제목을 덜고 장면 먼저 (v2)

Sang은 전체 글자와 제목이 차지하는 면적이 크고 사진/텍스트 비중을 줄이고 싶다고 했다.
v1의 이야기 흐름 승인은 유지하되, 새 시각 변경은 Studio에서 다시 비교한다.

- 기존 재질/색/사진/대사/분기 유지. 매 장면 제목64px 줄을36px 시간·장소·출처 줄로
  줄이고 제목은 목차/접근성 레이블에 남긴다. ‘서장을 마치고’ 장 경계만 큰 제목 유지.
- 기본 본문18→17px, 큰 글씨21px 유지. 화자 초상48→36px/큰 글씨44px,
  인물/문단 간 여백을 줄인다. 원본16:9 그림 높이는 줄이지 않으며 결과/선택에서도 동일.
- 반복되는 초안 설명은 목차 안내로 모은다. 이야기 원문을 생략·말줄임하거나 비용·
  선택지/다음 행동·회상 시점/출처를 숨겨 맞추지 않는다.
- 같은 화면의 ‘이전 안’ 체크로 v1형 제목/18px/화자 간격을 비교한다. 게임 설정 아님.
- 관찰 전 가설: 제목에서28px와 반복 주석 면적을 돌려받아 읽기 공간이 늘고 사진이
  더 위에서 시작한다. 사진 픽셀을 키웠다는 뜻은 아니며, 실제 보기 전 선호를 확정하지 않는다.
- 이 변경은 같은 읽기 인터페이스의 비중 조정이다. 새 이미지/전체 앱 재설계/스토리
  대규모 요약은 범위 밖이다. 현재 게임08:45를 시험 삼아 되감지 않는다.
- 검수 완료: Studio360 같은 기억에서 그림202.50px 유지·본문324.25→376.74px,
  기본17/이전18px 측정. 실제 CSS320×568 큰 글씨21px의 기억 끝·역사 출처·두 선택
  끝까지 확인. 전체762/762 통과. [v2 증거·한계](../tools/design-drafts/opening-presence-quiet.md).
  승인된 v1 흐름은 유지하고 v2 새 비중은 Studio 검토 뒤 통합한다.

초안은 흐름의 발췌다. 기존 수리3방법, 이름 인사, 민원2선택과 장치2선택은 삭제하는 것이
아니라 초안에서 생략한다. 실제 지급 결과, 플레이 커서, 08:45 시각을 복제하지 않는다.
열쇠 결과2개도 초안 링크일 뿐 실제 선택이나 소비가 아니다. 마지막 그림은 출발 시네마틱
정지컷이며 실제 움직이는 도로나 캔버스의 대체안이 아니다.

## 시각 계획과 자체 검토

- 색: 부두 금속 `#24343e`, 생활 종이 `#e4dcc6`, 잉크 `#29312e`, 기억 표지 `#d5b77c`,
  전해 들은 이야기의 청회색 `#a8c2ca`. 기존 게임 재질에 맞춘다.
- 본문18/21px, 동일한 산세리프와 줄간격. 장의 경계·마지막 인사에 기존 명조 계열,
  인물은 공식48px 초상.
- 구조: 검토 도구 → 출처/시간/장소 → 고정 그림 → 본문 → 고정 다음 행동.
- 현재는 금속 가장자리, 기억은 따뜻한 제본 가장자리, 전해 들은 이야기는 출처와 인용선.
  사진 필터, 새 래스터, 글씨 축소, 색만으로 구분하는 방식은 쓰지 않는다.
- 여러 UI를 새로 디자인하는 대신 의미 표지와 가장자리 한 축만 변화시킨다.
- 평소에는 한 페이지를 읽으며 좁거나 큰 글씨일 때 본문만 명시적으로 스크롤한다.

## 승인 후 실제 구현 때 지킬 것

현재 / 기억 / 전해 들은 이야기는 `D.intro`라는 함수 구분이 아니라 대본의 출처다.
전해 들은2026년을 주인공의 직접 기억으로 만들지 않는다. 직접 조작하는 현재에만 비용·선택을 둔다.
기존 opening5단계 인덱스, 이름 끼움, 지급 영수증, 과거 저장을 보존하며, 이미 출발한 현재
저장에 작별을 강제로 재생하지 않는다. 미리 읽기는 출발까지 중복하지 않는 별도 역할로
정리하되 현재 읽기 커서를 강제 초기화하지 않는다. 본게임 구현 전 Sang과 초안을 논의한다.

## 검증 계획

독립 HTML의 스크립트/스토리지/폼 부재, 모든 왕복 링크, 원문 발췌의 실제 출처,
현재·기억·전해 들은 이야기 표지, 동일 그림 높이, 큰 글씨·짧은 화면을 검사한다.
Studio 실제 초안에서360/320/480폭, 기억 왕복·역사 읽기/복귀·두 열쇠 결과·작별·출발을 관찰한다.
본게임 시각 QA나 실제 저장 플레이 검증으로 대신 보고하지 않는다.
