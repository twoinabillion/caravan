## 대상과 증거 수준

Sang이 선택의 고민·여정 리듬·차량/동료 애착과 첫 실행 검토를 지시했다. 실제 초심자 참여자를 모집하거나 사람의30분 반응을 관찰한 것은 아니다. 기존 개발 서버4319에서 사용자 저장과 분리한 유한 자원 브라우저로, 앞서 실제 획득한 밀양 저장을 이어 실제 버튼·대화·자원 소모를 검사했다. 정책은 보이는 첫 활성 선택지이며 결과를 미리 채점하지 않는다. 지정된 경로/메뉴를 쓰는 검사이므로 설명 없는 길 찾기 성공률이나 페이지 뒤 모든 대안의 선호도로 해석하지 않는다.

## 실제 관찰과 수정

- 첫 야영19조작/26.20초: 차 안 둘러보기·취소·식사/점검 비용·재접속·아침·다음 출발 통과. 획득한 DAY2 밀양 저장을 다음 검사에 사용했다.
- 첫 동료96조작/248.95초: 시장 구매/취소→민지 부탁 수락→양산→울산 현장→경주 동행→야영→합류 보류→다시 합류→다음 출발. 재접속8회, pageErrors0, 자원 추가/시계 가속 없음. 인간의 읽기시간과 구분한다.
- 실제 수락 직후 목적지 카드가 본편 방향 대구를 기본 선택한 혼선을 확인했다. **명시적 미션 추적/목표 선택이 없을 때에만** 수락한 임시 승객의 task 목적지를 기본 제안하도록 수정했다. 실제 추적 중인 배달과 명시적 본편 선택은 우선한다. 이미 끝난 과제/road 단계는 기본 본편 경로를 유지한다. 제안일 뿐 출발/자원 지출은 일으키지 않는다.
- 수정 후 획득 저장에서 실제28조작/40.26초로 재현: 울산을 향하는 양산 경유지가 기본 선택되고, 예고에 울산이 표시됨. 실제320/360계열 캡처에서 관찰했다.
- 새3개 회귀는 변경 전1실패/2통과를 확인하고 변경 후3/3 통과. 관련25/25, 최종 전체8,617/8,617 통과. 최종 HTML167,548,613B, 기존200MB 한도/160MB 경고 유지.

## 디렉터 판단

- 첫 부탁은 실제 우회 주행과 연료, 현장의 고철/차체 비용, 하루를 함께 보내는 조건이 있어 아무 비용 없는 동료 수집은 아니다. 다만 첫 활성 선택 위주의 이번 검사로 대안들이 사람에게 같은 무게로 읽히는지는 확인하지 못했다.
- 민지의 손 신호→현장 작업→한 구간 동행→공구함 자리라는 연결은 실제 표현에서 확인했다. 합류 전 약속과 합류 확정의 분리도 작동한다. 애착이 생겼다는 인간 반응의 증거는 아니다.
- 생활 공간/야영과 동료의 흔적이 이미 있으므로 새 호감도/보상 시스템을 추가하지 않았다. 이번 검토만으로 사건 빈도나 자원 난도를 일괄 변경할 근거도 없어 그대로 뒀다.
- 다음 체험 관찰에서 볼 것: 수락 후 스스로 길을 찾는가, 다음 선택지 페이지도 확인하는가, 끝난 뒤 사람·선택·다음 목적지를 자기 말로 설명하는가. 질문은 플레이 도중 정답을 가르치지 않고 구간 종료 후 한다.

## 첫 실행 프로파일

실물 휴대폰 연결 도구가 현재 세션에 없고 `xcrun devicectl`도 설치되지 않아 실제 iPhone/Android·발열을 측정하지 못했다. 단순히 연결 기기가 없다고 단정한 것은 아니다.

`tools/qa-startup-profile.py`로 Mac의 headless Chromium360×728/DPR2, 새 컨텍스트·캐시 비활성화·CPU profiler 활성화 상태에서 측정한다. CPU4배 지연은 휴대폰 모델이 아니다. localhost 원본 HTML은 압축하지 않은167MB 응답이며 공개 GitHub 서버의 전송 압축·실제 통신망 시간과 다르다. JSHeapUsedSize는 이미지/GPU/프로세스 전체 메모리가 아니다.

첫 진단에서 CPU1:준비6932.9ms/JS힙160845832B, CPU4:24718.6ms/159668816B. 함수 샘플에서 CARAVAN_URI 자체에 각각1239.8/5057.9ms가 잡혔다. `(program)` 표본을 모두 파싱 시간이라고 단정하지 않는다. 이 최초 측정은 동료 경로 검사가 함께 돌던 시점이므로 아래 반복 측정을 우선한다.

진단상 단일 대형 스크립트 실행과 자산 문자열 복원이 첫 실행 비용의 유력한 작업 대상이다. 이미지 품질을 낮추는 조치나 단일 HTML/오프라인 계약을 깨는 배포 구조 변경은 이번 관찰만으로 자동 적용하지 않았다.
