# 8점 업그레이드 — 구현 결과 (2026-08-06)

계획서: [`UPGRADE-PLAN-2026-08-06.md`](UPGRADE-PLAN-2026-08-06.md)
스코프: 오디오·비주얼 아트를 제외한 전 영역 (Sang 지시).

이번 사이클의 주제는 새 콘텐츠가 아니라 **압박과 대가**였다. 리뷰의 진단이
"모든 시스템이 진짜로 배선돼 있는데, 아무것도 플레이어를 밀어붙이지 않는다"였으므로,
작업의 다수는 추가가 아니라 **이미 만들어 둔 것을 살리는 일**이었다 —
선언만 된 시한, 써 놓고 도달 불가능했던 실패 분기, 바이블에만 있던 갈등 원칙.

## Phase 1 — 코어 루프 (6.5 → 8 목표)

- **DAY 30을 실제로 집행**: `G.tickDeadline()` 신설, `dawn()`과 `arrive()`에 배선.
  D-10 이송 버스 목격 → D-5 통제 강화(+관측) → D-0 전야 → **초과 시 첫 이송 행렬과 실제로 마주친다**.
  이벤트 5종 신규 작성. 늦으면 `seoul_costs`·`seoul_decision`·에필로그 텍스트가 전부 달라진다.
  - ⚠️ **구현 중 발견**: 실엔진 시뮬 결과 평균 완주가 DAY 3~4라 날짜 기준만으로는
    압박 이벤트가 **정상 플레이에서 한 번도 안 뜨는** 문제가 있었다. 그래서 시한을
    **남은 날 OR 남은 거리** 두 축 중 이른 쪽에서 열리게 고쳤다(260km/150km/60km).
    현재 실엔진 시뮬 **100% 런에서 압박 목격**.
- **구제 유상화**: `G.openRescue()` 사다리 도입. 연료·차체·탈진 각각 2·3회차 전용 이벤트를 새로 써서,
  반복할수록 시간·자원·**관측**이 실제로 청구된다(3회차 연료는 탐색등에 걸린다).
- **야영 밸런스**: 정착지 첫 밤 무상 → 이후 품앗이 삯 고철 2 → 삯 없으면 배급 축소.
  노숙에는 동료 경계 당번 보상(위험 -5%p/인, 최대 2인)을 붙여 "안전을 사거나, 준비로 벌거나"로 만들었다.
- **페이싱**: peak 국면이 무거운 사건을 **억제하던**(×0.42) 로직을 뒤집어 **가중**(×1.45)하도록.
  breather가 절정을 가로채지 못하게 하고, peak는 무거운 사건 2개까지 유지 후 fade로 내려간다.

## Phase 2 — 전투 (6 → 8 목표)

- **phase 2 자동 성공 제거**: `combatReadGuaranteed` 삭제. counter 선택은 의도 보정(+4%→**+7%**)과
  높은 기본치를 받되 확정이 아니다. 그동안 **도달 불가능했던 실패 분기가 전부 살아났다**(테스트로 확인).
- **정답 표시 제거**: 선택 전에는 `성공률 62% · 난이도 6/10` 대신 **등급 + "실패하면 무엇을 잃는가"**를 보여 준다
  (`G.combatFailurePreview` 신설 — 차체/연료/관측/부상/압박을 데이터에서 뽑아 표기).
  정확한 수치 분해는 결과 뒤 디브리프가 계속 담당한다.
- **구조·호송 실패 상태**: `pickOutcome`이 out 3개일 때 실패 대역을 분할(성공 / 부분 60% / 실패 40%).
  능선 구조·장터 호송 4개 선택 전부에 실패 분기를 새로 썼다 — 약 상자 유실, 부상, **기록에 남는 행렬**.
- **확정 성공 캡**: `kw_sniper`는 **조우당 첫 발만** 확정(연발은 위치가 드러난다 — 소음×관측과 정합).
- **적응 난이도 실질화**: `COMBAT_AUTO_ADJUST_SCALE` 0.08 → 0.16 (±4% → ±8%).
- **phase 1 열위 선택지 정리**: 유인/엄폐/위장 계열에 edge +2를 부여해 "읽는 순간 우열 종료"를 없앴다.

## Phase 3 — 성장 (7 → 8 목표)

- **탑재 슬롯**: `D.upSlots` 신설 — 지붕 3칸(텃밭·집수기·태양광·안테나·벌통·망원대가 경합),
  후미 마지막 칸 1개(**대형탱크 vs 후미 서비스칸**). 카탈로그가 빌드 선택이 됐다.
- **중량**: 업그레이드마다 `w` 부여, `G.upWeight()` → 연비(8pt 초과분 ×1.2%/pt, 최대 +12%)와
  험로 마모(10pt 초과분 ×2%/pt, 최대 +20%)에 항으로 추가. 상태창에 탑재 중량·자리 표시.
- **퍼크 리밸런스**: mj_fuel −8%→−5%, mj_camp +6→+8 (명백 우열쌍 완화).
- **효과 가시화**: 안테나·라이트바·망원대·왕경적·윈치가 실제로 개입한 순간 짧은 귀속 토스트.

## Phase 4 — 콘텐츠

- **갈등 아크 3이벤트 신규**(`conflict_fuel_detour` → `conflict_silent_cab` → `conflict_campfire`):
  연료 vs 왕진으로 강우와 박 선생이 진짜로 충돌하고, **어느 쪽을 들어도 실비용을 잃고**,
  각자의 방식(재계산표 / 처방전 쪽지)으로 수리한 뒤 불가에서 순서를 정하는 것으로 화해한다.
  보이스 바이블의 "갈등과 수리는 행동·비용을 바꿔야 한다" 원칙을 처음으로 집행.
- **최종막 저항**(`seoul_costs` 신설): 처분 **전에** 세 값을 극화한다 — 이음망의 첫 다툼,
  회색으로 바뀌는 기록 검색창과 「면사무소·내일·이송표 3건」 예약, 빈 근무표.
  그리고 **동료 하나가 처음으로 반대한다**(파티 구성에 따라 은수/강우/재이).
  반대를 누르고 결정하면 에필로그에 그 사람의 밤이 따로 남는다.
- **에필로그 분화**: 마지막 신호가 처분별로 갈라진다 — 수면은 **켜지지 않는 수신등**,
  보존은 감시조의 등불, 인계는 이음망의 잡음. 「후속 목록: 없음」 단일 합류를 해소.
- **악의 조우 2종 신규**: 관공서를 흉내 낸 가짜 통행세 조직(`levy_office`),
  이탈자를 **부드럽게 포위하는** 정리자 회수조(`cleaners_recall`). 국밥과 오지랖뿐이던 세계에 대비를 넣었다.
- **경구 다이어트**: 목발 단어를 동의어로 흩었다 — 한참 82→43, 처음으로 47→35, 백미러 73→64.
  **lint에 상한을 박아** 다시 늘면 게이트가 막는다. 경구 종결 비율도 측정·감시(현재 10%, 상한 16%).

## Phase 5 — 아키텍처 (6 → 8 목표)

- **경제 로직 엔진 이관**: UI가 직접 `S.scrap -= …` 하던 거래·묶음·정착지 수리를
  `G.trade` / `G.tradeBundle` / `G.settlementRepair` / `G.tradeDiscount`로 이관. UI는 호출과 표시만.
  **실엔진 시뮬레이터가 실제 거래 규칙을 쓰게 된 전제 작업**이기도 하다.
- **07-ui.js(3,713줄) 5분할**: `07a-ui-core`(614) / `07b-ui-panel`(705) / `07c-ui-story`(896) /
  `07d-ui-town`(1,008) / `07e-ui-audio`(500). 동작 변경 0(리팩터링이 아니라 이사), 빌드 순서만 추가.
- **세이브 스키마 버전**: `SAVE_VERSION` 도입 + `G.saveMigrations[v]` 단계 배열.
  기존 defaulting 블록은 v1 보강 담당으로 유지(멱등).
- **릴리스 위생**: 빌드 문자열을 `src/04-engine.js` 단일 소스로 — 게이트와 테스트가 읽어서 대조한다(3곳 수기 중복 제거).

## Phase 6 — 검증 (7.5 → 8 목표)

- **실엔진 시뮬레이터 신설**(`tools/simulate-engine.py`): 기존 시뮬은 이벤트 층을 하드코딩 확률로
  대체한 **병렬 모델**이라 "게임의 모델"을 측정했다. 새 시뮬은 로드된 페이지의 `G.newGame` →
  `startTravel` → `tick` → `pickOutcome`/`applyFx`를 직접 구동해 **게임 자체**를 측정한다.
  정책 3종(direct/prepared/explorer)으로 완주·사망·구제 횟수·시한 목격률을 리포트.
  기존 시뮬은 지도·연비 전용 체크로 강등하고 게이트에 둘 다 남겼다.
- **결정성 확보**: `G.seedOverride` 주입 API + `G.resetDriveTimers()`.
  **버그 발견·수정** — 주행 쿨다운(banterCd/radioCd/choiceEchoCd)이 모듈 변수라 새 게임에서
  리셋되지 않아 같은 시드가 다른 여정을 만들고 있었다. 이제 `test:determinism`이 지킨다.
  offroad 잡담의 raw `Math.random()`도 게임 rng로 교체.
- **CI**(`.github/workflows/gate.yml`): PR은 빠른 층(빌드·lint·세이브·보안·결정성·골든 루트·아티팩트),
  push는 전체 릴리스 게이트 + 시뮬 리포트 아티팩트 업로드.
- **UI 마감**: 데스크톱 ≥1200px 여백에 **여정 사이드 레일**(이송 시계·여정·노선·달구지) —
  새 시스템이 아니라 기존 정보의 재배치. sub-12px는 이미 12px 바닥이 적용돼 있음을 확인.

## 실측 — 게이트 전체 통과 (2026-08-06)

`npm run test:release` 전 단계 통과. 밸런스가 실제로 움직였다:

| 지표 | 개편 전 | 개편 후 (실엔진 60런) |
|---|---|---|
| 완주율 | 98.2% (모델 시뮬, 실게임은 구제로 사실상 100%) | direct 70% · prepared 80% · explorer 85% |
| 사망 | 사실상 없음(갈증 3일뿐) | direct 정책 **15%** |
| 시한 압박 목격 | 0% (코드에 0줄) | **100%** |
| 평균 구제 호출 | 무한 반복 가능·무료 | 런당 2.7~3.3회, **2회차부터 유상** |

`direct`(보급 최소·최단 돌파) 정책이 처음으로 실패하기 시작했다는 게 핵심이다 —
"모든 실패가 소액 과금"이던 루프가 끝났다. 기존 모델 시뮬(98.2%)도 지도·연비 회귀 감시용으로 함께 유지한다.
