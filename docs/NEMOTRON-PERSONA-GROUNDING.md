# Nemotron 한국어 페르소나 그라운딩

## 목적

동료 대사가 설정을 설명하는 데서 끝나지 않고, 같은 사람이 상황마다 같은 방식으로
돌보고 실수하고 화해하도록 만드는 편집 기준이다. 데이터셋의 문장을 게임 대사로
복사하거나, 생성된 인물의 이름·나이·가족·지역을 캐릭터에게 이식하지 않는다.

## 참고 자료와 사용 이력

- NVIDIA NGC: `nvidia/nemotron-personas/nemotron-personas-dataset-ko_kr:0.0.1`
  - <https://catalog.ngc.nvidia.com/orgs/nvidia/nemotron-personas/resources/nemotron-personas-dataset-ko_kr>
- NVIDIA 공개 배포본: `nvidia/Nemotron-Personas-Korea`
  - <https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea>
  - 라이선스: CC BY 4.0

2026-08-12 파일럿에서는 공개 배포본의 20개 레코드를 스키마·문체 연구용으로만
검토했다.

2026-08-14에는 NGC CLI 4.34.10으로 위의 정확한 `0.0.1` 리소스를 내려받아
전체 스키마와 직업군을 검사했다.

- 1,000,000행, 72개 row group, 51개 필드
- 전송량 2.66GB, `ko_KR.parquet` 한 파일
- 주요 검토 필드: 직업, Big Five 다섯 축, 문화 배경, 기술과 전문성, 취미,
  직업·가족·상세 페르소나
- 정비 12,961행, 보건 12,238행, 경비·보안 36,161행, 공연 516행,
  재활용 1,276행, 관제·통신 12,549행을 직업 행동 참고군으로 확인

원본 레코드와 Parquet 파일은 저장소·게임 빌드·배포물에 포함하지 않는다.
이름, 주소, 나이, 가족사, 지역, 취미 문장을 캐릭터에게 복사하지 않는다.

## 적용 방식

공개 샘플에서 유용했던 것은 성격 형용사보다 다음 구조였다.

1. 직업에서 생긴 반복 행동
2. 말보다 먼저 나오는 돌봄
3. 장점과 같은 뿌리에서 생기는 결함
4. 갈등 뒤 관계를 고치는 방식
5. 압박을 받을 때 무너지는 습관

이를 `D.companionVoices.{id}`의 두 층으로 정리했다.

`personaModel`은 데이터셋의 51필드 구조를 게임 정본에 맞게 축약한 편집 렌즈다.

- `traits`: Big Five 다섯 축. 데이터 표본 평균이 아니라 게임 정본을 구조화한 값
- `analog`: 참고한 직업 행동과 가져오지 말아야 할 범위
- `contradiction`: 장점과 같은 뿌리에서 생기는 결함
- `tell`: 감정을 말로 설명하기 전에 반복되는 관찰 가능한 행동

`grounding`은 장면을 실제 행동으로 쓰는 여섯 규칙이다.

- `value`: 이 인물이 실제로 지키는 가치
- `routine`: 대화 중에도 손이 먼저 하는 행동
- `care`: 호의를 표현하는 방식
- `conflict`: 장점이 과해져 관계를 상하게 하는 방식
- `repair`: 사과하고 관계를 복구하는 방식
- `stress`: 압박 아래 반복되는 취약 행동

## 캐릭터 정본 보호 원칙

- 민지는 17세다. 성인만 포함하는 참고 데이터의 나이·생활사를 대응시키지 않는다.
- 기존 생존사, 가족 관계, 지역, 직업, 말투를 데이터셋보다 우선한다.
- 지역 말투는 캐릭터 정본에 근거가 있을 때만 쓴다. 샘플 인물의 사투리를 옮기지 않는다.
- “정비사라서 기계 말만 한다” 같은 단일 특성화를 피한다. 직업은 돌봄과 결함이
  드러나는 통로이지 성격 전부가 아니다.
- 캐치프레이즈 반복보다 선택, 행동, 침묵의 차이로 인물을 구분한다.
- 데이터셋의 성격 점수 평균으로 캐릭터를 만들지 않는다. 직업군 평균은 대부분
  50 부근이므로, 평균값보다 구체적인 습관과 모순을 참고한다.
- 데이터셋은 대사 코퍼스가 아니다. 레코드 문장을 캐릭터 말투로 오인해 복사하지 않는다.

## 전체 대사 적용 범위

각 동료의 기존 행동 규칙 여섯 개에 `personaModel`과 관계별 호칭표를 추가했다.
전체 문장을 데이터셋 문장으로 치환하지 않고, 게임 안의 모든 대사를 한 인벤토리로
모은 다음 정본과 어긋나는 줄만 고친다.

2026-08-14 기준 `npm run lint:dialogue`의 검사 범위는 4,112줄이다.

- 티키타카 188줄
- 주행 대사 179줄
- NPC 153줄
- 라디오 18줄
- 인트로 150줄
- 사건 속 따옴표 발화 3,424줄

동료 화자가 확정된 495줄은 각 인물의 금지 표현과 직접 대조한다. 사건의 익명 행인처럼
화자를 확정할 수 없는 줄도 AI식 연결어, 긴 한 호흡, 폐기 설정, 중복 경구 검사를 받는다.
NPC는 인사 3줄, 생활 대사 5줄, 소문 1줄을 모두 검사한다.

이번 전수 검사에서 실제 수정한 문제는 다음과 같다.

- 28세 레오가 17세 민지를 `누나`라고 부르던 호칭 역전
- 22세 재이가 17세 민지를 `언니`라고 부르던 호칭 역전
- 17세 민지가 22세 재이를 장면마다 `재이야`와 `재이 언니`로 바꾸던 관계 단계 충돌
- 재이가 레오를 무작위 장면마다 `씨`와 `오빠`로 바꾸던 호칭 충돌
- NPC 전용 생활 대사 85줄이 전수 검사에서 빠져 있던 범위 누락
- 사건 화자 스크립트가 있어도 보이스 금지 표현 검사에는 연결되지 않던 범위 누락

데이터셋 전체를 게임 런타임에 넣거나 플레이 중 무작위 대사를 생성하지 않는다.
새 사건은 같은 전수 게이트를 통과해야 하며, 플레이테스트에서 목소리가 겹치는 인물 쌍만
골라 대사를 교정한다.
