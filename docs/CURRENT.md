5. 게임 규모를 문서에 직접 복사하지 않고 이 문서의 자동 집계 블록을 사용한다.

- 2026-09-21 전체 검토 후 개선을 원본4176에 적용했다. 대화는 고정된 현재 단위와 읽은 기록으로 나누고, 증거 비교·일곱 지역 공간·실제 물건과 기억이 있는 차 안·개인화 엔딩·관계망을 연결했다. 화자/가족 기록과 저장 복원을 수정했다. [구현·검증·백업](../audits/cohesion-2026-09-21/IMPLEMENTATION.md). 새 출발 일부와 기존 획득 저장의 장면·결말을 검증했으며, 모든 분기를 새로 완주한 검증은 아니다. 기존 [전체 검토](../audits/whole-game-2026-09-21/REVIEW.md)는 변경 전 기록으로 보존한다.
- 단일 HTML은 오프라인 실행과 AIT 입력을 위해 유지한다. 현재 파일은 32,000,000 bytes 권고선을 넘지만 80,000,000 bytes 상한 안에 있다. 두 기준은 `tools/build-html.mjs`에서 관리한다.
- 현재 자산 검사는 이전부터 있던 시각 경고 58건을 그대로 보고한다. 새 경고가 생겼는지는 보존한 경고 목록과 문자열 단위로 비교한다.
- 처음 하는 사람이 초반 목표와 행동을 얼마나 잘 찾는지, 동료에게 애착을 느끼는지, 결말의 읽기 양과 회수가 적절한지는 참가자 테스트가 필요하다. 현재 UI 턴 수와 자동 입력 기록은 사람의 읽기 시간이나 만족도 측정값이 아니다.
- 320~476px 화면 배치 검사는 통과했지만 실제 휴대폰의 첫 실행 시간, 메모리 사용량, 터치 반응은 측정하지 않았다.
- 과거 `audits/`에는 대용량 중간 산출물이 남아 있다. 기록은 보존하되 새 감사부터 보관 정책을 적용한다.
- 큰 UI 파일은 전면 재작성하지 않고 해당 기능을 수정할 때 화면 단위로 점진 분리한다.
