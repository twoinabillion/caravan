# 서울까지 400km 이미지 바이블

이 문서는 사건마다 구도, 인물 크기, 얼굴과 의상이 달라지는 문제를 막는 제작 계약이다.
새 이미지는 아래 규격을 통과해야 게임에 넣을 수 있다.

## 1. 사건 시네마틱

- 원본 제작 크기: 1536x864, 16:9.
- 게임 배포 크기: 768x432.
- 모바일 안전 영역: 화면 중앙 가로 70%, 세로 82%.
- 한 장면에는 주요 행동 하나와 시선의 중심 하나만 둔다.
- 인물 머리 높이는 전체 화면 높이의 18~28%를 기본으로 한다.
- 대화 UI가 하단을 덮으므로 얼굴과 손의 핵심 동작은 상단 65% 안에 둔다.
- 같은 사건 안에서는 카메라 높이, 렌즈 감각, 시간대와 광원을 유지한다.
- 전체 장면은 assets/scenes 아래에 두고 768x432가 아니면 검사에서 실패한다.

## 2. 동료 초상화

- 제작 원본은 정사각형 1:1, 최소 512x512를 사용한다.
- 게임에 넣는 최적화 배포본은 96x96으로 통일한다. 원본을 별도 보관하고 배포본을 다시 확대해 원본처럼 사용하지 않는다.
- 얼굴은 프레임 높이의 55~68%, 눈높이는 상단에서 38~44%에 둔다.
- 기본은 가슴 위 3/4 시점이다. 정면, 전신, 극단적 클로즈업을 섞지 않는다.
- 나이, 얼굴 골격, 피부색, 머리 모양, 대표 의상, 대표 소품은 src/03-data.js의 anchor와 avoid를 정본으로 삼는다.
- 표정과 먼지, 상처는 장면에 따라 달라질 수 있지만 얼굴 구조와 나이는 바꾸지 않는다.
- 동료별 기준표에는 정면, 3/4, 뒷모습, 키 비율, 대표 색상과 금지 변형을 함께 보관한다.

## 3. 첫 만남과 영입

- 첫 만남은 사건 시네마틱 16:9와 공식 초상화 1:1을 함께 사용한다.
- 별도의 새로운 얼굴 구도를 매 사건마다 만들지 않는다.
- 영입 카드가 필요할 때만 4:5를 사용하며, 같은 공식 초상화의 확장 구도로 만든다.
- 차량 안, 차량 밖, 정착지 중 현재 위치를 장면 문맥에 표시한다.

## 4. 콕핏과 외부 차량

- 콕핏 셸: 853x1844 PNG, 창문 영역 투명.
- 외부 달구지: 720x720 투명 WebP, 차량 전체가 프레임 안에 들어와야 한다.
- 도로, 지역 랜드마크, 시간대와 날씨는 차량·콕핏보다 뒤 레이어에서 실시간으로 바뀐다.
- 콕핏 장치 위치는 시동, 지도, 라디오, 계기판의 실제 터치 영역과 일치해야 한다.
- 외부 달구지는 차체 비율, 적재함 생활칸, 지붕 짐과 색상을 모든 장면에서 유지한다.

## 5. 파일 이름과 버전

- 사건: event-{event-id}-{beat}.jpg
- 동료 초상화: {companion-id}.png
- 동료 기준표: {companion-id}-turnaround-v{number}.png
- 차량 UI: cockpit-shell-v{number}.png, caravan-exterior-v{number}.webp
- 기존 파일을 교체할 때 의도적으로 교체하는 경우가 아니면 버전 번호를 올린다.

## 6. 생성 프롬프트 필수 항목

- 캐릭터 ID와 src/03-data.js의 anchor, avoid.
- 장면 위치와 인물의 현재 물리적 위치.
- 정확한 카메라 거리와 인물 머리 비율.
- 시간대, 날씨, 주광 방향과 색온도.
- 유지해야 할 의상, 머리, 나이, 소품.
- 금지할 얼굴 변화, 현대적 물건, 로고, 글자와 워터마크.

## 7. 자동 검사

- npm run audit:scene-assets
- 사건 이미지는 768x432인지 검사한다.
- 게임용 동료 초상화는 정사각형 96x96인지 검사한다.
- 콕핏과 외부 차량 UI 자산은 고정 규격과 알파 채널용 파일 형식을 사용한다.
