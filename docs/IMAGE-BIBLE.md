# 서울까지 400km 이미지 바이블

이 문서는 인트로, 사건, 정착지, 엔딩, 초상화의 **유일한 아트 제작 계약**이다.
기계가 읽는 동일 계약은 `assets/visual-contract.json`에 있다. 다른 문서와 규칙이
충돌하면 이 문서와 계약 JSON을 우선한다.

## 1. 하나의 작품으로 보이게 하는 기준

스타일 ID는 `caravan-grounded-cinematic-v1`이다.

- 매체: 사진에 가까운 시네마틱 페인터리 리얼리즘. 실제 사진처럼 번들거리거나
  붓자국이 과장된 삽화처럼 보이지 않는 중간 지점을 유지한다.
- 세계: 붕괴 이후 한국을 사람 크기에서 바라본 로드무비다. 도로, 항구, 시장,
  아파트, 버스, 작업장과 행정 시설은 한국의 실제 구조를 바탕으로 한다.
- 색: 외부는 저채도 청회색, 흐림, 비, 안개, 먼지와 젖은 아스팔트를 기본으로
  한다. 사람이 머무는 곳에만 제한적으로 앰버색 생활 조명을 둔다.
- 카메라: 35~50mm 영화 스틸에 가까운 자연스러운 원근과 눈높이를 기본으로
  한다. 극단적인 광각, 과한 아웃포커싱, 영웅 포스터 구도를 피한다.
- 표면: 낡은 천, 금속, 목재와 피부는 믿을 수 있게 표현하되 광고 사진 같은
  과도한 선명도와 피부 모공 중심의 극사실주의는 금지한다.
- 장면: 한 프레임에는 중심 행동과 시선의 목적을 하나씩만 둔다. 본문을 읽기
  전에 장소, 사람, 위험 또는 단서 중 무엇이 중요한지 바로 보여야 한다.

다음 스타일은 섞지 않는다: 애니메이션, 만화 잉크선, 셀 셰이딩, 아동용 삽화,
픽셀아트, 광택이 강한 광고 사진, 패션 화보, 3D 렌더, 게임 엔진 스크린샷,
네온 사이버펑크, 판타지 폐허. 픽셀아트는 `assets/road-cues/`의 도로 접근 연출에만
허용한다.

## 2. 용도별 고정 규격

| 용도 | 생성 원본 | 저장소 배포본 | 화면비·형식 |
|---|---:|---:|---|
| 일반 사건·풍경·인트로 | 1536×864 | **1024×576 권장** | 16:9, sRGB WebP |
| 핵심 시네마틱·엔딩 | 1536×864 이상 | 1280×720 | 16:9, sRGB WebP |
| 기존 사건 호환본 | - | 768×432 | 16:9, JPEG/WebP |
| 정착지 도착 장면 | 864×1440 이상 | 540×900 이상 | 세로 0.55~0.61 |
| 정착지 허브 배경 | 1200×1500 이상 | 960×1200 권장 | 세로 0.75~0.85 |
| 인물 공식 초상 | 768×768 | **256×256 권장** | 1:1, PNG/WebP |
| 달구지 업그레이드 | 용도별 원본 | 384×256 또는 1440×480 | UI 카드·좌석 파노라마 전용 |

- `960×640` 같은 3:2 장면은 기존 호환용으로만 남긴다. 새 장면은 만들지 않는다.
- assets/upgrades의 3:2·3:1 파일은 사건 장면이 아니라 달구지 UI 전용 예외다.
- 생성 원본을 게임에 그대로 넣지 않는다. 중앙 크롭, 색 관리, 축소와 WebP
  압축을 거쳐 배포본을 만든다.
- 화면에 보이는 CSS 크기보다 원본이 큰 것은 정상이다. 480px 모바일 화면의
  DPR 2 선명도를 위해 약 960px 너비가 필요하므로 1024×576을 기본값으로 삼는다.
- 단일 HTML 용량을 위해 일반 장면은 가능하면 850KB 이하로 유지한다.

## 3. 사건·인트로·풍경 구도

- 중요한 얼굴, 손, 차량, 단서는 중앙 가로 80%, 세로 82% 안전 영역에 둔다.
- 하단 대화나 선택 UI를 고려해 얼굴과 핵심 행동은 가능하면 상단 65% 안에 둔다.
- 인물 머리 높이는 화면 높이의 18~28%를 기본으로 한다.
- `place`: 장소가 주인공이다. 사람과 달구지는 규모를 보여 주는 작은 기준점이다.
- `character`: 얼굴과 손의 행동이 읽히는 중간 거리다. 인물은 한쪽 3분할선,
  반대쪽에는 대화의 물리적 단서를 둔다.
- `action`: 위험원과 대응 수단을 같은 프레임에 두고 동작 방향을 통일한다.
- `detail`: 물건 하나를 중심으로 손과 주변 환경을 함께 보여 제품 사진처럼
  보이지 않게 한다.
- 이미지 자체에는 글자, 로고, UI, 테두리, 자막, 워터마크를 넣지 않는다.

## 4. 인물 초상 계약

- 모든 초상은 장면과 동일한 시네마틱 페인터리 리얼리즘을 쓴다. 픽셀 초상과
  스튜디오 실사 사진을 섞지 않는다.
- 가슴 위 3/4 시점, 눈높이는 위에서 38~44%, 얼굴은 높이의 55~68%로 맞춘다.
- 배경은 단순한 청회색 생활 공간 또는 어두운 무채색 질감으로 통일하고, 오른쪽
  또는 뒤쪽의 약한 앰버 실용광을 기본으로 한다.
- 얼굴 골격, 나이, 피부색, 머리, 대표 의상과 소품은
  `docs/COMPANION-VISUAL-BIBLE.md`와 공식 초상을 정본으로 삼는다.
- 표정, 먼지, 비, 상처는 바꿀 수 있지만 정체성을 설명하는 요소는 바꾸지 않는다.
- 영입 카드가 필요한 경우에만 공식 초상을 확장한 4:5 구도를 별도로 만든다.

## 5. 인물·달구지 연속성

- 이름 있는 인물이 등장하면 `assets/reference/people-canon-2026-08-11.png`와
  해당 `assets/portraits/{id}.png`를 반드시 함께 참조한다.
- 아직 합류하거나 만나지 않은 인물은 장면에 넣지 않는다. 군중 속 닮은 얼굴도
  피한다.
- 달구지가 등장하면 `assets/reference/visual-canon-2026-08-11.png`와
  `assets/reference/dalguji-technical-canon-2026-08-11.webp`를 함께 참조한다.
- 달구지는 따뜻한 회백색 한국형 캡오버 한 톤 트럭, 분리된 직사각 생활칸,
  앰버 창, 지붕 짐, 빨간 연료통 두 개, 안테나와 빛바랜 흰 X를 유지한다.
- 밴, 미국식 RV, 픽업 캠퍼, 버스, 파란 포터 또는 일체형 스텝밴으로 바꾸지 않는다.

## 6. 생성할 때 반드시 사용하는 재료

모든 생성 작업은 다음 네 파일을 스타일 레퍼런스로 붙인다.

1. `assets/reference/visual-canon-2026-08-11.png`
2. `assets/reference/world-canon-2026-08-11.png`
3. `assets/reference/people-canon-2026-08-11.png`
4. 달구지가 나오면 `assets/reference/dalguji-technical-canon-2026-08-11.webp`

고정 공통 프롬프트와 네거티브 프롬프트는 `assets/visual-contract.json`의
`prompt.base`, `prompt.negative`를 그대로 사용한다. 여기에 장면 위치, 인물의 현재
물리적 위치, 카메라 거리, 행동, 시간, 날씨, 주광 방향만 덧붙인다. 공통 프롬프트를
작업마다 새로 의역하지 않는다.

## 7. 승인 절차

1. 사건의 `place`·`character`·`action`·`detail` 형식을 먼저 정한다.
2. 필수 레퍼런스와 등장인물 공식 초상을 첨부한다.
3. 큰 원본을 생성한 뒤 규격에 맞춰 배포본을 만든다.
4. 480px와 360px 폭에서 핵심 행동과 얼굴이 한눈에 읽히는지 본다.
5. 기존 대표 장면 옆에 붙여 만화풍, 실사풍, 채도, 렌즈와 얼굴 크기 이탈을
   비교한다.
6. `npm run audit:scene-assets`로 비율, 해상도와 참조 파일을 검사한다.

자동 검사는 화풍을 판별할 수 없다. 규격 검사를 통과했더라도 기존 장면과 나란히
보았을 때 다른 게임처럼 느껴지면 승인하지 않는다.
