# Caravan — 전 섹션 9.0 도달 계획 (2026-08-06)

기준: 2026-08-06 리뷰 스코어카드. 기존 `QUALITY-9-NO-AUDIO-PLAN.md`,
`QUALITY-95-EXECUTION-PLAN.md`와 중복되지 않게, 이번 리뷰에서 나온 **구체적
증거(오디트/시뮬레이션 로그)**를 섹션별 실행 항목으로 변환한다. 오디오는
기존 계획대로 이번 라운드에서 제외.

작업 순서는 "임팩트 큰 것 먼저, 의존관계 고려"로 정렬했다. 각 섹션은
현재점수 → 목표 9.0 → 완료 조건(측정 가능한 것) → 구체 작업으로 구성.

## 순서와 이유

1. **탐색·자원 관리 (6.5→9)** — 봇 플레이 11/12가 물/식량 0 도달. 다른 모든
   섹션의 재미보다 우선 (게임을 끝까지 못 깨면 나머지가 의미 없음).
2. **접근성 (5.5→9)** — 수정 흔적 없는 P0급 이슈들. 손 대면 회귀 위험이 낮고
   임팩트가 큰 "닫힌 버그"들.
3. **UI·정보 구조 (6.5→9)** — 고아 상태 퀘스트 경고 P0, 버튼 위치 불안정.
4. **동료·관계 (7→9)** — 6개 아크 동일 구조, 유대 20 도달 불가 문제.
5. **전투 (7→9)** — 손맛/피드백 약점.
6. **차량 개조·빌드 (7.5→9)** — 설치가 버튼 1개짜리 상호작용.
7. **핵심 여행 루프 (7.5→9)** — 위 자원 수정 이후 재검증하면 자연 상승분 있음.
8. **반복 플레이 (6→9)** — 동료 아크 분화 이후 자연 상승 + 추가 분기.
9. **서울·엔드게임 (7→9)** — 파이널 35턴에 씬 2개뿐.
10. **온보딩·초반 몰입 (6.5→9)** — 스킵 옵션, 모바일 오탭 위험.
11. **비주얼 일관성 (8→9)** — 866개 이벤트 중 103개만 전용 아트.
12. **지도·경로 선택 (8→9)** — 소사용 분기 정리/보강.
13. **메인 스토리·세계관 (8.5→9)** — 대사 오디트 잔여 이슈(placeholder, 화자 오류) 재검증.
14. **정착지 (8.5→9)** — 이미 근접, 재방문 변화 마감.
15. **기술 안정성 (8→9)** — 저장 슬롯 다중화, 최신 커밋 스모크 검증.

각 섹션 작업이 끝나면 반드시: (a) 코드 diff, (b) 관련 시뮬레이션/오디트
재실행, (c) 스코어 재평가 순서로 검증한다. "고쳤다고 주장"만으로 완료 처리
하지 않는다 — 이번 리뷰에서 발견한 가장 큰 문제가 정확히 그 패턴이었다.

## 1. 탐색·자원 관리 (6.5 → 9.0)

**증거**: `reports/journey-simulation.json` explorer 정책 완주율 92.8% (최저),
`audits/deep-ux-audit-2026-07-31` 봇 플레이 11/12 물/식량 0 경험, 5/12만 풀
크루 완주.

**작업**
- [ ] 자원 소비/공급 밸런스 재계산: 탐색 행동의 시간/자원 비용 대비 보상
  곡선을 로그로 뽑아 "탐색이 손해"인 구간을 특정 (fuel/water/food 소비율
  vs 정착지·현장 보급 확률).
- [ ] explorer 정책 시뮬레이터 파라미터를 봇 실측 정책과 맞춰 재실행 —
  현재 1,000-run 시뮬레이터가 낙관적인 이유를 찾아 정책 모델 자체를 고친다.
- [ ] 저자원 상태에 "즉시 게임오버"가 아닌 완충 장치 검토 (경고 단계,
  응급 보급 이벤트 확률 상향, 동료 스킬로 완화).
- [ ] 고유 발견/희귀 보상 추가 검토는 자원 밸런스 고정 후에만 (순서 중요).

**완료 조건**: 재실행한 봇 플레이 12/12 물/식량 0 도달 없이 최소 10/12
완주, 시뮬레이터 explorer 완주율 98%+.

## 2. 접근성 (5.5 → 9.0)

**증거**: `audits/deep-ux-audit-2026-07-31` — focus trap 없음, tab order
누수, `role="tab"`에 `aria-selected` 없음, dialog에 `role="dialog"`/
`aria-modal` 없음, viewport `user-scalable=no`, HUD 텍스트 12px 미만.

**작업**
- [ ] `user-scalable=no` 제거 (viewport meta) — 핀치줌 차단 해제, 200%
  확대 시 레이아웃 파손 여부 재검증.
- [ ] 모든 모달/오버레이에 `role="dialog"` + `aria-modal="true"` + focus
  trap(열릴 때 첫 포커스 이동, Tab 순환, Esc 닫기) 구현.
- [ ] 탭 컴포넌트에 `aria-selected`, `aria-controls`, roving tabindex 추가.
- [ ] HUD 텍스트 12px 미만 전체 그렙 후 최소 12px(모바일 기준)로 상향.
- [ ] 키보드만으로 인트로→첫 정착지→전투 1회→저장까지 완주 가능한지
  수동 경로 테스트, 안 되는 지점 목록화.

**완료 조건**: 위 항목 전부 코드 반영 + 키보드 완주 1회 통과 + 200% 확대
스크린샷 확인.

## 3. UI·정보 구조 (6.5 → 9.0)

**증거**: 동료 퀘스트 활성 시 보드 배달 퀘스트가 UI에서 사라지지만
"마감 임박" 경고는 남아 고아 상태. 진행 버튼 위치가 텍스트 길이에 따라
이동.

**작업**
- [ ] 퀘스트 패널: 동시 활성 퀘스트가 여러 개일 때 전부 리스트에 남도록
  수정, 경고 배지는 해당 퀘스트 항목에만 종속.
- [ ] 진행/확인 버튼을 고정 위치(sticky footer 등)로 전환, 텍스트 길이
  변화에 영향받지 않게.
- [ ] 나머지 미해결 UI 오디트 항목 재검토 후 목록화.

**완료 조건**: 두 P0 버그 재현 시나리오로 회귀 테스트, 통과.

## 4. 동료·관계 (7 → 9.0)

**증거**: 6개 아크 동일 5비트 구조, 성공 런에서 유대 20 도달 0/30.

**작업**
- [ ] 6개 중 최소 2~3개 아크에 실패/거절 분기 추가 (완전 신규 동료 추가는
  동결 원칙 위반이므로, 기존 아크 내부 분기만).
- [ ] 유대치 획득 곡선 검토 — 20 도달이 현실적으로 가능한 액션 빈도인지
  계산, 필요시 임계값 또는 획득량 조정.
- [ ] 화자 오류(`???` 136턴), placeholder 텍스트(`형(누나)` 13줄) 잔여
  건 재검색 후 전량 수정.

**완료 조건**: 유대 20 도달 시뮬레이션상 정상 진행 시 50%+ 도달, 대사
린트 placeholder 0건.

## 5. 전투 (7 → 9.0)

**증거**: 자체 평가 "손맛" 7.9 최저.

**작업**

- [ ] 실패 원인 결산 화면: 전투 패배 시 "왜 졌는지" 1~2줄 귀책 요약

**완료 조건**: 전투 후 결과 이해율 오디트 재실행, 90%+.

## 6. 차량 개조·빌드 (7.5 → 9.0)

**증거**: 설치가 대기→확인 버튼 1개.

**작업**
- [ ] 설치 3단계(분해→고정→시동확인) 각 단계에 최소한의 입력/타이밍
  상호작용 부여 (신규 계통 추가 아님, 기존 3단계의 표현만 강화).
- [ ] 계통별 고유 실패/보정 이벤트 1개씩 최소 추가 검토.

**완료 조건**: 정착지 워크스루 오디트 재실행, "버튼 하나" 지적 해소.
