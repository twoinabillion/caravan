# 2026-11-09 · 미룬 여행 기억과 여러 편 열람

여행 중 회상은 기존 비차단 알림에서 사용자가 열며, 여러 편이면 같은 진입 버튼으로 목록을 연다. 기본 프롤로그와 현재 사건의 발견→감속→정차→장면 흐름은 유지한다. 별도 책갈피 위치와 읽은 기억 보관함은 디자인 초안 단계이며 이번 변경에 포함하지 않는다.

## 수정

- 미룬 기억이 있는 동안 새 기억이 와도 알림을 다시 펼치지 않는다. 장면·모달 뒤 돌아왔을 때도 조용한 진입 상태를 유지한다.
- 유효성 검사 전 16개를 잘라내던 제한을 제거했다. 중복·잘못된 ID를 걸러도 유효한 미열람 기억의 발견 순서를 보존한다.
- 여러 편은 목록에서 원하는 한 편을 고른다. 읽고 나면 길로 돌아오며 다음 기억을 자동으로 열지 않는다.
- 목록은 실제 modalOpen/일시정지에 참여한다. Escape·닫기·화면 전환은 미열람 항목을 소비하지 않으며, 정상 닫기는 진입 버튼으로 초점을 돌린다.
- 반복 렌더는 바뀌지 않은 aria-live 본문을 다시 쓰지 않는다. 목록 안쪽만 스크롤하고 카드 높이는 줄이지 않는다.

## 검증과 범위

- 수정 전 실패로 문제를 재현했다. 최종 집중 회귀 16/16 통과: 24개 가상 항목, 미루기 뒤 추가, 잘못된 ID/중복, 뒤쪽 항목 선택, 저장 후 유지, 한 번에 한 편, 실제 modalOpen을 통한 주행 정지, 화면 이탈, 반복 안내 억제, CSS 스크롤 소유권.
