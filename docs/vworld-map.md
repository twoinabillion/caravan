# V-World 실측 지도 연결

게임 지도는 세 가지 배경으로 동작한다.

1. **여정도**는 외부 연결 없이 항상 작동하는 기본 Canvas 지도다.
2. **대한민국 OSM**은 2026년 OpenStreetMap 원본을 빌드 시 경량화한
   오프라인 기록 지도다. API 키와 네트워크가 필요 없다.
3. **V-WORLD 실측**은 인증키가 있을 때만 2D 지도 API 2.0을 동적으로
   불러오는 선택형 지도다.

세 지도는 `D.geo`의 WGS84 좌표를 함께 사용한다. 58개 노드 전부에
`[경도, 위도]`가 있으며, 정착지·도시는 실제 중심 좌표를 사용한다.
발견형 장소는 해당 사건과 연결된 도시 주변의 서사 좌표다. 자체 여정도의
600×760 좌표도 이 값을 Web Mercator 방식으로 다시 투영하므로 두 지도에서
도시와 경로의 위치관계가 달라지지 않는다.

## 인증키 사용

- 지도에서 `V-WORLD 실측`을 누른 뒤 인증키와 등록 도메인을 입력한다.
- 키와 도메인은 현재 브라우저의 `localStorage`에만 저장된다.
- 저장소, 빌드 산출물, 세이브 파일에는 키를 쓰지 않는다.
- 등록 도메인은 `https://`와 경로를 제외한 호스트만 입력한다.
  예: `twoinabillion.github.io`
- `file://` 로컬 파일에는 인증 도메인이 없으므로, 배포 주소용 키 또는
  별도로 등록한 `localhost` 키가 필요하다.

API 로드·인증·네트워크 중 하나라도 실패하면 연결창에 오류를 표시하고
여정도로 돌아간다. 키가 없는 브라우저에서는 외부 스크립트 요청 자체를
보내지 않는다.

V-World 2D SDK 호출 형식:

```text
https://map.vworld.kr/js/vworldMapInit.js.do
  ?version=2.0
  &apiKey={브라우저에 입력한 키}
  &domain={등록 도메인}
```

실측 지도는 `GRAPHIC_NIGHT` 배경 위에 게임의 알려진 도로, 정착지,
미확인 장소, 의뢰 목적지와 달구지 위치를 OpenLayers 벡터 레이어로
다시 그린다. 지도의 지명을 눌렀을 때는 자체 여정도와 같은 노드 상세와
이동 버튼을 사용한다.

## 보안 원칙

V-World 키를 공개 단일 HTML이나 GitHub Actions 산출물에 자동 삽입하지
않는다. 클라이언트 키를 모든 플레이어에게 자동 제공하려면 도메인 제한과
공개 노출을 전제로 별도 결정이 필요하다.
