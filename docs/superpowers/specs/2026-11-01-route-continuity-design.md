# 도시와 길이 한 세계로 이어지는 배경

사용자 요청: 78개 길의 배경을 매끄럽게 만드는 전체 계획을 세우고 이행한다. 게임 디렉터 관점에서 그림·지도·연출·기술·검증을 함께 책임진다.

## 원하는 경험

항구를 출발하면 창고가 뒤로 물러나고 외곽과 농지, 산길을 지나 다음 도시가 나타난다. 도착·정차·다음 출발은 같은 장소다. 갈림길에서 다른 길을 택하거나 돌아가도 도시가 달라지지 않는다. 카메라는 실제 저장된 이동 거리를 따라가며 시간·날씨·차량은 기존 동적 렌더러가 맡는다.

## 선택과 근거

전국 한 장은 갈림길을 표현할 수 없고 거대한 텍스처가 된다. 길마다 독립 그림을 바꿔 보여주는 방식은 도시가 달라진다. 따라서 **58개 고정 도시 뷰 + 78개 연결 파노라마를 가진 그래프**로 만든다. 노선의 방향과 게임 거리는 기존 D.edges를 따른다. 역방향은 같은 픽셀 위를 반대로 이동하며 그림을 반전하지 않는다.

2026-11-01 실측: 공유 파노라마 부산–양산·양산–밀양 2개는 양호. 다른 76개는 서로 다른 원본의 건물/수면/능선을 24px 재질 보간과 능선 변형으로 붙이면서 절단/세로 띠가 생긴다. 픽셀 끝점 일치만으로 자연스러움을 판정하지 않는다.

## 제작 규칙

- 58개 도시의 현재 고정 뷰를 기준 이미지로 보존한다. 도시의 정체성과 도착/출발의 같은 시점을 유지한다.
- 2개 양호 노선은 보존한다. 나머지 길은 도시 양끝과 중간 지형을 함께 보며 완성된 긴 판으로 만든다.
- 먼저 부산–김해(항구/수면), 경주–포항(왕릉/산/산업), 대관령–강릉(산림/해안)을 비교 시안으로 검증한다.
- 기존 큰 파노라마를 재료로 재사용하되, 서로 다른 건물이나 수면을 단순 혼합/흐림/안개로 가리는 결과는 탈락이다. 필요한 접속 지형은 image_gen으로 제작한다. 고정 참조/프롬프트/큰 원본/배포본/실패작의 출처를 보존한다.
- 한 노선의 도시 양끝은 보호된 기준 뷰이며, 가운데는 실제로 이어지는 외곽/지형이다. 생성 결과가 보호 구간을 바꾸면 그대로 채택하지 않는다. 길이/타일 수는 대표 시안의 시각 검증 후 확정한다.
- 기존 caravan-grounded-cinematic-v1, 투명 하늘, 같은 축척/접지선/조명, 최소 1024px/뷰포트. 실측 도로 복원이 아닌 지역 지형 해석이다.
- 런타임은 완성된 판을 한 번 디코드하여 실제 gone/dist로 이동한다. 주행 중 그림 교체, 주행 중 픽셀 합성을 제거한다. 출발 전 새로 그린 조용한 외곽에만 능선 높이를 보간하고 실제 원본 재질을 합성한다. 도시 중앙·큰 구조물은 변형하지 않는다. 유한 캐시·미리 디코드·실패 fallback·오프라인 임베딩을 유지한다.

## 경계

세이브, 이동 비용, 도로망/거리, 사건 발견/감속/정차, 차량/동료/강수/낮밤, 도시 허브/서사 장면은 바꾸지 않는다. UI 개편이 아니다. 원본과 구버전 데이터는 삭제하지 않는다. 단일 HTML 200MB hard /160MB warning. 그림 품질을 낮춰 옛 한도를 맞추지 않는다.

## 완료 기준

78개 노선/156개 방향/58개 도시가 누락 없이 연결된다. 모든 도시 진입–정차–출발 경계에서 같은 뷰를 유지한다. 전체 노선의 중간·합성 경계를 실제 렌더 캡처로 검토하며 건물 절단·물가 단절·세로 띠·반복 픽셀 열·하늘 사각형을 허용하지 않는다. 320/360/480px, 낮/황혼/밤, 날씨, 역방향, 로드/실패, 사건 감속–재개, 오프라인에서 검증한다. 게임 화면에서 본 것과 독립 렌더러 증거를 구분한다.

## 이행 권한과 검토

Sang이 이 계획 작성과 이어지는 이행을 명시적으로 요청했다. 세부 구현은 디렉터가 정하고 시안을 먼저 공개한다. 원격 push/배포는 이번 요청에 포함하지 않는다. 현재 Studio4327은 연결되지 않고 기존 게임4319는 살아 있다. 독립 초안과 실제 사용자 미리보기/세이브를 구별하고, 현재 화면을 초기화하지 않는다.

## 사용자 후속 확정

Sang은 내장 이미지 도구 계속 사용과 도시 외곽 변경을 허용했고, 별도 API를 사용하지 말라고 명시했다. 도시 주요 정체성은 지키되 새 외곽을 가진 정본을 도시마다1개씩 승인해 공유한다. 이전 정본 전체 픽셀을 영구히 고정하는 조건은 디렉터가 과하게 설정한 것이므로 폐기한다. 도시2048px 타일 중앙1024px를 공통 정차뷰로 삼고 양쪽512px 외곽을 연결부로 설계한다. 원래2양호 노선의 그림도 보존하며, 새 정본 적용 때문에 필요하면 동일한 그래프 방식으로 연결한다.


## 최종 구현 규칙과 검증

58개 도시2048×576 중앙1024px를 공유하고12종 지역 지형으로78길을 구성했다.512px 조용한 외곽의 단단한 지형 윤곽을 출발 전 한 번 합성하고, 주행 중에는 고정판을 이동한다. 기존2개 양호 노선/전체 옛 atlas는 fallback으로 보존했다. 옛 도시 원본 픽셀의 완전 고정과 모든길 독립 그림이라는 초기 가정은 사용자 외곽 변경 허용 및 실제 시안 검수로 대체됐다. 내장 도구만 사용했으며 별도 API는 사용하지 않았다.

노선마다 양쪽 도시/중간 그림/합성 코드 해시가 검수 기록에 묶인다. 도시 중앙은 어떤 길에서 진입해도 같은 원본이며 정확한 출발·도착에는 동일한 도시 캔버스를 그린다. 로드·출발·백업 복원은 준비 후 상태를 교체하고, 취소된 요청은 진행을 바꾸지 않는다.

최종 증거와 범위는 구현 계획의 Final delivery 및 qa-artifacts/route-continuity-v3/를 따른다.12중간 지형의 재사용, 고정된 구미 연기, 서울의 오른쪽에 붙은 주 탑 구도는 남는 미술적 특성이다. 실제 사용자 창·모바일 실기·음향·주관적 재미를 전수 검증했다는 뜻은 아니다.
