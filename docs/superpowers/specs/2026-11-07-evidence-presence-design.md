# 이야기가 가리키는 사물

Sang은 “종이가 있었다 혹은 무엇이 보였다 하면 그 이미지가 보여야” 한다며 현재 게임을 평가하고 개선을 계속하라고 요청했다. 단서가 선택형 inspector 안에만 있던 이전 구현에서, 본문에서 물건을 발견할 때 화면에 바로 보이는 연출로 확장한다. 고화질 풍경·얼굴·차량과 기존 원문/선택/효과는 보존한다.

## 경험
현재 게임의 강점은 고화질 여행 분위기와 인물 표정이다. 남은 약점은 물건에 쓰인 핵심 정보를 설명으로 듣는 비중이다. 발견하는 대목에서는 해당 종이/표/기계 화면을 가까이 보이고, 대화나 회상으로 넘어가면 원래 장면을 되돌린다. 사용자는 계속 읽기를 직접 누르고, 물건을 누르면 기존 검사 모드에서 크게 읽는다.

## 범위와 표현
- 42개 정적 문자열 후보를 먼저 추렸다. 이는 동적 본문을 모두 포괄한 전수 판정이 아니며 회상/비유/라디오를 실제 사물로 만들지 않는다.
- 핵심12장면: 기존 버스 기록·세 증언·명령 원본에 자동 제시를 연결하고, 검문소 안내판·부모님 화물표·세 세대 이송표·첫 검문 종이띠/그 사본·초반 이송표와 민원 단말·자판기·주유기·온천 안내판으로 확장한다.
- 기존 HD 그림을 현장 배경으로 유지하고 그 앞에 선명한 종이/표/금속 안내판/단말기 화면을 합성한다. 정확한 글자는 실제 텍스트다. 새 raster/외부 의존성을 도입하지 않는다.
- 짧은 화면은 글자를 억지로 줄이지 않고 핵심 한 줄과 물건 형태를 보여 주며, 누르면 전체 원본을 읽는다. 원래 그림 확대도 계속 가능하다.

## 상태와 시간
새 순수 표시 모듈 EvidenceScenes가 명시적인 eventId/본문 anchor/증거 proof를 소비한다. 현재 페이지의 실제 end/cursor와 원문 turn 경계를 사용하며, turn 개수 비례나 시간 타이머/런타임 단어 추측으로 그림을 바꾸지 않는다. 회상/후일담/검사/기록모드에서는 현재의 사물 합성을 숨긴다. 이미 지불된 결과에는 entry 사물을 자동 덧씌우지 않는다.

표시 내용의 proof는 현재 저장된 turn 원문에 있어야 한다. 회복용 사본은 원본 획득으로 오해시키지 않고 출처를 표시한다. 최종 서명·완료 도장·정정된 결과를 선택 전 미리 그리지 않는다. 알 수 없는 번호/이름/날짜는 만들지 않는다. 검사 열기/닫기/이전/확대/reload는 읽기 위치와 자원·시간·RNG를 보존한다.

## 구현 경계
src/07i-evidence-scenes.js가 사물 데이터·현재 대목 판정·순수 preview markup을 소유한다. src/07-ui.js는 기존 검사/페이지/장면 컨트롤러 안에서 렌더링만 연결한다. CSS는 기존 reader scene/evidence 소유 블록에 둔다. 빌더에 모듈을 UI보다 먼저 포함한다. 엔진/원문/선택/효과/저장키·StoryPages 자체를 변경하지 않는다.
