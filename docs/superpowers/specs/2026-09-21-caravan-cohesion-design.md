## 의도와 시각 기준

Caravan은 낡은 달구지를 집으로 고치며 한국의 길을 북상하는 게임이다. 조수석에서 쓰는 생활 도구, 지역의 생활 공간, 실제로 함께 겪은 일이 화면의 중심이다. 기존 선택1의 청록 철판/크림 글자/마모된 황동을 따른다: 바탕 #142826, 그늘 #0b1718, 본문 #eee9d9, 보조 #b0b5aa, 강조 #c29958. 제목은 이미 내장된 Black Han Sans, 본문은 기존 한국어 sans를 사용한다. 읽기 폭은 좁게 유지하고 데스크톱의 추가 폭은 장면과 조작의 분리에 쓴다.

전면에 같은 카드·영문 소제목·진행 숫자를 붙이지 않는다. 기록은 종이/인용, 사람은 실제 화자, 기계는 기계 표시로 구분한다. 결과와 의미를 여러 번 반복하지 않는다. 정착지와 차 안은 텍스트를 읽기 전에도 차이를 보인다.

## 구현 범위

1. 개인 후반6장면의 발화/기록 주체, 유나 호칭, 캠프 원시로그를 수정한다. 추정만으로 틀린 인물을 확정하지 않는다. 어머니 재회·아버지 기록은 중요한 순간을 명시 턴으로 연출한다. 주요 증거 일부는 플레이어가 대조할 물건/증언을 먼저 살피게 하고 결과를 자동 해설만으로 넘기지 않는다.
2. 일반 사건은 현재 문장 또는 짧은 의미 단위와 선택을 고정된 장면 안에 표시한다. 이미 읽은 전체 대화·선택·결과는 기록에서 보고 닫으면 같은 곳으로 돌아온다. 저장된 presentation receipt가 여전히 유일한 상태 소유자다. 전투는 별도 전술 레이아웃을 유지한다. 큰 글씨·320px에서 내부 스크롤과 선택 버튼을 사용할 수 있다.
3. 엔딩 일지 관계망을 실제 렌더하고 원시 wikilink 문법을 표시하지 않는다. 중요한 사건의 결과에 무관한 레벨·미션 안내를 끼워 넣지 않는다. 구조/호송 명칭, 제작 안내, 지역/캠프의 의미 없는 진행 계수를 정리한다. 동료 상세와 정비·야영·서울·엔딩의 색/글꼴/조작 규칙을 정돈한다.

7. 레오 방송국의 잘못 연결된 장면을 적합한 기존 자산 또는 canonical reference로 만든 실내 방송 장면으로 고친다. 이미 정한 지역·지도·목적지 비율은 유지한다.
