# 손에 잡히는 기록과 버튼 정렬

Sang은 기록의 시간·빈칸을 직접 읽는 표현을 요청했고 버튼 글자가 왼쪽으로 치우친 느낌을 지적했다. 앞서 제안한 고화질 현장 + 정확한 기록 글자를 구현한다. 현재 Studio4327은 연결 거부, CUA 브라우저 호스트 불가, live4319 clients0이다. 실제 사용자 화면을 봤다고 하지 않는다. 버튼 종류는 선택 질문을 남기고, 인접 맥락인 대화 선택지를 먼저 검사한다.

## 범위
- 기존 inspection owner를 확장해 출력지/이송표/명령 원본을 구조화해 그린다. `story_bridge_trace_gap`의 세 시각과 빈 확인자, 기존 `main_transfer_testimony` 세 사람의 정정 요청, `main_command_ledger` 세 원본에 적용한다.
- 고화질 장면에 자료 열기 버튼을 두며, 기존 수동 reader·검사 모드에서 열고 닫는다. 기본 대화·선택은 그대로 도달 가능하다. 작은 화면/큰 글씨 자료는 명시적으로 스크롤한다.
- 아트에 가짜 글자를 생성하지 않고 실제 선명한 텍스트를 표시한다. 존재하지 않는 발신 번호·성명·일자·서명·선택 후 정정/완료 도장은 만들지 않는다. 단서는 그 장면의 기존 원문에서 확인된 사실만 쓴다.
- 대화 선택지 주문구는 버튼 중앙에 둔다. 실행 버튼의 중앙 정렬도 검사하고 내용 카드/예산표는 읽기 위한 왼쪽 정렬을 유지한다.

## 보존
엔진·효과·원문·선택 순서·저장 키·자원/시계/RNG·유료 영수증을 바꾸지 않는다. 새 입력/의존성/이미지 생성 없음. 자료 열기/탭/닫기는 읽기 상태만 바꾸며 선택 결제를 실행하지 않는다. 읽기 커서와 지불 결과는 기존 presentation owner로 보존한다. CSS는 기존 inspection와 pages/materials/cinematic 소유 블록만 수정한다. 관련 legacy important/클릭 차단도 확인한다.
