## Phase 0 — 즉효·보안 (반나절, 다른 작업 전 선행)

- 완료 조건: 오프로드 스모크에 `<script>`/`onerror` 페이로드 주입 픽스처 추가, 렌더 후 DOM에 미실행 확인.

## Phase 1 — 코어 루프: 6.5 → 8 (핵심 사이클)

### 1-1. DAY 30을 진짜로 집행한다 ★ 이 계획서에서 단 하나만 한다면 이것
- 현상: 인트로·노트·출발 과업에서 반복 선언되는 시한인데, `S.day`를 30과 비교하는 코드가 **0줄**.
  31일차에 아무 일도 없다. 카운트다운이 전제인 게임에서 중심 압박이 허구.
- 작업 (`dawn()`에 배선):
  - **D-10 (20일차~)**: 관측 기본치 상승, 이송 준비 목격 이벤트 풀 활성화(호송 차열, 정리자 이동,
    라디오의 이송 공지). 플레이어가 "시간이 줄고 있다"를 길 위에서 본다.
  - **D-5**: 저항 연대망 거점들이 시한 언급, 회랑 검문 강화(추적 가중).
  - **D-3~D-0**: HUD 날짜에 시한 표시 강조, 동료 1:1 대화에 시한 반영 라인.
  - **D+1 (31일차~)**: 이송 개시. 두 갈래 중 택1로 설계 —
    (a) **실패 엔딩**: 남산 도착 전 이송 개시 → "늦은 상행" 엔딩(이미 있는 늦은 결말을 확장,
    6,412명 중 첫 이송분은 떠난 뒤·되돌릴 수 없는 것 하나를 명시) 후 회차 유도.
    (b) **대가 분기**: 완주는 가능하되 코어 대면의 전제가 바뀜(첫 이송분 구제 불가가 처분 선택지에 각인).
    권장은 (b) — 리뷰가 지적한 "실패=소액 과금" 문제를 반복하지 않으면서 시한을 서사 대가로 전환.
- 완료 조건: 지연 정책 시뮬 런(정착지 만끽형)이 30일 초과 시 실제로 다른 결말/각인에 도달.
  골든 루트 테스트에 D-10 압박 이벤트 존재 어서션 추가.

### 1-2. 구제 이벤트 유상화 — "실패는 소액 과금"의 종료
- 현상: 연료 0 → `crisis_nofuel`이 **매번, 무한히** +8~10L(`03-data.js:2699`, p:1만 3개).
  차체 0 → 맨손 수리 상시 존재. 피로 99 → 4시간 기절. 유일한 사망은 갈증 3일(`04-engine.js:1298`).
- 작업 (횟수 카운터 `S.stats.rescues` 신설):
  - 1회차: 현행 유지 (첫 실수는 배움).
  - 2회차: 실비용 인상 — 시간 +하루, 관측 +1, 고철 추가 차감. 텍스트도 2회차용("또 걸었다. 이번엔 아무도 신기해하지 않았다").
  - 3회차~: 회랑·서사 대가 — 추적 +1 또는 가장 가까운 정착지로 견인(경로 되돌림). DAY 30과 결합되면 시간 자체가 벌금이 된다.
  - 맨손 수리·기절도 동일 원칙(반복 시 비용 상승).
- 완료 조건: 실엔진 시뮬(3-1)에서 무보급 직행 정책의 완주율이 유의미하게 하락(100% → 80%대),
  준비형과 직행형의 소요일이 갈라짐.

### 1-3. 야영 밸런스 — 정착지 절대 우위 해소
- 현상: 정착지 야영 = 물 +min(6,인원)·식량 +1·습격 0 vs 노숙 = 33~45% 습격(`04-engine.js:2451-2487`).
  시뮬 데이터가 증명: 준비형이 직행형과 소요일 동일(4.42일)인데 위기율 0.3% vs 42.8% — 준비가 공짜다.
- 작업: 정착지 숙박에 소비용(품앗이 1회 또는 고철 소액, 첫 방문 면제) + 시간 대가(입촌 절차).
  노숙엔 준비 보상 — 경계 당번 배정(피로 분담), 위장막 업그레이드 시 습격률 반감. "안전을 사거나, 준비로 벌거나".
- 완료 조건: 시뮬에서 정책 간 소요일 스프레드 ≥ 1일.

### 1-4. 페이싱 감독을 쿨다운에서 에스컬레이션으로
- 현상: peak 국면이 무거운 이벤트를 0.42배로 **억제**(`04-engine.js:1777-1787`) — 절정이 절정을 피한다.
  peak는 이벤트 1개 만에 fade 전환(`:1835-1852`).
- 작업: peak 전용 이벤트 태그 신설(추적·검문·위기 강화판 8~10개는 기존 이벤트 변형으로 조달),
  peak에서는 그 풀을 가중하고 일상·잡담을 억제. rest 국면의 현행 동작은 유지(잘 작동함).
- 완료 조건: 텔레메트리(q.timeline)에서 peak 국면의 무거운 이벤트 비율이 rest 대비 2배 이상.

## Phase 2 — 전투·현장 임무: 6 → 8

### 2-1. Phase 2 자동 성공 제거 — 죽은 실패 분기의 부활
- 현상: counter 선택 시 무조건 `out[0]`(`04-engine.js:1192`, `combatReadGuaranteed`).
  정성껏 써 둔 실패 분기(combatRoll 0.64의 뒷면)가 전부 도달 불가능. walker 2단계는 4지선다 중 3개가 counter.
- 작업: 자동 성공을 제거하고 combatRoll 복원. 단, 실패해도 read는 남기되 **부정확한 read**
  (틀린 tactics 리스트 → 3단계에서 +10% 대신 -5%)를 준다. "정보를 얻느냐"가 아니라 "정보의 질"이 도박 대상.
- 완료 조건: 스모크에 walker phase 2 실패 분기 도달 테스트 추가. 15단계 전 실패 분기 도달 가능 검증.

### 2-2. 정답 표시 제거 — 확률을 리스크 프로파일로
- 현상: UI가 counter에 "↳ 의도 대응" 마크와 성공률 100%를 그대로 표기(`07-ui.js:1594-1599`).
  숫자 최대값 고르기 게임이 된다.
- 작업: 정확한 %를 등급(확실/유리/반반/불리)으로 뭉개고, 대신 **실패했을 때 무엇을 잃는지**를 선택지에 명시
  (연료 실패/부상 실패/관측 실패 — 이미 데이터에 있다). "성공률 선택"이 "감당할 실패 선택"으로 바뀐다.
- 완료 조건: 전투 선택지 전체에 실패 비용 라벨 렌더 확인.

### 2-3. Phase 1 열위 선택지 정리
- 현상: walker 1단계 엄폐(edge+1·pressure-1·비용 time 5) vs 유인(van-2·pressure+1) — 전부 p:1 확정이라
  읽는 순간 우열 종료(`03-data.js:4213-4214`).
- 작업: 5조우 × phase 1 선택지 전수 점검. 각 선택지가 서로 다른 축(edge/pressure/소음/자원)을 사고팔게 —
  "엄폐는 edge를 사지만 시간과 관측을 내고, 유인은 pressure를 팔지만 차체를 낸다"가 실제 수치로 성립하도록.
- 완료 조건: phase 1 선택지 중 지배 전략(전 축 우위) 0개 — 데이터 lint로 검증 자동화.

### 2-4. 확정 성공 캡
- `kw_sniper`가 탄약 선택지를 무조건 성공(`04-engine.js:1193`) → **조우당 1회**로 캡. 이유는 서사로
  (연발엔 위치가 드러난다 — 소음×관측 시스템과 정합). 동료 `req:{comp:…}` p:1 치트키 선택지도 전수 점검,
  성공은 유지하되 비용(시간·피로·유대 소모 중 하나)을 붙인다.
- 완료 조건: p:1 && 비용 0 선택지 수를 lint로 집계, 위기·전투 계열에서 0.

### 2-5. 구조·호송에 실패 상태 추가

### 2-6. 적응 난이도 실질화

- mj_fuel(영구 연비 -8%) vs mj_camp(야영당 차체 +6) 같은 명백 우열쌍 전수 점검.
  약한 쪽에 고유 상황(야영 이벤트 추가 분기 등)을 붙여 "다른 플레이"로 만들거나 수치 조정.
- 완료 조건: 블라인드 4빌드 샘플에서 A/B 선택 분포가 20:80보다 고름.

### 3-3. 보이지 않는 효과의 가시화
- 현상: "발견 이벤트 ×1.5", "매복 ×0.75" 같은 풀 가중치는 코드를 안 읽으면 플라시보와 구별 불가.
- 작업: 가중치가 실제 발동/억제한 순간, 이벤트 텍스트에 한 줄 귀속("망원대가 먼저 빛을 잡았다").
  이벤트 후 리포트(이미 원인 분해를 보여주는 시스템 존재)에 장비 기여 표기.
- 완료 조건: 풀 가중치형 업그레이드 전종에 발동 귀속 라인 1개 이상.

## Phase 4 — 캐릭터·대사: 7.5 → 8 / 스토리: 8 → 8.5

### 4-1. 갈등 아크 1개 — "빈자리 없는 저녁"의 값
- 현상: 잡담·티키타카 전량이 애정 어린 놀림. 여섯 명 전원이 지혜롭고 성숙하며 틀리는 순간이 없다.
  성인 여섯이 밴 한 대로 400km를 가는데 진짜 싸움이 0회 — 앙상블의 신뢰도를 깎는다.
- 작업: 중반(김천 분기 전후) 실비용이 걸린 충돌 아크 1개 — 예: 연료 잔량 vs 우회 구조 요청에서
  강우(임무 우선)와 박 선생(사람 우선)이 충돌, **플레이어가 어느 쪽을 들어도 자원이나 유대를 실제로 잃고**,
  이후 두 사람이 각자의 방식(강우는 행동, 박 선생은 처방)으로 수리하는 3이벤트 체인.
  보이스 바이블의 "갈등과 수리는 행동·비용을 바꿔야 한다" 원칙을 드디어 집행하는 것.
- 완료 조건: 충돌 선택이 김천 분기 태도·엔딩 콜백에 반영.

### 4-2. 경구 다이어트
- 현상: 거의 모든 이벤트가 재치 있는 한 줄로 닫힘("양말은 문명이다"류). 개별로는 좋은데 수백 개가
  같은 리듬 — 세계 전체가 한 사람의 목소리로 말한다. 정량: "한참" 82회, "백미러" 68회, "처음으로" 45회.
- 작업: dialogue lint에 종결 경구 패턴·빈출어 상한 검출 추가 → 위반 상위부터 손질, 목표는 경구 종결 비율 절반.
  대체는 "그냥 끝나는 문장"과 "다음 행동으로 끝나는 문장". 경구를 지우는 게 아니라 희소하게 만들어 값을 올린다.
- 완료 조건: lint 리포트에서 경구 종결 비율 ≤ 기존의 50%, "한참" ≤ 40회.

### 4-3. 최종막 저항 — 항복 문서를 찢는다
- 현상: 천리안이 문을 열어주고 성실히 답하고 판단을 넘겨달라 요청 — 실패도 상실도 불가능한 문답.
  세 처분안의 대가는 사후 텍스트로만 존재. 시한 초과조차 부드럽게 회수.
- 작업 (설정 정합 유지 — 인계 규약 자체는 훼손하지 않는 선에서):
  - 처분안의 대가를 **선택 전에 극화**: 격리 수면을 고르면 닫히는 것(면사무소 기록 조회)을,
    존속을 고르면 남는 것(감시 근무)을, 선택 화면 이전에 구체 인물의 장면으로 보여준다.
  - 코어 앞에서 하나는 플레이어의 뜻을 거스른다: 권장안 = **동료 1인의 반대**. 여정 내 선택 이력
    (여정 장부 4기둥)에 따라 반대자가 달라지면 17개 핵심 선택 시스템과도 맞물린다.
  - 1-1의 (b)안과 결합: 30일 초과 시 첫 이송분이 이미 떠났음이 처분 선택지에 각인.
  - 에필로그 동일 문단 합류(「후속 목록: 없음」) 분화 — 처분·반대자·시한 3변수로 최소 4종.
- 완료 조건: 블라인드 플레이어가 "마지막 선택이 어려웠다"를 보고(기존 QUALITY-9-BLIND-VALIDATION 항목에 추가).

### 4-4. 세계의 대비 — 온기의 값
- 현상: 멸망 143년의 길이 국밥·오지랖·예의 바른 도둑으로만 채워짐. 악의는 일화 수준, 정리자들 교단은 1회 소비.
- 작업: 진짜 악의 조우 2~3개 (제안: 장터길 가짜 통행세 조직 — 호송 시스템과 연동 / 정리자들 2차 조우 —
  개켜진 옷의 주인 문제를 정면으로). 무겁게 2~3개면 충분 — 대비가 생기면 기존 온기 전체의 값이 오른다.
