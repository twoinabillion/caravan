선택은 미리보기이고 출발 버튼만 이동한다. 경로 제한·거리·확률·자원·날짜·합류 조건·저장 버전은 변경하지 않는다. 완료했던 첫 검문소에 새 기억을 소급 생성하지 않으며 이미 저장된 대사/결과는 보존한다. 새 목적지 예고는 보상·상점 재고·안전·아직 모르는 장소의 발견을 보장하지 않는다.

## 전체 검토에서 유지한 것

- 길 위 사건은 이미 peak/fade/relax와 실제 무사건 breather 구간을 갖는다. 이번 문제를 ‘사건이 너무 많다’로 단정할 실측은 없어 빈도를 일괄 삭감하지 않았다.
- 차량 안은 실제 합류 동료의 물건, 소유한 개조와 저장된 야영 기억으로 구성된다. 떠난 동료의 기억은 물리적 소품으로 만들지 않으며 침구 단계도 겹치지 않는다. 이동하는 집의 뼈대는 이미 존재하므로 신규 수집 시스템을 추가하지 않았다.
- 가족·발신 기록·검증키·증언·부모님 행방·거점 연락·남산 진입은 기존 메인 스토리와 회귀를 따른다. 필수 인과를 공책에만 숨기거나 동료 합류를 강제하지 않았다.
