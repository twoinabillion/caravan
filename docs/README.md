# 문서 안내

현재 프로젝트 상태는 [CURRENT.md](CURRENT.md)를 단일 기준으로 사용한다.
게임 소개와 실행 방법은 루트의 [README.md](../README.md)를 확인한다.

## 현재 기준

- [CURRENT.md](CURRENT.md): 구현 규모, 구조, 관리 과제
- [DESIGN.md](DESIGN.md): 게임과 인터페이스 설계 원칙
- [SERIES-BIBLE.md](SERIES-BIBLE.md): 세계관과 장기 연작의 불변 설정
- [DIALOGUE.md](DIALOGUE.md): 대사 작성 규칙
- [IMAGE-BIBLE.md](IMAGE-BIBLE.md): 장면 이미지 규칙
- [COMPANION-VISUAL-BIBLE.md](COMPANION-VISUAL-BIBLE.md): 동료 외형 규칙
- [COMPANION-VOICE-BIBLE.md](COMPANION-VOICE-BIBLE.md): 동료 말투 규칙

## 제작 자료

장면·초상·오디오 제작 프롬프트와 가이드는 이 폴더에 유지한다. 완료된 로드맵과
과거 인수인계는 [history](history/README.md)에 보관하며 현재 작업 지시로 사용하지 않는다.
