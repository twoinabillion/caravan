# 서울까지 400km — 프로토타입 v0.1

포스트아포칼립스 한국 로드트립 게임. 낡은 캠핑밴 '달구지'로 부산에서 서울 남산의 AI '천리안' 코어까지 411km.

## 실행

- **웹 (온로드 모드)**: https://claude.ai/code/artifact/7c985fb8-0f23-463a-ac72-261d089f5725
- **로컬 (오프로드 모드 가능)**: `서울까지400km.html`을 브라우저로 열기
  - 오프로드 모드 = 이벤트·잡담·NPC 대화를 LLM(claude-opus-4-8)이 실시간 생성
  - 모드 선택 화면에서 Anthropic API 키 입력 (localStorage에만 저장, 직접 브라우저→API 호출)
  - 아티팩트 호스팅에서는 CSP가 외부 API를 막아 오프로드가 잠김 — 로컬 파일에서만 활성화

## 구조 (단일 HTML, 의존성 0)

| 영역 | 내용 |
|---|---|
| 지도 | 노드 30개(정착지 6·히든 8) + 안개, 한반도 남부 스타일라이즈드 |
| 주행 뷰 | 캔버스 절차 생성 — 낮밤 사이클·날씨·폐허 스카이라인·거리 표지판(남은 km 실시간)·동료 탑승 렌더 |
| 자원 | 연료(이동)·물/식량(시간)·고철(화폐)·밴 내구도 |
| 이벤트 | 손으로 쓴 40여 종 (조우/탐색/발견/동행/추적/위기) + 히든 로케이션 8곳 |
| 동료 | 6명 · 직업군: 민지(정비사)·박 선생(의술사)·강우(파수꾼)·레오+보리(음유시인)·재이(수집꾼)·은수(관제사) — 각자 이벤트 해금 키 |
| 진전도 | 유대(5/12/20) → Lv1·2 퍼크 A/B 택1, Lv3 = 시그니처 스토리 퍼크(개인 서사 해금). 동료 카드 탭 → 시트 |
| 천리안 | 관측 수치(0~5)에 따라 추적 이벤트 강화, 북부에서 존재감 상승 |
| 일지 | Obsidian식 지식 그래프([[링크]]) — 기록 타임라인 + 관계망 뷰 + .md 내보내기 |
| 세이브 | localStorage 자동 저장, 이어하기 |

소스 파트 파일은 세션 스크래치패드 `scratchpad/game/`(01-style ~ 08-offroad)에 있음 — 단일 파일이 곧 배포본이므로 이 HTML을 직접 수정해도 됨.
