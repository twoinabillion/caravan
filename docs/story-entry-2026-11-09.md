# 여행 중 기억과 이야기 연결 — 2026-11-09

Sang은 기본 프롤로그를 자동으로 먼저 보여 주고, 여행 중 끼어드는 회상만 알림을 눌러 읽는 흐름을 승인했다. Studio 독립 초안 `story-entry-v1`의 ‘떠오른 기억 → 기억 들여다보기/나중에’와 ‘길 위의 단서 → 감속·정차 → 장면’을 반영했다.

## 동작

- 부산 터미널 회상은 읽지 않은 초대로 저장된다. ‘나중에’는 작은 알림으로 접고, 열람은 원래 사건 리더로 넘긴다. 알림만으로 사건·지식·시간·자원을 지급/소모하지 않는다. 활성 사건·도착·메뉴·위기·전투 중에는 다른 소유자를 덮어쓰지 않는다. 지난밤 야영의 미해결 선택과 기본 프롤로그는 기존 진입을 유지한다.
- 보통 길 위 사건의 예고 시간을 늘렸다. 우편부는 자전거 단서 뒤에 등장한다. 도윤 가족의 현재 소식은 길가 단말의 주파수 표시, 공중 단말 그림, 연락소를 부르는 행동을 같은 장소로 맞췄다. 위급 상황은 기존 안전 경로를 유지한다.
- 새 기본 프롤로그는 할아버지와 차를 고치고 집으로 바꾸던 기존 장면을 이어 준다. 짧은 복스 농담을 중복하지 않으며 문맥 없는 ‘돌아오는 길’ 연결을 고쳤다. 기존 v1 독자의 페이지·턴은 이전 목록에 고정한다.
- 조사 우선 선택은 다음 기록의 순서를 바꾼다. 마지막 두 장은 이미 안 원칙을 다시 발견하는 대신 실제 배선·커넥터 순서를 완성한다. 아빠의 마지막 기록 뒤에는 함께 있는 동료의 반응이나 혼자 머무는 동작을 두고 평상 잡담을 잠시 쉰다.
- 도윤 가족의 환승 대기구역 소식을 받고 마지막 연락까지 같은 위치를 유지한다. 코어에서는 실제 지급된 초반 행동을 되짚고, 자기 보존 규칙과 외부 검증키의 인과를 설명한다. 본편 마무리 뒤 남은 신호는 후일담을 선택했을 때 잇는다.

## 검증과 한계

기능 검사는 알림·나중에·열람·저장 복원·현재 사건과의 충돌·정확히 한 번 지급을 다룬다. 새 서술 판본은 진입과 결과에 고정되며, 과거에 지급된 본문·화자·커서·정산은 보존한다. 과거 코퍼스의 기계적 해시는 유지하고 승인된 판본/추가 사건을 명시적으로 검증한 뒤 비교한다. 동결된 예전 소스에 없던 새 모듈은 그 예전 실행기에서만 생략한다.

동결 소스 44개로 별도의 실제 리더 기반 유한 새 여정 두 개를 진행했다. 기록 우선 여정은 DAY18 문경에서 `shunned` 패배(554행동·93장면), 실용 여정은 DAY18 `story_done`(한 새 게임, 실제 결과98건·고유장면73개)으로 끝났다. 회상 즉시 열람과 나중에 정차 후 열람, 아빠/엄마 조사 순서, 가족 연락의 마지막 연결을 각각 확인했다. 읽기·화자 불일치와 재지급은 없었다. 실용 여정의 초기 논산 정체는 이전 QA 정책의 경로 기억 문제였고, 보이는 합법 경로로 같은 여정을 이어 종료했다. 준비 오류나 재시도는 독립 플레이로 세지 않았다.

브라우저 연결 호스트가 사용할 수 없어 실제 현재 화면·휴대폰 뷰포트·그림 잘림·소리 검사는 이번에 확인하지 못했다. 짧은 화면과 큰 글씨 알림은 소스에서 한 줄 구조와44px버튼을 검토했지만 이것을 실제 화면 검수로 부르지 않는다. 사용자 저장과 현재 미리보기에 강제 새로고침/적용하지 않았다.

세부 실행 기록은 로컬 `qa-artifacts/story-entry-20261109/`에 있으며 플레이 준비 실패·원정·정책 복구를 분리해 보존한다. 최종 소스 검사와 게시 결과는 CURRENT 및 같은 폴더의 verification.json에 기록한다.
