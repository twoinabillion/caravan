# Stop Slop 기반 대사 감사

기준일: 2026-08-23  
원문 기준: [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop)

## 적용 원칙

이 프로젝트는 stop-slop을 금칙어 사전으로 쓰지 않는다. 원 자료는 설명문 편집법이므로, 질문으로 시작하지 말 것·부사를 지울 것 같은 규칙을 대사에 그대로 적용하면 인물이 오히려 부자연스러워진다.

- 인물이 상황에 반응하지 않고 작가의 결론을 대신 말하는가?
- "중요한 것은 A가 아니라 B" 같은 대조 공식이 반복되는가?
- 장면이 행동이 아니라 인용문처럼 매끈한 교훈으로 닫히는가?
- 감정을 표정·행동·침묵 대신 추상어로 요약하는가?
- 어린이가 퀘스트 설계자나 행정 담당자처럼 정보를 정리하는가?
- 서로 다른 인물이 같은 문장 길이와 논리 순서로 말하는가?

## 이번 전수 감사

런타임 데이터에서 대사·서술·선택지·결과를 포함한 한국어 텍스트 6,026개를 추출했다. 휴리스틱은 2,071건을 후보로 잡았지만 짧은 질문, 사투리, 농담도 포함된 수치라 자동 치환하지 않았다. 화자와 장면을 다시 보고 확실한 문제만 고쳤다.

NPC의 명언형 대사는 먹는 일, 장사, 순찰, 보급처럼 당장 하는 행동으로 바꿨다. 동료 장면 뒤의 "설명이 필요 없었다", "인생 수업" 같은 작가 해설은 구체적인 손짓과 행동으로 바꿨다. 서울이 보이는 순간과 감시 방송 뒤의 감정도 운전과 시선 변화로 보이게 했다. 저항 조직은 멋진 구호보다 실제 보안 절차가 드러나게 정리했다.

## 남겨 둔 예외

- 천리안과 단말기는 의도적으로 차갑고 행정적인 문장을 쓴다.
- 강우의 짧은 군대식 말투, 지역 NPC의 사투리, 레오의 농담은 고르게 다듬지 않는다.
- 긴 문장은 그 자체로 오류가 아니다. 감정이 쌓이는 장면에서는 호흡을 유지한다.
- 한 번만 등장하는 좋은 경구는 남길 수 있다. 여러 인물과 결과가 같은 방식으로 끝날 때 줄인다.

## 재검사

```bash
node tools/dialogue-slop-audit.cjs
node tools/dialogue-slop-audit.cjs --json
npm run lint:dialogue
```

이 도구는 후보를 보여 줄 뿐 자동 실패시키지 않는다. 최종 판정은 화자의 나이, 관계, 감정, 지식 범위를 함께 본다.
