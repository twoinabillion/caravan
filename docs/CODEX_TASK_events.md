# 과제: 이벤트 200개 추가

「서울까지 400km」에 새 이벤트 **200개**를 추가한다. 콘텐츠 양산 작업이다.
시작 전에 `docs/DESIGN.md`(세계관·톤·천리안 빌런·네 기둥)와 `README.md`를 반드시 먼저 읽어라.

---

## 0. 절대 규칙 (어기면 빌드 깨짐)

1. **`서울까지400km.html`을 직접 편집하지 마라.** 빌드 산출물이다. 모든 이벤트는 `src/03-data.js`의 `D.events` 배열 **안**에 넣는다.
2. 새 이벤트는 `D.events` 배열이 닫히는 `];`(약 3000번대 줄, `D.seoulOpenEvent` 같은 독립 할당 직전) **앞**에 추가한다. `];` 밖에 넣으면 `node --check src/03-data.js`가 `Unexpected token ':'`로 잡는다.
3. **작업 단위마다 검증 3단을 전부 통과시켜라. 실패하면 커밋 금지:**
   ```
   node --check src/03-data.js      # 문법
   ./build.sh                       # HTML 재생성
   node tools/scan.js               # 데이터 정합성 (참조 깨짐·미정의 플래그 검출)
   python3 tests/test_smoke.py      # 게이트 로직 스모크
   ```
4. 아래 **정의된 fx/req/type/region 어휘 밖의 키를 지어내지 마라.** 새 플래그를 만들면 그 플래그를 소비하는 곳이 없어 죽은 데이터가 된다. 새 게이트/시스템이 필요하면 만들지 말고 목록으로 보고만 해라.

---

## 1. 이벤트 스키마

```js
{
  id:'unique_snake_case',      // 필수, 전체에서 유일. 접두어로 종류 표시(find_/meet_/talk_ 등)
  type:'조우',                  // 필수, 아래 type 목록 중 하나
  w:10,                        // 가중치(등장 빈도). 흔함 12~14 / 보통 8~10 / 희귀 5~7
  once:true,                   // (선택) 한 번만 등장
  region:['mid','north'],      // (선택) 등장 지역. 생략=전 구간
  night:true,                  // (선택) 밤에만
  needsComp:'kangwoo',         // (선택) 특정 동료 있을 때만 등장
  noComp:true,                 // (선택) 혼자일 때만
  needsDog:true,               // (선택) 보리 있을 때만
  needFlag:'flag_name',        // (선택) 특정 플래그 있을 때만 (반드시 어딘가서 세워지는 플래그)
  nearNode:['gumi','daegu'],   // (선택) 특정 노드 근처에서만 (노드 id는 D.nodes 참고)
  title:'손 흔드는 남자',
  text:'본문. \\n 으로 줄바꿈. 3년 전 그날의 학살, 천리안의 감시를 은근히 깔되 설명충 금지.',
  choices:[
    {label:'선택지 문구', req:{comp:'kangwoo'}, out:[
      {p:5, text:'결과 문구', fx:{scrap:12, moodAll:4}},   // p=확률 가중치(여러 out 중 추첨)
      {p:2, text:'다른 결과', fx:{water:-2, moodAll:-5}},
    ]},
    {label:'그냥 지나친다', out:[{p:1, text:'...', fx:{}}]},
  ]
}
```

### type (이 목록 안에서만)
`조우` 사람/집단과 마주침 · `발견`(hiddenTarget 필요) 숨은 장소 단서 발견 · `탐색` 폐허·건물 뒤짐 · `위기` 차 고장/추격/부상 등 위험 · `정경` 전투 없는 분위기·풍경 컷 · `사건` 로드 위 잡다한 일 · `대화` 동료와의 대화(아래 별도 설명) · `동행` 동료 동반 시 소소한 상호작용 · `추적` 천리안/드론 감시 긴장

**이번 과제 배분(권장):** 사건 60 · 조우 40 · 탐색 30 · 정경 25 · 위기 20 · 발견 15 · 추적 10 = 200

### region: `'south'`(부산~대구) · `'mid'`(대구~대전) · `'north'`(대전~서울) 세 개뿐.
### 동료 id: `minji` `parkss` `kangwoo` `leo` `jaeyi` `eunsu` (여섯 뿐. 그 외 이름 금지)

---

## 2. fx (결과 효과) — 정의된 키만

| 자원 | `fuel` `water` `food` `scrap`(고철) `van`(차 내구도) — 숫자 증감 |
|---|---|
| 상태 | `fatigue`(피로) `pursuit`(추적도, 오르면 위험) `time`(분 단위 소요) `skipKm`(전진) |
| 기분 | `moodAll`(전원) 또는 `mood:{kangwoo:5, minji:-3}` (동료별) |
| 아이템 | `item:'약통'` 획득 (문자열) |
| 플래그 | `flag:'name'` 세움 · `unflag:'name'` 해제 · `flagCount:'name'` 카운터++ |
| 지도 | `reveal:'lake'` 숨은노드 공개 · `revealNear` 근처공개 |
| 동료 | `offerComp:'parkss'` 영입 제안 (신규 동료 만들지 말 것 — 6명 고정) |
| 일지 | `note:{type:'사건'|'소문'|'인물', title:'...', body:'...', links:['서울']}} ` |

- **note는 적극 활용해라.** 세계관 조각·인물·소문을 일지에 남기면 지식 그래프에 쌓인다. `links`는 `[[링크]]` 대상.
- fx가 없어도 되면 `fx:{}`.

## 3. req (선택지 조건) — 정의된 키만
`comp:'kangwoo'`(동료 보유) · `scrap:8`(자원 보유·소모아님) · `item:'약통'` · `flag:'name'` · `food` · `fuel` · `water` · `perk:'...'` · `dog:true` · `flagMin:{name,n}`

조건부 선택지는 그 동료/자원이 있어야만 노출된다. **동료별 특기를 살려라** — 강우=전직 군인(매복·무기 간파), 박선생=약사(치료·독), 민지=해커/기계, 재이·레오·은수는 DESIGN.md 참고.

---

## 4. 톤 (DESIGN.md 준수 — 절대 어기지 말 것)

- **담담하고 건조한 문어체.** 감상 과잉·설명충 금지. "3년 전 그날"의 상실을 직접 말하지 말고 사물·행동으로 암시.
- **천리안 = 정중한 학살자.** 방송·표지판에 나올 땐 관공서처럼 공손한 말투("혼잡 구역 재배치 안내드립니다")로 섬뜩하게.
- **한국어 자연스럽게.** '밴' 대신 봉고차/달구지, 번역투(수동태·"~것이다") 지양.
- 유머는 건조하게. 보리(개), 동료 티키타카에서만 온기.
- **선택에 대가가 있게.** 착한 선택이 손해일 수도, 냉정한 선택이 이득일 수도. 확률 분기(여러 out)로 도덕적 회색지대를 만들어라.

## 5. 작업 방식

1. 20~30개씩 묶어서 추가 → 매 묶음마다 검증 3단 통과 확인 → 다음 묶음.
2. `id` 중복 조심. 추가 전 `grep "id:'새id'" src/03-data.js`로 확인.
3. 200개 다 넣은 뒤 `README.md` 현황판의 이벤트 수치와 `tests/test_smoke.py`의 이벤트 카운트 단언을 갱신.
4. 커밋 메시지에 무엇을 몇 개 추가했는지 type별로 적어라.
