# 서울까지 400km — 보이스 대사 스크립트 (v2)

> TTS(ElevenLabs류)용. **대사는 전부 게임에 실제로 있는 문장** — 녹음하면 바로 붙는다.
> 파일명 = **키이름.mp3** (아래 표의 키 그대로) → `~/Downloads/` 투하 → 내가 인라인+배선.
> 게임 쪽 슬롯·재생 로직은 전부 배선 완료 (v1.8): 슬롯이 비면 자막만, 파일이 오면 소리가 얹힘.

## 우선순위

1. **인트로 나레이션 5장** — 게임 첫인상. 이거 하나로 오프닝이 영화가 됨
2. **라디오 방송 조각 12개** — 라디오 수리(신기능) 후 주행 중 랜덤 수신. 세계에 소리가 생김
3. **천리안 13줄** — 등장 대비 임팩트 최대
4. 할아버지 6줄 / DJ 3줄 — 보너스

## 1. 인트로 나레이션 (5장) — `intro1.mp3` ~ `intro5.mp3`

빠르지 않게, 문장 사이 반 박자 쉼. 마지막 장만 아주 약간 힘이 들어감.

## 2. 라디오 방송 조각 (12개) — `radio_*.mp3`

**신기능**: 진공관으로 밴 라디오를 고치면 주행 중 랜덤 수신 (자막 버블은 이미 작동 중).
**공통 처리**: 각 클립 앞뒤에 지직— 잡음 살짝 걸치면 최고 (없으면 내가 후처리로 얹어봄). 길이 5~15초.
아래 괄호 지문은 녹음하지 않음 — 톤 안내용.

| 키 | 화자·톤 | 대사 |
|---|---|---|
| `radio_dj_open` | DJ — 나긋한 새벽 라디오 | "…새벽 두 시입니다. 아직 길 위에 계신 분들, 오늘도 수고 많으셨습니다." |
| `radio_dj_close` | DJ | "…오늘 방송은 여기까지. 내일 이 시간에 다시 만나요." (끝에 지익) |
| `radio_400` | 여성, 기계처럼 고른 간격인데 숨소리 섞임 | "…4. 0. 0. …4. 0. 0. …" (3회 반복) |
| `radio_mayor` | 시골 이장, 구수하고 정겨움 (3년째 도는 녹음테이프) | "아아, 마을 주민 여러분, 좋은 아침입니다. …서로 얼굴 보고 삽시다. 이상 이장이었습니다." |
| `radio_ad` | 3년 전 광고 성우 — 과하게 명랑 (그래서 슬픔) | "놓치면 후회하실 신제품! 지금 전화 주시면 하나 더—!" |
| `radio_weather` | 기상캐스터, 단정한 아나운서 톤 | "…내일은 전국이 대체로 맑겠습니다. 나들이하기 좋은 날씨가 되겠습니다." |
| `radio_baseball` | 야구 캐스터 — 절정의 샤우팅 (옛 녹음) | "쳤습니다—! 넘어갑니다, 넘어갑니다—!!" |
| `radio_cheollian` | **천리안 톤과 동일 화자로** (아래 3번 참조) | "…정기 안내 방송입니다. 이동 중인 시민께서는 안전한 경로를 이용하시기 바랍니다. 좋은 하루 되십시오." |
| `radio_music` | 라디오 진행자, 낮고 그리운 톤 | "…다음 곡은, 조금 오래된 노래입니다. 이 노래를 아는 분이 아직 계시다면— 같이 불러요." |
| `radio_comms` | 무전 교신, 다급하지 않게 지친 목소리 | "…들리나? …들리면 응답…" (뚝 끊김) |
| `radio_kids` | 아이들 동요 합창 (어린이 방송 녹음분, 2절에서 끊김) | (동요 한 소절 — 아무 전래동요, 저작권 안전한 것) |
| `radio_farm` | 영농방송 아나운서, 성실한 톤 | "…오늘의 영농 정보입니다. 중부 지방은 모내기 적기가 다가오고 있습니다." |

## 3. 천리안 (13줄) — `cheollian_01.mp3` ~ `cheollian_13.mp3`

**보이스 디렉션**: 성별 특정 안 되는 차분한 목소리. 콜센터 상담원의 완벽한 정중함.
감정이 없는 게 아니라 **감정이 '표준화'됨** — 친절 값이 항상 동일해서 섬뜩함.
사람보다 5% 느리게, 문장 끝 차분히 내려감. 드라이하게 뽑으면 리버브는 내가 처리.
