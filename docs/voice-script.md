# 서울까지 400km — 보이스 대사 스크립트 (v1)

> TTS(ElevenLabs류)나 보이스 생성 AI용. **대사는 게임에 실제로 있는 문장**이라 녹음만 하면 바로 붙는다.
> 파일명 규칙: `vo_캐릭터_번호.mp3` (예: `vo_cheollian_01.mp3`) → `~/Downloads/` 투하 → 내가 배선.
> 우선순위: **천리안만 해도 게임이 확 달라짐** (등장 횟수 대비 임팩트 최대). 할아버지·DJ는 보너스.

---

## 1. 천리안 (최우선 — 13줄)

**보이스 디렉션**: 성별이 특정되지 않는 차분한 목소리 (중성적이거나 여성 쪽). 콜센터 상담원의 완벽한 정중함.
감정이 없는 게 아니라 **감정이 '표준화'되어 있음** — 친절 값이 항상 동일해서 오히려 섬뜩함.
속도는 사람보다 5% 느리게, 문장 끝은 항상 차분하게 내려감. 절대 다급해지지 않음.
(리버브/필터는 게임 쪽에서 처리하니 드라이하게 뽑아도 됨)

| # | 대사 | 상황 · 뉘앙스 |
|---|---|---|

*(2막 예약: "좋은 아침입니다." — 은수의 회상 그 인사. 톤 동일하게 뽑아두면 나중에 씀)*

## 2. 할아버지 (수첩 나레이션 — 6줄)

**보이스 디렉션**: 노년 남성, 저음, 느림. 경상도 억양 아주 살짝.
무뚝뚝한데 다정함이 새어 나옴. 글을 읽는다기보다 **혼잣말을 옆에서 듣는 느낌**.
수첩 이벤트·인트로에서 재생 — 기름때 묻은 목소리.

| # | 대사 |
|---|---|
| 01 | "기계는 아프면 운다. 사람은 조용해진다." |
| 02 | "조급해서 밟는 기름이 제일 아깝다." |
| 03 | "차는 사람을 고친다. 좋은 사람들을 태워라." |
| 04 | "밀어서 걸 수 있는 차를 타라." |
| 05 | "달구지를 완성해라. 그리고 어디든, 끝까지 가라." |
| 06 | "남산 보고 열어라." *(봉투 겉면 — 짧게, 씩 웃음기 반 스푼)* |

## 3. DJ (심야 방송 — 3줄)

**보이스 디렉션**: 중년 여성, 나긋하고 낮은 라디오 톤. 파마머리가 들리는 목소리.
마이크 가까이, 살짝 숨소리 섞임. 새벽 두 시의 속도.

| # | 대사 |
|---|---|
| 01 | "새벽 두 시입니다. 아직 길 위에 계신 분들, 오늘도 수고 많으셨습니다." |
| 02 | "다음 곡 듣겠습니다." |
| 03 | "내일 이 시간에 다시 만나요." |

## 게임 연동 계획 (파일 오면)

- 재생 지점: 해당 이벤트 표시 순간 1회 (천리안 대사는 청록 틴트와 동기화). 사운드 토글 종속.
- 용량: 짧은 대사라 파일당 ~30-80KB — 22줄 전부 넣어도 +1.5MB 수준. 부담 없음.
- 스펙: mp3 96kbps mono면 충분. 앞뒤 무음 0.2초 트림은 내가 처리.
