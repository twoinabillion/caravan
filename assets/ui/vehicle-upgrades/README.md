# 달구지 개조 부품 — 2026-09-26

주행·정차·정비소 비교에 쓰는 **투명 렌더러 부품**이다. 사건 일러스트나 완성된 게임 화면이 아니다. 같은 크림색 캡오버 운전석, 흰 X, 캔버스 짐과 빨간 통을 유지하고 실제 소유한 개조만 조립한다.

## 구성과 소유권

- `body-*-v1.webp` 4장: 후미 1차 → 거주구 2차 → 상부 수면칸 → 후미 서비스칸. 각각512×256, alpha.
- `parts-equipment-v1.webp`, `parts-living-v1.webp`: 각각384×512, 3열×4행. 총24개 장비. `manifest-v1.json`에 셀 순서가 있다.
- `src/05b-vehicle-kit.js`: 실제 유리창·부품 경계, 조립 위치, 야간/차양/커튼을 소유한다. `src/05-scene.js`의 동료·동작·날씨 렌더러와 연결한다.
- `src/03-data.js`의 `D.upEngineering`과 `src/04e-engine-world.js`의 `G.upRequirements`, `G.canBuyUp`: 공사 선행 조건과 구매 판단을 소유한다.
- 완성 차량을 조합마다 새로 그리지 않는다. 증축 본체4장과 장비24종을 분리해 장착 순서와 무관하게 같은 외형을 만든다. 실내 장비는 유리창 안에 보이며 별도의 외장 부품을 허위로 추가하지 않는다.

## 설치 규칙

- 보강 서스펜션 → 거주구 2차 증축 / 장갑판 / 대형 연료탱크. 기존 탱크·증축의 선행 단계도 필요하다.
- 전면 가드 → 윈치. 가드의 차대 연결 받침에 체결한다.
- 텃밭 → 온실, 난로 → 주방, 태양광 → 냉장 박스, 공구함 → 무기 선반은 기존 연결을 유지한다.
- 지붕3자리와 후미1자리 제한 유지. 온실은 기존 텃밭 자리를 대체하며, 대형 연료탱크와 마지막 서비스칸은 후미 자리를 공유한다.
- 이미 설치한 구형 저장의 부품을 제거하거나 선행 부품을 무료로 지급하지 않는다. 과거 초과 설치도 그림에 남긴다.
- 가격·능력치·작업시간·28개 항목 수는 바꾸지 않았다. 정비소에서 선택한 항목은 필요한 선행 설치와 이유를 표시한다.

## 제작 기록

내장 `image_gen`으로6개 마스터를 생성했다. 외부 CLI/API를 사용하지 않았다. 세 스타일 정본, 달구지 기술 정본, 승인된 차량 기본 이미지를 모두 참조했다. 최종 프롬프트·참조·마스터 경로는 [prompts-v1.json](prompts-v1.json)에 기록했다. `tools/prepare-vehicle-upgrades.mjs`로 alpha 여백을 정리하고 정해진 크기의 WebP로 내보냈다. 개조 장면용 기존768×512 일러스트는 별개이며 그대로 유지한다.
