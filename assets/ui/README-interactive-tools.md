# Interactive road tools

The goal, map, and bag shells are intentionally empty raster props. All readable
labels, values, progress, selections, and actions are rendered live by the game.

- `goal-folio-shell-v1.webp`: leather travel folio / objective surface
- `map-navigator-shell-v1.webp`: fold-out CRT navigator / map surface
- `bag-supply-roll-v1.webp`: canvas supply roll / inventory surface

Source visual concepts are kept on the user's Desktop in
`Caravan UI 시안 - 목표 지도 가방`.
