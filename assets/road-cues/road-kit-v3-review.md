## 이번에 생성·저장한 부품

- 공식 초상 참조 전신 10종: 지도장이, 한별(안경 보완 v2 채택), 민규, 소연, 산지기, 김 선장, 하 여사, 금자, 서진, 태식.
- 사건의 도구/자세 참조 전용 인물 3종: 사진사, 꽃장수, 발판 재봉틀에 앉은 재봉사.
- 독립 사물 3종: 이동 도서관 버스, 지도장이 사이드카, 빈 그랜드 피아노.
- 생성은 내장 이미지 도구 사용. 마스터는 masters/, 배송 WebP는 이 폴더. 정확한 프롬프트·참조·원본 경로는 road-characters-v3.prompts.json, road-characters-v4.provenance.json, road-props-v3.provenance.json에 보존.
- 출력 이미지의 얼굴·자세·도구는 vision으로 확인. 한별의 초기 v1은 안경이 없어 채택하지 않고 v2를 사용한다. 전체 배송 자산은 실제 4319 /__live/assets 목록에 게시 확인 후 manifest에 연결.

## 연결 범위

지도장이, 한별의 실제 버스 대면, 소연의 대면, 산지기, 김 선장의 첫 대면, 사진사·꽃장수·재봉사를 이벤트 ID별 연결. 빈 피아노에는 사람 0명. 차량 폭은 달구지의 52%, 서 있는 성인은 기존 20.5% 높이/공유 발 기준선 유지. 앉은 재봉사는 성인 높이의 74%.

민규·하 여사·금자·서진·태식 부품은 준비되어 있지만 본문 대면/무전/실내 구분을 전체 검토하지 않아 자동으로 도로에 연결하지 않았다. 초상 메타데이터로 인물 출현을 추정하지 않는다.

## 남은 일

전체 교체는 아직 미완료. 동료 첫 대면의 전용 전신, 아코디언 할머니·거리 화가 등 추가 역할과 무인 로봇·시설·장애물은 기존 표현이 남아 있다. tools/audit-road-cue-coverage.cjs는 후보 분류를 제공하며 실제 도로 진입/시각 검수 완료 여부를 뜻하지 않는다. covered는 비어 있지 않은 새 부품 구성이 있는지일 뿐이다.

## 검증과 차단

- 관련 테스트 15개 통과(인물·비율, 독립 초안, 연쇄 이벤트 handoff).
- HTML 전용 빌드 성공: 79,057,347 bytes, 기존 80,000,000 상한 유지. 콘텐츠/시각 계약 자동 검사 통과. 생성 HTML 수동 수정 없음.
- 전체 npm run build의 별도 AIT 번들은 외부 연결 node_modules/.vite-temp 쓰기 EPERM으로 실패. 게임 HTML 전용 빌드는 별도로 성공.
- 요청된 현재 장면 GET은 HTTP 400: Studio 창에서 현재 장면을 받지 못했다는 오류. 실제 이동/밤/날씨/정차 화면 검수 및 loaded/style/pending 비교 불가. 구조는 준비만 했으며 live apply 강제 실행이나 새 게임/저장 변경 없음.
- 디자인 초안 v6 갤러리에 추가. 파일 및 정적 구성은 검사했으나 Studio 디자인 창에서의 직접 관찰도 미완료.

다음에는 Studio 현재 장면 연결을 먼저 회복하고, 남은 전용 역할·시설 제작 및 실제 저장의 접근→정차→사건→다음 행동을 검수해야 한다.
