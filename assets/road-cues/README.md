# 길 위 조우: 세밀한 렌더 부품 1차 (2026-09-26)

이 파일들은 사건의 전체 배경 그림이 아니다. 기존 달구지와 같은 236 논리 좌표,
2배 버퍼의 주행 캔버스에 조합하는 투명 물체다. 이야기 그림은 정차 후 기존 사건
화면에서만 나온다. 도로·배경·플레이어 차체·개조·탑승자·제동은 평면 이미지에
합치지 않았다.

| 파일 | 배포 크기 | 기본 사건 |
|---|---|---|
| `cue-coffee-van-v3.webp` | 512×265 | 트럭 카페: 주인 1명 |
| `cue-broken-vehicle-v3.webp` | 512×238 | 고장난 트럭의 가족: 아버지, 짐칸의 아이 2명 |
| `cue-temporary-checkpoint-v1.webp` | 512×182 | 가짜 검문소: 형광 조끼 2명 |

빌트인 image_gen으로 생성했다. 네 공식 캐논과
`assets/ui/journey-dalguji-base-v1.webp`를 모든 생성에 첨부했다.
[전체 프롬프트와 원본 경로](detailed-cues-prompts.json),
[크롭·규격·렌더 계약](detailed-cues-manifest.json)을 보존한다.
1536×1024 원본에서 투명 여백만 정리하고 비율을 유지해 WebP q82로 축소했다.
합계 85,752 bytes. 이전 버전은 삭제하거나 덮어쓰지 않았다.

사람은 그림에 박아 넣지 않고 사건의 `roadApproach.scene`으로 그린다. 아이는
트럭 옆이 아니라 짐칸 안에서 측벽 뒤로 가려진다. 이동 중 물체 확대는 없고,
차량은 실제 달구지 폭의 52%를 유지한다. 밤 밝기는 달구지와 같은 0.52이며
사람이 머무는 커피차·임시 검문소에만 조용한 생활 조명을 더한다. 자동 검문소와
철길 건널목은 가짜 검문소 그림을 재사용하지 않는다.

## 검증 및 남은 게이트

- 원본/배포본 관찰: 측면 방향·금속/천 재질·열린 보닛·판매창·투명 알파 확인.
- 실제 `http://127.0.0.1:4318/__live/assets`에서 3개 배포본을 연결 전에 확인.
- `node tests/test_detailed_road_cues.cjs`: 실제 프로필/렌더 코드의 36개 접근
  프레임, 기본/확장 달구지, 비율, 인원, 낮밤, 디코드 실패, JSON 저장 왕복,
  사건 종료 후 잔상 제거 통과. 녹화나 사람의 시각 검수는 아니다.
- 기존 여정 렌더러, 58지역/78노선, 환경3480조합, 정착지10검사, 소스 상태 통과.
- 빌드79,764,318 bytes, 기존80MB 상한 유지. 권장32MB 초과는 기존 관리 과제.
- 사용자 화면을 초기화/이동/새로고침하지 않았다. 변경 전후 `levy_office`,
  DAY1 20:29, 구미→김천14.43km, 360×728 유지. 적용 리비전1790392581418,
  준비된 리비전1790407094911(확인 시점).
- **아직 미완료:** 실제 Studio 앱 미리보기 접근 권한이 없어 주행 중 크기,
  가려짐, 야간 대비, 제동-사건 전환을 직접 보지 못했다. 새 게임이나 임의
  fixture를 사용자 화면으로 대신하지 않았다. 코드 적용 후 해당 조우에서
  360/480px 실제 화면과 다음 행동을 확인해야 최종 승인이다.
